# ExoClim-3

惑星のパラメータ(主星・軌道・自転・大気・海洋・地形)を与えると、
**ITCZ → 風帯 → 海流 → 気流 → 気温 → 降水 → 気候区分** の 7 段階を順に導出し、
ケッペン気候区分図を生成する、ワールドビルディング向けの対話型気候設計ツール。

物理仕様の一次参照は **Worldbuilding Pasta**(ブログ「An Apple Pie from Scratch」)。
作図手順の見本は **Artifexian「Worldbuilder's Log」**(YouTube)。
**この 2 つは別の著者である**(旧世代の文書は前者の名義で後者を誤記していた。
[docs/INTENT.md](docs/INTENT.md) の帰属の訂正を参照)。

段階構成は Pasta の手順を踏襲しつつ、数値の中核(気温・降水)は
**エネルギー収支モデルと水収支モデルによる定量計算**で置き換えている。

> **2026-08-09 の転回**: 降水は当初「供給 × 倍率の積」で作っていたが、
> 外部レビューで**水を +64% 創っている**ことが判明し、
> **可降水量を状態とする保存型水蒸気輸送**へ土台ごと置き換えた。
> 現在の全球水収支の閉包は −0.0%(惑星パラメータを振っても保たれる)。
> 正本: [docs/計画_保存則の段階的置換_2026-08-09.md](docs/計画_保存則の段階的置換_2026-08-09.md)

本プロジェクトは [ExoClim-2](../ExoClim-2/) の全面再構築(第 3 世代)。

## 使い方

```bash
npm install
npm run dev        # 開発サーバ起動
npm run build      # 本番ビルド(静的 SPA、完全オフライン動作)
npm test           # ユニットテスト(Vitest)
npm run validate   # ヘッドレス検証(PNG 出力 + 地球再現度の自動採点)
```

### 現在地を知りたいとき

| 知りたいこと | 見る場所 |
| --- | --- |
| **当日の状況・次にやること** | `docs/引き継ぎ_<最新日付>.md` |
