# 診断: 降水は平されていない。**乾きすぎる場所がある**

日付: 2026-08-13
道具: `scripts/diag_precip_distribution.ts`(新規)

## 仮説は外れた

段 18 で「サハラ 4.74 倍 / east_asia 0.17 倍」を見て、
**分布が中央へ圧縮されている**(乾いた所が湿り、湿った所が乾く)と読んだ。
分布を出したら**逆だった**。

```
陸セル 20814、面積重み平均  モデル 701 / 観測 767 mm/年

分位     モデル    観測    モデル/観測
  5%         1      26       0.05
 10%         2      36       0.05
 25%         7     120       0.06
 50%       237     353       0.67
 75%       561     701       0.80
 90%      1351    1394       0.97
 95%      2062    1863       1.11
 99%      2736    3067       0.89

対数標準偏差   モデル 1.052 / 観測 0.586
```

**モデルの散らばりは観測の 1.8 倍**ある。圧縮ではなく**過剰な広がり**である。

## 何が起きているか

**下位 25% が壊滅的に乾いている。**観測 120mm に対しモデル 7mm。
5% 分位に至っては 26mm 対 **1mm** で、実在しない乾きである。

一方で上位は観測とよく合う(90% で 0.97、95% で 1.11)。
つまり**湿った所は合っていて、乾いた所が乾きすぎている**。

サハラが 4.74 倍という段 18 の結果と矛盾しない。両立する読みはこうなる:

> **乾燥域が正しい場所に無い。** モデルは実在しないほど乾いたセルを
> どこかに作り、本来の砂漠(サハラ)は湿らせている。

## 乾きすぎているのはどこか

ゲートの値から見当がつく。

```
antarctica_ice   降水 観測の 1%
tibet_cold_highland  観測の 6%（2026-08-10 の診断）
east_asia        観測の 17%
```

**南極(陸の 9.5%)とチベット高原**が下位分位の主力である。
どちらも**寒い / 高い**場所で、保存型では飽和比湿 q_s が小さく、
可降水量 W が小さく、凝結量も小さくなる。

実物の南極は年 150mm、チベットは 454mm 降る。
**寒くても降る**のは、実物では総観規模の擾乱が水を運び込むからである。

## 次に疑うこと

保存型の凝結は `P = λ·G·W` で、W は輸送方程式の解である。
寒い場所では W が小さいので P も小さくなる。
だが実物の高緯度・高地の降水は「その場の水蒸気量」ではなく
**運ばれてきた水の収束**で決まる。

**渦拡散(2.06e6 m²/s)は水を運んでいるはずだが、
届いた先で凝結しているかは別の話**である。
凝結率 G が寒い場所で小さくなる項(CRH・沈降・持上げのどれか)が
効きすぎている可能性がある。

段 18 までは「東岸に水が来ない」を追っていたが、
**面積で見れば南極・チベットのほうがずっと大きい**(陸の 9.5% + 高原)。
詳細一致 44.9% の伸びしろもここにある可能性が高い。
