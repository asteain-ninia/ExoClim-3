# 診断: 湿潤温帯の降水不足を、降水の因子まで分解する(R5 の入口)

日付: 2026-08-08
道具: `scripts/diag_temperate_factors.ts`
前提: [実験記録_温帯の乾燥化](実験記録_温帯の乾燥化_2026-08-07.md)、v15 の定数

## 方法

降水は「供給 × 持上げ × 抑制の積」で作られており、診断の受け皿
(`runPipelineWithPrecipDiag`)が各因子を分解して返す(再構成誤差 <1e-4)。

**観測が C 温帯のセルを、モデルの答えで 2 群に分けて比べる。**
地域名(中国東部・ラプラタ)ではなく**症状で群を作る**ので地理中立である。

## 読み取り

### 単一犯ではない — 供給で 2 倍、乗数で 3 倍

```
供給の合計   63.9 対 127.4      比 0.50
乗数の積     0.371 対 1.092     比 0.34
積            0.17              （実際の降水比 0.23）
```

**乗数側のほうが効いている。** その内訳で最大なのは:

| 因子 | 比 | 意味 |
|---|---:|---|
| **沈降の残存** | 0.597 | 亜熱帯沈降の抑制が落ちた群で強く効いている |
| **風上遮蔽** | 0.776 | 風上の山脈が水蒸気の到達を削っている |
| 前線持上げ | 0.854 | 梅雨・バイウ型の前線が立っていない |
| その他の持上げ | 0.832 | ストーム帯・高温湿潤対流 |

2026-08-01 の R1 病因分解が地域単位で出した「中国東部・ラプラタ = 沈降抑制過多」
という結論が、**症状で括った 665 セル全体でも再現した**。

### 収束持上げは両群で厳密に 1.000 — 封印されている

`convergenceLiftBoost = 0` / `convergenceSubsidenceRelief = 0` で、
2026-08-01 の R4 棄却時に**配管だけ残して封印**された状態のまま。
つまりこの機構は現在まったく仕事をしていない。

### 風上遮蔽 0.669 は「冬の内陸風」の跡と見られる

落ちた群では風上遮蔽が 33% 削っている。これは月別倍率の年平均なので、
**夏に海から吹くときではなく、冬に大陸内部(チベット・内陸高地)から
吹くときの遮蔽**が効いていると読める。年平均で見ると本来の季節構造が潰れる。

## R4 の壁をどう越えるか

R4(水蒸気フラックス収束)は 2026-08-01 に棄却されている。理由は
**供給場 q が水蒸気量ではなく「湿潤源への到達可能性」**で、暑い海を長く辿るほど
大きくなるため、乾燥を維持したいアラビアの実効収束(0.269)が
湿らせたい中国東部(0.138)の 2 倍になってしまうこと。
相対飽和度で温度スケールを割り戻しても逆転は解けなかった。

**ただし当時の解析はすべて年平均だった。**

[R3 の診断](実験記録_温帯の乾燥化_2026-08-07.md)が示したのは季節配分の失敗である:

```
しきい値の底上げ項      観測    モデル
  夏型(+28)             108      67     ← 41 セルが夏型から落ちた
  平均型(+14)            62     107
```

中国東部・ラプラタは「年中乾いている」のではなく **夏が足りない**。
一方アラビア・サハラは年間を通じて乾いている。

**季節の差を取れば、セルごとの『到達可能性のスケール』は共通因子として割れる。**
q(i, 夏) / q(i, 年平均) は無次元で、i に固有のバイアスが分子分母で相殺される。
これが R4 の型の不一致に正面から答える形になる**可能性がある**。

→ `scripts/diag_monsoon_index.ts` で、地域ゲートの枠ごとに
「観測の夏率 / モデルの夏率 / 供給の季節比 / 夏の沈降残存」を測り、
**湿らせたい地域と乾燥維持したい地域を判別できるか**を先に確かめる。
判別できなければ R4 と同じ壁なので、機構を書く前に止める。

## 教訓(暫定)

- **年平均で見ると季節構造が潰れる。** 風上遮蔽 0.669 は「夏の海風が山に阻まれて
  いる」ようにも読めるが、実際は冬の内陸風の寄与と考えるほうが自然である。
  月別の量を年平均で比べるときは、何が潰れるかを意識すること。
- **棄却された機構の棄却理由は、再挑戦の設計条件になる。** R4 は
  「アラビアと中国東部を判別できない」で落ちた。だから再挑戦するなら
  **判別できることを先に示す**必要があり、それ抜きに係数を上げても同じ壁に当たる。

## 追記(2026-08-09): 季節比の仮説は**実測で棄却**

上で立てた「季節比 q(夏)/q(年平均) なら判別できるのではないか」を測った
(`scripts/diag_monsoon_index.ts`)。

```

sahara_arid            乾燥維持       29.9%     49.1%   +19.2     1.670      0.425
arabia_arid            乾燥維持       15.7%     45.9%   +30.2     1.200      0.629
australia_interior     乾燥維持       51.6%     45.3%    -6.3     1.751      0.365
india_tropical         湿らせたい      70.2%     72.8%    +2.7     2.358      0.676
east_asia_humid        湿らせたい      43.1%     35.7%    -7.3     1.966      0.466

```

**判別できない。** 東アジア 1.966 に対し豪州内陸 1.751・サハラ 1.670 で分布が重なり、
**シベリア(2.2〜2.4)のほうが高い**。R4 が年平均で失敗したのと同じ形である。

外部レビュー(Codex `gpt-5.6-sol`、2026-08-09)は測定前に同じ結論を予告していた:

> 「セル固有スケールが相殺される」という前提は、季節変化が乗法分離できる
> (q = A_i·f_m)場合だけ成立します。実際の q は月ごとに風向・到達海域・経路長・
> 海面温度が変わり、e_s(T) も非線形なので、比を取っても影響は消えません。

さらに**私が気づいていなかった罠**も指摘された:

> 夏雨を増やして 70% 基準を越えると、乾燥閾値自身が +14 上がります。
> 小さな夏雨補正は、逆に B 判定を難しくする場合があります。

ケッペンの乾燥しきい値は季節性で底上げされる(夏型 +28 / 平均型 +14 / 冬型 +0)。
**夏を少し増やすと平均型から夏型へ移り、しきい値が上がって余計に B になる。**

## 代わりに見えた 2 つの defect(こちらが本命)

### (1) 砂漠は「夏に降らせすぎ」ている

```
アラビア  観測の夏率 15.7% → モデル 45.9%  (+30.2)
サハラ    観測の夏率 29.9% → モデル 49.1%  (+19.2)
```

砂漠の過大降水は**夏に集中している**。一方モンスーン地域は夏が足りない
(チベット −40.7、東アジア −7.3)。**同じ季節で符号が逆**である。

### (2) 沈降の抑制が事実と逆向きに効いている

```
夏の沈降残存   アラビア  0.629 （抑制が弱い）
              東アジア  0.466 （抑制が強い）
              チベット  0.280 （最も強い）
```

**乾かしたいアラビアで抑制が弱く、湿らせたい東アジア・チベットで強い。**
緯度の幾何で窓を決めているため、効き方がアンチ相関になっている。
「粗い」のではなく「逆」である。

## 外部レビューが示した方向

- 緯度だけの沈降窓は構造的な誤り。**ただし「低圧なら緩める」も同じく誤り**
  (乾燥した熱的低気圧がある)。東部中国の雨帯は低圧中心ではなく、
  **大陸低圧と西太平洋高気圧の間の南西風ジェット・梅雨前線上**にある。
- 過去の失敗は「気圧を使ったから」ではなく
  **「セル局所の気圧符号を直接、降水乗数へ変換したから」**。
- 現在の**積構造**(全機構を最後に幾何学的沈降で殺す)では、正しいモンスーン
  持上げを足しても窓が潰す。**レジーム混合**へ変えるべき:
  `P = (1−M−S)·P_亜熱帯 + M·P_モンスーン + S·P_ストーム`
- ストーム供給 1/5 は本命ではない(供給差の 72% は海洋供給、ストームは 24%)。
  加えて**群分けに選択バイアス**がある(モデルの降水で分けたので、
  低降水群でストーム項が低いのは半ば構造的)。
- 海面気圧しかなく鉛直安定度も上層場もない状態で、アラビアの乾燥熱低気圧と
  湿潤モンスーン低圧を完全に識別するのは原理的に困難。
  独立変数を 1 つ足すほうが、ゲート調整より健全。

## 次の測定

**q を一切使わない判別量**を測る(`scripts/diag_wind_reversal.ts`)。
古典的なモンスーン指数(Ramage 1971)は風だけで定義される:
冬と夏で卓越風向が反転し、かつ夏の風上が海であること。
これなら R4 を殺した「到達可能性」型の問題に免疫がある。

## 教訓

- **自分の仮説は、実装する前に判別できることを示す。** 今回は測って死んだので
  実装せずに済んだ。R4 も同じ形で棄却されており、**同じ失敗を 2 度しかけた**。
- **症状で群を作る手法には選択バイアスがある。** モデルの出力で群を分けると、
  出力と相関する因子はすべて「差がある」ように見える。
  比の大小をそのまま原因の順位と読んではいけない。
- **採点の物差しに非線形な閾値があると、部分的な改善が逆効果になりうる。**
  ケッペンの季節性による底上げ(+28/+14/+0)がその例。
  「少し良くする」が通用しない指標があることを設計時に確かめること。
