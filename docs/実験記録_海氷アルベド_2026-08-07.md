## 第 1 版が不成立だった本当の理由 — 3 つの不具合

第 1 版の「不成立」は機構の評価になっていなかった。3 件とも実装の誤りである。

### (1) 陸の季節雪アルベドが丸ごと消えていた

`iceW` を氷厚の有無だけで決めていたが、氷厚は**海セルにしか育たない**
(更新ループが `oceanFrac <= 0` を飛ばす)。0 層模型を有効にすると
北ユーラシア・北米の季節雪が消え、冬と融雪期がまるごと壊れていた。

陸の雪(温度ランプ)と海氷(氷量)を分けて持ち、陸率で混ぜるようにした。
断熱は海の側だけの現象なので海氷の被覆率だけで掛ける。

### (2) GPU 経路に 0 層模型が無かった

第 1 版は CPU 経路にしかなく、**加速器があると黙って無効化されていた**。
較正は GPU で回すので、これが無いと実験そのものが成立しない。
WGSL へ移植し(`updateIce` カーネル・氷厚バッファ)、CPU 版と 1 対 1 に対応させた。

### (3) ユニフォームの CPU 側だけ 144 バイトのままだった

移植の途中で踏んだ。GPU バッファは 192 バイトへ広げたのに CPU 側の
ArrayBuffer が 144 のままで、**はみ出した書き込みが TypedArray の仕様で
例外にならず捨てられ**、海氷の物性値が全部 0 で渡る状態になっていた。
実行するまで気づけない種類の不具合なので、大きさを 1 か所の定数に置いて共有させた。

## 副産物 — 費用 25 倍の正体は残差の測り方だった

最初の測定は 4 件で **7.7 時間**かかり、残差が **26.4°C**(許容差 1e-3 の 4 桁上)
で張り付いた。桁が異常なので実装を疑ったところ、`finish` カーネルが
「残差の縮約」と「月別積算」を兼ねており、その直前に氷更新を挟んでいた。

残差は `|temp − tPrev|` なので、**反復の外で起きる物理(海氷の生成・融解に
よる温度の飛び)がそのまま残差に化ける**。反復回数の適応は**決して下がらない
残差**を追いかけ、毎ステップ上限 8192 まで登っていた。
しかも CPU 経路は反復の中でしか変化量を取らないので、両経路で残差の意味が
食い違ってもいた。

順序を直した(9c4a914):

```
反復 → 残差(収束の測定) → 氷更新 → 積算(最終温度)
```

結果:

```
        修正前              修正後
所要    約 2.5 時間/件      6.0〜10.4 分/件
反復    上限 8192 まで登る  512(梯子を登らない)
年数    梯子を登る          24 年(梯子を登らない)
残差    2.6e+1              4.6e-5
```

**8 時間 → 23 分。**「健全性 ×」も見せかけで、直せば ○ になった。

## 検算 — 1 件成立、1 件は受入ゲートで測り直す

### 帯状平均気温の乖離は受入ゲートで測り直す

実験台に自前で書いた帯状乖離の指標が、`validate.ts` と**帯の切り方が 5° ずれて**
おり、南緯 60° 帯(南極半島)を取りこぼしていた(自前は `lat >= lo && lat < lo+10`、
正本は `Math.round((89 − 行*2)/10)*10` の四捨五入)。式を写して揃えたが、
**受入ゲートの 26.4°C との突合はまだ取れていない**。
採否の判定には `npm run validate` の値を使う。

### CPU/GPU の一致 — 成立

事前登録の副判定。全熱容量 6 年に固定して両経路を回した
(`scripts/check_cpu_gpu_seaice.ts`)。年数を固定するのは、自動で増やすと
両経路で積分量が食い違い「物理の差」と分離できなくなるため。

```
年平均気温の差(GPU − CPU): 面積重み平均 0.0258°C / 最大 0.558°C(83°N, 99°E)
所要: GPU 1.5 分 / CPU 26.5 分
```

**副判定(0.5°C 以下)は成立。** 最大値が出たのは北極海の 1 セルで、
氷の有無という閾値的な処理が f32 と f64 の丸めの差を拡大する場所である。
面積重み平均が 0.026°C に収まっているので、式の食い違いではない。

## 判断

較正へ進める(飽和 300mm)。理由:

- 主判定(両極が同時に改善)を満たす。
- 副判定の北極 7 月・健全性を満たす。
- 費用が基準とほぼ同じ(6.0 分 対 6.4 分)。
- 全球成績の低下が小さい(v3 −0.12、大分類 −0.10、詳細 −0.12)。
- 直したのは**物理の双安定**であって地球に合わせ込んだ補正ではない。

**最終採否は較正後に 5 点で総合判断する。**

## 教訓

- **失敗した実験の「不成立」を、機構の不成立だと決めつけない。** 第 1 版の
  3 つの不具合はどれも「実行はできるが物理が違う」種類で、結果だけ見ていたら
  機構ごと棄却していた。**片方の経路にしか入っていない機構**、
  **片側にしか掛からない項**、**大きさの合っていないバッファ**は、
  症状ではなく構造として探すこと。
- **残差のような「収束の指標」に、反復の外の物理を混ぜてはいけない。**
  適応制御が指標を追いかけるので、混ぜると費用が爆発する。
  しかも「遅い」としか見えないので原因に辿り着きにくい。
- **長時間の実験は逐次出力が要る。** 最後にまとめて出す造りにしたせいで、
  8 時間走らせて「遅いのか壊れているのか」すら分からなかった。
- **既にある判定と同じ数字を出したいなら、同じ式を写す。** 自前で書き直すと
  帯が 5° ずれるような差が入り、別物を測っていることに気づけない。
