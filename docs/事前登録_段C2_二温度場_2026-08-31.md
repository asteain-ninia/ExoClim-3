# 事前登録: 段 C-2 — 完全 2 温度場(T_a / T_s)。5 大課題の合流点

日付: 2026-08-31 朝(実装前に書いた)
前段: 探査終端(受け皿 6 本+段 C-1 の消去法)。単一温度場では
「雪→遮断→冷却」の正フィードバックの入口が原理的に存在しない、が実証。

## 設計(docs/設計_海気の温度分離 + 監査訂正の実装形)

セルごとに 2 状態:

```
C_s/dt·ΔT_s = SW吸収 − (A + B·T_s) − k_x·(T_s − T_a) [+ 海氷・蒸発帰還(現行どおり T_s 側)]
C_a/dt·ΔT_a = k_x·(T_s − T_a) + 輸送(T_a)          [輸送 = 保存的移流 + 拡散(段 C-0 の形)]
```

- C_s = 現行 heatCap(陸小・海混合層 — 海氷断熱も現行どおり C_s 側)。
- C_a = 大気柱の熱容量(c_p·p/g ≈ 1.0e7 J/m²/K、**物理定数 — 掃引しない**)。
- k_x = airSurfaceExchangeWm2PerK(SPACE 候補 [5, 60])。
  **k_x → 大 で単一場に漸近**(2 式の和が現行式)。
- 段 C-1 の snowGrip は輸送側でなく **k_x の変調**として生き返る:
  k_x_eff = k_x × (1 − (1−snowGrip)·snowW(T_s)) — 雪面で交換が切れ、
  T_s は自分の放射収支で冷えられる(入口の実装)。
- ケッペン・蒸発・降水など下流はすべて **T_s** を読む(現行 T の後継)。
  T_a は輸送の内部状態(v7 の風採点等は不変)。
- 数値: 各セル 2×2 を陰的に消去してから空間 GS(輸送は T_a のみ) —
  現行ソルバの拡張。**twoTemperatureMode = 0(既定)で旧経路を 1 文字も
  変えず並走**(conservativeMoisture の前例)。

     (全球平均差 < 0.5°C — 漸近性の検証)。
158. **本丸**: mode=1・k_x=15・snowGrip=0.3 で、極東シベリアの 1 月が
     **−15°C を下回る**(現行 −2.5。実物 −30 級への入口)。
     夏(7 月 7.0°C)は雪が無いので大きく動かない → 振幅が立つ。
