## v43 からの変更(2 点、いずれも結果依存でない根拠)

1. **thermalWindFactor を SPACE へ [0, 1.5]**(80 定数)。
   根拠: 熱風リンクの再訪条件「W が本物になった後」が部分的に成立
   (W-RMSE 22.9→19.6)し、v43 の最大欠損が 35-90 冬雨(移入の暦 =
   この機構の照準)である。9/1 の掃引では風の比 0.72→1.02 まで直った
   (72 ○)が W が薄くて雨が動かなかった(73 ✗)。
2. **moistureDecay の範囲を Ḡ で換算**: 海 [1500,3200]→[714,1523]・
   陸 [1100,2400]→[524,1143]。根拠: 段 W-1 の正規化で rate = U_ref/L·G_n
   となり、旧範囲は未正規化 G 向け。同じ物理の排水率範囲は /Ḡ。v43 は
   この訂正漏れのまま走り、両 L が旧下限(1500/1100)に張り付いた。

種 = v43 最良(80 定数。thermalWindFactor は 0 から)。物差し不変(v7b + ゲート v3)。

## 判定

- **採用: v7b ≥ 73.505** かつ 108・109。
- 72.5 ≤ f < 73.505 → 不採用。レジーム維持の是非を「v42 との地図の差」
  (大小分類・帯別)で作戦盤に並べ、利用者の裁定材料とする(既定案 =
  レジーム維持で第 3 ラウンド、ただし裁定を待たずには起動しない=
  次の機構検証に回る)。
- f < 72.5(105 ✗)→ レジームの回復力の天井を記録。v42 既定へ復帰し、
  レジームは「地中海・東岸・詳細の資産」を持つ実験系統として保存。
- 106 ✗(熱風が効かない)→ 移入の暦の残る因子(海洋 W の暦)を W-3
  (発散監査)と合わせて分解。
