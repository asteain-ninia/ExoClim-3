## 効果の中身

**パタゴニアの区分が ET(ツンドラ)から Cfb(西岸海洋性)へ反転した。**
観測は Cfb なので、これは正しい向きである。最暖月が 3°C 上がったことで
「最暖月 < 10°C」の ET 条件から外れた。

ゲート自体はまだ落ちている(降水 159%)が、**落ちている理由が
気温から降水へ変わった**。これは前進である — 気温は直り、
残るのは降水だけになった。

**全球の気温 RMSE が 3.943 → 3.560 と 0.38°C 改善したのは、
単一の変更としてこれまでで最大**である。南緯 40〜55° の帯が
まるごと冷えすぎていたことになる。

## 何が悪かったのか

周極海峡という概念(南極周極流 = 遮られない緯度行では南北の熱交換が
抑えられる)は正しく、地理中立にも書けている。**壊れていたのは二値判定**だった。

```
−41.5°S  陸 4.17%  → 非海峡
−43.5°S  陸 3.33%  → 海峡
```

閾値 4% のすぐ両側で不連続に切り替わり、**南米南部が乗る行(1.7〜3.3%)が
まるごと「遮られていない」扱い**になっていた。海峡行は
南北拡散 0.48 倍・雲 +54%・海洋混合層 3 倍 を同時に受け、**3 つとも冷やす**。
雲と混合層は夏の昇温を抑えるので、最暖月だけ大きく外れていた。

連続にすると陸 3.3% の行では効果が 0.175 倍になり、南極海(陸 0%)は
現行のまま残る。**新しい定数は要らなかった** — 階段を線形にしただけである。

## 教訓として残すこと

**閾値による二値判定は、閾値の近くにある実物を丸ごと取り違える。**
この判定は「南極周極流を表現する」ために作られ、地球の南極海では正しく働く。
だが同じ閾値が、**細い大陸が横切る行**にも同じ判定を下していた。

地理中立に書かれた規則でも、**二値である限り境目の実物を巻き込む**。
連続にできる量は連続にすること。
