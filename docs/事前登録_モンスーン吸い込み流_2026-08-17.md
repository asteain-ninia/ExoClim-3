## 実装

`step04_airflow.ts` の帯状風合成に、**規定風の第 4 成分**を足す:

```
対象: ITCZ が夏半球へ変位した経度セクター(熱帯陸割合ゲート、段 42 の再利用)
      の、ITCZ の極側 〜 リッジ +halfWidth
向き: 極向き(夏半球で赤道から陸へ)。海セルも陸セルも同じ(fetch)
強さ: bv += sign(lat) × K.monsoonInflowMs × disp × ramp × fade × gate
  disp = ITCZ 変位 / crossEquatorialRefDeg(既存。夏の強さ)
  ramp = clamp((|lat| − |itczLat|) / halfWidthDeg, 0, 1)   ← ITCZ の雨帯を守る
  fade = clamp(1 − (|lat| − |ridge|) / halfWidthDeg, 0, 1)  ← リッジの先で減衰
  gate = min(1, colLandFrac / monsoonLandFracRef)           ← 段 42 の再利用
```

- 新しい定数は `monsoonInflowMs`(m/s)1 つ。**既定 0 = 従来とビット一致**。
- ランプ幅は `itcz.halfWidthDeg`(既存)を使い回す。新しい隠し量を作らない。
- ITCZ 変位と陸割合という幾何だけで書く。地理中立、逆行でも成立。

### 大きさの目安(測定から)

C→B の必要正味輸入は年 +80〜120mm。W ≈ 3mm・行程 ~500km として
**沿岸の through-flow で 2〜3 m/s** が射程。実物の夏モンスーンの下層南風
(5〜10 m/s)より控えめな範囲で掃引する。

## 予測(結果を見る前に固定)

`sweep_lever.ts monsoonInflowMs 0,1,2,4 --parallel 4` →
最良水準で `diag_ctb_budget`。

1. **C→B の夏の移流流入が −25.8 → −10 以上へ**(できれば正)。
   加算 through-flow なら場の汲み直しでは消えないはず。**ここが家系の審判。**
2. **99% 分位 ≥ 2990**(ITCZ 保護が効いた証拠。段 41/42 は 2924〜2954 まで潰した)。
   1% 分位 ≤ 70。
3. インド ≥ 0.50 / 米南東 ≥ 0.40 / 欧州 ≥ 0.90 / コンゴ 1.2〜1.35。
4. **連続部分 > 70.35 かつ分布誤差 ≤ 0.410**。
5. 数値的健全性(全水準)。

## 判定

- **1・2・4 がすべて当たったら**: 採用候補として利用者に裁定を仰ぐ
  (探索空間 57+1 で v25 を回す提案)。
- **1 が外れたら**: 加算でも場が汲み直す = 定常輸送では規定風の追加でも
  輸入を作れない、という強い結論になる。その場合この路線を打ち切り、
  **輸送方程式の側**(モンスーンセクターでの実効拡散の異方性 =
  海→陸方向だけ拡散を強める等)へ移る。
- **2 が外れたら**: ランプ幅が狭すぎる。halfWidth の使い方を見直す。
- **4 だけ外れたら**: 何を壊したか分解。説明できない変化は採用しない。

**目的関数の重みは動かさない。既定値も 0 のまま。**
