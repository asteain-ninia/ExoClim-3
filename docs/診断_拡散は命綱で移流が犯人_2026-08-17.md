# 診断: C→B セルでは**拡散が命綱で、移流が犯人**だった

日付: 2026-08-17
道具: `scripts/diag_diffusion_by_latitude.ts` / `scripts/diag_ctb_budget.ts`(いずれも新規)
出力: `out/diag_diffusion_by_latitude.txt` / `out/diag_ctb_budget.txt`
前段: [調査_他のモデルは同じ壁に当たっているか](調査_他のモデルは同じ壁に当たっているか_2026-08-17.md)

## 測る前の見立ては外れた

文献(「拡散が妥当なのは中緯度、熱帯・亜熱帯では過大」)から、
**「亜熱帯の陸への水輸入は拡散が主導しているはず」**と見立てて緯度帯で測った。

```
【年 / 陸】        移流流入  拡散流入    源E   降水P
熱帯    0〜15°       +60.4     −7.8     111    162
亜熱帯 15〜35°       +28.6    −23.7      35     36
中緯度 35〜60°       +12.6     −5.9      41     48
```

**外れ。** 亜熱帯の陸で拡散は輸入どころか**排出**(−23.7mm/年)だった。
どの帯でも移流が輸入し、拡散が捨てている。

だがこれは掃引の実測(D を下げるとインド・米南東が**乾く**)と符号が合わない。
帯平均が「縁(排出側)」と「内陸(受取側)」を混ぜているためと考え、
**直したいセルそのもの(C→B 誤分類)**で測り直した。

## 本丸のセルで測ると、体制が正反対だった

```
             移流流入   拡散流入    源E   降水P   正味輸入
── 年 ──
C→B(誤判定)    −9.1      +7.6      26     26     −1.4
C→C(対照)     +60.2     −41.3      61     77     +19.0
── 夏半年 ──
C→B(誤判定)   −25.8     +25.0      69     63     −0.8
C→C(対照)    +207.9    −149.0     139    183    +58.8
```

**同じ「観測 C」の土地なのに、水の来かたがまったく違う。**

- **当たっている C**: 移流(風)が水を届け(+208)、拡散が余剰を捨てる(−149)。
  健康な体制。実物の温帯と同じ形である。
- **C→B(誤判定)**: **移流が水を奪っていく**(−26)。夏の貿易風が赤道向きに
  吹いて、そのセルの水蒸気を持ち去る。**唯一の輸入が拡散**(+25)で、
  それでようやく収支ゼロ。降水は自前の蒸発散の再循環だけ(P 63 ≈ E 69)。

## これで 3 日分の矛盾が全部解ける

| 観察 | 説明 |
| --- | --- |
| D を下げるとインド・米南東が乾く(掃引) | C→B 型のセルは**拡散が命綱**だから。命綱を切れば死ぬ |
| D を下げると分布の両端が観測へ近づく(掃引) | 拡散は乾いた極(輸入)からも湿った極(排出)からも**均している**から |
| 帯平均では亜熱帯の拡散が「排出」 | 帯平均は当たっている C(排出側)が支配するから |
| 段 41(子午面反転)で C→B 地域が改善 | **移流の符号を輸出→輸入へ反転させた**から。原因に直接触った唯一の手 |
| 段 41 で分布が潰れた | 反転を**海にも一様に掛けた**ため、海上でも均し始めたから |

## 結論 — 打つ手の順序が確定した

> **C→B の犯人は移流(夏の貿易風が水を持ち去る)であり、拡散は応急手当である。**
> 拡散の変調(文献の推奨)は分布の両端には効くが、**先に C→B の移流を
> 輸出から輸入へ反転させないと、拡散を絞った瞬間に C→B が死ぬ。**

手順:

1. **段 42: 段 41 の子午面反転に「経度の選択性」を付ける。**
   段 41 の欠陥は海にも掛かることだった。経度列の熱帯陸割合
   (`troughLandFrac` — step02 が既に計算している地理中立な量)でゲートし、
   **陸の多い経度でだけ**反転させる。
2. それで C→B の移流が正に転じたら、**次に拡散の変調**(緯度・季節)で
   分布の両端を直す。この順でないと 1 の前に 2 をやると C→B が死ぬ。

### 定量目標(測定から決めた — 当てずっぽうの終わり)

- C→B の夏の移流流入: **−25.8 → 正**(まず符号)。
- C→B の降水は再循環が支配(P ≈ E)なので、正味輸入 ΔI に対して
  降水は再循環倍率つきで応答する。分類の閾値まで年 +252mm 必要、
  E の応答を考えると**正味輸入で年 +80〜120mm** が目標。
  夏の移流を +50mm/年 級まで持ち上げれば射程に入る。

## 教訓

- **帯平均は体制の違いを消す。** 同じ帯・同じ「観測 C」でも、
  移流に養われるセルと奪われるセルが混在していた。処方を決める集計は
  **直したい集合そのもの**で取る。
- **「拡散が犯人」と「拡散が命綱」は同時に成り立つ**(場所が違う)。
  一様な係数を動かす手が 3 回失敗したのは、この両面性のせいである。
