# 事前登録: 凝結閉包の二成分化(監査 #3、台帳 22 — W が水を持てるように)

日付: 2026-08-26 朝(実装前に書いた)
出所: 外部監査 #3。v8 酸性試験の敗因分析(どの機構でも W が 4〜6% しか
動かない = 固定 λ の即時降雨が W の応答を殺す)で物理側の前提と確定。

## 機構(実在の物理)

実在大気の凝結は一つの時定数ではない: (a) 背景の層状凝結(ゆっくり、
W に比例)、(b) 湿潤対流(柱相対湿度が臨界を超えたときだけ急速に調整)、
(c) 地形・前線の強制上昇。現行の C = (U_ref/L)·G·W は全部を 1 本の
比例則に畳み、**持ち上げの強さがそのまま水の寿命**になる。そのため
全球 W 3.7〜4.1mm(実物 25mm)・滞留 1.1 日(実物 ~9 日)。

## 設計

凝結を線形項と閾値項の**和**にする(ソルバは両方の下地を持つが排他だった):

```
C = linRate·W + convRate·max(0, W − cap)
linRate  = (1−c)·rate_old + c·(30.44/τ_bg)          // c=0 で旧式と厳密一致
convRate = c·(30.44/τ_conv)
cap      = RHcrit · W_sat(T) / max(0.05, G)          // 持ち上げは閾値を下げる
```

- `c = condensationClosureBlend`(**既定 0 = 旧式とビット一致**)。
- G(ITCZ 傘・前線・地形・沈降の積)は「寿命の係数」から「対流閾値の
  変調」へ役割が移る(c=1 のとき)。沈降 G↓ → cap↑ → 対流不発、
  背景凝結だけが残る = 乾くが水は下流へ**輸出**される。
- W_sat = saturatedColumnMm(T)(既存関数)。

新定数(命名・既定):

| 定数 | 既定 | 意味 |
| --- | --- | --- |
| condensationClosureBlend | **0** | 閉包の混合率(0 = 旧式) |
| backgroundCondensationTimeDays | 15 | 背景凝結の時定数(実物の滞留 ~9 日は対流込みなので背景はそれより長い) |
| criticalColumnRelativeHumidity | 0.7 | 対流発火の臨界柱湿度 |
| convectiveAdjustmentDays | 1 | 対流調整の時定数 |

## 予測(監査 (d) を引き継ぎ、測る前に固定)

106. 生存性: c=0 でビット一致。c=0.5 で変化。
107. c=1(既定パラメータ)で全球平均 W が **10mm 以上**へ(現行 4.1)。
     滞留時間が 7〜10 日側へ動く。
108. 分布: 分位誤差(平均対数)が改善する。東岸・内陸への到達が延びる
     (congo/east の年降水比が上がる方向)。
109. 位相は c 単独ではほぼ動かない(動けば蒸発との結合)。
110. 数値: 輸送の未収束 0 件を維持(閾値の活性集合の切り替えが収まる —
     台帳 18 の懸念の実地検証)。
111. **v8 酸性試験の再走**: c=1 の物理の上では τ=3 が τ=0 に**勝つ**
     (v8 有効化の関門。冬の蒸発が W に留まり内陸へ運ばれるため)。

## 判定

- 106 ✗ → バグ。110 ✗ → 活性集合の振動。外側反復に減衰を入れて 1 回だけ
  再試験、それでも ✗ なら撤退(既定 0 残置)。
- 107・108 ○ → c と 3 定数を SPACE へ。111 ○ なら **v8 を有効化して v36**
  (種 = v35、71 定数)。
- 107 ✗(W が上がらない)→ λ 以外に W を殺す経路がある(virga・鉛直輸出・
  蒸発下限)。P=λGW をもう一段分解してから出直す。

読み: **W の動的範囲は設計どおり回復した**(v8 の係留が初めて機構に応答)。
しかし既定の形状定数(RHcrit 0.7・τ_bg 15 日)では背景凝結が構造を均し、
対流が湿潤端で暴れる。「c を上げるほど W は正しく、地図は悪い」——
形状の共調整で両立点があるかが焦点。SPACE 入りは保留し、下の追加登録で
形状を先に掃引する(結果を見て判定を緩めるのではなく、新しい予測で次を測る)。

## 追加登録: 形状定数の掃引(c=0.5 固定、測る前に固定)

112. criticalColumnRelativeHumidity 0.5 / 0.7 / 0.9(c=0.5): RHcrit を上げる
     ほど対流が絞られ 99% 分位が下がる(湿潤端の暴れの主犯は対流項)。
113. backgroundCondensationTimeDays 8 / 15 / 30(c=0.5): τ_bg を**短く**する
     ほど旧式(即時降雨)に近づき分布誤差は基準へ戻る。長くすると W は
     増えるが均しが進む(分布誤差悪化)。
114. どこかの組で「分布誤差 ≤ 0.46(基準+0.02)かつ全球 W ≥ 6mm」が
     成立すれば SPACE 入り(c・RHcrit・τ_bg・τ_conv の 4 定数)。
     成立しなければ、均しの主犯は背景項の**空間一様性** — G を背景項にも
     弱く掛ける(lin = c·bg·G^p)再設計を起票してから出直す。
