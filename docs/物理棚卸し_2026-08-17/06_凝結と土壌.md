## 1. 凝結率 G の全因子(保存型の中核)

### 1.0 G は何か

保存型では

```
∇·(uW) − ∇·(D∇W) = S − C ,  C = rate·W ,  rate = max(0.05, λ·G)
λ = U_ref/L  [1/月]
```

**G は「その場でどれだけ水蒸気が雨になりやすいか」の無次元係数**であって、
降水量そのものではない。降水量は輸送方程式の解が決める。
G は `convertToPrecip`(行 2087〜2584)の中で乗数の積として作られ、
`condRateOut` で外へ返る(行 2561)。**関数の戻り値 `out`(mm/月)は
保存型では捨てられる**(行 1150 で戻り値を受けていない)。

λ の実値: `condensationRefWindMs = 10.95 m/s` × `SECONDS_PER_MONTH = 30.44 日`
= **28,807 km/月**。これを `moistureDecayLandKm = 1837` / `OceanKm = 1627` で割ると
**λ = 15.7(陸)/ 17.7(海)、単位 1/月**。凝結の時定数は **1.7〜1.9 日**。

## 3. 土壌水分バケツ

`solveSoilWater`(行 568〜689)、`potentialEtMmPerMonth`(行 519〜524)。

```
available = 前月貯水 + 当月降水
wet       = clamp(available / 容量, 0, 1)
ET        = min(available, PET(T) × wet)
runoff    = max(0, available − ET − 容量)
S         = clamp(available − ET, 0, 容量)
```

| 定数 | 値 | SPACE | 備考 |
| --- | --- | --- | --- |
| `soilWaterCapacityMm` | 600 | **外** | 深根系の植物利用可能水量 |
| `soilPetScaleMmPerMonth` | 90 | **外** | 20°C の可能蒸発散。**陸面供給の規格化にも使われる二役**(行 1639) |
| `soilSpinupYears` | 2000 | 外(数値) | 地球 1° は 191 年で抜けるので律速しない |
| `SOIL_SPINUP_TOLERANCE_MM` | 0.05 | 外(数値) | 陸セル平均の年間ドリフト |

**既知の縮退**: `available ≥ 容量` の月は ET が貯水に依らず写像の傾きが 1 になり
(陸セル月の 33.5%)、**陸の 11.15% で周期定常解が連続族をなす**。
貯水の絶対値は読んではならない。ET と流出は初期値に依らない(面積平均で 0.00%)。

**0°C で PET が断崖的に 0 になる**(行 520)。連続化されていない唯一の主要な不連続。

## 5. 後処理

`applyPostAdjust`(行 1449〜1526)。**どちらも陸のみ・セル年総量を保存する。**

### 5.1 冬季の弱前線の床(行 1450–1508)

最乾月が 0mm に張り付く癖への対策。最多雨月の一定割合を床にし、
湿潤月から比例控除して埋める。

| 量 | 値 | SPACE |
| --- | --- | --- |
| `winterFloorFracOfWettest` | 0.485 | [0.2,0.5](**上端近い**) |
| `winterFloorMaxMm` | 31.36 | [12,34](**上端近い**) |
| 適用月 | 正規化赤緯 < **0.5** | 裸 |
| 適用帯 | \|リッジ\|+**1** 〜 \|極前線\|+**12** | 裸 |
| 移転上限 | 湿潤月の余剰の **35%** | 裸 |
| 足切り | 床 < **0.5mm** なら何もしない | 裸 |

**`min(31.36, 0.485×最多雨月)` は最多雨月が 64.6mm を超えると上限側が律速する** —
つまり湿潤なセルでは frac が効かず、**乾いた所でしか frac は意味を持たない**。
2 定数が同じ SPACE に入っているのに、実効的にはほぼ排他である。

### 5.2 降水の月平滑(行 1509–1525)

`precipMonthBlend = 0.2` [0.04,0.2](**上端張り付き**)。
翼 0.2 = 重み **0.6/0.2/0.2** の循環 3 点。かなり強い平滑で、
「降水の分布の両端が潰れている」(1% 分位 7.11 倍)の一因になりうる位置にいる。

## 付録: この棚卸しで使った突き合わせ手順

1. `convertToPrecip` を先頭から末尾まで読み、`Math.min` / `Math.max` / 三項の
   閾値をすべて抜く(41 か所)。
2. 各ゲートの被ゲート量が「尺度を持つ量」か「0〜1 の無次元量」かを分ける。
   **尺度を持つ量を割るゲートだけが形骸化しうる。**
3. その norm が `constants.ts` にあるか、`SPACE` にあるか、
   `docs/spec/06_降水.md` にあるかを 3 点照合する。
   **3 つのどれにも無い数は「裸」。**
4. 親(倍率本体)が 0 の因子を探し、その正規化定数を連鎖死として拾う。
