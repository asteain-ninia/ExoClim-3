## 1. 物理現象の全数列挙

### 1-A. 海盆トポロジーの検出

**(a) 素人向け**
その緯度の線をぐるりと一周して、「いま居る海の点から西へ何歩で陸に当たるか」
「東へ何歩で当たるか」を数える。これで、その点が海盆(大きな海)の西の端寄りか
東の端寄りか、その海盆がどれくらい広いかが分かる。陸に一度も当たらない緯度
(南極海のような一周つながった海)は「海盆ではない」として扱いを別にする。

**(b) 実装式**(`step03_ocean.ts:86-102`)

```
westCells = min{ d ≥ 1 : land(row, col−d) }      （最大 1 周)
eastCells = min{ d ≥ 1 : land(row, col+d) }
basinCells    = westCells + eastCells − 1
basinWidthDeg = basinCells × resolutionDeg
basinPos      = westCells / (basinCells + 1)          # 0 = 西端、1 = 東端
nearWestBoundaryKm = prograde ? westKm : eastKm       # 逆行で東西役割が入れ替わる
pos                = prograde ? basinPos : 1 − basinPos
```
どちらか片方でも陸に当たらなければ `continue`(周極海は中立、`:92`)。

**(c) 定数**

| 名前 | 値 | 単位 | SPACE | ゲート |
| --- | ---: | --- | --- | --- |
| (裸)`W*4` のラップ余裕 | 4 | — | — | — |
| `resolutionDeg` | 利用者 | ° | — | — |

> 走査は行単位で `O(W)`、全体 `O(H·W²)` 最悪。実測では上限 1 周で抜けるので問題化していない。

### 1-C. 亜熱帯の境界流(黒潮・湾流 / カリフォルニア・カナリア海流の対応物)

**(a) 素人向け**
大きな海の**西の縁**(大陸から見ると東岸沖)には、赤道の熱を極へ運ぶ細くて速い

### 1-D. 中高緯度の暖流吹送域と寒流帰還(北大西洋海流 / 親潮・ラブラドルの対応物)

**(a) 素人向け**
分離した暖流は偏西風に乗って海を斜めに横切り、海の東側の高緯度を暖める
(ヨーロッパが同緯度のカナダより暖かい理由)。逆に海の西の端(30% より西)には
極から冷たい水が降りてくる。狭すぎる海ではこの循環は育たず、逆に一周つながって
しまうような「海盆」(南極海)では周極流が環流を切ってしまうので成立しない。

**(b) 実装式**(`step03_ocean.ts:120-132`)

```

                × clamp((300 − basinWidthDeg)/120, 0, 1)      # ほぼ一周する海は 0
```

### 1-I. EBM への Q フラックス結合

**(a) 素人向け**
海流が運んでいる熱を、気温を解く方程式に「その場所に余分に入る熱(W/m²)」として
足す。ただし地球全体で熱が湧いたり消えたりしないよう、全球平均がゼロになるように
海の上だけで差し引く(陸に寒冷税をかけないため)。

**(b) 実装式**(`step05_temperature.ts:436` と `:438-456`)

```
qFlux[i] = sstAnomalyCouplingWm2PerK × sstAnomalyC_coarse[i] × (1 − landFrac[i])
meanOcean = Σ w·qFlux / Σ w·(1−landFrac)
qFlux[i] ← qFlux[i] − meanOcean × (1 − landFrac[i])
```
`sstAnomalyC_coarse` は EBM 粗格子への海セル単純平均(`:1505-1511`)。
**月に依らない**(年一定)。

**(c) 定数**

| 名前 | 値 | 単位 | SPACE | ゲート |
| --- | ---: | --- | --- | --- |
| `sstAnomalyCouplingWm2PerK` | 22.0128 | W/m² per °C | **[12, 26]**(`optimize_lib.ts:111`) | 無し |

> **spec は 18 W/m²/K と書いている**(`docs/spec/01-04_循環.md:53`)。実装は 22.0128。→ 疑い 12。

### 1-L. 海面蒸発のバルク式(保存型の唯一の一次源泉)

**(a) 素人向け**
海から空気へ水が移る速さは、(1) 海面がどれだけ暖かいか(暖かいほど水は蒸発しやすい)、
(2) 風がどれだけ強いか(風が湿った空気を運び去るほど次が蒸発できる)、
(3) すぐ上の空気がどれだけ乾いているか、の 3 つの掛け算で決まる。
このモデルでは (3) を「常に 80% の湿り気」と決め打ちしている。

**(b) 実装式**(`evaporation.ts:92-139`)

```
p        = surfacePressureBar × 1013.25                              # :98
ρ_ref    = 1.225 × surfacePressureBar × 288.15/288.15                # :100 （288.15 は約分され無意味)
海セルのみ、T ≤ seaFreezeC は 0                                       # :117-119
|V|      = hypot(monthlyWindU[m][i], monthlyWindV[m][i])              # :120
V_eff    = max(evapMinWindMs, |V|)                                    # :122
ρ        = ρ_ref × 288.15/(T+273.15)                                  # :123
q_s(T,p) = ε·e_s(T) / max(1e−3, p − (1−ε)·e_s(T))     ε = 0.622       # :46-50
E        = ρ · C_E · V_eff · q_s · (1 − RH)      [kg/m²/s]            # :125
E_mm     = max(0, E × 30.44×86400)               [mm/月]              # :127
```
付随して**飽和可降水量**(`:72-77`):
`W_sat = q_s(T_s)·(p/g)/(α+1)`、`α = HUMIDITY_PROFILE_EXPONENT = 2.5`
(コメントに「**較正定数ではない。探索空間へ入れてはならない**」と明記)。

**入力の出所**:
- 温度 `T` = EBM の解(混合層温度)。Q フラックス経由で SST 偏差が入っている。
- 風 `|V|` = **Step 4 の合成風**(`airflow.monthlyWindU/V`)。
  内訳(`step04_airflow.ts`)は 帯状卓越風(`tradeWindMs` / `westerlyWindMs` /

  標高 1500m 超で減衰、**総風速上限 13 m/s**。

- 湿度 `RH` = **場ではなく定数 0.8**。輸送が解いている可降水量 `W` は見ていない。

**消費先**: `step06_precipitation.ts:1201-1207`
`src[i] = 陸 ? actualEtMm : monthlyOceanEvapMm` として保存型輸送の源泉に入る。

### 疑い 4 【A】SST 偏差の °C は物性ではなく「形 × 較正振幅」で、しかも単位が全体で一貫していない

**分類**: 較正つまみの偽装 / 尺度ずれ

**問われた点への回答**:

1. 5 つの °C 定数(`warmBoundaryCurrentC` 3.0 / `coldBoundaryCurrentC` −2.2 /
   `warmDriftC` 3.2 / `coldReturnC` −1.5 / `equatorialUpwellingC` −1.2)は
   **探索空間に入っていない**。コメントにも「物性である」という主張は無い。
   出所は spec の記述のみで、観測との突き合わせ記録は見当たらない
   (SST は採点対象ではない — `実験記録_源泉の検証_2026-08-09.md:15` が明言)。
2. しかし EBM への入り口 `sstAnomalyCouplingWm2PerK` は**探索空間にある**
   ([12, 26]、現在 22.0128)。EBM が見るのは
   `coupling × anomaly` の**積だけ**なので、°C の絶対値と結合係数は
   **完全に縮退している**。すなわち **EBM に関する限り、SST 偏差の振幅は
   較正が決めている**。°C 定数は「空間パターン」を担当しているにすぎない。
3. ところが °C は**他の 4 経路では絶対値の閾値として読まれる**:
   - 層積雲: `min(1.5, −sstA/2)` — 分母 2 が裸
   - 寒流沿岸: `cold < −0.8` で発火、`min(1, −cold/2.5)`
   - 東の海: `(sstA + 0.6)/1.2`
   - 湧昇 `< −0.8` / サンゴ `> −0.5` / `currentClass` `±0.5`

   **結合係数を較正が動かしても、これらの閾値は動かない。**
   つまり `sstAnomalyCouplingWm2PerK` を上げることは「海流の熱輸送を強める」
   ことではなく「**EBM だけを強め、雲と降水の応答は据え置く**」という
   物理的に意味を持たない操作になっている。

**結論**: SST 偏差の °C は **物性でも較正つまみでもない中途半端な量**である。
どちらかに寄せるべきで、寄せ方は 2 つ:
(i) °C を物性として観測(WOA の SST 偏差)に照らして固定し、
   結合係数を物理値(混合層深さと熱容量から)で決めて探索空間から外す。
(ii) 5 つの °C を探索空間に入れ、結合係数を 1 つの物理値に固定する
   (縮退を潰す)。**いまは縮退したまま片方だけ振っている。**

### 疑い 5 【A】蒸発が「相対湿度 = 定数 0.8」で、保存型が解いている可降水量 W を見ていない

**分類**: 死んだ帰還 / 現行の症状との整合

バルク式の第 3 因子は本来
`(q_s(T_s) − q_a)` で、`q_a` は**その場の空気の湿り**である。
実装は `q_a = 0.8·q_s(T_s)` と置いているので、

- 乾いた空気が海上へ吹き出しても蒸発は増えない
- 湿った空気が停滞しても蒸発は減らない

**源泉が状態を見ない = 保存型の負帰還が 1 本も無い**。
これは現在の最大の症状「降水分布の両端が潰れている」
(1% 分位 7.11 倍・99% 分位 0.89 倍)と方向が一致する。乾燥端は
「乾いた空気が海上で余分に蒸発を汲み上げてしまう」ことでは作れないが、
逆に**湿潤端は「湿った海上で蒸発が止まらない」ことで平坦化される**。

**しかも道具は既にある**: `evaporation.ts:72-77` の `saturatedColumnMm(W_sat)` は
まさに `RH = W/W_sat` を作るために書かれており、`step06_precipitation.ts` の
CRH 機構(`CRH_INNER`)がその式を使っている。にもかかわらず

- `crhSuppressionSharpness = 0`(`constants.ts:586`)→ CRH 抑制は**完全に無効**
- `CRH_INNER.enabled = false`(`step06:764`)
- 蒸発側は `W` を引数にすら取っていない

つまり **モデル内に湿度の場は存在するのに、蒸発も凝結もそれを見ていない。**

また `evaporation.ts:26-27` のコメントは
「近地表の相対湿度を定数で置くのは粗いが、海上では実測でも 0.75〜0.85 に収まる」
と書くが、それは**全球平均としての話**であり、亜熱帯高圧帯の吹き出し(RH 0.7 以下)と
熱帯収束帯(RH 0.85 以上)の**差**を消してしまうことの弁明にはなっていない。

### 疑い 6 【B】蒸発の風速が「月平均合成風の大きさ」で、バルク式が要求する「風速の平均」ではない

**分類**: 尺度ずれ

バルク式が要求するのは `⟨|V|⟩`(瞬時風速の絶対値の時間平均)だが、
実装が渡しているのは `|⟨V⟩|`(月平均風ベクトルの大きさ)である。
イェンセンの不等式で常に `|⟨V⟩| ≤ ⟨|V|⟩`、差は変動が大きい海域ほど大きい
(南大洋・北大西洋の冬)。この差を埋めるために置かれているのが
`evapMinWindMs = 2.0` の下限だが、これは**下限であって分散補正ではない**ので、
平均風が既に 10 m/s ある海域では 1 ビットも効かない。

さらに、蒸発が見る風には**裸の上限が 2 段**掛かっている
(`step04_airflow.ts:195` の `P_MAX = 8`、`:213` の `MAX_WIND = 13`)。
これらは「水蒸気追跡が壊れる」という**旧・非保存モデルの都合**で入った値である
(spec `01-04_循環.md:79-81` に「無制限だと ±40 m/s 級が出て水蒸気追跡が壊れる」)。
**保存型に移行したいま、その理由は失効している可能性がある**のに、
上限は蒸発の上限として生き続けている。

加えて `constants.ts:262-263` は自ら
> **2 倍・半分にして全球平均が大きく動かないことを確かめること**(動くならこの下限が答えを決めている)

と課しているが、docs 全文検索でこの確認の記録は見つからない。**未実施。**

### 疑い 7 【B】蒸発の全球平均 `oceanMeanMmPerYear` が「氷の無い海の平均」であり、S2 の主判定はその値で判定されている

**分類**: 検証の指標の欠陥

`evaporation.ts:117-131`:
```
if (tc <= K.seaFreezeC) continue;   // ← ここで抜けるので sumW にも加算されない
…
sumW  += w;
sumWE += w × mm;
oceanMeanMmPerYear = (sumWE / sumW) × 12
```
**凍結セルは分子からも分母からも落ちる。** したがってこの量は
「海の平均蒸発」ではなく「**氷の無い海月の平均蒸発**」である。
`scripts/exp_evap_source.ts:77-78` は

```
globalMean = landFrac × landMean + (1 − landFrac) × oceanMean
```

としてこの値を**海の全面積に掛けている**ので、S2 の主判定に使われた
全球平均 1035 mm/年 は上振れしている(年平均で海面の 1 割弱が
月別には凍結側に入りうる → 数 % 〜 10% 程度。未測)。

方向は疑い 1 と逆(こちらは過大評価)なので、2 つのバイアスが部分的に
打ち消し合っている可能性がある。**どちらも測っていないので、
現在の真値が範囲内かどうかは誰も知らない**というのが正確な状態である。

### 疑い 8 【B】蒸発の凍結カットが階段で、EBM の海氷ランプ(5°C 幅)と食い違う

**分類**: 実装の食い違い

- EBM: `iceW = clamp((seaFreezeC − T)/iceRampWidthC, 0, 1)`、`iceRampWidthC = 5`
  → −1.9°C から −6.9°C にかけて**連続に**海氷が張る。
- 蒸発: `T ≤ −1.9` で**即座に 0**、`T = −1.88` では**全開**。

つまり「海氷が 50% 張っている(T ≈ −4.4°C)」セルで、蒸発は 0 と扱われる一方、
「海氷が 0% だが T = −1.85°C」のセルは全開になる。**海氷分率という既存の場を
蒸発が参照していない。** 影響量は小さい(その温度では `q_s` が小さい)が、
高緯度の月別収支と海氷縁の位置に階段を持ち込む。

### 疑い 9 【B】蒸発は表面気圧にほぼ非依存だが、ファイル冒頭は「気圧に陽に依存する」と主張している

**分類**: コメント/実装の食い違い + 惑星応答の欠落

`evaporation.ts:25-27`:
> **気圧に陽に依存する**ので他の惑星でも意味を持つ(薄い大気ほど同じ温度で
> 比湿が大きくなる)。

実際に代入すると相殺する:
```
ρ    ∝ p        （:100, :123）
q_s  ≈ ε·e_s/p  （:46-50、e_s ≪ p のとき)
E    ∝ ρ·q_s ∝ ε·e_s   ← p が消える
```
数値で確認(T = 15°C、e_s ≈ 17hPa):
`0.5 bar → ρ·q_s = 0.01295`、`1.0 bar → 0.01287`。**差 0.6%。**

物理としては**これで正しい**(バルク式は質量フラックスで、比湿の増加と密度の減少が
相殺する)。問題は 2 つ:
1. コメントが逆のことを書いており、読んだ人が「気圧を振れば水が動く」と誤解する。
2. **利用者スライダー `surfacePressureBar` が水の源泉を 1% も動かさない。**
   `saturatedColumnMm` も同様に `q_s·p` の形なので p が消える。
   2026-08-16 の惑星応答の測定で「気圧を 4 倍振っても赤道-極差が動かない」
   という同型の欠落が見つかり `heatTransportPressureExponent` が入った。
   **水の側は未点検である。**(実物では気圧が上がると乱流輸送効率と海面抵抗が
   変わるので、C_E 自体が気圧に弱く依存する。)

### 疑い 10 【B】SST 偏差が年一定で、季節を持たない

**分類**: 未実装の既知欠落

`computeOceanCurrent` は `sstAnomalyC` を**1 枚しか返さない**。
したがって Q フラックスも層積雲も寒流沿岸も**年間を通じて同じ**である。
実物では西岸境界流の海洋熱輸送は**冬に最大**(海が大気へ熱を放出する季節)で、
その季節性こそが東岸の冬の温暖化(日本・米東岸)を作っている。

`step03_ocean.ts:138-140` の注記が

### 疑い 13 【C】診断スクリプトが本番と違う密度で蒸発を再現している

### 疑い 14 【B】海盆の広さを「経度の度数」で測っており、惑星半径に依存しない

**分類**: 尺度ずれ / 地理中立の裏返し

`step03_ocean.ts` の中で、境界流の届き幅は `boundaryCurrentReachKm = 900`(**km**)、
沖合スタンドオフは `140`(**km**)なのに、海盆の広さの判定は

```
widthFactor = min(1, basinWidthDeg/55) × clamp((300 − basinWidthDeg)/120, 0, 1)   # :122-124
basinWidthDeg > 40                                                                # :134
```

と**すべて経度の度数**である。半径が地球の半分の惑星では、同じ 55° の海盆の
物理的な幅は半分しかないのに、同じだけ「発達した」と判定される。
一方で境界流の届き幅は km なので、**同じ式の中で 2 つの尺度が混在**している。
「一周に近いか」の判定(300°)だけは度で正しい(トポロジーの量なので)。

## 3. 「問われた 2 点」への短い答え

### Q1. SST 偏差の °C 値は較正でどう扱われているか — 物性か、較正つまみか

**どちらでもない。「空間パターンを担当する固定値」と「較正が決める振幅」に
割れており、しかもその振幅は消費先の 1 つ(EBM)にしか掛からない。**

- 5 つの °C は探索空間に**無い**(固定)。
- EBM への結合 `sstAnomalyCouplingWm2PerK` は探索空間に**ある**([12,26]、22.0128)。
  積でしか効かないので **EBM 側の振幅は較正が決めている**。
- 一方、層積雲(−sstA/2)・寒流沿岸(−0.8, /2.5)・東の海((sstA+0.6)/1.2)・
  湧昇/サンゴ(−0.8, −0.5)は **°C の絶対値を閾値として読む**ので、
  結合係数を動かしても連動しない。
- 観測(SST)との突き合わせは**一度も行われていない**
  (「SST は採点されていない」と記録が明言)。

→ 縮退を潰すまで、`sstAnomalyCouplingWm2PerK` の較正結果は
「海流の強さ」を意味しない。

### Q2. 蒸発が使う風速・湿度の場はどこから来るか — 帯状風か合成風か

**風は合成風。湿度は場ではなく定数。**

- 風 = `airflow.monthlyWindU/V`(`step04_airflow.ts` の出力)
  = 帯状卓越風(貿易 6.72 / 偏西 **9.0** / 極東 3)
  + 気圧勾配風(回転成分 + 横断成分、合成上限 **8 m/s**)
  → 標高 1500m 超で減衰 → 総風速上限 **13 m/s**。
  月平均ベクトルの大きさで、下限 `evapMinWindMs = 2.0` を噛ませる。
  **降水の輸送(`solveMoistureTransport`)に渡す風と同一の場**なので、
  源泉と移流は整合している(ここは健全)。
- 湿度 = `evapOceanRelHumidity = 0.8` の**全球一定値**。
  輸送が解いている可降水量 `W` も、飽和可降水量 `W_sat`(同じファイルに実装あり)も
  参照していない。
