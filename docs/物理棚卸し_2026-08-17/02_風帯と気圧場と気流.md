## 1. 実装している物理現象の一覧

### 1.1 大循環セルの境界(ハドレー端リッジ・極前線)

**(a) 素人向け**
太陽で暖められた赤道の空気は上昇し、上空を極方向へ流れ、途中で冷えて沈む。
沈む場所が「亜熱帯高圧帯(リッジ)」で、地球ではおよそ南北 30 度。ここから
赤道側へ吹き戻す風が貿易風、極側へ吹く風が偏西風になる。惑星の自転が遅いほど
この循環は大きく広がり、沈む場所が極寄りになる。さらに極側には、暖かい空気と
極の冷たい空気がぶつかる「極前線」があり、そこは低気圧の通り道になる。

**(b) 実装**

```
step02 L28   rotFactor      = (自転周期h / 24) ^ hadleyRotationExponent
step02 L29   ridgeBase      = clamp(hadleyEdgeBaseDeg × rotFactor, 18, 78)
step02 L30-33 polarFrontBase = clamp(polarFrontBaseDeg × √rotFactor, ridgeBase+12, 85)
step02 L117  declNorm       = clamp(赤緯 / 自転軸傾斜, −1.5, +1.5)
step02 L118  shift          = ridgeSeasonalShiftDeg × declNorm
step02 L119-120 ridgeN = ridgeBase + shift ／ ridgeS = −ridgeBase + shift
step02 L137-138 極前線N/S   = ±polarFrontBase + shift × 0.8
```

**(c) 定数**

| 名前 | 値 | SPACE | ゲート/norm |
| --- | --- | --- | --- |
| `hadleyEdgeBaseDeg` | 31 | 非所属 | クランプ [18, 78] |
| `hadleyRotationExponent` | 0.35 | 非所属 | — |
| `polarFrontBaseDeg` | 60 | 非所属 | クランプ [ridgeBase+12, 85] |
| `ridgeSeasonalShiftDeg` | 6 | 非所属 | declNorm クランプ ±1.5 |

**自転周期を読む箇所は、`src/sim/` 全体でこの L28 ただ 1 か所である**
(`rotationPeriodHours` の全参照を確認)。自転方向 `rotationDirection` は
step02/03/04/06 で東西の鏡像に使われるが、**自転の速さ**が効くのはここだけ。
→ 疑い A01(§3.1)。

### 1.2 リッジの経度別の押し上げ(段 16。**既定 0 = 不活性**)

**(a) 素人向け**
実物の夏の大陸上では、亜熱帯高気圧が地面の加熱で作られた低気圧に押しのけられ、
高圧帯が北へ逃げる(チベット高気圧)。一方、海の上の高気圧は低い緯度に居座る。
モデルは高圧帯を「半球に 1 本の緯度線」として持つので、この経度差が出ない。
その差を、経度ごとの熱帯の陸の割合に比例して足す仕掛け。

**(b) 実装**

```
step02 L99-113  troughLandFrac[col] = |lat| ≲ 30° の帯に占める陸セル比(経度列ごと)
step02 L130-135 summer = min(1, |declNorm|)
                ridgeShift[col] = ridgeLandShiftDeg × troughLandFrac[col] × summer
step02 L164-166 dN = (lat − (ridgeN + shiftCol)) / 7 ／ dS = (lat − (ridgeS − shiftCol)) / 7
step04 L61-63   ridgeN = ridgeBaseN + rShift ／ ridgeS = ridgeBaseS − rShift
step06 L2224-2225 沈降帯・前線の窓・ストーム帯が見るリッジにも同じ押し上げ
```

**(c) 定数**

| 名前 | 値 | SPACE | ゲート/norm |
| --- | --- | --- | --- |
| `ridgeLandShiftDeg` | **0(不活性)** | 非所属 | `> 0` で計算ごと分岐 |

判定: **意図的な棄却**。掃引で押し上げ 0/3/6/9 を測り、大分類が単調低下・
詳細が 44.88 → 41.14 と大崩れ。向きは正しい(未達 3 地域が揃って改善)が
桁が 1 桁足りない、が結論。配管は将来のために残すと明記されている。
(出典: [実験記録_リッジの経度依存](../実験記録_リッジの経度依存_2026-08-13.md))

→ ただしこの棄却は**実装の不備を含んだ状態で測られている**。疑い C01(§3.3)。

### 1.3 亜熱帯高気圧(帯 + 離散セル化 WL#29)

**(a) 素人向け**
沈む空気は地面を押すので、リッジの緯度には高気圧の帯ができる。ただし実物の
高気圧は帯として一様ではなく、海の上に「ぽつぽつと塊」で並ぶ(太平洋高気圧・
バミューダ高気圧)。塊が特に強いのは、大陸の西岸沖 — 自転方向の東側にすぐ
大陸がある海域で、そこには冷たい海流が流れている。モデルは「自転方向の東に
どれだけ近く陸があるか」だけを見て塊の強さを決めるので、地球の地名を一切
使わず、逆回りの惑星でも自動的に鏡像になる。

**(b) 実装**

```
step02 L48-71  eastLandKm[i] = 海セルから「自転方向の東」の陸までの距離(km)
               走査幅は 6000km 相当・最低 10 列、陸セルは 0、見つからなければ 1e9
step02 L168-172 陸: oceanW = 0.35
                海: oceanW = 0.8 + subtropicalCellEastBoost × exp(−eastLandKm / subtropicalCellEastScaleKm)
step02 L182     v += subtropicalHighHpa × oceanW × (exp(−dN²) + exp(−dS²))   ※ 幅 7°
```

**(c) 定数**

| 名前 | 値 | SPACE | ゲート/norm |
| --- | --- | --- | --- |
| `subtropicalHighHpa` | 6 | 非所属(段 8 で 6/8/10 を掃引 → 6 維持) | — |
| `subtropicalCellEastBoost` | 0.336 | **[0.3, 0.9]**(範囲の **6.0%** 位置) | — |
| `subtropicalCellEastScaleKm` | 2200 | 非所属 | 減衰長 |

→ 疑い A05(探索範囲の端に近い)。

### 1.4 夏の高気圧の西方張り出し(段 39。**既定 0 = 不活性**)

**(a) 素人向け**
実物の小笠原高気圧・バミューダ高気圧は、夏に大陸の東岸まで西へ張り出す。
その高気圧の西のふちを回る風は南寄りになり、湿った空気を海から大陸へ運ぶ。
モデルの高気圧は海盆の**東**のふちしか強めていなかったので、大陸東岸沖は
いちばん弱いままだった。それを夏だけ強める仕掛け。

**(b) 実装**

```
step02 L76-97   westLandKm[i](eastLandKm の鏡像。**係数 0 のときは走査ごと飛ばす**)
step02 L176-180 summerW = clamp(seasonalHeating, 0, 1.2)
                wcell   = exp(−westLandKm / subtropicalCellWestScaleKm)
                oceanW += subtropicalCellWestSummerBoost × wcell × summerW
```

**(c) 定数**

| 名前 | 値 | SPACE | ゲート/norm |
| --- | --- | --- | --- |
| `subtropicalCellWestSummerBoost` | **0(不活性)** | 非所属 | `> 0` で走査と加算を分岐 |
| `subtropicalCellWestScaleKm` | 2200 | 非所属 | **親が 0 のため到達不能** |

判定: **意図的な棄却**。0/0.3/0.6/1.0 の掃引で連続部分は +0.098 改善したが、
狙った米南東が 0.37 で不動。追測で「向きは完全に正しいが必要量の 8% しか
動かない(線形外挿で boost ≈ 7.9 が必要)」と判明。
副作用が無いことは確認済み(欧州 0.92・コンゴ 1.27 で不動)。
(出典: [実験記録_夏の高気圧の西方張り出し](../実験記録_夏の高気圧の西方張り出し_2026-08-16.md))

同記録は残る犯人候補を **「気圧偏差そのものが小さい」** と **「P_MAX = 8 の
頭打ち」** の 2 つに絞り、`rotRamp` 犯人説は棄却済みと明記している。
**P_MAX の側はまだ切り分けられていない。** → 疑い A02(§3.1)。

### 1.5 大陸の熱的高低気圧(日射駆動)

**(a) 素人向け**
大陸は海より暖まりやすく冷めやすい。夏の内陸は熱で空気が膨らんで軽くなり
低気圧に、冬は冷えて重くなり高気圧になる(シベリア高気圧)。海岸から遠いほど
その効きが強い。

**(b) 実装**

```
step02 L43-46  interiorness[i] = 陸なら min(1, 海岸距離km / 1500)、海は 0
step02 L149    seasonalHeating = (その月の行平均日射 − 年平均日射) / 120   ※ ±1 程度
step02 L184    v += −continentalThermalHpa × interiorness × seasonalHeating
```

**(c) 定数**

| 名前 | 値 | SPACE | ゲート/norm |
| --- | --- | --- | --- |
| `continentalThermalHpa` | 9 | 非所属(段 8 で 9/14/20 を掃引 → 9 維持) | 規格化 120 W/m² |

段 8 の掃引では 14・20 で全指標が単調悪化し「探索空間に入れる価値も無い」と
結論されている。理由は `interiorness` 重みで内陸だけが深くなり、水が沿岸に
届く前に内陸へ吸い込まれるため。

→ この項だけ `seasonalHeating` に**クランプが無い**。疑い A03(§3.1)。

### 1.6 ITCZ トラフとモンスーン増深

**(a) 素人向け**
赤道付近の雨の帯(ITCZ)の下は空気が集まって上昇するので気圧が低い。
陸の多い経度では、大陸の加熱が加わってこの低気圧の谷がさらに深くなる
(アジアの夏のモンスーン低気圧)。

**(b) 実装**

```
step02 L186-190 c  = ITCZ 中心緯度(経度列ごと)
                dI = (lat − c) / (itcz.halfWidthDeg × 1.2)
                troughDepth = itczTroughHpa × (1 + monsoonTroughDeepening × troughLandFrac[col])
                v += −troughDepth × exp(−dI²)
```

**(c) 定数**

| 名前 | 値 | SPACE | ゲート/norm |
| --- | --- | --- | --- |
| `itczTroughHpa` | 5 | 非所属 | — |
| `monsoonTroughDeepening` | **1.5** | 非所属 | 陸割合 `troughLandFrac`(0〜1) |
| (幅) | `itczHalfWidthDeg = 9` × 1.2 | 非所属 | Step 1 の定数 |

**この作戦系列で唯一「採用」された機構**(段 8、0 → 1.5)。物理上限は
`itczTroughHpa × (1+2.0) = 15 hPa`(実物のアジア夏季モンスーン低気圧 −10〜−15 hPa)
と見積もられ、1.5 はその手前。インド流入 427 → 522 mm/年。
(出典: [実験記録_気圧レバーの洗い直し](../実験記録_気圧レバーの洗い直し_2026-08-10.md) §1)

### 1.7 冬の亜寒帯海上低気圧(WL#32 / #34)

**(a) 素人向け**

(アリューシャン低気圧・アイスランド低気圧)。海は陸より暖かく、暖気と寒気の

### 1.9 温度 → 気圧の帰還(熱的低気圧、段 9。**既定 0 = 不活性**)

**(a) 素人向け**
上の 1.5 の熱的低気圧は「日射と海岸からの距離」だけで書かれていて、
**モデルが自分で計算した気温をまったく見ていない**。だから標高が高くても、
寒流が流れていても、雪が積もっていても、低気圧の位置が変わらない。
ここでは前のパスで解いた気温を使い、同じ緯度円の平均より暖かい柱の気圧を
下げる。さらに「乾いた柱では暖かさが地面の近くに閉じ込められるので低気圧は
浅い」という区別を入れている(サハラ型と対比したモンスーン型)。

**(b) 実装**

```
step02 L150-158 rowMeanT = 同じ緯度円(行)の平均気温    ← 地理中立の基準点
step02 L206-215 wet   = 陸なら前パスの湿り度、海は 1
                depth = thermalLowDryDepth + (1 − thermalLowDryDepth) × wet
                dp    = −thermalLowHpaPerK × (T − rowMeanT) × depth
                v    += clamp(dp, −30, +30)
pipeline L201-225, L404-425  係数 > 0 のときだけ step2b/step4b(気圧場と風の作り直し)を走らせる
```

**(c) 定数**

| 名前 | 値 | SPACE | ゲート/norm |
| --- | --- | --- | --- |
| `thermalLowHpaPerK` | **0(不活性)** | 非所属 | `> 0` でパイプラインの段が 2 つ増える |
| `thermalLowDryDepth` | 0.25 | 非所属 | **親が 0 のため到達不能** |

判定: **意図的な棄却(2 回測って 2 回とも)**。v4 の物差しで測り直しても
連続部分が 70.32 → 68.53 と落ち、棄却が再確認された。分解も済んでおり、
「東縁で南風(米南東が助かる)・西縁で北風(欧州が壊れる)」という、
円い低気圧が構造的に両方を連れてくる問題と判明している。
(出典: [実験記録_熱的低気圧v4再測](../実験記録_熱的低気圧v4再測_2026-08-16.md))

→ 副作用として、`priorWetness01` 引数・pipeline の step2b/step4b 経路・
`thermalLowDryDepth` がまとめて死んでいる。疑い B(§3.2)。

### 1.10 帯状卓越風 4 種(Step 4)

**(a) 素人向け**
大循環の地表側の風。赤道と亜熱帯高圧帯の間は貿易風(東寄りで、赤道へ向かって

**(b) 実装**

```
                                                    bv = −trade×0.4×t×meridRev
step04 L137-140 南貿易風  (ridgeS ≤ lat ≤ itczLat): bu 同上、bv = +trade×0.4×t×meridRev

                                                    bv = +westerly×0.15×t
step04 L145-148 南偏西風  (pfS ≤ lat < ridgeS):     bv = −westerly×0.15×t
step04 L149-154 極東風    (|lat| > |pf|):           bu = −polarEasterly×dirSign
                                                    bv = ∓polarEasterly×0.3   ※帯重み無し
```

**(c) 定数**

### 1.11 赤道越えモンスーン(WL#29。**既定 0 = 不活性**)

**(a) 素人向け**
夏に雨の帯が赤道から大きく離れると、反対の半球の貿易風が赤道を越えて流れ込む。
赤道を越えるとコリオリの曲がる向きが逆になるので、東風だったものが西風に
変わる(実物の南西モンスーン)。

**(b) 実装**

```
step04 L82-89   赤道と ITCZ の間の帯(lat×itczLat > 0 かつ |lat| < |itczLat|)でのみ:
                disp    = min(1, |itczLat| / crossEquatorialRefDeg)
                turn    = |lat| / |itczLat|         ※ 赤道 0 → ITCZ 線上 1
                crossEq = crossEquatorialMonsoon × disp × turn
                zonalRev = 1 − 2 × crossEq          ※ 1 で従来、−1 で同強度の逆向き
```

**(c) 定数**

| 名前 | 値 | SPACE | ゲート/norm |
| --- | --- | --- | --- |
| `crossEquatorialMonsoon` | **0(不活性)** | 非所属 | 適用域は赤道〜ITCZ の間のみ |

### 1.14 気圧勾配風(回転成分 + 横断成分、上限 P_MAX)

**(a) 素人向け**
気圧の高いほうから低いほうへ空気は押される。ただし惑星が回っているので、
押された空気はまっすぐ低圧側へは行かず、等圧線に沿って曲げられる(回転成分)。
地面の摩擦があるぶんだけ、少し低圧側へ切り込む(横断成分)。赤道に近いほど
曲がりが弱いので、切り込む成分が主役になる。

**(b) 実装**

```
step04 L177-202
  dpdx = (p[東] − p[西]) / (2·dxKm) × 1000     [hPa / 1000km]
  dpdy = (p[北] − p[南]) / (2·dyKm) × 1000
  f       = sin(|lat|)
  rotRamp = clamp((|lat| − 10) / 20, 0, 1)
  rotSign = (lat≥0 ? 1 : −1) × dirSign
  rotW    = pressureGradientRotationalMsPerHpaPerMm × f × rotRamp
  crossW  = pressureGradientCrossMsPerHpaPerMm × (1 − 0.5·f)
  pu = rotSign·rotW·(−dpdy) − crossW·dpdx
  pv = rotSign·rotW·( dpdx) − crossW·dpdy
  P_MAX = 8 ;  |(pu,pv)| > 8 なら 8 へ等方縮小
  bu += pu ; bv += pv
```

**(c) 定数**

| 名前 | 値 | SPACE | ゲート/norm |

| `pressureGradientCrossMsPerHpaPerMm` | 1.6 | 非所属(段 8 で 1.6/2.4/3.2 掃引 → 1.6 維持) | × (1 − 0.5 sin\|lat\|) |

## 3. 棚卸し

### 3.1 (i) ゲート・閾値の尺度ずれ疑い

#### **A01【最重要】気圧勾配風のコリオリ依存が、緯度に対して逆向き・自転と大気質量に盲目**

`step04 L187-190`:

```ts
const f = Math.sin((Math.abs(lat) * Math.PI) / 180);
const rotW = K.pressureGradientRotationalMsPerHpaPerMm * f * rotRamp;
```

回転成分 `(pu, pv) ∝ rot·(−∂p/∂y, +∂p/∂x)` は地衡風の形そのものである。
ところが地衡風の振幅は

```
V_g = |∇p| / (ρ · f) ,   f = 2Ω sinφ
```

で、**f に反比例**する。実装は `× f` と**比例**させている。地球の値で確かめると:

| 緯度 | 実際の地衡風(1 hPa/1000km あたり) | モデルの `rotW` |
| --- | --- | --- |
| 30° | 1.14 m/s | 1.60 m/s |
| 60° | 0.66 m/s | 3.20 m/s |

**緯度に対する向きが逆で、高緯度では 5 倍近く過大**である
(この 2 行は本書で計算した。ρ = 1.2 kg/m³、Ω = 7.29e−5 s⁻¹)。

コメントの意図は「コリオリの効く緯度では等圧線沿い、低緯度では横断が主」で、
`f` を**地衡性の重み**として使っている。重みとしては向きが正しい。
しかし同じ係数が**振幅**も兼ねているため、重みの正しさと引き換えに振幅の
緯度依存が反転している。**重みと振幅を 1 つの係数に同居させたのが根**である。

さらに:

- **`Ω`(自転角速度)が入っていない。** `rotationPeriodHours` の参照は
  `src/sim/` 全体で `step02 L28`(ハドレー端)の 1 か所のみ。
  自転周期を 4 倍にしてもハドレー端は動くが、**風の地衡性は 1 ビットも変わらない**。
- **`ρ`(大気密度 ∝ 表面気圧)が入っていない。** `surfacePressureBar` は
  EBM・降水・蒸発では読まれるが、step02/step04 では一度も読まれない。
  0.5 bar の惑星では同じ hPa 勾配が 2 倍の風を生むはずだが、モデルは不変。
  加えて気圧偏差の振幅(`subtropicalHighHpa = 6` hPa 等)自体が**絶対 hPa**
  なので、薄い大気ほど相対的に巨大な偏差になる。

これは 2026-08-16 に段 40 で見つかった
「**熱輸送係数が大気質量を見ていない**」(`heatTransportPressureExponent`)と
**同じ型の欠落**である。あちらは「気圧を 4 倍振っても赤道-極差が 44.6 → 44.7°C と
動かない」で発覚した。**風は惑星応答としてまだ測られていない。**

そして段 39 と段 42 の実験記録が、揃ってこの係数を次の被疑者に挙げている:

> 気圧場経由なら振幅の制約(**P_MAX=8 と回転係数**)を見直すか。
> (実験記録_モンスーン反転の経度選択 §機構一族の総括)

**優先度: 最高。** 較正されない生きた定数(`pressureGradient*` 2 件)の
緯度形状そのものが疑わしく、かつ惑星応答の要件(自転・気圧を振る)に直結する。

#### A02 P_MAX = 8 の頭打ちが、どこでどれだけ効いているか未測

`step04 L195-199`。合成した気圧勾配風の大きさを 8 m/s で等方に切る。
段 39 の実験記録は、機構が効かなかった理由の候補としてこれを残したまま
**まだ切り分けていない**と明記している(候補 3 の `rotRamp` は棄却済み)。

上限に張り付いているセルでは、**気圧偏差をいくら強めても風が増えない** —
つまり段 39・段 8 の「振幅レバーが効かない」という 4 回の実測結果と、
症状が一致する。飽和率(月別・帯別に P_MAX に当たっているセルの面積割合)は
本書の範囲では測れない(パイプライン実行禁止)。**測定を推奨**。

#### A03 `seasonalHeating` のクランプが項ごとに不揃い

`step02 L149` の `seasonalHeating = (月日射 − 年平均日射)/120` を使う 3 項のうち、

| 項 | クランプ |
| --- | --- |
| 大陸熱的高低気圧(L184) | **無し** |
| 夏の西方張り出し(L177) | `[0, 1.2]` |
| 冬の亜寒帯低気圧(L197) | `[0, 1.2]` |

規格化の 120(W/m²)は地球の季節振幅から決めた尺度で、名前を持たない。
高傾斜・高離心率・高光度の惑星では `seasonalHeating` が 1.2 を大きく超え、
**クランプのある 2 項は飽和して緯度一様に退化する一方、大陸熱的高低気圧だけが
青天井で伸びる**。惑星応答としての振る舞いが項ごとに変わる。

#### A04 「熱帯」を表す ±30° 帯が、リッジと連動しない・格子分解能で動く

`troughLandFrac`(step02 L102-103)・`colLandFrac`(step04 L30-31)・
段 44 の `hCol`(step06 L2162-2163)の**3 か所**が、同じ「|lat| ≤ 30° の帯の
陸割合」を独立に再実装している。

- リッジは自転で 18°〜78° まで動くのに、**この帯は 30° に固定**。
  低速自転の惑星ではハドレー循環の内側のごく一部しか数えないことになる。
- 行番号の丸めのため、実際の帯は **1° 格子で ±30.5°、2° 格子で ±31°**。
  較正は 2°、`npm run validate` は 1° で走るので、**較正と検証で
  ゲートの定義がわずかに違う**。

#### A05 SPACE に居る 3 件のうち 2 件が範囲の端に近い

| 定数 | 値 | 範囲 | 位置 |

### 3.3 (iii) コメントと実装の食い違い

#### **C01【重い】リッジの経度別押し上げは「夏半球でのみ」ではない**

コメント(step02 L124-128)と `constants.ts` L342-343 はどちらも

> **夏半球でのみ**、その経度列の熱帯陸割合に比例して極側へ動かす

と書いている。実装は:

```ts
const summer = Math.min(1, Math.abs(declNorm));           // L131 半球に依存しない
ridgeShift[col] = K.ridgeLandShiftDeg * troughLandFrac[col] * summer;
...
const dN = (lat - (ridgeN + shiftCol)) / 7;               // L165 北を極側へ
const dS = (lat - (ridgeS - shiftCol)) / 7;               // L166 南も極側へ
```

`summer` は `|declNorm|` なので**半球を区別しない**。結果として

1. **冬半球のリッジも同じ量だけ極側へ押し上げられる**(至点付近では両半球で最大)。
2. `troughLandFrac` は |lat| ≤ 30° の**両半球を合算**した陸割合なので、
   南半球熱帯にしか陸が無い経度でも北半球のリッジが動く。

step04 L61-63 も同じ形(`ridgeN + rShift` と `ridgeS − rShift`)なので、
風の帯の境界にも同じ扱いが伝播する。

**影響**: 2026-08-13 の段 16 の掃引(0/3/6/9)は**この状態で測られている**。
「詳細が 44.88 → 41.14 と大崩れ」という棄却理由が、狙った夏の大陸効果ではなく
**冬半球のリッジを不当に極へ押した副作用**である可能性を排除できていない。
記録には「リッジは詳細分類の型(乾燥の縁・地中海性気候の位置)に強く効く」と
書かれており、**地中海性気候は冬雨の分類**なので、冬半球のリッジ位置は
まさにその型を決める量である。

コード変更禁止のため直していない。**再測するなら実装を直してから**が筋である。

#### C02 段 44 が `crossEquatorialRefDeg` と `monsoonLandFracRef` を**リテラルで複製**

`step06 L2174-2175`:


定義そのものに当たる — 計算に効くのに、名前も仕様書の記載も無い量が 2 つある。

### 3.4 (iv) 地理中立への抵触疑い

三原則の「地理中立」は「計算層のどこにも『地球でこうだから』という座標決め打ちを
書かない」である。**担当範囲に、実在地名・実在座標の決め打ちは 1 件も無かった。**
海陸の判定はすべて `landMask` と距離、東西はすべて `rotationDirection` 経由で、
逆行自転で鏡像になる設計が一貫している(`tests/unit/sim/pipeline_properties.test.ts`
に「逆行で東西風の符号が反転する」検査あり)。**この点は健全である。**

残るのは「**惑星パラメータと連動しない緯度・距離の決め打ち**」で、
座標決め打ちほど悪質ではないが、他の惑星で意味を失う種類の量である。

| # | 箇所 | 決め打ち | 何と連動すべきか |
| --- | --- | --- | --- |
| D01 | step02 L201 | 極域高気圧 `\|lat\| > 75`、幅 15° | 極前線緯度(最大 85° まで動く。**現状は重なりうる**) |
| D02 | step02 L102-103 / step04 L30-31 / step06 L2162 | 熱帯 = `\|lat\| ≤ 30°` | ハドレー端(18〜78°) |
| D03 | step04 L188 | `rotRamp = (\|lat\| − 10)/20` | 自転角速度(ロスビー数) |
| D04 | step02 L45 | 内陸度 `距離 / 1500km` | 惑星半径 or 水蒸気の輸送距離 |
| D05 | step02 L55 / L81 | 海盆走査 6000 km | 惑星半径(`radiusKm` は `cellWidthKm` 経由で入るが、上限 6000 は固定) |
| D06 | step04 L206-207 | 山岳減衰 標高 1500m / 幅 4000m | 大気スケールハイト(表面気圧・重力) |

D01 は緯度の重なりが具体的に起きうる点で他より実害が近い:

地球条件(極前線 60°)では 75° と 60±8° = 52〜68° が分離しているので表面化しない。
