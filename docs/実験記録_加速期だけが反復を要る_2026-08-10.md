# 実験記録: 反復 512 回が要るのは加速期だけだった — 1 評価 313s → 146s

日付: 2026-08-10
枝: `perf/multigrid`(多重格子を試すために切った作業場。多重格子の前に
これが見つかったので、まずこちらを出す)
道具: `scripts/diag_ebm_step_residual.ts`(新規)、`scripts/prof_stage_cost.ts`

## 出発点

[実験記録_評価費用の内訳](実験記録_評価費用の内訳_2026-08-10.md) で、
1 評価 313 秒の **88.4% が EBM** と分かった。EBM の中身は
「1 時間ステップあたり赤黒ガウス=ザイデル 512 回」を**全ステップで固定**
して回すものである。

512 の根拠は 2026-08-01 の実測がある:

> 反復 128 → 残差 3.6e-2 / 256 → 2.6e-3 / **512 → 1.7e-5**、許容差 1e-3

これは正しく測られている。**ただし「全ステップを通じた最大残差」である。**
一番苦しい 1 ステップが 512 を要求するとして、**残りのステップも
512 が要るのか**は測られていなかった。

## 測った: 8 割のステップは 128 回で足りている

反復を 128 に固定し、ステップごとの残差の分布を出した。

```
反復 128 回・8 年(加速 2 + 全熱容量 6)・2400 ステップ、許容差 1e-3
  残差 ≤1e-5      14 ステップ   0.6%
  残差 ≤1e-4    1624 ステップ  67.7%
  残差 ≤1e-3     321 ステップ  13.4%
  残差 ≤1e-2     431 ステップ  18.0%
  残差 ≤1e-1      10 ステップ   0.4%

128 回で許容差を満たしたステップ: 81.6%
未達ステップの位置: 最初 0 / 最後 479
```

**未達は 1 つ残らずステップ 479 以前**にある。加速期は 0〜599 なので、
**未達はすべて加速期の中**である。

温間開始でも分布は同じだった(81.7%、未達の最後は 479)。
**冷間開始の過渡ではない。**

## 理由は物理でつく

加速期は緩和を早めるために**熱容量を 1/16 にする**。陰解法の対角項は
C/dt なので、熱容量が 16 分の 1 になれば**対角優位が 16 分の 1 に弱まる**。
ガウス=ザイデルの収束は対角優位で決まるので、加速期だけ反復が効かない。

全熱容量に戻れば対角項が 16 倍になり、128 回で十分に収束する。
**加速期の苦しさを全ステップが肩代わりしていた。**

## 直したこと

加速期を抜けたら反復を 4 分の 1 にする(`src/sim/gpu/ebm_gpu.ts`)。

```ts
const itersNow = step < spinupSteps ? iters : itersLate;  // itersLate = iters >> 2
```

`spinupSteps` は既に GPU 側が持っている量なので、**新しい境界の定数は
要らない**。落とす比 4 は上の測定から。

## 効果(いずれも他プロセスを止めた状態で計測)

```
                  修正前     修正後
全体              313.3s    146.2s    2.14 倍速
  step5_temperature 138.8s     66.2s
  step5b_temperature 138.3s     41.9s
  step6_precipitation 18.1s     23.3s  ← 変わっていない(相対比が上がる)
EBM 合計          277.1s    108.1s    2.56 倍速
```

EBM が費用に占める割合は 88.4% → 74%。降水(保存型の輸送)が 25% になった。

## 精度は緩めていない

**判定の基準は 1 ビットも変えていない。** 残差は従来どおり**毎ステップ**
測っており、`converged = 全ステップの最大残差 ≤ 1e-3` も同じ。
足りなければ外側が `iters` ごと倍化して回し直す(加速期と後期の比は保たれる)。

実測でも、4 回の EBM 呼び出しすべてが**反復 512 のまま倍化せずに収束**した
= 後期を 128 に落としても**全ステップが許容差を満たしている**。

```
              修正前     修正後
v3           81.029    81.058
大分類        72.02     72.05
詳細          41.77     41.78
気温 RMSE      3.919     3.926
ゲート          13        13
地域の流入  522/-75/-28/-146/-54 → 522/-75/-28/-146/-55
```

v3 の差 0.029 は、周期定常の許容差 0.05°C が作る数値の揺れ(v3 にして
約 0.02 — [実験記録_ウォームスタート](実験記録_ウォームスタート_2026-08-06.md) §3)
と同じ桁である。**別解に飛んだのではなく、同じ許容差の中の別の点**に落ちている。
地域の水蒸気流入はヨーロッパの 1mm を除いて全桁一致。

## まだ残っていること

- **多重格子。** この作業場はもともとそのために切った。赤黒ガウス=ザイデルの
  収束比は実測で ρ ≈ 0.98/回(256 → 512 で残差が 153 分の 1)。多重格子なら
  V サイクル 1 回で ρ ≈ 0.1 が狙えるので、**まだ 1 桁ぶんの余地がある**。
  ただし加速期の対角優位の弱さは多重格子のほうが得意な領域でもあるので、
  今回削った後期ではなく**加速期**が主戦場になる。
- **加速期そのものを見直す。** 熱容量 1/16 は緩和を早めるための工夫だが、
  そのせいで反復が 4 倍要る。1/8 や 1/4 なら反復が減って総費用が下がる
  可能性がある(未測定)。**加速期の倍率と反復回数は対で最適化すべき量**。
