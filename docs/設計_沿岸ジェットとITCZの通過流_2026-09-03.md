# 設計メモ: 沿岸ジェット領域では ITCZ を「収束線」でなく「通過流」にする(角の処方案)

日付: 2026-09-03 夜(設計のみ。実装・事前登録は未着手)
根拠: [診断_アフリカの角](診断_アフリカの角_2026-09-03.md)。

## 何を表すか

実物の盛夏、越赤道の下層流が夏半球側の大陸東岸(西に高地・東に海)に沿って
北東へ加速する低層ジェット(ソマリジェット型)ができる経度帯では、
ITCZ の収束線は存在せず(トラフはさらに極側の大陸上へ)、ジェット下流は
発散・沿岸湧昇で乾く。模型は全経度で ITCZ 中心緯度に収束線を置くため、
この領域(角)に 250mm/月 の雨を作る(観測 10-20)。

## 地理中立な判定(緯度・経度・地名を使わない)

経度列ごとに、夏半球側で以下がそろうとき「ジェット列」とする:
1. ITCZ が赤道から大きく変位(disp = |itczLat|/crossEquatorialRefDeg が閾値以上)
   = 越赤道流が立つ季節・経度。
2. 赤道〜ITCZ の帯で、当該列が海または海岸で、**西隣の列が陸**(east-coast 幾何)。
   さらに西隣の陸に高地(標高 ≥ 閾値)があれば強い(高地に沿う転向)。
3. 列の陸割合(troughLandFrac)が低い(大陸の内側ではない)。
判定値 J ∈ [0,1] を連続に作る(閾値の崖を避ける)。

## 作用(3 点、いずれも既定 0 でビット一致)

- ITCZ 持ち上げの置換: liftItczF を J で (1 − jetLiftReduce·J) 倍(通過流)。
- 下流の沈降: J 列の ITCZ 中心より極側 halfWidth 以内に subs を jetSubsBoost·J
  だけ加える(発散 → 沈降の代理。傘発散ゲートの死因「発散場が無い」を、
  ジェット幾何で置き換える)。
- 風: 当該帯の子午成分を極向き・東西成分を海岸沿いに転向(既存の
  monsoonMeridionalReversal の配管を J でゲート)。輸送の W も動く。

## 危険と検収

- 名指しの疑い: 判定は幾何(東岸・越赤道変位・陸割合・高地)だけで書き、
  理想化大陸(45d)で「東岸の越赤道側に乾いた沿岸が出るか」を先に確認する。
- 巻き添え: 同じ幾何は南米北東岸(ブラジル・ノルデステの乾燥は実在)、
  オーストラリア北西岸にも当たる — これらは観測でも乾く側なので方向は正しい。
  インド西岸(ジェット到達側)は湿潤 — 判定 2 で「西隣が陸」の条件が
  インド西岸では逆(東隣が陸)になるので当たらない、を確認する。
- 既定 0 で HEAD とビット一致 → 単独掃引(horn・india・sahara・amazon の share、
  Af/Aw、fitness)→ 組 → 事前登録の順。

## 検証 1(9/4 未明): 判定 J 第 1 版の点灯経度(out/diag_jet_columns.ts)

J = disp × (当列が海 × 西隣 3〜6° が陸) × (1 − 陸割合) × 高地係数、
北夏(6-8 月)・南夏(1-2 月)の最大値。

```
角 43-51E:       0.70 0.45 0.26 0.19 0.19 0.22 0.40 0.49   ← 点灯 ○
ソマリ沖 51-60E: 0.63 0.45 0.39 0.32 0.19 0.12 0 0 0        ← 点灯 ○
インド西岸 70-76E: 0 0 0 0 0 0                              ← 消灯 ○(西隣が海)
北東ブラジル 36-44W: 0.05〜0.15                              ← 弱(南夏の変位が小さい)
北西豪州 115-125E: 0.06〜0.62                                ← 誤点灯(実物は南夏に湿潤)
ベンガル湾東 86-92E: 0.16〜0.35                              ← 誤点灯(実物は最湿)
インドシナ東岸 104-109E: 0.2〜0.52                            ← 半分正しい(中部ベトナムの夏乾)
```

- 方向は正しい(角 ○・インド西岸 ○)が、「夏半球の大陸東側の海」が広く点灯し
  選択性が足りない。
- 差分の物理: ソマリジェットは**赤道をまたいで南北に走る東岸**に沿う越赤道流。
  ベンガル湾・北西豪州の西隣の陸は赤道の片側にしかない(越赤道流は外洋から
  到達 → 収束 → 湿潤、が実物で正しい)。
- 第 2 版: 西隣の陸が赤道の両側(−12〜0 と 0〜12)にある度合い spanEq を掛ける。
  検証中。

## 検証 2(9/4 未明): 第 2 版(spanEq = 西隣の陸が赤道の両側にある度合い)

```
J > 0.15 の列: −47.5/−46.5W(0.21/0.18、南米北岸・南夏)
               39.5〜45.5E(0.26 0.39 0.46 **0.84** 0.70 0.45 0.17 — 東アフリカ沿岸)
               107.5/108.5E(0.22/0.20、インドシナ東岸)、119.5/122.5E(0.16/0.22)
角 43-51E:       0.70 0.45 0.17 0.05 0.02 0 0 0   ← 西半分のみ点灯
ソマリ沖 51-60E: ≈0                               ← 消灯(西隣の南半球側が外洋)
インド西岸: 0 / ベンガル湾東: 消灯 / 北西豪州: ≤0.22 / 北東ブラジル: 0
```

- 選択性は確保(誤点灯はほぼ消え、東アフリカ沿岸が突出)。
- 消えた角の東半分・ソマリ沖は、実物ではジェットの**下流**(海岸を離れて外洋を
  北東へ加速し、発散する区間)。判定 J は「発生域(海岸に沿う区間)」の検出器で、
  下流は**流れに沿った拡張**として別に表す: J 列の ITCZ 変位方向(極側・東側)へ
  減衰つきで J を運ぶ(輸送方向は既存の風、距離スケールは 1 定数)。
  → 機構は「発生域 J(幾何)+ 下流拡張(風で運ぶ)+ 作用 3 点(持ち上げ置換・
  沈降・転向)」の構成で事前登録する。
- 実装は v45 判定後の次章として着手(既定 0 ビット一致 → 単独掃引 → 組 → 較正)。

## 結論(9/4 昼): 凝結ゲートでは角は乾かない — 風場(発散)の章へ

判定 J(第 3 版)は角を正しく点灯させたが、持ち上げ置換・沈降加算は角の雨を
−6mm しか動かさなかった。保存型輸送では収束域の雨 = 水蒸気フラックス収束で、
凝結係数は分配を変えるだけ。角の処方は**風場**にしか無い: 越赤道流が海岸に沿って
転向・加速し、角の上で発散する構造(実物のソマリジェット)を、地理中立に
(判定 J を適用域として)風の場に作ること。これは 8 月に 4 連敗したモンスーン流
一族の再設計(「輸入」でなく「経路と発散」)であり、W-3 の発散監査(横断流の
質量非保存)と合流する。次章の候補として台帳に置く。
