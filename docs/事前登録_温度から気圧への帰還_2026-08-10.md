# 事前登録: 温度 → 気圧 → 風 の帰還(段 9)

日付: 2026-08-10
**結果を見る前に書いている。**
前段: [実験記録_気圧レバーの洗い直し](実験記録_気圧レバーの洗い直し_2026-08-10.md)、
[診断_地域の水蒸気収支](診断_地域の水蒸気収支_2026-08-10.md)

## なぜここへ来たか

気圧側のレバーを 3 本振った結果、**熱帯の ITCZ トラフだけが効いた**。
中緯度東岸(米南東・東アジア)はどのレバーでも動かない。

| レバー | 結果 | 未達 3 地域 |
|---|---|---|
| モンスーントラフ増深 | 採用 0 → 1.5 | インドのみ改善 |
| 大陸の熱的低気圧の振幅 | 棄却(単調悪化) | 全部悪化 |
| 亜熱帯高気圧の振幅 | 棄却(詳細が低下) | 米南東が逆向きに悪化 |

3 本に共通する事実がある。**気圧場が幾何と日射だけから作られている。**
`step02_windbelt.ts` の熱的低気圧は

```
v += -continentalThermalHpa × interiorness × seasonalHeating
seasonalHeating = (その月の日射 − 年平均日射) / 120   ← 行(緯度)ごと
```

で、`seasonalHeating` は**緯度と月だけの関数**、`interiorness` は
**海岸からの距離だけの関数**である。つまりモデルの熱的低気圧は
「その緯度のその月に、内陸ならこれだけ下がる」としか言っていない。

**モデル自身が計算した気温をまったく見ていない。**
だから標高でも、海流でも、土壌の湿りでも、雪氷でも低気圧の位置は変わらない。
振幅のレバーを上げても**低気圧が立つ場所は 1 セルも動かず**、
深さだけが増える。段 8 の 3 本が揃って失敗した理由はこれだと考えている。

診断 2 件(地域の水蒸気収支・境界 4 面の分解)と外部レビュー 2 件
(2026-08-09、Fable「温度→気圧の帰還」/ Codex「循環の質量連続」)が
別経路から同じ場所を指していた。

## 変えるもの

気温の**同一緯度円からの偏差**で気圧を下げる項を足す。静水圧の一次近似:

```
Δp = -thermalLowHpaPerK × (T(i) − T̄(その緯度・その月))
```

- `T̄` は**その月・その緯度行の平均**。緯度円からの偏差なので、
  水惑星では自動的に 0 になり、大陸の名指しも緯度帯の名指しも要らない。
- 係数の目安: 実物のインド上の夏の熱的低気圧は緯度円平均より
  +5〜6K 暑く、地上気圧偏差は −8hPa 級。**1.3hPa/K 前後**が実物相当。
  探索は 0(無効)から 2.0 まで。
- 既存の `continentalThermalHpa`(日射駆動)は**残したまま**足す。
  片方ずつ動かせないと、どちらが効いたか分からなくなる。
  新項が効くなら、次の段で古い項を外せるかを別に測る。

## どこに挿すか

パイプラインは既に 2 パスある(`pipeline.ts`)。

```
現在: itcz → windBelt → ocean → airflow → 気温1 → 降水1 → 気温2 → 降水2
                          ↑ 気温を見ずに一度だけ作られる
```

**気温 1 の後に windBelt と airflow を作り直し**、パス 2 をその風で回す。
気温と降水の再計算はもともとパス 2 で走っているので、**増える費用は
windBelt + airflow の 1 回分**だけ。費用の 97.9% は EBM の時間積分なので
実質ただである(ロードマップ「外側の反復を増やすと 1.5 倍」の話とは別物)。

## 予想される危険(先に書く)

**これは正帰還である。** 気温が高い → 気圧が下がる → 風が集まる →
降水が増える → 蒸発冷却で気温が下がる、あるいは逆に回る。

同じ型で 1 度死んでいる。2026-08-01 の蒸発冷却フィードバックは
「モデル自身の降水誤差が温度誤差へ増幅される誤差の正帰還」で
気温 RMSE 4.85 → 6.76 と大破した(較正記録)。

したがって:

- **反復しない。**帰還は 1 回だけ適用する(気温1 → 気圧 → 風 → パス 2)。
  収束するまで回さない。
- **気温 RMSE を監視項に入れる。**下の判定 4 で明示する。

## 判定(先に固定する)

段 8 と同じ物差しを使う(`scripts/exp_pressure_lever.ts`)。
主たる物差しは **v3 ではなく夏の正味流入(P − E)**。

1. **未達 3 地域(india / us_southeast / east_asia)の夏の正味流入が
   揃って正へ動く。**段 8 の値(522 / −75 / −28)を起点にする。
2. **対照 2 地域(congo / europe_russia)の流入が半減しない。**
3. **v3 が 81.046 から 1.0 以上落ちない。**
4. **気温年 RMSE が 0.3°C 以上悪化しない。**正帰還の暴走を捕まえる番人。
   悪化したら係数に関わらず**棄却**する(1〜3 を満たしていても)。

1・2 を満たし 3 を満たさない場合は保留にし、原因を特定してから再判断する
(較正前の定数で成績を判定するのは公平でないため)。

## やらないと決めていること

- 地域名・緯度帯・海岸側を名指しした条件分岐(教訓 §1 地理中立)。
  緯度円平均からの偏差という形以外は使わない。
- 帰還を収束するまで回すこと(上記の危険による)。
- 3 地域だけを見て採否を決めること。**全 17 ゲートと大分類・詳細も必ず出す**。
- 新項が効かなかったときに、係数を探索空間へ入れて較正で救うこと。
  **効かないなら効かないと書いて次へ行く。**
