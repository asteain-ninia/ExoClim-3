## 判定(登録どおり)

- 157 ○ の 3 定数を **まとめて 1 回の較正(v48)** の SPACE 変更に載せる:
  subsidenceItczProtection [0.6, 0.95]→[0.6, **1.0**]・subsidenceBasinAsymmetry [0, 0.95]→
  [0, **1.0**]・conveyorStrength [0, 60]→[0, **90**]。単独で ±0 なのは 9/3 の赤道残存や
  9/4 の沈降抑制(単独 −0.0x → 共調整で +0.51)と同じ型で、**範囲を広げて較正に選ばせる**
  のが目的。
- 158 ✗ は「ITCZ 防護は単独では熱帯を動かさない」という事実。v47 で 4 版連続で登ったのは
  沈降抑制との**対**で価値が出ていたから、と読める(共調整でしか測れない)。

## 注記(道具)

掃引の基準値 74.278 は較正の自己採点の continuousV3 74.347 と 0.07 ずれる。掃引と較正で
