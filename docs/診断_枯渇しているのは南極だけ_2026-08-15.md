# 診断: W が潰れているのは**南極だけ**。しかも遠いからではなく**寒いから**

日付: 2026-08-15
道具: `scripts/diag_water_starved.ts`(新規)
前段: [診断_幅を作っているのはGではなくW](診断_幅を作っているのはGではなくW_2026-08-15.md)
出力: `out/diag_water_starved.txt`

## 問い

前段で「W は 1% の 0.007mm から 99% の 6.76mm まで約 1000 倍動く」
「陸の 25% 以上で W が 0.04mm を下回る」と分かった。
**その乾いた側の山がどこで、なぜ水が届かないのか**を数えた。

見当(南極内陸・チベット・大陸内部)はついていたが、見当では書かない。

## 【1】枯渇セルは 100% が南極

```
閾値W      セル数   陸の%   モデル降水  観測降水   中央値W    中央緯度
<0.05      5636    26.2          2        57    1.14e-2     -81.5
<0.10      6076    28.2          2        62    1.23e-2     -81.5
<0.20      6092    28.3          2        63    1.23e-2     -81.5
<1.00      8860    41.2          4       139    2.27e-2     -76.5

枯渇セル(W < 0.2mm)= 6092 個の緯度分布
  90〜60S   6092 / 6092  (帯の 100%)  中央標高 2614m  海岸距離 500km  気温 −36.7°C
  60〜30S      0 /  550
  30S〜30N     0 / 5618
  30〜60N      0 / 5410
  60〜90N      0 / 3842   ← グリーンランドにも 1 セルも無い
```

**閾値を 0.05 から 0.2 まで動かしても、枯渇セルは 1 つ残らず 60°S 以南にある。**
チベットも大陸内部も枯渇していない — 見当は当たっていなかった。
グリーンランドも無傷である(周りの海が南極ほど冷たくない)。

そこのモデル降水は年 **2mm**、観測は年 **57〜63mm**。**約 30 倍乾いている。**

## 【2】寒いからか、遠いからか → **寒いから**

海岸距離 × 年平均気温の 2 元表(中央値 W mm、括弧はセル数):

```
海岸km \ 気温      〜−20       −20〜−5      −5〜10       10〜25        25〜
〜250          0.02(1499)  0.52(1090)  0.98(1924)  2.52(1698)  5.30(849)
250〜500       0.02(1591)  0.82( 335)  1.31(1148)  2.53(1452)  4.06(481)
500〜1000      0.01(2256)  1.13( 173)  1.55(1386)  2.63(1754)  4.02(474)
1000〜2000     0.01( 829)  1.17( 139)  1.87( 994)  2.89( 766)  4.88(528)
```

**列方向(寒くなる)には 250 倍落ちるが、行方向(遠くなる)にはほとんど落ちない。**
むしろ −20〜−5°C の列は内陸へ行くほど**増える**(0.52 → 1.17)。

つまり **到達距離の問題ではない。** 最も冷たい列は**海岸から 250km でも
すでに 0.02mm** しかない。水は「届かない」のではなく、
**そもそも冷たい空気の中に存在していない**。

理論値もそれを裏づける:

```
λ(陸) = 15.68 /月    枯渇セルの中央 G = 1.002 → 実効 λG = 15.71 /月（滞留 1.9 日）
移流長 L_adv = U/(λG) = 1834 km
拡散長 L_dif = sqrt(D/(λG)) = 706 km
枯渇セルの中央海岸距離 = 500 km → 拡散長の 0.7 倍
```

**枯渇セルは拡散長の内側にいる。** 指数減衰で説明できる位置ではない。

実測の減衰長も同じことを言う:

```
寒い陸 (< −5°C)  118km:0.058  366km:0.024  714km:0.012  1139km:0.009  → 558 km
温暖な陸 (≥ 10°C) 111km:3.082  363km:2.894  701km:2.859  1264km:4.184  → 2900 km
```

寒い陸は**海岸(118km)の時点で既に 0.058mm** しかない。
そこから先の減衰は、少ない水がさらに減っているだけである。

## 【2b】同じ枠でモデルと観測の降水を比べる — 誤りは 4 種類ある

同じ 2 元表で年降水の中央値(mm/年)を出した。**モデル / 観測**:

```
海岸km \ 気温     〜−20      −20〜−5     −5〜10     10〜25      25〜
〜250            4/194     103/286    263/577    529/710   1469/1374
                 0.02        0.36       0.46       0.75       1.07
250〜500         3/ 88     187/353    389/581    423/598   1142/ 852
                 0.03        0.53       0.67       0.71       1.34
500〜1000        2/ 39     287/393    477/510    310/635   1209/ 949
                 0.05        0.73       0.94       0.49       1.27
1000〜2000       2/ 31      71/338    503/426    457/669   1781/ 987
                 0.06        0.21       1.18       0.68       1.80
2000〜             —       466/247    366/242    274/204        —
                             1.89       1.51       1.34
```

**南極(最左列)以外にも、系統的な誤りが 3 つ見える。**

1. **暑い列(25°C〜)は全域で湿りすぎ、しかも内陸ほどひどい**
   (1.07 → 1.34 → 1.27 → **1.80**)。観測は内陸で減る(1374 → 987)のに、
   モデルは**増える**(1469 → 1781)。サハラ 4.74 倍の正体をこの枠で見ている。
2. **2000km を超えるとどの列でも湿りすぎ**(1.34〜1.89)。
   大陸の深部に雨を配りすぎている。
3. **10〜25°C の列は逆に乾かしすぎ**(0.49〜0.75)。
   C 温帯が乾燥 B に食われる既知の症状と整合する。

**「広すぎる/狭すぎる」の一言では書けない。** 温度と内陸度の両方向に
食い違いの符号が変わる。**降水の分布を 1 つの散らばりの数で語るのは
粗すぎる**ということでもある。

## 【3】前段の読みの訂正 — 「陸の 25%」は面積ではなくセル数

**南極は 1° 格子で陸セルの 28.3% を占めるが、面積では 9.5% でしかない**
([実験記録_冷帯の夏](実験記録_冷帯の夏_2026-08-06.md))。
極ではセルが小さいのに数が多いためである。

したがって:

- 前段の「陸の 25% 以上で W が 0.04mm を下回る」は、
  **面積では 1 割弱**である。分位も重み無しで採っていた。
- [診断_降水の分布](診断_降水の分布_2026-08-13.md) の
  「**下位 25% が壊滅的に乾いている**(観測 120mm 対モデル 7mm)」も
  重み無しの分位なので、**同じ偏りを持つ**。その正体はほぼ南極である。
  あの文書が「乾きすぎているのはどこか」で南極とチベットを挙げたのは
  結果として正しかったが、**チベットは枯渇していない**(W < 0.2 のセロは無い)。

**面積重みつきで測り直した分解は [前段の文書](診断_幅を作っているのはGではなくW_2026-08-15.md)
に追記した。** 重み無しの数字を単独で読まないこと。

## 何が言えるか

1. **モデルの W が 1000 倍動く正体は、南極が 0 へ潰れていることである。**
   2 元表の**中央値で見るかぎり**、最も冷たい列を除いた枠の W は
   0.52〜5.30mm(約 10 倍)に収まる。
   ただしこれは枠ごとの中央値の幅であって、南極を除いた全セルの分布の幅ではない
   — **枠の中央値の幅を分布の幅と読み替えるのは、考察_凝結率の意味が
   7 点平均で犯したのと同じ誤り**である。分布は面積重みつきで測り直す。
2. **南極が乾くのは輸送の到達距離ではなく、冷たい空気に水が無いからである。**
   したがって渦拡散を上げても、滞留時間を伸ばしても(段 19)、
   **根本の位置には届かない**。段 19 で南極が 0.02 → 0.31 と改善したのは、
   滞留を伸ばして「海の上で作った水を落とさずに運んだ」効果であり、
   同じ理由で湿潤域が肥大して成績を 5 点落とした。
3. **実物の南極が年 150mm 降るのは、総観規模の擾乱が暖湿気を突入させるから**
   である(月平均の移流拡散では原理的に作れない)。
   [診断_降水の分布](診断_降水の分布_2026-08-13.md) の読みはここでは正しい。
4. 一方で **南極はケッペン判定では観測もモデルも一律 EF** なので、
   降水が 30 倍外れていても**成績には出ない**。
   直す価値は物理の正しさの側にあり、成績の側には無い。

## したがって次に問うべきこと

**「南極を直すか」ではない。**

前段は「W の幅が広すぎる」を本丸と読んだが、その幅の大半は南極だった。
南極を除いた陸で W と G のどちらが幅を作っているのかを、
**面積重みつきで**測り直してから方針を決める。
それが前段の文書へ追記した分解である。

成績の伸びしろは依然として面積の大きい D 冷帯(24.5%、詳細 19.7%)と
C 温帯(11.7%、大分類 46.8%)にあり、
2 元表ではそこは **−20〜−5°C と −5〜10°C の列**にあたる。
その列の W は 0.5〜1.9mm で、枯渇はしていない。
**この列でモデルと観測がどれだけ食い違っているか**が次の問いである。
