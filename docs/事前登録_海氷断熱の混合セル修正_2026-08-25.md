# 事前登録: 海氷断熱を海成分だけに掛ける(混合セルの式誤り修正、台帳 21a)

日付: 2026-08-25 午後(実装前に書いた)
出所: 外部監査(docs/外部レビュー_機構の不足_2026-08-25.md「2温度場の前に」)。

## 事実(結果に依存しない根拠)

現行 step05: `capEff = (landFrac·C_land + oceanFrac·C_ocean) × (1 − ins·seaW·oceanFrac)`。
海氷断熱(混合層の切り離し)は**海の側だけの現象**なのに、混合後の全熱容量に
係数を掛けるため、oceanFrac=0.5・seaW=1 のとき本来
`0.5·C_land + 0.5·C_ocean·(1−ins)` であるべきところが
`0.525·(0.5·C_land + 0.5·C_ocean)` になる。C_ocean ≫ C_land なので氷結時の
実効熱容量が**約 10 倍過大** — 沿岸ブロックが冬も鈍いまま。

実測(修正前の基準、1°、55-72°N 陸): 振幅誤差は
純陸 −2.9°C / **海混じり −6.6°C** / 海過半 −6.3°C。

## 修正

```
capEff = [ landFrac·C_land + oceanFrac·C_ocean·(1 − ins·seaW) ] × capScale
```

landFrac = 0(純海)と seaW = 0(無氷)は現行と**代数的に同値**。
変わるのは「氷のある混合セル」だけ。

## 予測(測る前に固定)

90. 純海・無氷セルは全月ビット一致(浮動小数の並べ替えによる僅差は
    純海=oceanFrac·C·(1−ins·seaW) 同形なので生じない見込み。生じたら
    その大きさを記録し、1e-6°C 未満なら同値とみなす)。
91. 海混じりブロックの振幅誤差 −6.6°C が **−4.5°C より小さく**なる
    (純陸 −2.9 へ向かう。完全には届かない — 移流結合の共有問題が残るため)。
92. fareast_siberia / alaska の share は微増(箱は内陸主体なので大きくは
    動かない。動けば儲けもの)。
93. 大分類の変化は ±0.3 以内(局所修正)。

## 判定

- 90 ✗(氷の無い場所まで動く)→ 実装バグ。
- 91 ○ → 修正を確定(点数に依らず維持 — 縁海修正と同じ「事実に基づく判断」)。
  v35 較正の物理に含める。
- 91 ✗ → 混合セルの鈍さの主因は断熱式でなく移流結合。修正自体は式として
  正しいので維持するが、台帳 3(海気分離)の優先度を上げる。
