# 事前登録: 蒸発の季節性 — 海上の湿度を定数から「モデル自身の水」へ(台帳 項目 3)

日付: 2026-08-24 未明(実装前に書いた)
診断: scripts/diag_evap_seasonality.ts(2026-08-23)—
**北半球の海の蒸発ピークが 8.9〜9.2 月(初秋)**。実物の中緯度・亜熱帯の海は
**冬に蒸発が最大**(冷たく乾いた大気が暖かい海面上を吹き、湿度差が開く)。
モデルは逆位相。これが W の季節性を殺し、位相 70 日の残り(中緯度・亜熱帯の
冬雨)の真因と絞り込まれた(λ を変えても W の振幅は ±7% のままだった)。

## 原因(式から)

`E = ρ · C_E · |V| · q_s(T_s) · (1 − RH)`、**RH = 0.8 の定数**。
大気側の湿度が季節を持たないので、E は海面温度 q_s(T_s) だけで決まり、
海が最も暖かい初秋にピークが来る。

## 実装(既定 0 でビット一致)

大気側の湿度を**モデル自身の可降水量 W**で季節変調する:
```
RH_m(i) = RH_const × clamp( (W_m(i) / W̄(i))^k , 0.5, 1.2 )   W̄ = 12 か月平均
```
k = `evapHumiditySeasonalExp`(既定 0 = 従来と厳密一致)。冬に W が少ない
(= 乾いた空気)海では RH が下がり蒸発が増える。年平均の RH はほぼ保たれる
(W/W̄ の平均 ≈ 1)ので、全球蒸発量は大きく動かない。
W は前の結合反復の解(warmStart)を使う(コンベアと同じ作法)。初回は変調 1。
W/W_sat を直接使わないのは、モデルの W が実物の 1/6 で絶対湿度としては
使えないため(相対変調だけを借りる)。地理中立・季節相対。

## 予測(結果を見る前に固定)

63. k = 1〜2 で北半球中緯度の海の蒸発ピークが **9.2 月 → 12 月側へ 2 か月以上**動く。
64. W の相対振幅が増える(中緯度 0.28 → 0.4 以上)。
65. 位相(帯別平均)が **2 日以上改善**(v7b の位相項が下がる)。
66. 全球の海上蒸発の年合計は ±5% 以内。大分類は −0.3 以内。

## 判定

- 63・65 ○ → SPACE に [0, 3] で投入し、冬雨機構(winterStormEquatorwardReachDeg)
  と**組で**掃引 → v33 較正。
- 63 ○ だが 65 ✗ → 蒸発は冬へ動いたが降水の位相に届かない = 輸送の経路で
  季節性が消えている。W の位相を段階ごとに追う診断へ。
- 63 ✗ → W の季節性が弱すぎて変調が効かない。k の上限を上げる前に
  W の季節振幅の出所(供給か凝結か)を分解する。

## 追記 1: 初回掃引 — W は真冬へ移ったが結合反復が振動(緩和を追加)

```
k=1.5 の診断: W のピーク 熱帯 1.4 月 / 亜熱帯 1.7 月 / 中緯度 2.1 月(全て真冬!)、
              相対振幅 0.59 / 0.76 / 0.45(← 64 ◎: 0.28 → 0.45 以上)
掃引 k=0/1/2/3: 位相 71.2 / 70.1 / 70.9 / 69.4(k=3 で −1.8 日、65 は半分)
              ゲート 13 → 14(!)、しかし **健全性 ×(全水準)**、所要 364 → 689 秒
```

原因: 前反復の W をそのまま係数に使うと、W→蒸発→W の正帰還が 2 周期振動に
なり結合反復が収束しない(教訓「反復が 2 周期に割れたら遅延を疑う」の同型)。
**処方**: 係数 f を前反復の f と半々に混ぜる緩和 + 振れ幅を [0.7, 1.15] に
絞る。健全性が戻るまで k の掃引は判定に使わない(未収束の数字は採らない)。
予測 63(蒸発ピークの移動)は診断が変調前の蒸発を見ていたため未測定 —
W のピークが真冬へ移ったことを代理指標とする。

## 追記 2: 緩和でも未収束(残差 6〜16 mm/月)→ 定式化を 2 版へ

利得の見積もり: RH=0.8 の変調は (1−RH)=0.2 を相対的に大きく動かし、
W ±20% → 蒸発 ±80%(ループ利得 ≈ 4)。緩和 0.5 でも利得 2 で発散する。
**2 版**: 湿度欠損 (1−RH) を直接 (W̄/W_m)^k で変調(蒸発 × f、f を [0.75, 1.3]
に絞り緩和は維持)。利得 = k なので k < 1 で安定の見込み。物理は同じ
(乾いた月ほど欠損が大きく蒸発が増える)。k の掃引は 0 / 0.3 / 0.6 / 0.9。
予測 63〜66 はそのまま(63 は W のピーク月で代理)。

## 追記 3: 2 版の掃引 — 収束は戻ったが位相は動かない

```
k        0      0.3    0.6    0.9
健全     ○      ○      ○      ○(結合残差 0.176 → 0.161、むしろ改善)
位相     71.2   71.3   71.3   71.4(**動かない**、65 ✗)
大分類   74.38  74.33  74.24  74.17(−0.2、66 ○)
分布誤差 0.490  0.487  0.484  0.483(微改善)
```

利得を下げて収束は戻ったが、位相への効果が消えた。振れ幅 [0.75, 1.3] と
k<1 では W の季節性を動かすに足りない可能性と、W の季節性は動いても
降水の位相に届かない可能性の両方がある。**W の月別を直接見て切り分ける**
(k=0.9 の診断を実行)。

## 追記 4: W 帰還は誤った道具 — 風上の気温で大気側湿度を書く(3 版、実装前に登録)

k=0.9 の診断: W の相対振幅は**減った**(中緯度 0.28→0.18、亜熱帯 0.19→0.10)、
ピークは夏のまま(8.4 / 6.6 月)。負帰還は乾いた月の W を埋める復元力として
働き、季節性を**平坦化**する。1 版で見えた「真冬ピーク」は発散の産物だった。

**正しい物理**: 実物の冬の蒸発極大(黒潮・湾流)は、冬の大陸から吹き出す
**冷たく乾いた空気**が暖かい海面上に来て湿度差 q_s(T_s) − q_a が開くため。
大気側の湿度は**風上の空気**が持ってくる量であり、局所の W ではない。

**3 版**: `q_a = RH × q_s(T_風上)`。T_風上 = 風の向きに 1 セル遡った気温
(月別の気温場と風場は既にある)。E = ρ C_E |V| max(0, q_s(T_s) − q_a)。
冬の大陸風下の海では T_風上 ≪ T_s で q_a が下がり蒸発が増える。
帰還なし(気温は蒸発に依らない)なので安定。定数 `evapUpwindHumidity`
(0 = 従来の局所 RH、1 = 風上。0〜1 で混合)、既定 0 でビット一致。
地理中立(風と気温の場だけ)。

予測(測る前に固定):
67. k=1 で北半球中緯度の海の蒸発ピークが 9.2 月 → **11 月以降**へ(変調後の
    蒸発を見る診断を足して測る)。
68. W の相対振幅が増え、ピークが**冬側へ**動く(中緯度 8.4 月 → 11 月以降)。
69. 位相(帯別)が **2 日以上改善**。
70. 健全性維持・大分類 −0.3 以内。
W 帰還版(evapHumiditySeasonalExp)は**既定 0 で残置し SPACE には入れない**
(分布誤差に微効果があるが位相の道具ではない)。

## 追記 5: 3 版の判定 — 外れ。3 案連続で反復を停止し、構造の結論へ

```
evapUpwindHumidity 0 / 0.5 / 1:
蒸発ピーク(北半球中緯度の海) 9.2 / — / 9.2 月(**不動**、67 ✗)
W ピーク 8.3 月・振幅 0.30(不動、68 ✗)/ 位相 71.2 → 70.9(69 ✗)/ 健全 ○(70 ○)
大分類 74.38 → 74.14(−0.24)
```

1 セル風上では海の隣も海でほぼ同じ気温 — 冷たい大陸気塊の信号は届かない。
数セル遡れば届くが、それは「風上の陸の気温を何日分の移流で混ぜるか」という
**気温の移流モデル**であり、定数 1 つの変調ではない。

## 構造の結論(台帳へ)

3 案(W 帰還 1 版・2 版、風上湿度 3 版)はすべて、**1 セルに気温が 1 つしか
無い**ことに阻まれた。冬の蒸発極大の物理は「海面(SST)は熱容量で暖かいまま・
その上の大気は大陸から来て冷たい」という**海気の温度分離**である。
モデルの EBM の T は海上では混合層の熱容量を持つので SST 寄りで、
大気側の T が無い。**海上の大気温度(移流で運ばれる量)を別に持つ**のが
本筋で、これは段 45(コンベア)級の構造追加。台帳 項目 3 は
「海気分離」に題を改めて [保] とし、設計を別途起票する。

蒸発の 3 定数(evapHumiditySeasonalExp / evapUpwindHumidity)は既定 0 で残置、
SPACE 非投入。
