## 根拠(全部測定済み)

1. C→B(失点の 32%)の主因は **G の沈降残存**(夏 0.48 対 0.71)。
2. その原因はゲートではなく**帯の重なり**(descW 0.999 対 0.637)。
   C→B は夏も沈降帯の芯にいる。実物の夏のモンスーン域では大陸上の下降枝は
   トラフに置き換わる — **モデルは実在しない沈降を敷いている**。
3. 緩めるだけだと**アラビア(正しく乾燥)も条件を満たしてしまう**。
   利用者の問い「アラビアは南端まで乾燥、同緯度の中華は湿潤、なんで?」の
   定説が Rodwell–Hoskins (1996):**モンスーン加熱の西側に下降流が立つ**。
   アラビアはインドの加熱の西。華中は自分が加熱源。
4. モデル内の候補量を全部測って比べた(diag_arabia_vs_china):

```
                         C→B(救う)  B→B(守る)   比
可降水量 W                  2.79      2.83     0.99  ← 無力
供給                       10.1       8.2     1.23  ← 弱い
自列の加熱 H                0.495     0.474    1.04  ← 単独では無力
**H − eastH(R-H 位相)**   0.100     0.044    **2.28** ← 唯一分けられる
```

**Rodwell–Hoskins の位相変数だけが 2 群を分ける。** これをゲートに使う。

## 実装

step06 の沈降合成に第 4 の緩和(モンスーントラフ)を足す:

```
H(col,m)    = min(1, |itczLat|/15) × min(1, 熱帯陸割合/0.3)      ← 加熱
eastH(col,m)= max_{5°..60° 東} H × exp(−距離/30°)                ← 東方の加熱
phase       = clamp((H − eastH) / monsoonHeatContrastNorm, 0, 1)  ← R-H 位相
trough      = monsoonTroughSubsRelief × phase                      (陸のみ・夏半球側)
subs       *= (1 − trough)
```

- 新定数 2 つ: `monsoonTroughSubsRelief`(強さ、**既定 0 = ビット一致**)、
  `monsoonHeatContrastNorm`(位相の規格化、0.1 = C→B の実測中央値)。
- ITCZ 変位・熱帯陸割合・経度方向の位相 — すべて幾何で地理中立。
  逆行では「東」が自転方向で反転し、R-H の物理(加熱の**風上側**に下降)と整合。
- 湿りへの依存なし(乾いた平衡の罠を避ける)。

## 予測(結果を見る前に固定)

`sweep_lever.ts monsoonTroughSubsRelief 0,0.3,0.6,0.9` → 最良水準で
`diag_ctb_gfactors` と validate(地域ゲート)。

1. **C→B の夏の沈降残存が 0.48 → 0.58 以上**(κ=0.6)。
   位相ゲート 1.0 × 0.6 の緩和で帯の芯でも残存が立つ。
2. **アラビア・サハラの地域ゲートは PASS を維持**。B 側の湿潤化は
   位相 0.44 でゲートされ、半分以下に抑えられる。
   **1% 分位の悪化 ≤ +4mm**(64 → 68 以内)。
3. **大分類が +0.2 以上**(C→B 651 セルの一部が C へ戻る)。
   これまでの機構(±0.1 未満)と桁が違うはず — 主因に直接触るため。
4. 連続部分 > 70.40。分布誤差 ≤ 0.412。
5. 数値的健全性(全水準)。

## 判定

- **1〜4 がすべて当たったら**: 採用候補。利用者に裁定
  (探索空間 57+1〜2 で v25)。
- **1 が外れたら**: 位相の規格化か緩和の合成位置が誤り。式を見直す。
- **2 が外れたら**(アラビアが湿る): 位相 2.28 倍では足りない。
  eastH の窓(5〜60°)・減衰(30°)を実測の分離が最大になるよう調整
  — ただし**調整後は必ずこの表を測り直して記録する**。
- **3 だけ外れたら**: 残存は直ったのに分類が動かない = 別の因子が縛っている。
  G 分解を再測。

**目的関数の重みは動かさない。既定値 0 のまま。**
