# 事前登録: 周極海峡の判定が南米南部を巻き込んでいる(段 15)

日付: 2026-08-12
**結果を見る前に書いている。**
前段: [実験記録_渦拡散とパタゴニアの取り違え](実験記録_渦拡散とパタゴニアの取り違え_2026-08-12.md)

## 測って見つけたこと

パタゴニアのゲートは降水ではなく**気温**で落ちている(最暖月 −6.0°C)。
標高は犯人ではなかった(相関 0.10、**低標高セルのほうが誤差が大きい**:
0–200m で −7.28°C、500–1000m で −4.87°C)。

そこで周極海峡の判定を調べた(`scripts/diag_channel_rows.ts`)。

```
緯度    陸割合   海峡判定
 -38.5   5.83%
 -39.5   3.89%  ← 海峡扱い
 -41.5   4.17%
 -43.5   3.33%  ← 海峡扱い
 -45.5   3.06%  ← 海峡扱い
 -48.5   2.22%  ← 海峡扱い
 -51.5   2.22%  ← 海峡扱い
 -52.5   1.67%  ← 海峡扱い
```

**パタゴニアが乗っている行(−43.5〜−52.5°S)はすべて海峡と判定されている。**

海峡行は 3 つを同時に受ける:

| 効果 | 定数 | 値 | 向き |
| --- | --- | --- | --- |
| 南北拡散の低減 | `circumpolarChannelFactor` | 0.48 | 冷やす(暖気が来ない) |
| 海上の雲の増強 | `channelCloudBoost` | 0.54 | 冷やす(日射を削る) |
| 海洋混合層の増深 | `channelMixedLayerBoost` | 3.0 | 冷やす(夏に暖まらない) |

**3 つとも冷やす向き**で、しかも夏に効く(雲と混合層は夏の昇温を抑える)。
最暖月だけ −6.0°C と大きいのはこれで筋が通る。

## 判定の作り自体の問題

`-41.5°S` は 4.17% で非海峡、`-43.5°S` は 3.33% で海峡。
**閾値 4% のすぐ両側で不連続に切り替わっている。**

周極海峡という概念は正しい(南極周極流は実在し、地理中立に書ける)。
だが**「行に陸が 4% 未満なら遮られていない」という二値判定**は、
南米南部のように**細い大陸が横切る行**を「遮られていない」と扱ってしまう。
実際には南米が塞いでおり、その陸上に気候がある。

## 変えるもの

**判定を二値から連続へ変える。** 海峡らしさを

```
channelness = 1 − min(1, 陸割合 / channelLandFracMax)
```

とし、3 つの効果をこの重みで掛ける(現行は 0/1 の階段)。
`channelLandFracMax` は据え置き(0.04)。

- 陸 0% の行は現行と同じ(channelness = 1)
- 陸 3.3% の行は channelness = 0.175 となり、効果がほぼ消える
- 陸 4% 以上は現行と同じ(0)

**新しい定数は要らない。** 階段を線形へ置き換えるだけである。

### なぜ「陸割合で割る」形が正しいか

遮蔽の物理は「流れが陸に当たる割合」なので、陸割合に対して連続に効くのが筋。
二値にする理由は無い。南極海(陸 0%)は完全な海峡のまま、
南米が横切る行は部分的に遮られる、となる。

## 予測(先に書く)

- **パタゴニアの最暖月の誤差が縮む**(−6.0 → −3 前後)。3 つの冷却が
  0.175 倍になるため。
- **南極海の気候は変わらない**(陸 0% なので channelness = 1 のまま)。
- 北半球には海峡行が無いので影響しない。
- 全球の気温 RMSE は改善するはず(南緯 40〜55° の冷えすぎが減る)。

**外れる筋**: 海峡の効果が薄まると南大洋の熱輸送が増えて南極が暖まり、
氷が減って別の場所が壊れる。南極のゲートを必ず見る。

## 判定(先に固定する)

較正 v20 の定数の上で測る。二値/連続の切り替えは `channelnessLinear`(0/1)。

1. **patagonia の最暖月の誤差が −6.0°C から −4.0°C 以内へ縮む。**
2. **antarctica_ice ゲートが PASS のまま。**(外れる筋の番人)
3. **v3 が 84.40 から 1.0 以上落ちない。**
4. **大分類が落ちない。**

1〜4 をすべて満たせば採用。1 を満たさなければ、海峡判定は犯人ではないので
雲と海流を個別に疑う段へ移る。

## やらないと決めていること

- 南米や南緯を名指しした例外(教訓 §1 地理中立)。**陸割合の連続関数だけ**で書く。
- `channelLandFracMax` を同時に動かすこと。階段を連続にする効果だけを見る。
- 3 つの効果を個別に切ること。**まず 3 つまとめて連続化**し、
  効いたら次の段で分解する。
