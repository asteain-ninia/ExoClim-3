# 事前登録: 結合反復に緩和を入れる(段 21)

日付: 2026-08-14
**結果を見る前に書いている。**
前段: [実験記録_凝結率の幅の再測定](実験記録_凝結率の幅の再測定_2026-08-14.md)

## 問い

段 20 の再測定で、CRH の指数抑制は鋭さ 2 以上で**結合反復が発散**した。
そこで「棄却」としたが、**発散が物理の限界なのか反復の作り方の限界なのか**
を分けていない。分けないまま棄却すると、**道具の欠陥を物理の結論として
記録する**ことになる。これは前世代が繰り返した型そのものである。

## 根拠

結合反復は**素のピカール反復**である:

```ts
precipEst = next;          // P(k+1) = F(P(k))。緩和なし
```

一方 virga の外側反復には `VIRGA_RELAXATION = 0.6` が入っている。
既知の実測では、この写像は通常**縮小写像**である:

```
地球       縮小比 0.79、7 回で収束（COUPLING_MAX_ITERATIONS のコメント）
傾斜 80°   単調に 0.79 で減り 13 回で収束
```

指数抑制 `exp(s·(CRH − 1))` は降水の W に対する感度を s 倍する。
W は降水を通じて再循環に返るので、**写像の傾き L が s とともに増える**。
L > 1 になれば素のピカールは必ず発散する。残差が鋭さとともに
4.695 → 26.652 → 46.608 と増えるのは、その形と整合する。

素のピカールが比 L で拡大するとき、緩和 α の反復
`P(k+1) = (1−α)·P(k) + α·F(P(k))` の実効の比は `|1 − α + αL|` になる。
**L < ∞ である限り、α を小さくすれば収束させられる。**

## 決定的な性質(これが無ければやらない)

**緩和は不動点を変えない。** `P = (1−α)P + αF(P)` は `P = F(P)` と同値。
したがって収束したときの答えは緩和の有無で**同じ**であり、
これは**物理の変更ではなく解き方の変更**である。

したがって「較正つまみ」にはならない。α は**答えを決めてはならない量**
であり、EBM の反復数と同じ扱いにする(収束を確かめたうえで使う)。

## 変えるもの

`COUPLING_RELAXATION`(既定 1.0 = 現行と厳密に一致)を導入し、
`precipEst = next` を `precipEst = (1−α)·precipEst + α·next` にする。

**既定 1.0 では 1 ビットも変わらない**ことをテストで守る。

## 実測による前提の訂正(2026-08-14、実装前)

**この事前登録は「発散を緩和で止める」という前提で書いた。実測は違った。**
`scripts/diag_crh_coupling_ratio.ts` の残差列:

```
鋭さ 0  縮小 比 0.55        8 回で収束
鋭さ 1  縮小 比 0.42        7 回で収束
鋭さ 2  緩慢 比 0.99 へ悪化  収束はするが追加で約 250 回
鋭さ 3  停滞 比 1.00        残差 22.62 で固定（2 周期）
鋭さ 4  停滞 比 1.00        残差 41.17 で固定（2 周期）
```

**どれも発散していない。** 壊れ方が 2 種類あり、効く手が逆になる:

- **緩慢**(固有値が +1 へ近づく)。緩和 α<1 の実効比は 1−α(1−L) で、
  **α を下げるほど遅くなる。逆効果。** 効くのは上限引き上げか加速。
- **停滞**(固有値が −1 側)。α=0.5 は −1 を 0 へ写すので**よく効く**。

したがって「緩和を入れれば CRH が救われる」は**成り立たない**。
α で 2 周期を潰しても、その裏に比 0.99 の緩慢な成分が残る。
実装するなら緩和と加速の両方が要り、それでも反復は 1〜2 桁増える。

**この事前登録は実装に進まない。** 前提が実測で否定されたので、
段 20 の棄却は動かない(理由が「発散」から「実用にならない硬さ」に変わる)。
記録は、**同じ思いつきを次のセッションが繰り返さないため**に残す。

以下は訂正前に書いた内容(前提が誤っている。読むときは上を先に読むこと)。

## 予測(先に書く)

- 診断 `diag_crh_coupling_ratio.ts` で、鋭さ 2 以上の残差の比は
  **1 を超えて安定する**(単調拡大)。不規則に暴れるなら緩和では救えない。
- α = 0.5 程度で鋭さ 2 が収束する。鋭さ 4 はより小さい α が要る。
- 収束した鋭さ 2 の W は、未収束時に表示された 9.6mm とは**違う値**になる。
  未収束の値は解ではないので、これは当然である。

**外れる筋**: 比が不規則に暴れる(写像が滑らかでない)。その場合、
指数抑制は不動点そのものを壊しており、緩和では救えない。
そのときは段 20 の棄却が**物理の結論として確定**する。

## 判定(先に固定する)

1. **既定 1.0 で現行と厳密に一致する**(v3 が 85.235 のまま、
   `npm test` 172/172 通過)。**これを満たさなければ即座に棄却。**
2. 緩和を入れた鋭さ 2 で、**5 系統すべてが収束**する。
3. 収束した鋭さ 2 の W と v3 を記録する。
   **ここで初めて、段 20 の問いが正しい形で立つ。**
4. 収束に要した α と反復数を記録する。α が 0.1 を下回るなら
   実用的でない(費用が桁で増える)ので、その旨を明記して打ち切る。

判定 2 を満たしたら、**段 20 の棄却は「道具の欠陥による棄却」だったことに
なる**ので、実験記録を訂正する。満たさなければ棄却が確定する。

## やらないと決めていること

- α を較正の探索空間に入れること(**答えを決めてはならない量**)。
- 既定値を 1.0 以外にすること(現行の答えを変えない)。
- 収束したからといって、成績の判定を緩めること。
  段 20 の判定 5「v3 が 1.0 以上落ちない」はそのまま使う。
