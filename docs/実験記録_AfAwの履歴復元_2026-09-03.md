## 読み

- **Af > 観測・Aw < 観測 の不均衡は保存則転回より前(v15、非保存)から存在**
  (8.7 対 8.2)。「非保存時代は雨林が足りなかった」は 7 月末のアマゾン局所の話で、
  全球の Af/Aw には当てはまらない — 本日の私の説明を訂正する。
- 較正の系列で Af は **8.7 → 11.6(v37)→ 11.0** と単調に近く増え、Aw は
  8.2 → 6.8(v37)→ 7.1。段差は v30→v32(+1.7、陸面摩擦で陸の風が弱まり
  赤道帯の水が滞る向き)と v36→v37(+1.0、閉包と T_bl = 位相を買った版)。
  v40 の 2 温度場で僅かに戻す。
- 同じ期間に大分類は 74.4 → 76.3 と上がっている: Af↔Aw は同じ大分類 A の
  内側の付け替えなので v7b の大分類項には映らず、詳細項(重み 0.25)だけが
  僅かに払う。**物差しが Af/Aw の区別に鈍いまま、後段の機構が赤道帯の
  年中の W を増やす向きに積み上がった**、が交絡込みの読み。
- 上限は「λ が W から降らせる床」(同日の台帳 27 診断)で、どの版でも
  乾季を作れていない。Aw が唯一 10% 台に乗ったのはレジーム系統 v43b(10.3)。
