# 06 降水 — 水収支モデル(mm/月)

実装: `src/sim/step06_precipitation.ts`。ExoClim-2 の 4 段階ラベルを全面置換。
derle-climate の系統バイアス一覧(教訓 §8.2)への正面対応として設計。

## 構成

**降水 = (追跡供給 + 渦供給) × 持ち上げ × 風上遮蔽 × 全球係数 × √気圧**

### 1. 追跡供給(風上トレース)

各セルから月平均風を遡り(1 ステップ = 南北 1 セル相当、最大 5200km)、
経路上の海セルで q_sat(T)/q_sat(20°C) に比例した蒸発を拾う。減衰は
海上 e^(−d/2200km)・陸上 e^(−d/1700km)。

**経路障壁の脱水**: 供給源と対象の間の「これまでの最高標高」が両端より
高い分だけ、拾いを e^(−比高/1600m)(下限 0.25)で減衰(風上斜面で雨として
落ちた分。パタゴニア・チベット風下の雨陰の主機構)。逐次複利にすると丘陵の
起伏が累積し全球が乾く(較正記録 2026-07-30 の失敗)— 最高障壁 1 本で判定。

**陸面再循環(R3 以降は土壌水分の季節記憶)**: 当初はパス 1(海のみ供給)の
降水から陸の湿りを求める無記憶方式だったが、2026-08-01 に**根群域バケツ**へ
置き換えた(下記「6. 土壌水分の季節記憶」を参照)。乾いた砂漠は
自己湿潤しない(サハラ)が、雨の届く内陸は再蒸発で繋がる(シベリア)。

**供給の月ブレンド(R2)**: 供給場を前/当/翌月で 0.25/0.5/0.25 に均す
(循環 3 点、1 月と 12 月は隣接)。月平均風の単一方向トレースは風向の月替わりで
供給が断絶するため。後段の降水場平滑(`precipMonthBlend`)とは役割が異なり、
こちらは非線形変換の**前**に断絶を埋める。

**Fetch 則(WL#32)**: 閉じた内海・湖(海の連結成分で面積 < 1.2M km²。
カスピ海・黒海級。海峡で外洋に繋がる縁辺海は外洋と同成分になり対象外)からの
供給は、水域ごとに保留して横断幅(Fetch)確定時に
f = clamp((min(Fetch, 2000km) + 250km − 進入前陸距離) / 500km, 0.3, 1)
を掛けて計上する。内海は自分の幅ぶんしか内陸を湿らせない。位相判定なので
地理中立。A/B は [../較正記録.md](../較正記録.md) 2026-07-30 参照。

### 2. 渦供給(ストームトラック帯)

移動性低気圧による海からの水蒸気混合は月平均風では表現できない(derle の
中緯度冬雨問題)。リッジ+1°〜極前線+12° の台形帯で、
1.6 × q_sat(T_海+3°C)× e^(−海岸距離/減衰長)、寒候期 ×1.4。
- **T_海 = 近傍(±6 セル)で最も暖かい海面の気温**(冬の東岸の低気圧は
  暖流から汲む — 湾流・黒潮型。局所陸気温では一段低すぎる)。下限 qRel 0.4。
- **減衰長 = 1,400km × (0.5 + 0.5×風上海率)**(WL#31 の onshore 2,000km /
  offshore 1,000km 規則の連続化。風上 500km ウォークの海率で判定)。

### 3. 持ち上げ・抑制(乗算)

- ITCZ 収束: ×(1 + 2.2·影響·**海洋性**)。海洋性 = min(1, 供給/1.1) —
  傘は湿潤収束が豊富なときだけ開く(乾いた内陸のトラフ直下 = アラビア型の
  熱的低気圧は乾いた低気圧のまま)。沈降防護にも同じ重みを掛ける。
- ストームトラック: ×(1 + (1.1 + 冬 0.5)·帯重み)
- 地形性: 上り勾配 ×(1 + 1.6·min(2.5, 勾配/基準))、下り(局所雨陰)
  ×max(0.35, 1−勾配比)
- 亜熱帯沈降: 下降枝全域(リッジ −16°〜+5°)×(1 − 0.68·重み)。
  ITCZ 影響下は 85% 防護。**東岸緩和**: 自転方向の東に海が近い陸は
  ×(1 − 0.8·e^(−距離/900km)) だけ沈降が緩む(亜熱帯高気圧の西翼湿潤 =
  バミューダ高気圧型。トポロジー規則であり座標決め打ちではない)。
- 寒流沿岸(|lat| 10-42°、海岸 300km 以内、近傍 SST 偏差 < −0.8°C):
  ×(1 − 0.45·強度)(ナミブ/アタカマ型)

### 4. 風上山脈の遮蔽(R5: セル内高分位標高)

風上 900km を走査し、経路最大の**稜線標高** − 自標高 > 300m から遮蔽開始、
1200m 超で最大。追跡・渦供給の双方に掛かる(パタゴニア型雨陰)。

**稜線標高 ≠ 平均標高**(2026-08-01、R5)。狭い山脈は 1° 平均で稜線が均される
ため、生の高解像度標高(ETOPO 2022 60 秒)から**セル内 p95 標高**を作り
(`scripts/build_crest_elevation.py` → `src/domain/data/earth_crest_1deg.json`)、
遮蔽・脱水にのみ使う。気温・地表状態は平均標高のまま。実測で狭い山脈と
高原を判別できる: 南部アンデス 989 → 1,734m(1.75 倍)、チベット高原
4,914 → 5,277m(1.07 倍)、アマゾン平地 33 → 43m。粗格子への集約は最大値
(遮蔽は最も高い壁で決まる)。高解像度データの無い地形(手続き生成・
簡易プリセット)では稜線標高 = 平均標高で、演算子は全惑星共通。

## 5. 結合反復(土壌 ⇄ 再循環 ⇄ 降水)

供給 → 降水 → 土壌水分 → 蒸発散 → 供給 の輪を、**後処理(冬季床の再配分・
降水の月平滑)まで含めた一つの演算子**の固定点として解く。反復内と最終出力で
同じ演算子を使わないと、土壌が収支に使った降水と最終降水が食い違う。

- 収束指標: 陸面積重み平均 |ΔP|、許容差 0.20 mm/月、上限 8 回(較正対象外)。
- 未収束は診断に `converged: false` として残す。
- 最終の土壌診断は収束後の最終降水場で解き直す(統合水収支が閉じる)。
- 実測: 0.5°/1°/2°/4° すべて 5 回で収束、水収支残差 0.0000 mm/年。

## 6. 土壌水分の季節記憶(R3)

各陸セルに月別貯水 S(mm)を持ち、乾季へ前月までの雨を持ち越す。

```
available = 前月貯水 + 当月降水
wetness   = clamp(available / 容量, 0, 1)
ET        = min(available, 可能蒸発散(気温) × wetness)
runoff    = max(0, available − ET − 容量)
S         = clamp(available − ET, 0, 容量)
```

- 容量 600mm(深根系の植物利用可能水量)、可能蒸発散は 20°C で 90mm/月、
  0°C 以下は 0(凍結)。
- 12 月 → 1 月を接続し、年間貯水変化が許容差(陸セル平均 0.05mm)を下回るまで
  空回し(上限 2000 年)。初期貯水に依らない決定的な周期定常解。
- 大気への供給は**実蒸発散(質量フラックス)**に比例させる。湿り度分数
  S/容量 での正規化は実測で悪化した(供給はフラックスであって湿り具合ではない)。

## 7. 保存型水蒸気輸送(P2-1、実装済・未接続)

上記の「追跡供給」は湿潤源への**到達可能性**であって水蒸気量ではない。
可降水量 W を状態とする保存型の定常解を `src/sim/moisture_transport.ts` に
実装済み(風上有限体積・共有面フラックス・凝結項は陰的)。全球水収支を
5e-9 で閉じるが、凝結率に既存の経験的倍率を使う限り地域判別は改善しない
(FB対応記録 P2-1)。接続には凝結の物理化(上昇流の導入)が必要。
