# 00 基盤 — 格子・軌道・日射

実装: `src/domain/grid.ts` / `src/domain/insolation.ts` / `src/domain/terrain.ts`

## 2. 格子

- 緯度経度規則格子。**row 0 = 北端(+89.5° 側)、col 0 = 西端(−179.5° 側)**、
  行優先フラット配列。経度は循環(`wrapCol`)。
- 表示格子は既定 1°(360×180)。面積重みは cos φ。
- 地形は標高(m、海は負の水深)+ 陸海マスク。実在地球プリセットは
  ETOPO 2022 の 1° 中心サンプル(`scripts/build_earth_fixtures.py`)。
  陸海マスクの面積重み陸率 29.1%(実地球 29.2%)。

## 3. 軌道と日射

- ケプラー方程式 M = E − e·sinE を Newton 法で解き(≤32 反復、決定的)、
  真近点角 → 太陽黄経 λs = ν + 近日点季節位相。赤緯 δ = asin(sin ε · sin λs)。
- **月の定義**: 北半球冬至(λs = 270°)の平均近点角を月 0 の開始とし、
  平均近点角を 12 等分(等時間)。任意の惑星で「月 6-8 = 北半球夏」が保たれる。
  地球では月 0 ≈ 1 月(近日点が λs=283° のため)。
- 日平均日射: Q = (S0/π)·(a/r)²·(H0 sinφ sinδ + cosφ cosδ sinH0)、
  H0 = acos(−tanφ·tanδ)(極夜 0 / 極昼 π)。月内 4 点サンプル平均。
- 検証済み: 全球年平均 ≈ S0/4 = 340 W/m²、赤道 417、極 175(実地球一致)。
- 恒星定数 S0 = 1361·L/a²。公転周期はケプラー第三法則(M∗ ≈ L^{1/4})。

## 4. 派生場(SimContext)

- 海岸距離(陸→海、海→陸)は 2 パス Chamfer 距離変換(経度循環対応)を
  行の平均セル寸法で km 化。`src/sim/context.ts`。
