## 支配方程式

粗格子(既定 2°)上の海面高度相当温度 T_sl について

```
C·dT/dt = S(t)·(1 − α) − (A_eff + B·T_sl) + ∇·(D∇T_sl) − 移流結合 + Q_ocean
```

を時間積分し、周期定常に達した年の月平均を記録する。

### 数値解法(2026-08-01 に隠しパラメータを除去)

- 各ステップの陰解法は**残差基準**で反復する。許容 `EBM_SOLVE_TOLERANCE_C = 1e-3`°C、
  上限 `EBM_MAX_SWEEPS = 400`。
  **かつての「ガウス=ザイデル 8 掃引固定」は隠しパラメータとして除去した**
  (打ち切り回数が答えを決めていた。教訓 §9)。
  `EBM_SOLVER.sweeps` は 0 が既定で、> 0 のときだけ回数固定になる**調査用**。
- 年数は周期定常に達するまで伸ばす(`EBM_FULL_CAPACITY_START_YEARS = 24` から
  開始し、ドリフトが残れば `EBM_MAX_FULL_CAPACITY_YEARS = 64` まで倍化)。
  序盤 `SPINUP_ACCEL_YEARS = 2` 年は熱容量を縮めた加速スピンアップ。
- 収束の実測値は `npm run validate` の「数値的健全性」で毎回判定する
  (残差・年次ドリフトの両方。未収束の解は較正で**失格**にする)。

## 項ごとの定義と、効く定数

### C(熱容量)

- 海 = 混合層深さ(利用者パラメータ)+ **大気 2.4 m/bar**(表面気圧に比例)。
- 陸 = `landEffectiveWaterDepthM` × (乾き補正) + **0.5 m/bar**。
  乾いた土壌は熱容量が小さい(`landDryCapacityFrac` で湿りとの内挿)。
- 周極海峡行の海は `channelMixedLayerBoost` 倍(深い鉛直混合)。
- **海氷断熱**: 氷結海面は混合層を大気から切り離すため、実効熱容量を
  `× (1 − seaIceInsulationFactor × 氷被覆 × 海率)` に毎ステップ縮小。

### α(アルベド)

惑星値 = 雲 + (1−雲)·地表。

- 地表: 陸 `albedoLand` / 海 `albedoOcean` / 季節雪氷 `albedoIce`
  (`iceOnsetC`(陸)・`seaFreezeC`(海)からランプ)/ 恒常氷床 `permanentIceAlbedo`。
- 雲は循環変調(下記)。

### A_eff, B(外向き長波放射)

- `A_eff` = `olrAWm2` − 温室強度の効果(利用者パラメータ)− `olrBWm2PerC`·Γ·h
  (標高 h の補正。輸送を T_sl 空間 = 温位相当で解くため)。
- **`B` = `olrBWm2PerC`。**
  > **注意(2026-08-16)**: B は**気候感度を支配する**。地球の気温分布は
  > 「A と B の組」で決まり、平均場だけからは B が一意に決まらない。
  > 惑星応答の測定で**日射 1% あたり 1.36°C**(実物の 2〜3 倍)と判明した。
  > 未対処。正本: [実験記録_惑星応答の初測定](../実験記録_惑星応答の初測定_2026-08-16.md)

### D(拡散熱輸送)

`diffusionWm2PerK` を基準に、次を掛ける:

- **半径²** (`radiusRatio²`)。小さい惑星ほど熱が全球に行き渡る。
- **表面気圧^`heatTransportPressureExponent`**(段 40、2026-08-16 追加)。
  南北熱輸送は大気の質量流量に比例する成分を持つ。**地球 1 bar で厳密に 1**。
  これが無いと気圧を 4 倍にしても赤道-極差が 0.1°C しか動かなかった。
- 利用者パラメータ「熱輸送強度」。
- ハドレー域は `hadleyDiffusionBoost` で増強(熱帯を平坦化)。
- 東西は縮小 + 計量上限 `zonalMetricCap`(等方だと大陸規模の季節モードが潰れる)。
- 周極海峡(陸率の低い行)を跨ぐ南北拡散は縮小(ACC 効果)。

### 移流結合(2026-07-30 に 2D 化)

Step 4 の月別 2D 風を EBM 格子へ集約し、風上セルとの固定結合
(`zonalAdvectionCouplingWm2PerK`)。

- 東西 u は全域。南北 v は**リッジより極側のみ** — ハドレー域の南北輸送は
  拡散増強で表現済みで、v を足すと「冷気コンベア」の二重計上になる。
- v には周極海峡の隔離則と陸グリップを掛ける。
  夏半球は `summerAdvectionFactor`(ジェット弱化)、
  冬の陸は `winterInversionAdvectionFactor`(接地逆転層)、
  同じく拡散側に `winterInversionDiffusionFactor`。
- **セル熱容量には掛けない**(海面が風速で流される誤りになる)。

### Q_ocean(海洋熱輸送)

Step 3 の海流分類から SST 偏差として与える(`sstAnomalyCouplingWm2PerK`)。
蒸発の潜熱冷却は `evapCoolingWm2PerMmDay`。

### 雲アルベド変調(月別セル別)

基準は利用者パラメータ。これに循環による変調を掛ける:
沈降域 `subsidenceCloudReduction`(海は `subsidenceOceanFactor`)、
ITCZ `convectiveCloudBoost` と `itczCloudWidthFactor`、
ストームトラック海上 `stormTrackCloudBoost`(夏 `stormCloudSummerOcean`)、
寒流上の層積雲 `stratocumulusBoostPerNegC`、陸の供給規格化 `landCloudSupplyNormMm`、
周極海峡行 `channelCloudBoost` / `circumpolarChannelFactor`。上限 `cloudAlbedoMax`。

### 氷(2026-08-04 に 0 層模型を採用)

- **恒常氷床**: パス 1(氷なし積分)の年平均・最暖月の条件で判定し、
  隣接陸へ限定的に拡張(氷床の流動近似)。
- **海氷 = 0 層熱力学模型**(`seaIceModel = 1`)。**旧「季節ランプのみ」は廃止。**
  氷厚 h を状態に持ち、表面(EBM が解く T)と海(凍結点に固定)を
  氷を通じた熱伝導 `F = seaIceConductivityWmK × (T_freeze − T) / h` でつなぐ。
  F ∝ 1/h なので厚いほど成長が鈍る(Stefan の √t 則)。

  | 定数 | 役割 | 性質 |
  | --- | --- | --- |
  | `seaIceModel` | 0 = 旧季節ランプ / 1 = 0 層模型(現行) | 切替 |
  | `seaIceConductivityWmK` | 氷の熱伝導率 | **物性値**(較正つまみではない) |
  | `seaIceLatentJPerMm` | 融解潜熱 ρL | **物性値** |
  | `seaIceMinThicknessMm` | 伝導評価時の氷厚下限 | **数値の下限**(k/h の発散防止)。2 倍・1/2 で答えが変わらないことを確認すること |
  | `seaIceCoverScaleMm` | アルベド・断熱が飽和する氷量 | 較正対象。薄氷ほど開水面が増える連続化 |
  | `seaIceInsulationFactor` | 氷結時に熱容量を縮める率 | 較正対象 |

  設計: [../設計_海氷の潜熱と伝導_2026-08-04.md](../設計_海氷の潜熱と伝導_2026-08-04.md)

## 出力(表示格子へ降尺度)

T_sl を双一次補間し、`T_surf = T_sl − Γ·h`(Γ = 減率)。
月別気温・年平均・最暖/最寒月・雪氷マスク。
