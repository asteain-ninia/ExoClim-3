# 05 気温 — 2 次元エネルギー収支モデル(EBM)

実装: `src/sim/step05_temperature.ts`。ExoClim-2 の経験 2 段階スケールを全面置換
する v3 の中核。設計判断の経緯は [../較正記録.md](../較正記録.md)。

## 支配方程式

粗格子(既定 2°)上の海面高度相当温度 T_sl について

```
C·dT/dt = S(t)·(1 − α) − (A_eff + B·T_sl) + ∇·(D∇T_sl) − 移流結合 + Q_ocean
```

を陰解法(ガウス=ザイデル 8 掃引/ステップ、240 ステップ/年 × 4 年、
序盤 2 年は C×1/16 の加速スピンアップ、温暖側初期化)で積分し、
最終年の月平均を記録する。

- **C(熱容量)**: 海 = 混合層深さ(利用者パラメータ、既定 50m)+ 大気 2.4m/bar。
  陸 = 1.2m 水当量(実大陸の位相遅れ ≈27 日から逆算)。
  周極海峡行の海は ×3(深い鉛直混合)。
- **α(アルベド)**: 惑星値 = 雲 + (1−雲)·地表。地表 = 陸 0.12 / 海 0.07 /
  季節雪氷 0.33(T_surf < 陸 −6°C・海 −1.9°C からランプ幅 5°C)/
  恒常氷床 0.62。雲は循環変調(下記)。
- **A_eff**: A(=203、全球平均 14.5°C へ較正)− 22·log2(温室強度) − B·Γ·h
  (標高 h の OLR 補正。輸送は T_sl 空間 = 温位相当で解くため)。
- **B** = 2.1 W/m²/°C。
- **D(拡散)**: 南北 0.55 W/m²/K(× 半径², × 熱輸送強度、× 海 1.2)。
  ハドレー域(リッジ内側)は ×(1+1.1·(1−(φ/リッジ)²))(熱帯を平坦化)。
  東西は ×0.12・計量上限 2(等方だと大陸規模の季節モードが潰れる)。
  周極海峡(陸率 <4% の行、|lat|≤70°)を跨ぐ南北拡散は ×0.45(ACC 効果)。
- **移流結合(2026-07-30 に 2D 化)**: Step 4 の月別 2D 風を EBM 格子へ集約し、
  風上セルとの固定結合(40 W/m²/K @4m/s、実効風速は東西 7 / 南北 5 m/s で頭打ち)。
  東西 u は全域。南北 v は **リッジより極側のみ**(+10° ランプ)—
  ハドレー域の南北輸送は拡散増強で表現済みで、v を足すと「冷気コンベア」
  (シベリア→インド)の二重計上になる。さらに v は周極海峡の隔離則
  (×0.45)と陸グリップ(0.25 + 0.75×陸率 — 海面温度への大気移流の掴みは
  小さい)を掛ける。夏半球 ×0.42(ジェット弱化)、冬の陸 ×0.5(接地逆転層)。
  セル熱容量には掛けない(海面が風速で流される誤りになる)。
  これで冬の大陸冷気の吹き出しと海からの暖気移流が経度別に表現される
  (西欧の ET 41→28%、熱帯沿岸の冬 +2〜3°C、1月 RMSE 6.4→6.0)。
- **雲アルベド変調(月別セル別)**: 基準は利用者パラメータ(既定 0.2)。
  沈降域(リッジ −16°〜+5°、陸全効・海 45%)×(1−0.55)、ITCZ +45%、
  ストームトラック海上 +60%(夏 ×0.35)、寒流上の層積雲 +35%/−2°C。上限 0.36。
- **恒常氷床**: パス 1(氷なし積分)の年平均 < −8°C かつ最暖月 < +2°C の
  陸優勢セル。さらに最暖月 < +6°C の隣接陸へ最大 4 回拡張(氷床の流動近似)。
  海氷は季節ランプのみ(夏は融解で 0°C 近傍に張り付くため)。

## 出力(表示格子へ降尺度)

T_sl を双一次補間し、T_surf = T_sl − Γ·h(Γ = 5.8°C/km)。月別気温・
年平均・最暖/最寒月・雪氷マスク。

## 検証状態(2026-07-29)

全球年平均 15.2°C(2026-07-30、2D 移流化後)。帯状の年平均は北半球 ±2°C 以内。
既知の弱点: 北極の夏 −15°C 級(最大バイアス)、南半球中緯度 +7°C 前後、
南極内陸の寒気不足(+12°C)。気温 RMSE 年 7.89 / 1月 5.99 / 7月 12.1°C。
