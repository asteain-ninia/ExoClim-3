## 判定(Peel et al. 2007 / Beck et al. 2023 の標準閾値)

月別気温(°C)・降水(mm)から、**B → A → C/D → E の順**(Beck 実装と同じ)。
**緯度帯・海岸側・地理を決め打ちした強制ルールは存在しない**(教訓 §1 の三原則)。

- 夏半年 = 北半球は月 3-8(冬至起点の月定義で 4-9 月相当)、南半球は逆。
- B: MAP < 10×Pth、Pth = 2·MAT (+28 夏雨型 / +14 混合 / +0 冬雨型)、負は 0。
  BW: MAP < 5×Pth。h/k: MAT 18°C。
- A: Tcold ≥ 18。Af: Pdry ≥ 60 / Am: Pdry ≥ 100 − MAP/25 / Aw: それ以外。
- C: 0 < Tcold < 18 かつ Thot > 10。D: Tcold ≤ 0 かつ Thot > 10。
  - s: 夏最乾月 < 40 かつ < 冬最湿月/3。w: 冬最乾月 < 夏最湿月/10。
    両立時は夏雨合計 > 冬雨合計なら w。それ以外 f。
  - a: Thot ≥ 22 / b: 10°C 以上月 ≥ 4 / d(D のみ): Tcold < −38 / c: 残り。
- E: Thot < 10。ET: Thot > 0 / EF: Thot ≤ 0。
