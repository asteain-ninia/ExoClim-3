# 事前登録: 収束している場所の沈降抑制を緩める(段 10)

日付: 2026-08-11
**結果を見る前に書いている。**
前段: [実験記録_熱的低気圧の深さ](実験記録_熱的低気圧の深さ_2026-08-11.md)
(段 9 は 2 版とも棄却。東アジアは熱的低気圧の問題ではないと判明)

## 測って見つけたこと

`scripts/diag_front_firing.ts` で、未達地域の夏の凝結率の内訳を出した。

```
地域   前線持上げ 収束持上げ 遮蔽  沈降残存 凝結率G 前線の発火セル%
east     1.070    1.000   1.000   0.546   0.614      16%
us       1.857    1.000   1.000   0.526   0.964      80%
india    1.000    1.000   1.000   0.758   1.741       0%
west     1.302    1.000   1.000   0.984   1.797      31%
congo    1.000    1.000   1.000   0.982   1.823       0%
```

**2 つ分かった。**

### 1. 中緯度東岸の凝結率が沈降抑制で半減している

east_asia の沈降残存 **0.546**、us_southeast **0.526**。
つまりこの 2 地域は「亜熱帯の沈降域だから雨を減らす」という扱いを受けており、
凝結率がおよそ半分に削られている。熱帯(0.76〜0.98)と比べて突出して低い。

**実物では、亜熱帯高気圧の沈降は東縁(大陸の西岸沖)に偏る。**
西縁(大陸の東岸)はむしろ収束して雨が降る — バミューダ高気圧の西縁が
米南東部へ、太平洋高気圧の西縁が東アジアへ南風を送る形である。
緯度帯で一律に抑制すると、**この東西の非対称が表現できない**。

### 2. 収束による緩和と持上げが、どちらも 0 で無効

```
convergenceLiftBoost: 0          湿潤収束による持上げ
convergenceSubsidenceRelief: 0   湿潤収束による沈降抑制の緩和
```

定数のコメントに理由が書かれている:

> 注: 沈降緩和と同時に効かせると二重増幅で結合反復が不安定化しうるため、
> 単独実験で分離して測る(2026-08-01 の外部レビュー指摘)

**単独実験は行われないまま 0 で残っている。** しかもこの判断は
**非保存のモデルでの話**である。保存型では事情が変わる:

- 非保存では「収束で持ち上げる」は供給を二重に数える危険があった
- **保存型では収束は既に W の増加として表れている。**
  収束で足すべきなのは水ではなく**凝結率**であり、二重計上にならない
- 不安定化の懸念も、いまは結合反復の収束を毎回検査している(段 8 で
  上限 8 → 24 にした際に確認済み)ので、**測れば分かる**

## 変えるもの

`convergenceSubsidenceRelief` を 0 から上げる。

```
沈降残存 = 1 − subsidenceSuppression × sink × (1 − relief × 収束度)
```

収束度はモデルが計算している水蒸気フラックス収束指数(`convergenceIndex`)。
**緯度も海岸も名指ししない**(教訓 §1 地理中立)。
実物の「高気圧の西縁は収束、東縁は沈降」がこれで表現される。

`convergenceLiftBoost` は**同時に動かさない**。外部レビューの懸念どおり
二重増幅を分離するため、まず緩和だけを測る。

## 判定(先に固定する)

較正 v20 の定数の上で測る(`scripts/exp_pressure_lever.ts`)。

1. **未達 3 地域(india / us_southeast / east_asia)の夏の正味流入が
   揃って正へ動く**、**または**降水そのものが観測へ近づく。
   ※ この機構は「運ぶ」ではなく「降らせる」側なので、流入が動かなくても
   降水が増えれば目的は達している。**両方を見る。**
2. **対照 2 地域(congo / europe_russia)が壊れない。**
3. **v3 が 84.025 から 1.0 以上落ちない。**
4. **結合反復と輸送が収束する**(未収束 0)。二重増幅の番人。
   1 件でも未収束が出たら、値に関わらず棄却する。

1〜4 を満たすうち v3 が最良の値を採る。全部満たす値が無ければ棄却。
