# 事前登録: 凝結閉包 c の再訪 — 鎖が繋がった後で「水をためる」は買われるか

日付: 2026-09-01(測る前に書いた)
文脈: v42 採用直後。冬雨型の時計分解(out/diag_winter_decomp_v42.log)で
中緯度 35-60 の宿題が確定した — **G の暦は正しい(condRateG 12.3 月・
振幅 0.48)のに、W が夏型(7.7 月・振幅 0.50)で降水を 10.8 月へ引く**。
観測ピークは 1.1 月。残差 −2.3 か月は「冬の W の崩落」が原因。

## 機構仮説(結果に依存しない)

凝結閉包(2026-08-26 実装)C = lin·W + conv·(W−cap)⁺、
lin = (1−c)·rate_old + c·bg、cap = RHcrit·W_sat(T)/G。
- c を上げるほど排水が「G 直結の rate_old」から「遅い背景 + cap 超過対流」へ
  移る。**冬は寒く(W_sat 小)G が大きいので cap が下がり、凝結効率が
  相対的に冬>夏になる** — 分解が要求する「冬の効率 2〜3 倍」の正しい住所。
- c は v36 系で SPACE にあり、v40/v42 とも **0.132** で着地。ただしその判定は
  reach(亜熱帯の冬の持ち上げ)不在の時代のもの。v42 で
  bg 凝結時定数が上限 90 日に張り付いた =「水をためたい」勾配は立っている。
- 本日の教訓(stormTrackBoost の下限剥がれ): 「均す」に負けるのは機構が
  孤立しているとき。鎖(T_bl・reach・2 温度場)が繋がった今、再掃引する価値。

## 掃引と測定

c ∈ {0.132(v42 基準), 0.4, 0.7}(1°・v42 採用定数・他は不変)。測るもの:
- 帯×季節型の位相表(35-90 冬雨の RMSE/符号が主標的)

- 68 ○(冬雨の針が動く)→ v43 = c 高め種(+τ_bg・RHcrit・conv の閉包 4 定数
