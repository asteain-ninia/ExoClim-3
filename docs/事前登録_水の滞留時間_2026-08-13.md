# 事前登録: 大気の水の滞留時間を実物へ合わせる(段 19)

日付: 2026-08-13
**結果を見る前に書いている。**
前段: [診断_凝結が速すぎる](診断_凝結が速すぎる_2026-08-13.md)

## 測って分かったこと

```
モデルの滞留時間   陸 1.9 日 / 海 1.7 日
実物              約 9 日（全球降水 1000mm/年 ÷ 可降水量 25mm = 年 40 回転）
```

**水が実物の 5 倍の速さで落ちている。** 滞留 2 日では風速 10 m/s でも
1,700km しか進めず、南極内陸・チベット・大陸内部へ構造的に届かない。

段 1 で保存型へ移すとき、非保存の距離減衰 `moistureDecay*Km` を
**そのまま凝結寿命として読み替えた**。意味が「供給が届く距離」から
「水が落ちるまでの時間」へ変わったのに、値を測り直していない。

## 変えるもの

凝結率は `λ = condensationRefWindMs / moistureDecay*Km`。
**分子の `condensationRefWindMs`(10.95 m/s)を下げて滞留時間を伸ばす。**

| 値 | 陸の滞留 | 備考 |
| --- | --- | --- |
| 10.95 | 1.9 日 | 現行 |
| 5.5 | 3.8 日 | |
| 2.7 | 7.7 日 | 実物にほぼ一致 |
| 1.8 | 11.5 日 | 実物より遅い |

**分母(距離)ではなく分子(基準風速)を動かす**理由: 距離のほうは陸海比を
持っており、その比は非保存時代に較正で決まった意味のある構造である。
分子は「λ を作るための係数」でしかないので、こちらで時間を合わせる。

## 予測(先に書く)

- **南極・チベット・大陸内部が湿る。** 水が届くようになるため。
  南極は観測比 0.01 → 0.3 以上へ動くはず。
- **サハラも湿る。** 内陸へ水が届くのだから当然で、**これが最大の危険**。
  現在すでに観測の 4.74 倍なので、さらに膨らむと砂漠が消える。
- 陸平均降水は増える(現在 701 対 観測 767)。
- **v3 は落ちるかもしれない。** 砂漠が壊れれば大分類が落ちる。

**外れる筋**: 滞留を伸ばしても内陸が湿らない。その場合、水が届かないのは
凝結の速さではなく**輸送そのもの**(風・拡散)の問題である。

## 判定(先に固定する)

較正 v22 の定数の上で測る。

1. **antarctica の年降水が観測比 0.01 → 0.20 以上。**
2. **tibet の年降水が観測比 0.06 → 0.20 以上。**
3. **サハラが観測比 4.74 から悪化しない**(= 増えない)。**逆効果の番人。**
4. **v3 が 85.235 から 1.0 以上落ちない。**
5. **輸送と結合反復が収束する**(未収束 0)。

1・2 を満たし 3 を満たさない場合は**保留**とし、
「内陸へ届かせると砂漠が壊れる」というトレードオフを別途扱う
(そのときは凝結率を湿り度で変える案が次の候補になる)。

## やらないと決めていること

- 滞留時間を合わせると同時に他の定数で砂漠を補償すること。**1 本ずつ。**
- 較正で吸収させること。**物理の目標(9 日)を先に決めて、そこへ合わせる。**
