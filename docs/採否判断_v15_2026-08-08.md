## 1. 数値的健全性 — PASS(必須条件)

```
EBM 残差 4.58e-5°C / 年次ドリフト 7.90e-3°C / 全熱容量 24 年 / 反復 512
```

許容差(残差 1e-3、周期定常 0.05)をどちらも 1〜2 桁下回る。
**海氷を入れても収束は悪化していない**(残差の測定順序の不具合を直したため。
直す前は 26.4°C で張り付き、費用が 25 倍になっていた)。

### 改善は「較正を余分に回したから」ではない

較正後の点で**陸の雲だけを切る**と v3 は **85.004** まで落ちる。
これは v13evap(85.769)にも届かない。**+0.42 は新しい機構そのものが稼いだ。**

```
boost   0      0.1     0.2      0.3     0.4
v3    85.004  85.703  86.190  86.022  85.398
```

較正**前**は v3 が boost に対して単調減少で、探索空間へ入れれば 0 へ戻る形だった。
較正**後**は 0.2 に内部の最大ができている。**谷は渡れていた。**

## 代償 — 悪化した項目を隠さない

**湿潤温帯の乾燥化は、むしろ進んだ。**

| 地域 | 基準(2026-07-31 凍結) | v13evap | **v15** | 第一目標 |
|---|---:|---:|---:|---:|
| 中国東部 年降水 | 401mm | 340mm | **350mm** | ≥ 750 |
| ラプラタ 年降水 | 444mm | 244mm | **261mm** | ≥ 700 |
| 温帯 C の乾燥 B 化 | 4.2pt | — | **5.3pt** | 0 |

中国東部とラプラタは v13evap よりわずかに戻したが、**凍結基準からは依然として退行**。
系統ハズレ追跡の「温帯 C の乾燥 B 化」は 4.2 → 5.3pt と**悪化**している。

これは [R3 の診断](実験記録_温帯の乾燥化_2026-08-07.md)が指した問題そのもので、
**v15 は温帯の乾燥化を直していない**(直すつもりの版でもなかった)。
ただし「悪化させた」可能性は残るので、R5 では**陸の対流雲が降水へ与えた影響**を
最初に確認する(雲で夏の陸が冷えれば対流も弱まるため、機構として繋がっている)。

一方で改善した地域指標もある:

| 地域 | 基準 | **v15** | 第一目標 |

| パタゴニア東部 年降水 | 1942mm | **921mm** | ≤ 900(あと 21mm) |
| アマゾン 年降水 / 最乾月 / Af+Am | — | **3 項目とも達成** | — |
| 南緯 30-40° 温暖バイアス | 5.2°C | **0.0°C** | 0 |

**南緯 30〜40° の温暖バイアスは消えた。** 北極圏 70-80°N は 4.5 → 5.5°C と悪化。

## 参照値との比較(単独では落とさない)

```
⚠ 気温年 RMSE 3.85°C > 基準 3.80°C
```

2026-07-31 に凍結した唯一の未達項目。v13evap の 4.16°C から 3.85°C まで詰めて、
**残り 0.05°C**。この基準は数値の欠陥を含んだ状態で得られたもので、
収束解へ移った時点で 6.80°C まで落ちた経緯がある(docs/退行防止ゲートの扱い_2026-08-02.md)。

## 最終受入ゲート — 未達 2 件(変わらず)

```
⏳ 地域ゲート 14/17 — 全件 PASS が必要
⏳ 帯状平均気温の最大乖離 25.5°C > ±5°C(60°S の 7 月)
```

帯状乖離は 26.4 → 25.5°C とわずかに改善したが、**桁が違う**。
南大洋(60°S の 7 月にモデルが 25.5°C 低い)が主因で、
0 層海氷は双安定を壊したが**南大洋の絶対的な冷えすぎは解いていない**。

## 結論

**採用する。** 5 点すべてで条件を満たすか、満たさない項目は理由が説明できている。

- 数値的健全性 … PASS(必須)
- 新旧両目的関数 … どちらも改善。しかも**機構を切ると v13evap にも届かない**
- 季節指標 … 詳細 +0.94・位相・気温 RMSE が改善、年較差のみ +0.05 悪化
- 地域ゲート … 不変(下げていない)
- 未見評価 … 過剰適合なし。訓練・未見とも v13evap から改善

**採用しつつ、湿潤温帯の乾燥化が進んだことを次の作業(R5)の起点にする。**
