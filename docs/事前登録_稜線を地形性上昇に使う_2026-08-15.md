# 事前登録: 稜線の場を地形性上昇・雨陰に使う(段 26)

日付: 2026-08-15
**結果を見る前に書いている。**
前段: [実験記録_CRHを輸送の内部で解く](実験記録_CRHを輸送の内部で解く_2026-08-15.md)(段 25)

## 問い

今日、乾いた端を作る手を 3 通り試してすべて棄却した(段 19 の再確認 /
段 22 virga / 段 25 CRH)。いずれも **λ·G の全球の水準を下げる**手で、
**すべて中位の陸を乾かした**。例外は無かった。

残っている別の入口は、**G の側から特定の場所だけ**乾かす手である。
全球の λG 水準を動かさないので、今日 3 回失敗した路線と原理的に違う。

その筆頭が**地形性の雨陰**である。

## 現状(調べた事実)

- 稜線の場(`earth_crest_1deg.json`、生 ETOPO 60 秒角のセル内 p95)は
  **既に存在し、`maxMeters` も入っている**。
- **風上遮蔽 `upwindMountainFactor` は既に稜線を使っている。**
- **地形性上昇・雨陰(`liftOro`)は稜線を使っていない** —
  `orographicCrestBlend = 0` で無効化されている。
- 無効化の理由は[較正記録](較正記録.md)に残っている:

  > 稜線推定(プロミネンス × 0.8): パタゴニアに BSk が出たが、コンゴ盆地の縁など
  > 「高原の段差」まで稜線扱いになり熱帯壊滅(64.6%)。係数 0 で無効化し配管のみ残す。

**この判断は 2026-07-31 頃、非保存の時代のものである。**
段 6(2026-08-09)で保存型へ移行し、降水は輸送方程式の解になった。
段 22 で virga について「非保存で測った結果は**別の演算子**の結果であり、
棄却根拠にならない」と整理したのと**同じ論法**が当てはまる。

したがって、**データ工事(セル内起伏の追加)に進む前に、いまのモデルで
測り直す**。安く済み、結果次第で次の設計が変わる。

## 変えるもの

`orographicCrestBlend` を 0 / 0.25 / 0.5 / 0.75 / 1.0 で掃く。
他の 62 定数は v22 のまま。`CRH_INNER` は無効、`subCloudEvapCoef` は 0。

この定数は `liftElev()` で使われ、**陸セルのみ**、
`m + blend·(crest − m)` の形で平均標高と稜線標高を混ぜる。
1.0 で完全に稜線、0 で完全に平均(現行)。

## 予測(先に書く)

- **パタゴニアの過湿が改善する。** 現在 年 667mm / 観測 428mm(比 **1.56**)。
  雨陰が効けば風下が乾く。**これが主判定。**
- **コンゴが壊れる方向へ動く。** 較正記録の失敗がそこだった。
  ただし保存型では「削った水は消えず下流へ回る」ので、
  非保存のときほど壊滅的にはならないと見る。**番人はここに置く。**
- 乾いた端の 1% 分位は**あまり動かない**。雨陰が効くのは山地の風下という
  限られた面積で、全陸の 1% 分位を動かすほどの広さは無いと見る。
  **動いたら望外の収穫。動かなくても棄却理由にはしない**(主判定ではない)。
- 中位(50%)は**下がらない**。全球の λG 水準を動かさないため。
  **ここが今日の 3 つの棄却との違い。中位が下がったら、
  「場所を選んで乾かす手なら中位を守れる」という私の読みが誤り。**
- 費用はほぼ変わらない(倍率を 1 つ掛けるだけ)。

**外れる筋**: 1° 格子では地形性上昇の比が 0.05 前後にしかならないので
(2026-08-12 実測: パタゴニアのアンデスで 4.6 m/km、峰を使っても 7.6)、
**稜線に替えても勾配が足りず、何も動かない**。
その場合は「機構が格子の粗さに殺されている」ことの確認になり、
処方はセル内起伏のデータ工事へ移る。

## 判定(先に固定する。結果を見てから緩めない)

1. **既定(0)で現行と一致**。v3 **85.235**、乾いた端 **64 / 88 / 468**。
2. **収束**: 5 系統すべて未収束 0。満たさない水準は適用範囲外。
3. **主判定**: パタゴニア東部の年降水／観測が **1.56 → 1.30 以下**へ下がる。
4. **番人(壊さない)**: 大分類が **74.49 から 1.0 以上落ちない**
   (較正記録の失敗は熱帯壊滅で 64.6% まで落ちた。そこを見張る)。
5. **番人(中位)**: 乾いた端の 50% 分位が **468 を下回らない**。
   段 22・25 と同じ閾値を使う。
6. **番人(地域)**: コンゴが **1.01〜1.61**、サハラが **4.74 を超えない**。
7. **費用**: 1 水準 **900 秒**以内(単独換算 = 秒 × 150 / 水準 0 の秒)。

3〜7 をすべて満たす水準があれば**採用候補**とし、再較正へ進む。

  (**1 度に 1 つ**)。

  (まず現行データで測る。工事は結果を見てから設計する)。
