# 診断: 南極を除き面積で重みをつけると、モデルの降水は**観測より狭い**。足りないのは乾いた端

出力: `out/diag_condensation_width3.txt`

**この文書が、2026-08-13 以来ねじれていた「幅」の議論の決着である。**

## 決定的な数字

南極(60°S 以南)を除き、**面積重みつき**で採った陸の年降水:

```
分位      実効G        W(mm)     降水モデル   降水観測
  1%     2.287e-1       0.438         64          9     ← モデルは 7 倍湿っている
  5%     3.009e-1       0.835         88         47     ← 1.9 倍
 25%     6.822e-1       1.585        241        300     ← 0.80
 50%     1.303e+0       2.292        468        593     ← 0.79
 75%     1.800e+0       4.188        995       1157     ← 0.86
 95%     2.364e+0       6.050       2353       2385     ← 0.99
 99%     2.907e+0       7.248       2968       3292     ← 0.90

対数標準偏差   降水モデル 0.429   降水観測 0.530
1〜99% 幅      降水モデル 46.2 倍   降水観測 365.8 倍
               実効G 12.7 倍   W 16.6 倍
```

**モデルの分布は観測より狭い(0.429 対 0.530)。1〜99% の幅は 8 倍足りない。**

そして**狭さは片側にしかない**:

- 下位 10% は**湿りすぎ**(1% で 7 倍、5% で 1.9 倍)
- 中位 25〜75% は**乾かしすぎ**(0.79〜0.86)
- 上位 95〜99% は**ほぼ合っている**(0.90〜0.99)

**モデルは「本当に乾いた場所」を作れない。** 最も乾いた 1% でも年 64mm 降る。
観測の 1% は年 9mm である。

## 3 つの訂正

### 訂正 1: [診断_降水の分布_2026-08-13] の「過剰な広がり」は成り立たない

あの文書は「モデルの対数標準偏差 1.052 対 観測 0.586。**圧縮ではなく
過剰な広がり**」と結論した。**面積の重みが無く、南極を含んでいた。**

```
                        モデル   観測
重み無し・南極込み       1.052   0.586   ← あの文書
面積重み・南極込み       0.709   0.560
面積重み・南極を除く     0.429   0.530   ← 逆転する
```

**あの文書が「外れた」と書いた当初の仮説(分布が中央へ圧縮されている)は、
正しく測れば当たっていた。**

### 訂正 2: [考察_凝結率の意味_2026-08-13] の「幅が足りない」は正しかった

ただし根拠にした「G は 3.8 倍しか動かない」は 7 点の地域平均の産物で、
全セルでは 12.7 倍ある。**結論は正しく、数字と理由づけが間違っていた。**

### 訂正 3: 私が同日に書いた「幅の 91% は W」も取り下げ済み

面積重みを外していた。前段の文書の冒頭に訂正を入れた。

## 何が乾いた端を塞いでいるか

**G と W のどちらも、2 桁の乾きを作れない。**

```
実効 G  1% = 0.229、中央 1.303  → 中央から 5.7 倍しか下げられない
W       1% = 0.438mm、中央 2.292mm → 5.2 倍しか下げられない
```

W の下限 0.44mm には説明がつく(**以下は見積りであって実測ではない**)。
渦拡散 D = 2.98e6 m²/s と実効凝結率 λG ≈ 15.7/月 から拡散長は **706km**、
移流長は **1834km** で、大陸のほとんどは海からその数倍の内側にある。
実測でも温暖な陸の W は内陸へ 1264km 進んでも 2.9〜4.2mm と**ほとんど減らない**
([診断_枯渇しているのは南極だけ](診断_枯渇しているのは南極だけ_2026-08-15.md) 【4】)。
**水はどこにでも配られている。** そこに G ≈ 1 が掛かると年 60〜80mm が
下限になり、実測の 1% 分位 64mm と桁が合う。

> **証拠の格**: 「W が内陸でほとんど減らない」は実測。
> 「だから拡散が下限を作っている」は、拡散長と移流長からの見積りである。
> 決着させるには渦拡散を下げて W の下限が下がるかを見る必要がある
> (`moistureEddyDiffusivityM2PerS` の掃引。未実施)。

一方 G の下限 0.229 は、抑制がすべて**線形の倍率**だからである
(沈降残存の下限 1 − 0.774 = 0.226 が効いている)。
**線形の倍率をいくつ掛けても、それぞれの下限の積までしか下がらない。**

## 要る補正はどの既存量とも揃っていない

観測に合わせるのに要る補正 `P_obs/P` と各倍率の相関(面積重み、南極を除く):

```
可降水量 W                  −0.255
持上げの積 lifts             −0.176
実効 G                      −0.150
沈降残存 subsidenceResidual  −0.041
風上遮蔽 upwindBlock          0.000
CRH 抑制 crhSuppression       0.000
```

**どれも弱い。** 既存のつまみを回して届く形ではない
(全陸で見ると W が −0.659 だが、それは南極が作っている相関である)。

## ここから言えること

1. **本丸の立て方が変わる。** 「W の全球平均が実物の 7 分の 1」は、
   大半が南極の枯渇だった。南極を除いた陸で足りないのは
   **乾いた端を作る能力**である。
2. **段 20(CRH の指数抑制)の主判定は、誤った標的の上に立っていた。**
   事前登録の主判定は「W が 20〜30mm に入る水準がある」だったが、
   W の全球平均は南極に支配された量である。棄却そのものは事前登録の規定に
   従っており**取り消さない**。だが**同じ機構を、正しい標的(乾いた端)で
   問い直す余地がある**。
3. **問い直すなら、判定条件を先に固定し直すこと。**
   結果を見てから緩めるのは禁止事項である。標的が変わったのだから
   **新しい事前登録**を書く(古い判定を書き換えるのではない)。
4. **同時に、較正の交絡を外さないと公平に測れない。** 段 20 も再測定も、
   他の 62 定数を**鋭さ 0 に対して較正された v22 の値**に固定して掃いている。
   降水を配り直す機構は、その機構が無い前提で較正された定数の下では
   必ず不利に出る。掃引で見るのは分布の形、成績の判定は再較正の後。
