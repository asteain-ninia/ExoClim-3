# 検証: 保存則の源泉(蒸発)は物理的に妥当な大きさか — **通過**

日付: 2026-08-09
事前登録: [docs/事前登録_保存則への移行_2026-08-09.md](事前登録_保存則への移行_2026-08-09.md) の S2
道具: `scripts/exp_evap_source.ts`、`src/sim/evaporation.ts`

## なぜ関門を置いたか

利用者の警告(2026-08-09):

> 保存ということは、**もとの量を見誤れば誤差が非常に大きくなる**ことが予想されます。

非保存の乗数方式なら局所に留まる誤差が、保存則の下では下流へ運ばれて非局所になる。
そして接続先の源泉は、これまで**一度も検証されていなかった**
(海面蒸発はモデルに存在せず、SST は採点されていない)。
だから輸送を繋ぐ前に、源泉だけで独立の関門を通す。

## 結果 — 主判定・副判定ともに通過

```
C_E        海の平均   陸の平均   全球平均   海/陸   緯度最大   主判定
1.0e-3      1247       513      1035     2.43    20°N ○      ○
1.2e-3      1496       513      1213     2.92    20°N ○      ×
1.5e-3      1870       513      1479     3.65    20°N ○      ×
```

実地球との比較(C_E = 1.0e-3):

| | モデル | 実地球 |
|---|---:|---:|
| 海面蒸発 | 1247 mm/年 | 約 1150 |
| 陸面蒸発散 | 513 mm/年 | 約 500 |
| 全球平均 | 1035 mm/年 | 約 1000 |

- **主判定**(全球平均 900〜1100 mm/年): ○ 1035
- **副判定 1**(海/陸 が 1.5〜3): ○ 2.43
- **副判定 2**(緯度分布の最大が亜熱帯): ○ **20°N**。赤道ではない
- **副判定 3**(現行の降水と桁が合う): ○ 陸平均降水 742mm/年 と同じ桁

## 特筆すべき 2 点

### 陸面蒸発散 513mm/年 は C_E に依らない独立の一致

これは既存の土壌バケツが出している量で、バルク係数を一切通っていない。
それが実測の約 500mm/年 とほぼ一致した。**源泉の陸側は元から正しかった。**

### 副判定 2 は「風の場が検証されていないこと」の踏み絵だった

事前登録にこう書いていた:

> ただし**緯度分布(副判定 2)が怪しい**。現行の風速場は帯状テンプレート由来なので、
> 亜熱帯の貿易風が実物より弱ければ蒸発の最大が赤道へ寄る。
> ここで落ちたら、それは**風の場の検証が無いこと**の最初の実害になる。

実際には 20°N に最大が来た。**貿易風帯で蒸発が最大**という実物の構造が
出ているので、風速場は少なくとも蒸発を駆動する範囲では壊れていない。

## 正直に書くべきこと — C_E は範囲の下端を選んだ

`C_E = 1.0e-3` は観測の妥当範囲 1.0〜1.5e-3 の**下端**である。
既定にしていた 1.2e-3 では全球平均 1213mm/年 で主判定を外した。

**SST と風速の誤差をこの係数が吸収している面は確実にある。**
範囲内に収まってはいるが、「たまたま合った」のではなく
「範囲の端を選んだ」ことを記録しておく。
**風の場と SST が採点されるようになったら測り直すこと。**

## 判断

**S2 通過。S3(保存型輸送の接続)へ進む。**

ただし事前登録どおり、接続は**置換であって追加ではない**。
「水が保存しないことの補償」だった乗数
(`orographicDepletionM` / `upwindBlock*` / `eastCoastSubsidenceRelief` /
`moistureDecay*Km`)は、凝結率の係数へ写すか、外す。
2026-08-04 の P2-1 棄却は乗数を残したまま足していたので、同じ轍は踏まない。

## 教訓

- **保存則を入れる前に、源泉を単独で検証する。** 利用者の警告がそのまま
  設計の順序になった。源泉が外れていたら、増幅された誤差を成績で
  追いかけることになり、それは前世代が停止した構造そのものである。
- **独立に決まる量が一致すると、検証の価値が跳ね上がる。** 陸面蒸発散 513 は
  バルク係数を通っていないので、「合わせた」のではなく「合った」量である。
  こういう量を 1 つでも見つけて突き合わせること。
