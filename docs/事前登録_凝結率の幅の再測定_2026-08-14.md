# 事前登録: 凝結率の幅を汚染なしで測り直す(段 20 再測定)

日付: 2026-08-14
**結果を見る前に書いている。**
前段: [診断_Wの累積汚染](診断_Wの累積汚染_2026-08-14.md)
訂正対象: [実験記録_凝結率の幅](実験記録_凝結率の幅_2026-08-14.md)

## なぜ測り直すか

段 20 の掃引は 2 つの穴を抱えていた。

1. **W が累積平均だった**(積算器のリセット漏れ)。表の W は無効。
2. **収束を印字していなかった。** 元の事前登録は判定 5 に
   「輸送と結合反復が収束する(未収束 0)」を**すでに含んでいた**が、
   道具がその数字を出さなかったため、判定が素通りした。
   鋭さ 8 の W = 328mm は解ではなく反復の打ち切りである疑いが濃い。

道具はどちらも直した。**同じ実験を、正しい計器で回す。**

## 変えるもの

`crhSuppressionSharpness` のみ。`crhFromWater = 1` は固定(保存型の W から
CRH を作る配管そのものは段 20 で通っており、そこは争点ではない)。

掃く値: **0 / 1 / 2 / 3 / 4**

- 0 は現行(対照)。
- 4 は段 20 が採ろうとした値。**逆算(真の W ≈ 55mm)の検算**を兼ねる。
- 1〜3 は**一度も測られていない**。前任が「指示がなければ C(鋭さ 2)を
  測っておきます」と書いて実行しないまま止まった区間そのもの
  ([教訓.md §11](教訓.md))。

費用の見積: 0 が 225 秒、4 が 1714 秒。中間は単調と仮定して合計 70 分前後。

## 予測(先に書く)

- **鋭さ 4 の真の W は 29.1mm より大きい**(見積もり 30〜45mm)。
  この不等号は逆算の仮定に依らない([診断_Wの累積汚染](診断_Wの累積汚染_2026-08-14.md))
  ので、**29.1mm 以下が出たら私の汚染の読み自体が誤り**であり、
  そのときは掃引の再現性から疑い直す。
- **W = 25mm 付近を通る鋭さが 1〜3 の間に存在する。** 指数なので
  W は鋭さに対して急峻に増えるはずで、2 前後を予想する。
- **その水準では v3 の低下が 3.45 より小さい。** 鋭さ 4 の −3.45 は
  行き過ぎ(W が実物の 2 倍)の代償を含んでいるため。
- サハラは鋭さとともに単調に乾く(4.74 → 3 台)。

**外れる筋**: W が鋭さに対して急峻すぎて 25mm 付近を通らずに飛ぶ
(例: 鋭さ 2 で 8mm、3 で 60mm)。その場合、CRH の指数抑制は
幅を作る道具として**粗すぎる**ことになり、鋭さを連続の較正対象に
するのではなく**別の変数を探す**。

## 判定(先に固定する)

較正 v22 の定数の上で測る(現行 HEAD の定数。鋭さ以外は動かさない)。

1. **収束**: 各水準で未収束 0 件・virga 未収束 0 件。
   未収束が出た水準は**適用範囲外**とし、その行の W も v3 も読まない。
   これは段 20 で素通りした判定の再掲であり、**最初に見る**。
2. **主判定**: 未収束 0 の水準の中に、**W が 20〜30mm に入るもの**がある。
3. **番人(乾燥域)**: その水準でサハラの年降水が観測比 3.5 以下。
4. **番人(湿潤域)**: その水準でコンゴが観測比 1.31 から ±0.3 以内。
5. **成績**: その水準で v3 が現行 85.235 から **1.0 以上落ちない**。
6. **費用**: その水準で 1 評価 600 秒以下
   (8 時間で 48 評価。62 定数にはまだ足りないが、多重格子前の目安)。

- 1〜4 を満たし 5 を満たさない → **保留**。「独立の観測量 W が実物に合う
  設定で成績が落ちる」ことの意味を利用者に諮る。**勝手に目的関数を変えない。**
- 2 を満たす水準が無い → **棄却**。外れる筋の通り、別変数を探す。
- 1〜6 をすべて満たす → **採択候補**。ただし採択の確定には、その鋭さを
  固定した**再較正**(62 定数の再最適化)が要る。段 20 の −3.45 は
  補償側を再最適化していない状態の数字だったという前任の指摘は、
  この点については依然として正しい。

## やらないと決めていること

- 未収束の行を「解」として表に載せること。
- 目的関数・採点の変更。
- 結果を見てから判定の閾値を緩めること。
