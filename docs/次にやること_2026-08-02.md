## 3. 降水の乾側の構造的欠陥(ご指摘 2・3・4 の根)

最乾セル月の **71.6% が供給ちょうど 0**。乾く → 蒸発散 0 → 陸面供給なし →
乾く、という**厳密なゼロの固定点**がある。実在の砂漠にも大気水蒸気はあるので
これは構造の誤り。

本命は **P2-1 保存型水蒸気輸送**(`src/sim/moisture_transport.ts`、実装済み・
未接続)。可降水量 W を状態にして収支を閉じるので、移流で必ず水が入り込み、
**厳密なゼロが原理的に消える**。

過去に「接続には凝結の物理化が要る」と判断して止まっているが、
**乾側のゼロを消すことだけが目的なら、凝結係数の精度は二の次**である。
事前登録すべき問い:

> 保存型輸送に置き換えると、(a) 供給が厳密に 0 のセル月は消えるか、
> (b) 降水の下位分位は観測に近づくか、(c) ケッペン一致率は下がらないか。

(c) には前科がある — **分位を実測に近づけると地図は悪くなる**
(渦拡散の 3 実験)。ただし拡散は空間の低域通過であり、保存型輸送は
向きのある移流なので、同じとは限らない。**測って決める。**

## 4. 季節の誤差(ご指摘 1・9)

修正後も残っている:

| | 値 |
|---|---:|
| 季節位相の遅れ(対観測) | +22.7 日 |
| 内陸(海岸 1000km 超)の季節振幅の過大 | +3.85°C |
| 沿岸(300km 未満)の季節振幅 | −0.87°C |

減衰 B を上げると両方改善するが平均気候が壊れる(実測)。
陸の実効熱容量は探索空間に入れた(較正が触れるようになった)。
残る候補は**海の実効的な熱交換**(現行は放射のみ B = 2.1 W/m²/K で、
実際の海面は蒸発・顕熱でもっと強く大気と結合している)。
