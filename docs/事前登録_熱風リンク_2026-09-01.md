# 事前登録: 段 10 熱風リンク — 偏西風の振幅が季節(温度勾配)を読む

日付: 2026-09-01(実装前に書いた)
文脈: v42 採用後の追跡診断 3 連(時計分解 → c 掃引の棄却 → 移入分解 →
西風季節性)で容疑が一点に絞られた。

## 根拠(実測、結果に依存しない)

1. 中緯度冬雨型の陸への正味移入は水の 82%(主役)だが、**暦が 10 月ピーク**
   (観測の雨は 12〜1 月)。移入 ≈ 上流海洋 W × 風で、海洋 W は 9 月ピーク。
2. **モデルの西風は反季節**: 40-60° 海上の u が DJF 7.4 対 JJA 10.2
   (比 0.72)。実物は冬に約 2 倍。バンド位置は季節移動するが振幅
   (westerlyWindMs)は定数で、冬はバンドが赤道側へ縮んで実効風速が落ちる。
3. **温度場は既に正しい季節性を持つ**: ∂T/∂y(30-40 対 55-65)は
   DJF/JJA 比 1.65(実物 ≈2)。2 温度場の成果。読む側が居ないだけ。
   (out/diag_westerly_seasonality.log / diag_winter_import_v42.log)

## 実装(既定 0 でビット一致)

新定数 `thermalWindFactor`(既定 0)。
- 2 パス目の airflow(thermalLow 用の既存配管を拡張)がパス 1 の月別気温を
  受け取り、半球ごとに B(m) = 行平均 T(|lat| 30-40) − 行平均 T(55-65) を計算。
- 正規化 s(m) = 1 + factor × (B(m)/B̄ − 1)(B̄ = 年平均、箍 [0.5, 1.7])。
- **偏西風帯の帯状卓越風(bu・bv)のみ**に乗算。貿易風・極東風・気圧勾配風は
  触らない。地理中立(行平均・半球相対、緯度経度の名指しなし)。
- CPU のみ(EBM 非接触 = GPU 3 実装規則の対象外)。airflow の 2 回目は
  thermalFeedback フラグを factor > 0 でも立てて確保。

## 掃引と測定

factor ∈ {0, 0.75, 1.5}(1°・v42 定数)。測るもの: 西風の DJF/JJA 比・
帯×季節型の位相表・移入の暦(可能なら)・fitness・大分類・主要ゲート・分位。

## 予測(実装前に固定)

72. u(北 40-60 海)の DJF/JJA 比 0.72 → factor 1.5 で **1.0 以上**。
73. 35-90 冬雨の符号 −76.6 日 → 遅い方向へ ≥ +8 日。RMSE 87.2 → 80 以下。
74. 単独 fitness は −0.5 まで受容。健全性 PASS・気温 RMSE ≤ 4.4。
75. 巻き添え監視: 35-90 夏雨(夏の風が弱まる側)RMSE 36.7 → 40 まで受容。
    東岸ゲート(east_asia・argentina)の share 悪化は「夏の輸送弱化」の
    シグナルとして量を記録(判定には 73 と 74 を使う)。

## 判定

- 72・73 ○ → SPACE に [0, 1.5] で投入。v43 = thermalWindFactor +
  stormTrackWinterBoost + reach の冬系共調整。
- 72 ○ だが 73 ✗(風は季節化しても雨が動かない)→ 移入の暦を直接測り直し、
  「風でなく上流 W の暦」が残る唯一の因子 = 海洋 W の秋偏りの分解へ。
- 74 ✗(−0.5 超)→ どの帯が払ったか分解してから組の設計を見直す。

## 判定(2026-09-02 未明): 72 ○ / 73 ✗ — 風は季節化したが雨は動かない

掃引実測(1°・v42 定数、out/sweep_thermalwind.log。全テスト 235 緑・
既定 0 は HEAD とハッシュ完全一致):

```
tw     fitness   u比(DJF/JJA)  35-90冬雨 RMSE/符号   us_southeast  gobi
0      73.449    0.72          87.2 / -76.6          0.615         0.261
0.75   73.259    0.85          87.3 / -75.2          0.661         0.201
1.5    73.226    1.02          87.1 / -75.4          0.689         0.192
```

- 72 ○: 比 0.72 → 1.02(機構は機械的に成立)。
- 73 ✗: 冬雨は不動(+1.2 日のみ)。**風を倍にしても、上流海洋の W が
  実物の 1/5〜1/13 しか無いので冬の移入は運べない。**
- 登録どおり SPACE 投入は見送り(実装は既定 0 で残置 — 機構は正しく、
  W が本物になった後に再訪)。
- ✗ 分岐(上流 W の分解)の実測が**物差しの核心**に到達:
  海 25-40N の W = 模型 2.8mm 対 観測 20.6mm(DJF)。位相の残債は
  「W の薄さ」の症状で、v7b は W を採点しないため探索がここを直せない。
  → 台帳 22 の登録分岐「物差し改訂を諮る」が発動。v8 酸性試験の再走へ
  (登録済みの再走条件 = 凝結閉包の実装後、を満たしたため)。
