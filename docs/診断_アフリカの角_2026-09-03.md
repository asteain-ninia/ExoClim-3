## 読み

- 観測は春(4-5 月)と秋(10-11 月)の二峰の弱い雨季で、**盛夏(6-9 月)は乾く**
  (10-20mm)。模型は盛夏に 250-290mm — 真逆。
- 模型では 6-9 月に subs=0・liftItcz 3.3-3.9・G 4.6-5.6: **ITCZ の雨帯が角の
  緯度(10N)に乗り、沈降ゼロ**。風は u −1.2 / v +2 と弱い(実物のソマリジェットは
  南西から海岸に平行に 10-15 m/s)。
- 実物の盛夏の角が乾く仕組み: 越赤道流が東アフリカ高地に沿って北東へ転じる
  低層ジェット → 海岸に平行・下流で加速 = **発散**・沿岸湧昇で冷たい海 →
  沈降。雨帯(モンスーントラフ)はアラビア・インドの側へ遠く北上している。
- 模型の欠け: (1) 越赤道流の海岸沿いジェット(強い along-shore 流)が無い、
  (2) ジェットに伴う発散が沈降場に入らない(subs は亜熱帯高気圧の幾何のみ)、
  (3) ITCZ 帯が角の経度で 10N に留まる(トラフの北上が足りない)。
  8/28 の「傘発散ゲート」撤退時の観察(角の風は陸向き収束)と整合。

## 追記: 越赤道モンスーン流の 3 定数はすべて 0・SPACE 外(過去 4 連敗の系譜)

crossEquatorialMonsoon 0 / monsoonMeridionalReversal 0 / monsoonInflowMs 0
(段 39・41・42・43 の死因: 定常輸送では局所の風いじりは場が汲み直して正味輸入を
作れない → 経路のある流れ = コンベア 段 45b へ移行済み)。角の問題はこの
一族の「輸入」でなく**盛夏に角を乾かす**こと。設計の軸は (a) 角の経度で ITCZ が
10N に居座る(トラフの北上不足)、(b) ジェット下流の発散 → 沈降(subs=0 の穴)。
まず経度別(30-60E を 2° 刻み)に JJA の ITCZ 中心と降水重心を模型対観測で測る。

- 模型の ITCZ 中心は 30-60E で一様に 10-11N(経度によらず)。角の経度
  (45-49E)では観測の JJA 陸雨がほぼ無いのに、模型は中心 10N の帯で陸 6-9N に
  250-290mm/月 を降らせる。
- 51E 以東では模型の陸雨の重心も 16-23N と観測に一致(アラビア南岸・オマーン)。
  つまり「トラフの北上」そのものは 51E 以東では成立しており、角の経度だけが
  **ITCZ 帯の中心線が海岸沿いジェットに置き換わっていない**。
- 実物: 45-50E・0-12N の盛夏は南西→北東の低層ジェット(海岸に平行)で、
  収束線は無い。模型の ITCZ 構造(全経度で中心緯度に収束線を置く)が、
  ジェット領域にも収束を置くのが根本。

## 設計の方向(次章の候補、事前登録はまだ)

- ジェット領域の判定を地理中立に書く: 「越赤道の子午流が、夏半球側の
  大陸東岸(西側に陸・東側に海)に沿って走る経度列」= 赤道をまたぐ帯で
  西隣が陸・当該列が海〜海岸の幾何。そこでは ITCZ 帯の持ち上げを弱め
  (収束線でなく通過流)、下流(極側)で発散 → 沈降を置く。
- 既存部品: somaliUpwellingC(SST 側、SPACE 内・生存)、itczDivergenceSuppress
  (傘発散ゲート、既定 0・撤退済み — 発散場が無いのが死因)。
- 前提: 風場に沿岸ジェットが無い(u −1.2 / v +2)。ジェット無しで抑制だけ
  置くのは名指しに近づくので、ジェットの形成(高地・海岸に沿う転向)を先に。
