## 判定: 棄却(0 のまま)

1. **✅ W が 3.4 → 29.1mm**(目標 8 以上)。実物の約 25mm にほぼ一致。
2. **❌ サハラ 3.25**(目標 3.0 以下)。僅かに届かない。
3. ✅ コンゴ 1.31 → 1.47(許容 ±0.3 の内)。
4. **❌ v3 が −3.45。**
5. **❌ 鋭さ 8 以上で解が壊れる**(下記)。

条件 2・4・5 が不成立なので棄却。

## 主判定は通った — **W が合わせずに実物へ着地した**

**W は採点にも目的関数にも入っておらず、較正が一度も触ったことがない量**である。
それが、CRH を保存型の W から厳密に作っただけで **3.4mm → 29.1mm**
(実物 約 25mm)へ動いた。

**合わせに行っていないのに合った。** 閉包の形が正しかったことの独立な証拠で、
利用者の指摘「実測に合わせるのは観測合わせでは」への答えでもある。

サハラも 4.74 → 3.25 と乾いた。**指数の幅は狙いどおり効いている。**

## 鋭さ 8 以上は解が壊れている

```
鋭さ 8   W = 328.8mm   鋭さ 12   W = 462.4mm
```

実物の可降水量は 25mm、飽和柱水量(30°C)でも 40〜50mm である。
**462mm は物理的にありえない。** 1 評価 7775 秒(基準の 35 倍)であることと
合わせて、**輸送か結合反復が収束していない**と読むのが自然である
(掃引の表に未収束の件数を出していなかった — 道具の不備)。

指数抑制を強めると乾燥域の凝結がほぼ止まるので、水が溜まり続ける。
`crh = min(1, W/W_sat)` は W が W_sat に達すれば抑制が解けて自己制限するはずだが、
**その前に反復の上限に当たっている**可能性が高い。

## 費用の問題

```
鋭さ 0 →   225s
鋭さ 4 →  1394s（6 倍）
鋭さ 8 →  7775s（35 倍）
```

**凝結率の幅を桁で開くと、輸送の求解が桁で遅くなる。**
これは多重格子の必要性を跳ね上げる — 較正 1 回が現実的でなくなる速度である。

## 残る問い(利用者の裁定が要る)

**採点に入っていない独立の観測量(W)が実物へ着地したのに、成績は 3.45 落ちる。**

- 現行(W = 3.4mm)は**物理的に明確に間違っているが成績が良い**
- 鋭さ 4(W = 29.1mm)は**物理的に正しいが成績が悪い**

これは 2026-08-11 に切り分けた「物差しの問題ではない」とも、
段 19 の「τ は独立でない」とも違う。**今回は独立の観測量が味方している。**

判断の材料:
- 大分類 −2.25、詳細 −1.77。落ちるのは east_asia の 0.17 → 0.03 と
  湿潤域の肥大(ヨーロッパ 0.74 → 0.88)。
- 費用が 6 倍になるので、採るなら多重格子が前提になる。
- サハラは改善する(4.74 → 3.25)。**乾燥域の表現は良くなっている。**
