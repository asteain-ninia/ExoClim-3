# 事前登録: EBM の格子は 2° でなければならないか(段 17)

日付: 2026-08-13
**結果を見る前に書いている。**

## なぜ

1 評価 146 秒のうち **74% が EBM**。多重格子に入る前に、
**格子そのものを粗くできないか**を先に確かめる(実装が要らず、5 分で分かる)。

EBM は表示格子(1°)ではなく `ebmResolutionDeg: 2` の粗格子で回っている。
この 2 という値は、**下向きに測られた形跡が無い**。
今日だけで同じ型が 3 件当たっている(反復 512 / 結合反復の上限 8 /
地形性上昇の基準勾配 800)。

格子を粗くすると二重に効く: セル数が 1/(比)² に減り、
かつガウス=ザイデルの収束も速くなる(格子が粗いほど低周波が早く伝わる)。

## 変えるもの

`ebmResolutionDeg` を **2(現行)/ 3 / 4** で掃く。

## 予測(先に書く)

- 3° で 1 評価が 2 割以上速くなる。4° なら半分近く。
- **成績は落ちる。** 沿岸・山地の温度勾配が鈍るので、大分類が 0.5 前後
  落ちるのではないか。落ち方が許容内なら「速さを買う」判断になる。
- 帯状平均の気温はほとんど変わらない(南北の構造は 4° でも解ける)。

**外れる筋**: 降尺度(粗格子 → 表示格子)が標高補正込みで働くので、
粗くしても成績がほとんど落ちない可能性がある。その場合は**ただの得**になる。

## 判定(先に固定する)

1. **v3 が 85.235 から 0.5 以上落ちない。**
2. **大分類が 0.3 以上落ちない。**
3. **地域の年降水比が ±0.05 以内。**
4. **1 評価の壁時計が有意に下がる**(他プロセスを止めた状態で 10% 以上)。

1〜3 を満たすうち最速の値を採る。満たさなければ現行(2°)のまま。

## やらないと決めていること

- 速くなったからという理由だけで成績の低下を受け入れること。判定 1〜3 が先。
- 表示格子(1°)を粗くすること。**これは EBM の内部格子だけの話**である。
