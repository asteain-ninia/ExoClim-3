# 実験記録: 渦拡散は犯人ではなかった。そしてパタゴニアは降水の問題ではなかった

日付: 2026-08-12
事前登録: [事前登録_水蒸気の渦拡散が強すぎないか](事前登録_水蒸気の渦拡散が強すぎないか_2026-08-12.md)

## 段 14: 棄却。予測は**向きごと**外れた

```
拡散(m²/s)   v3      大分類  詳細   patagonia 年降水／観測
2,057,275  84.396  74.14  44.34        1.48   ← 現行
1,000,000  82.872  73.25  43.03        1.66
  500,000  81.567  72.56  41.89        1.83
```

**拡散を下げるとパタゴニアはさらに湿る。** 予測は「風下が乾けるようになるので
1.2 台へ下がる」だった。逆だった。単調で明確なので、残り 2 値(2e5・5e4)は
測らずに打ち切った(判定は決している)。

拡散は水を**運び去る**側にも働いていた。下げると移流で運ばれた水がその場に
留まって凝結するので、風下が湿る。**較正が上端近く(2.06e6)を選んでいたのは
正しかった** — v3 も大分類も詳細も、現行値が最良である。

段 12 で「保存型の W は滑らかで前線の勾配が立たない」と分かったのを
「拡散が強すぎるせい」と読んだが、それも外れである。
**滑らかさは輸送の性質そのものだった。**

## もっと重要な取り違え: パタゴニアは降水の問題ではない

ゲートの内訳を読み直した。

```
patagonia_rainshadow:
  ET 49%, Cfb 34%, Cfc 8%
  [降水 134% / 年平均気温 −3.5°C / **最暖月 −6.0°C**]
```

**最暖月が 6°C 低い。** ケッペンの ET(ツンドラ)は「最暖月 < 10°C」で決まる。
観測の Cfb は最暖月 13〜15°C なので、6°C 下げれば 7〜9°C になって **ET へ落ちる**。

**降水を完璧にしても、この気温誤差だけで ET になる。**

私は「降水 134%」だけを読んで雨陰の話だと決めつけ、
**3 つの実験(峰の標高・基準勾配・渦拡散)を降水側で費やした**。
同じ行に気温の誤差が並んで書かれていたのに、読んでいなかった。

## 得られたもの(棄却でも残るもの)

1. **地形性上昇の基準勾配 800 は 1° 格子では届かない**(比 0.05)。
   これは事実として残る。峰の標高を使う配管も、名前を与えた定数も残した。
   **格子の粗さが機構を殺している**例として、他の機構でも疑う価値がある。
2. **渦拡散の現行値は正しい。** 上端近くにあるのは較正の癖ではなく、
   下げると全指標が悪化するため。今後この定数を疑わなくてよい。
3. 峰の場を混ぜる前の入力検査で、**海セルに 2.5km の山が生える**ところを
   潰した(1541 セル)。測る前に入力を見る習慣が実際に効いた。

## 次

パタゴニアは**気温の問題**として扱い直す。最暖月が 6°C 低い原因を
切り分けるところから始める(海流? 雲? 移流結合?)。
降水側の実験はもうしない。
