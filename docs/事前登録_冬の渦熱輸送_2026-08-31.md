# 事前登録: 冬の渦熱輸送(偽熱の受け皿・第 2 候補、EBM 南北拡散の季節変調)

日付: 2026-08-31 未明(実装前に書いた)
出所: v39 の受け皿分析 + OLR 案の撤退(W 平坦で桁不足)。実物の高緯度陸の
冬は、ストームトラックが運ぶ顕熱・潜熱で放射平衡より大幅に暖かい —
モデルの南北拡散(dMerid)は年中一定 + ハドレー増強のみで、この
**冬に強い**極向き熱輸送を持たない。偽熱源はこれを偶然肩代わりしていた。

## 設計(地理中立 — 既存の拡散の面で季節重みを掛けるだけ)

```
dMerid_row(m) = dBase × (1 + hadley項) × (1 + stormWinterHeatDiffBoost × stormW_row × winterW_row(m))
stormW_row   = リッジ極側の帯重み(既存 vBandW と同形: (|lat|−ridge)/10 clamp)
winterW_row  = 月日射 < 年平均 なら 1、else 0(既存 isWinterRow と同じ判定)
```

- 拡散なので**厳密に保存的**(面の量は隣接行と同じ式で一意 — 既存の
  dMeridOfRow 平均の作法に乗る)。
- 新定数: stormWinterHeatDiffBoost ∈ [0, 4] 既定 **0**(ビット一致)。

## 予測(測る前に固定)

148. 生存性: 0 ビット一致・1.5 で変化。
149. v39 定数 + boost 1.5(1°): **fareast の年平均 +11.1 → +9.5 以下**
     (冬が暖まる = 年平均が観測へ近づく…待て、モデルは年平均が**暖かすぎ**る
     — 冬をさらに暖めると悪化では?)
     **訂正**: fareast は年平均 +11.1(暖かすぎ)・最暖月 −4.5(夏が寒い)。
     受け皿の役割は「olrA を上げずに済ませる」こと — boost があれば較正は
     olrA を下げて全球を冷やし、高緯度の冬は拡散が支える配分に移れる。
     よって単独掃引の判定は**気温 RMSE と帯構造**で見る:
     149a. boost 1.5 単独で気温 RMSE 5.04 → 4.8 以下(冬の高緯度が
     過剰に冷えている帯があれば埋まる)。悪化なら「現状の高緯度は
     冬も暖かすぎ」= 受け皿仮説の前提が崩れる → 撤退。
150. v40 共調整(74 定数、種 = v39 + boost 1.5)で 71.0 回復・olrA が
     205.5 から**下がる**(受け皿があれば全球加熱で誤魔化す必要が消える)。
     alaska PASS 維持。

## 判定

- 149a ○ → SPACE 入り([0, 4])・v40 起動(判定 150 込み)。
- 149a ✗ → 撤退(既定 0)。受け皿は段 C 本体(2 温度場)まで無し、と
  結論して段 C-1 の実装に入る。

## 判定 1(boost=1.5)と用量の追加登録

- 148 ○(既定ビット一致 c0dc3c・boost で 3 実装とも効く — GPU 側も含め挙動確認)。
- 149a ✗ **過剰の向き**: boost 1.5 で高緯度が Cfb 化(fareast 年平均
  +16.2°C・RMSE 8.85)。冬拡散 ×2.5 は熱帯の熱を極へ流し込みすぎ。
  機構の感度は本物(これまでの受け皿候補で最大)— 量の問題。
- 追加登録(測る前に固定): boost 0.3 / 0.6 の用量反応。
  151. どこかの用量で「RMSE < 5.04(v39 素)かつ fareast 年平均 < +10.5」が
       成立 → SPACE 入り([0, 1.5])・v40 起動。
  152. 0.3 でも過剰(RMSE 悪化)→ 形(stormW の帯・冬重みの二値)を疑い、
       連続な冬重み(日射欠損比)で 1 回だけ再設計。

## 判定 2(用量反応)— 撤退。前提の誤りが確定

- 151 ✗: 0.3 で RMSE 5.92・fareast +12.6(単調悪化)、0.6 でさらに悪化。
- **前提が逆だった**: モデルの高緯度は「冬が暖かすぎる」(年平均 +11 の
  正体)。zonalAdvectionCoupling の天井 60 が既に冬の海→内陸加熱を過剰に
  担っており、渦熱輸送はその重複。実物の冬の渦熱は「放射で −40°C まで
  落ちるはずの内陸を −25°C に留める」ものだが、モデルの内陸はそもそも
  放射平衡まで冷えない(結合が一律で冬も切れない)。
- 152 の再設計条項も適用しない(形でなく前提)。**既定 0 残置・撤退。**
- 結論(6 例目の収束・外堀完了): 偽熱の受け皿は存在しない —
  「冬に結合が切れて内陸が冷える」構造(= 海気分離 段 C の T_a/T_s +
  k_x の季節・地表状態依存)そのものが必要。受け皿探しはここで終了し、
  段 C-1 へ入る。
