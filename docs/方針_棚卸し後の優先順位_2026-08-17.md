# 方針: 棚卸し後の優先順位(利用者裁定 2026-08-17 夕)

「モデル物理の全体像」(Opus 7 体の棚卸し統合)を読んだ利用者の裁定を記録し、
実行計画に落とす。**この文書が当面の作業順の正本。**

## 裁定(原文の要旨)

1. **目的関数の修正は早ければ早いほど良い。物差しを先に。**
2. **地球で成績の動かない欠落は最後。まず地球再現で権威を得る。**
3. 修正は**一括**でやる(個別に測って回すメリットがない)。
4. **探索空間は広げるべき**。ただし他分野の成果で確定できる定数は固定する
   (例: 標高と気温の関係 = 気温減率は既知)。
5. **較正への投資を継続**(昼間の GPU は余っている)。最適化手法の文献を
   漁って較正の速度・効率を上げるほうが優先では。
