## 判定: 閾値凝結は**採らない**

極乾燥核で 0.086 → 0.107〜0.178 と**悪化する**。BW 全域では改善する
(0.458 → 0.347)が、**集合の取り方で符号が変わる改善は採らない**。

鉛直輸出の 2 案は収支残差 0.29〜0.47 で水が保存していない(輸出した水を
戻していない)ので、判定の対象にしない。

## しかし 2026-08-04 の**結論**は覆った

当時の結論は「2 次元の柱収支では亜熱帯を乾かせない。保存型は棄却」だった。
保存型の核比は 0.222(現行 0.085 の 2.6 倍)。

**今日の段 3 の保存型は核比 0.086 で、現行と同等である。**

### 原因は凝結寿命 λ の選び方だった

当時は λ = 2.0/月(凝結寿命 0.5 か月)を定数で与えていた。
いまの実装は λ = U_ref / L で、L = 1636〜2400km・U_ref = 8m/s だと

```
λ = 8 × 2.63e6 / 1000 / 1636 ≈ 12.9 /月
```

**6 倍以上短い。** 凝結寿命が短いほど水は海の近くで降り、内陸へ届かない。
砂漠を乾かしていたのは保存則の有無ではなく**凝結寿命の長さ**で、
当時の λ が長すぎたことが「亜熱帯を乾かせない」の正体だった。

対照でも確かめた: 源泉を当時の手作りに戻しても核比は 0.089 で、
**源泉の違いは原因ではない**。

## 私の判断の誤り(記録)

この実験を始めた動機は「砂漠が 4.6 倍濡れているのは構造的欠落で、較正では
直らない」という見立てで、そのために**進行中の較正を止めた**。
測定はこれを否定した。構造は欠けていない。

見立ての根拠は `validate` の地域ゲート(サハラ 降水 458%)だったが、
これは**地域の箱の中での比**であって、砂漠の相対的な乾きを測っていない。
**「乾いているか」を測るなら、陸平均に対する比で見なければならない。**

## 実験そのものでも 1 つ誤りを踏んだ

最初の版は乾燥セルを「**現行モデルで**年 100mm 未満の陸」で選んでいた。
コメントには「循環参照になるので観測で選ぶ」と書いてあるのに、実装が
循環参照だった。基準にする側のモデルで評価集合を選ぶと、その基準が
良く見えるのは当たり前になる(実際 0.028 が出た)。

## 残る本当の課題

砂漠ではない。**湿潤な中緯度東岸が乾きすぎている**:

```
east_asia_humid    観測の 11%
us_southeast_humid 観測の 16%
india_tropical     観測の 39%
```

保存型では、そこに水が**運ばれてこない**と降らない。非保存の到達可能性
指数では「海が近ければ供給がある」で済んでいた。
これは分布の問題なので較正の対象であり、段 6 へ進む。
