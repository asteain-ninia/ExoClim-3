## 学び

- **上限張り付き × 根拠つき拡張 × 内点/上限着地** は v45 +0.51・v46 +1.50・v47 +0.32 の
  3 連続。沈降抑制は物理の限界(残存 2%)に達したので、次の候補は同型で単調に登っている
  subsidenceItczProtection(4 版連続、1.0 = 完全防護が物理の上限)。
- 較正が 0 に置いていた 3 つの機構(蒸発冷却帰還・熱風・暖湿対流)が同時に正へ動いた。
  抑制を強めて熱帯の周辺を乾かすほど、熱帯の内側で水と熱の帰還が価値を持つ、と読める
  (順序原則の「鎖の補完」の一例)。**evapCoolingWm2PerMmDay は同日の棚卸しで「撤退済み」と
  誤分類され削除候補に上がっていた**。SPACE 内の現役レバーだったため見送られ、その直後に
  生存が確認された。既定 0 = 死、ではない(台帳は B に訂正済み)。
- v48 下書き(赤道残存の下限 0.3→0)は前提が崩れたので取り下げ、候補を差し替える。
