# 実験記録: C 温帯の大分類一致 46.8% の正体 — 降水が観測の 1/5

日付: 2026-08-07
道具: `scripts/diag_temperate.ts`
前提: [ロードマップ](ロードマップ_2026-08-07.md) の R3

## きっかけ

大分類ごとの内訳で、**C 温帯だけ 46.8% と唯一の 5 割割れ**。混同行列でも
「観測 C をモデルが B と答える」が 5.4% で取り違えの最大項。
逆向き(B→C)は 1.9% と小さく、**系統的に乾かしすぎている**と読めた。

ケッペンの B 判定は 1 本の不等式で決まるので、成分に分けられる:

```
年降水 < しきい値      しきい値 = 10 × (2·年平均気温 + 季節性の項)
季節性の項: 夏に 70% 以上降る → +28 ／ 冬に 70% 以上 → +0 ／ それ以外 → +14
```

つまり **降水が足りない**のか、**気温が高くてしきい値が上がっている**のか、
**季節性を取り違えている**のかを分けられる。

Beck(1°)と気候値(2°)の格子違いを避けるため、観測の分類も気候値から起こした。

## 結果 — 降水がすべて

観測が C 温帯の 2° セル **466 個**。

```
モデルの答えの内訳
  A 熱帯     17   3.6%
  B 乾燥    181  38.8%   ← ここ
  C 温帯    239  51.3%
  D 冷帯     17   3.6%
  E 寒帯     12   2.6%
```

### 仮想実験

```
現状                      51.3%
降水だけ観測に             83.9%    ← これだけで解決する
気温だけ観測に             60.3%
全部観測に(上限の検算)     100.0%
```

### B へ落ちた 181 セルの不等式の両辺

```
年降水     観測 1213mm → モデル  259mm   (−79%)
しきい値   観測  577mm → モデル  549mm   (− 5%)
年平均気温 観測 18.1°C → モデル 18.1°C
```

**気温は小数第 1 位まで一致している。合っていないのは降水だけ。**
しかも「少し足りない」ではなく **観測の 21% しか降っていない**。

B から C へ戻すのに必要な追加降水は中央値 **296mm/年**
(下位 25% で 137mm、上位 25% で 398mm)。

### 季節性も取り違えている

```
しきい値の底上げ項      観測    モデル
  夏型(+28)             108      67
  平均型(+14)            62     107
  冬型(+0)               11       7
```

観測では夏に降水が集中する(夏型)セルが 108 個あるのに、モデルでは 67 個。
差の 41 個はそのまま平均型へ流れている。**モンスーン型の季節集中が弱く、
配分が平坦になっている。** これはしきい値を 140mm/年 下げる方向にも効くので、
乾燥判定をわずかに厳しくしている(ただし主因ではない)。

## 読み取れること

- **C 温帯の失敗は降水量の一変数で説明できる。** 冷帯が「夏の気温」の
  一変数だったのと同じ構造で、成分に開けば原因が一意に決まる。
- **中国東部の症状(年降水 340mm、目標 750mm)は例外ではなく典型**だった。
  観測 C の 4 割が同じ壊れ方をしている。
- **1/5 という比は、機構の微調整で埋まる差ではない。** 湿潤温帯へ水を運ぶ
  経路そのものが立っていないと考えるべき。

## 2026-08-04 の保存型水蒸気輸送との関係

P2-1(保存型の水収支)は**棄却済み**だが、あれは
「亜熱帯砂漠の過大降水」を直そうとした実験だった。今回の症状は逆向きで、
**湿潤温帯の過小降水**である。同じ機構でも狙う向きが違うので、
棄却の理由(「保存すると水は消えずに移動するだけ」)がそのまま当てはまるかは
別に検討が要る。むしろ「水が移動する」ことは今回**望ましい**性質になる。

## 次に何をするか

較正(v15)の後に **R5「湿潤温帯へ水を運ぶ経路」**として取り組む。
較正を先にするのは、陸の対流雲(R1b)で気温が変わると乾燥のしきい値
(気温の関数)も動くため。ただし今回の測定で
**しきい値側は既に合っている**ことが分かったので、
気温が多少動いても診断の結論は変わらないと見てよい。

## 教訓

- **判定が 1 本の不等式なら、両辺を別々に測る。** 「乾燥に食われている」では
  何も分からないが、「左辺が観測の 21%、右辺は 5% 以内で一致」まで割れば
  原因が一意に決まる。
- **仮想実験(量を 1 つずつ観測に差し替える)は 2 例目も効いた。**
  冷帯(最暖月を差し替えて 31.3% → 84.8%)、温帯(降水を差し替えて
  51.3% → 83.9%)。採点関数が手元にあるなら、成分を差し替えて採点し直せる。
