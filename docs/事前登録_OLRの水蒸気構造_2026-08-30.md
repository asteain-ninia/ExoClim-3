# 事前登録: OLR 切片の水蒸気構造(偽熱の受け皿、台帳 3 系・張り付き B 類の根治)

日付: 2026-08-30(実装前に書いた)
出所: v39 の敗因分解 — 消えた偽熱源は「高緯度の加熱パッチ」で、緯度一様な
olrA では受けられない。実物の物理: 晴天 OLR は柱水蒸気に対して対数的に
減る(水蒸気温室。乾いた高緯度・砂漠は大気の窓が開き放熱過大、湿った
熱帯は保温)。Clausius–Clapeyron 越しに W が緯度構造を持つので、
これが「緯度依存の受け皿」を地理中立に与える。

## 設計

step05 の OLR 切片(aEff、現行は標高補正のみ)に W 依存を足す:

```
aEff_i = A − olrB·γ·h_i − olrWaterTrapWm2 · ln(1 + W_ann_i / olrWaterRefMm)
```

- W_ann = 前反復の可降水量の年平均場(step06 の monthlyWaterMm)。
  気温の 2 パス目に渡す(1 パス目は W 無しの従来 aEff — 既存の 2 パス
  構造に乗る。土壌潜熱と同じ配管)。
- 実物のスケール: 晴天 OLR の水蒸気感度は ~5〜7 W/m² per ln(2×)。
  olrWaterTrapWm2 の範囲 [0, 12]、olrWaterRefMm = 8(全球平均 W 程度で
  ln 項が O(1) になる基準。固定・掃引しない)。
- **olrWaterTrapWm2 = 0(既定)= 従来とビット一致。**
- 全球エネルギーが動かないよう、**面積平均を差し引いて中立化**
  (qFlux の前例と同じ作法 — 構造だけを与え、全球平衡は olrA が持つ)。

## 予測(測る前に固定)

144. 生存性: 0 ビット一致・6 で変化。
145. 単独掃引(v39 定数 + trap 6、1°): **高緯度の年平均バイアスが縮む**
     (fareast +11.1 → +8 以下)。気温 RMSE 5.04 → 4.6 以下。
146. v40 較正(73+1=74 定数、種 = v39 最良 + trap 6): 71.0 以上へ回復し、
     **張り付きの本丸が剥がれる**: zonalAdvectionCoupling < 58 または
     hadleyBoost < 1.15 または olrA が内点([202, 205])— 3 つのうち
     1 つ以上(受け皿があれば天井を押す必要が消える、の検証)。
147. v39 の収穫(alaska PASS・fareast 0.295)を保持。

## 判定

- 145 ○ → SPACE へ([0, 12])。v40 起動。
- 145 ✗(高緯度が縮まない)→ 受け皿は OLR でなく熱輸送側(冬の潜熱・
  渦熱)。そちらを起票して出直す。
- 146 の張り付き予測が ✗ でも、145 ○なら機構は維持(張り付きの根治は
  複数機構の合算と認識を改める)。
