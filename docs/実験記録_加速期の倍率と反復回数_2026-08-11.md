# 実験記録: 加速期の倍率は 1/16 が最適だった — 予測は外れ

日付: 2026-08-11
事前登録: [事前登録_加速期の倍率と反復回数](事前登録_加速期の倍率と反復回数_2026-08-11.md)
道具: `scripts/exp_spinup_pair.ts`

年数は倍率に比例させ、加速期に得られる緩和量を揃えて比べた。

```
倍率   年数   秒*    v3      大分類  詳細   気温RMSE 反復  積算年 残差    ドリフト 未収束
1/32    1   655.3  81.057  72.05  41.77   3.912   512   151  3.0e-4 0.0379   0
1/16    2   685.5  81.058  72.05  41.78   3.926   512   128  2.8e-4 0.0356   0
1/8     4   894.9  81.032  72.01  41.82   3.928   512   148  2.5e-4 0.0139   0
1/4     8   993.8  81.036  72.01  41.84   3.918   512   116  2.0e-4 0.0254   0
```

\* 秒は**較正 v20 と並行して測ったので汚れている**。判定には使わず、
汚染されない「積算年数 × 反復」で見る(下記)。

## 判定: 現状維持(1/16)

1. **答えは変わらない。** v3 の幅は 0.026(許容 ±0.05)、地域の夏の正味流入は
   全条件で ±2mm 以内(india 521〜523、us −75、east −28、congo −145〜−146)。
2. **収束は保たれている。** 全条件で反復の倍化なし・残差 ≤3.0e-4(許容 1e-3)・
   年次ドリフト ≤0.0379(許容 0.05)・未収束 0。
3. **積算年数**: 1/16 の 128 に対し、1/32 は 151、1/8 は 148 と**増える**。
   → この 2 つは判定 3 で落ちる。1/4 は 116 で減るので通過。
4. 判定 1〜3 を通ったのは **1/16 と 1/4**。この 2 つで速いのは 1/16。
   → **現状維持。**

### 汚染されない物差しで見ても同じ

加速期の 1 年は反復 512、全熱容量の 1 年は 128 なので、費用は
「加速年数 × 4 + 全熱容量年数」で数えられる(単位は 128 反復年)。
加速年数は 1 パスあたりの年数 × 4 パス。

```
倍率   加速年  全熱容量年  重みつき費用
1/32     4       147        163
1/16     8       120        152   ← 最小
1/8     16       132        196
1/4     32        84        212
```

**壁時計の順位(1/16 と 1/32 が僅差で入れ替わる以外)と一致する。**
1/32 が壁時計でわずかに速く見えたのは並行負荷の揺れで、
費用の実体は 1/16 が最小である。

## 予測は外れた

事前登録で「費用 ∝ 倍率^0.5 なので**倍率を下げるほど安くなる**、
1/32 まで下げる価値がある」と予測した。**外れた。** 費用は倍率に対して
単調ではなく、**1/16 に谷がある**。

外れた理由は、事前登録で「外れる筋」として書いた側が実際に起きたためである:

> 倍率を下げすぎると加速期の解が実際の気候から離れすぎ、全熱容量に戻って
> からの立ち上がりに余分な年数が要る

1/32 は加速年数が 4 で済むのに、全熱容量の年数が 147 まで伸びた
(1/16 は 120)。**加速期で稼いだぶんを、後で返している。**

逆に 1/4 は全熱容量年数が 84 と最少で、年次ドリフトも 0.0254 と良い。
加速期が穏やかなぶん、質のよい状態で全熱容量へ渡している。
だが**加速期の 1 年は 4 倍高い**ので、8 年も回すと総額で負ける。

**両側から挟まれた谷**で、1/16 はそこに座っている。

## 得られたもの

数値そのものは動かなかったが、

- **1/16 が「測って選ばれた値」になった。** これまでは CPU と GPU に
  ベタ書きされた名前の無い数で、両方向とも測られていなかった。
- **加速期の 1 年は全熱容量の 1 年の 4 倍高い**という費用構造が分かった。
  今後この定数を触るときの計算に使える。
- 年次ドリフトは倍率を上げるほど良くなる(0.0379 → 0.0356 → 0.0139)。
  **加速は「速く終わる」ではなく「粗く終わる」を買っている。**

## 次

残る大きなレバーは**多重格子**だけになった(2026-08-06 の結論と同じ)。
今回の測定で分かったとおり、**加速期の 1 年は 4 倍高い**ので、
多重格子を入れるなら**加速期を主戦場にする**のが効率がよい。
加速期は対角優位が崩れている区間で、これは多重格子が最も得意な条件でもある。
