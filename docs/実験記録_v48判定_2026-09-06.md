## 学び

- **単独掃引「害なし」は「較正が使う」を意味しない。** 3 定数とも単独 |Δ| ≤ 0.08 で、
  共調整でも使われなかった。v45(沈降抑制、単独 −0.0x → 共調整 +0.51)の型が当たったのは
  「対になる定数(ITCZ 防護)が一緒に動ける」からで、今回は対の相手(沈降抑制)が
  物理の上限 0.98 で止まっているため、防護側だけ広げても動く理由が無かった、と読める。
- 上限張り付きの残りは、物理の上限に達したもの(沈降抑制 0.98)か、単独でも共調整でも
  動かないもの(今回の 3 つ)。**この型の次の候補は無い。**
- 停滞則 124 は 261 評価で発火し 288 分を残した。感度スクリーニング(81 本)を種のまま
  過ごす工程が評価数の半分を食う。種 = 前版の最良で再開するときは、スクリーニングを
  前版の感度で省く選択肢を道具側に持つ価値がある(台帳 16 の予算適応に合流)。
