# 事前登録: 沈降抑制の上限 0.82 — 熱帯の乾季を作れない床の正体か

日付: 2026-09-03 昼(測る前に書いた)。利用者の再指摘「Af が多い」(台帳 27)。

## 根拠(結果に依存しない実測)

- Af 11.0% 対 4.5%、Aw 7.1% 対 12.5%(A 群合計は一致 = 付け替え)。
- 熱帯陸 10-20 帯、観測で乾季 <10mm のセル: 模型の最乾月 P 30.6mm(観測 1.7)。
  **W は乾季 5.7 対 雨季 6.1 で不変**。動くのは G のみ(0.52 対 3.26)。
- 乾季の G 0.52 は `lift *= 1 − subsidenceSuppression·subs` の残存 18% で
  説明できる(基底 G ≈ 3 × 0.18 ≈ 0.54)。実物の沈降域の降水はほぼ 0 で、
  抑制 0.82 は物理的に低い上限(海盆非対称の上限 0.8→0.95 と同じ型の物理根拠)。
- 8/24 の張り付き診断は本定数を B「均す天井」に分類したが、乾季を深くする向きは
  「均す」の逆(分布の乾いた端を作る)。分類の誤りの疑い。

## 掃引

subsidenceSuppression ∈ {0.82(現行上限), 0.90, 0.95}(1°・v42 既定・他は不変)。
測るもの: Af/Am/Aw 面積%・熱帯陸の最乾月分布(<10mm の割合)・fitness・
大分類・詳細・分位 1%・主要ゲート(india/amazon/congo/sahara/east_asia)。

## 予測(測る前に固定)

121. 最乾月 <10mm の割合 14% → 0.95 で **≥ 30%**(観測 57%)。
     最乾月の平均 57.6 → ≤ 40mm。
122. Af 11.0 → ≤ 8%、Aw 7.1 → ≥ 9%(A 群合計は ±1 で保存)。
123. amazon/congo(A 過半)は PASS 維持(湿潤中心は subs が小さい)。
     india は変化を記録。
124. fitness は −0.5 まで受容(乾季形成は分類の付け替えなので大分類は動きにくい)。
     健全性 PASS・気温 RMSE ≤ 4.4。

## 判定

- 121・122 ○ → 上限を 0.95 へ拡張する事前登録(範囲拡張は根拠つき、利用者規則)
  → 次の較正へ。8/24 の分類 B は本定数について訂正する。
- 121 ✗(抑制を上げても最乾月が下がらない)→ 床の残りは G の他因子
  (基底 G の膨張 = λG 縮退)か供給側。乾季の G の因子分解へ。
- 123 ✗(雨林の中心が乾く)→ 抑制の地理(subs 場)の問題。範囲でなく場を疑う。

## 判定(同日): 121 ✗ / 122 ✗ — 沈降抑制は乾季の主犯ではない(ただし乾いた端には効く)

```
抑制     fitness   Af    Aw    最乾月<10mm  最乾月平均  1%分位  詳細   amazon/congo
0.82     73.449   11.4   7.1    15.7%        55.0       76     45.45  PASS/PASS
0.90     73.548   11.2   7.1    20.7%        53.7       46     45.65  PASS/PASS
0.95     73.817   11.2   7.2    23.6%        52.8       26     45.77  PASS/PASS
```

- 122 ✗: Af/Aw は動かない(11.4→11.2 / 7.1→7.2)。121 ✗(23.6% < 30%、平均
  52.8 > 40)。**サバナの乾季の床は沈降抑制の残存では説明しきれない** —
  推定では乾季のサバナ上の沈降場 subs が ≈0.6 程度で、抑制を 0.95 にしても
  G は 15% しか下がらない。実物では乾季のサバナ帯の上にハドレーの下降枝が
  乗る(subs ≈ 1)。**疑いは抑制の強さでなく沈降「場」の季節地理**。
  → 登録の 121 ✗ 分岐: 乾季の G の因子分解へ(subs 場の値・ITCZ 残存・対流/
  陸ブースト・前線)。
- 123 ○(amazon/congo 無傷)・124 ○(fitness はむしろ +0.37、RMSE 4.11)。
- **副産物(登録外・判定に使わない)**: 1% 分位 76→26(観測 9)、詳細 +0.32、
  fitness +0.37 — 「乾いた端」(砂漠)には抑制の上限が直接効く。8/24 の分類 B
  (「広げると病理を養う」)はこの定数については実測と逆(分布の端を作る向き)。
  → 上限 0.82→0.95 の範囲拡張を、乾季とは別件の「根拠つき範囲拡張」として
  v44 判定後の較正に向けて登録する(v44 走行中は SPACE を触らない = 来歴保護)。

## 因子分解(同日): 乾季の G 0.52 の内訳

```
サバナ(観測乾季<10mm)      乾季     雨季
subsDescW(沈降場)        0.881    0.408   ← 場は乾季に強い(季節地理は概ね正しい)
subsidenceResidual        0.384    0.810   ← 1 − 0.82·0.881 = 0.278 × 緩和(eastRel 0.85・itczProt 0.98)
liftItcz                  1.093    2.828
liftConvergence           1.073    1.296
condRateG                 0.524    3.265
waterMm                   5.72     6.11    ← W は不変
preAdjustMm(降水)        29.9     182.5
```

修正: 乾季の沈降場は 0.88 で**弱くない**。乾季の床は「線形の抑制形が持つ床」
(1 − c·subs は subs=0.88・c=0.82 でも 0.28 残る)× 年中掛かる緩和(東岸緩和
0.85)で決まる。上限 0.95 でも残存 0.30 → G は 2 割しか下がらない(掃引と整合)。
→ 処方は抑制の**非線形化**(下降枝の下は乾く): residual = (1 − c·subs)^p。
