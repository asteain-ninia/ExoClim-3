## 定式

```
リッジ(step02 の月別 ridge 緯度、半球ごと)× freeLayerHadleyEdgeScale = φ_H
|φ| < φ_H:  v_f = ±A · sin(π·|φ| / φ_H)   (北半球 +、南半球 − = 極向き。赤道と φ_H で 0、φ_H/2 で最大)
|φ| ≥ φ_H:  v_f = v_col(気柱輸送風のまま = 極への運びきりを防ぐ押し返しを残す)
u_f = u_col(従来)。A = freeLayerHadleyReturnMs(m/s)、既定 0 = ビット一致。
```

段 L-3b(符号反転)との違い: 反転は帯の中の**地表風の型**(貿易風の収束、赤道で最大)をそのまま極向きにした。
帯の型は赤道で 0・φ_H で 0 なので、上層の水を赤道からも極からも「30° の手前」に集める。集まった水は
下層の発散(亜熱帯高圧、σ_dn は境界層風の発散で判定)で境界層に降り、境界層の偏西風が極向きに運ぶ。
