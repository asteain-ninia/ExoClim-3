## 構造の事実(結果に依存しない、コードで確認)

v50 で `condensationClosureBlend` が 0 に落ちたため `capField` が作られず、2 層の自由対流圏の閉包は
`rateFree = rate × freeLayerLinearRateFrac(= 0)`・cap なし・床なし = **自由対流圏は一滴も降らない**
(step06 の 2 層分岐、`capField ? … : scaled(rate, freeLinFrac)`)。水が抜ける口は下向き交換 X_dn(発散域)だけ。
つまり自由対流圏は「降らない貯水槽」で、W_f(全球 14mm)は温度に関係なく溜まる。実物の可降水量は
クラウジウス・クラペイロンで気温に縛られ(熱帯 40〜50mm、極 2〜5mm)、観測 W の空間分布の大半は気温で決まる。
モデルが W-RMSE 24.5(観測 SD 13.9)なのは、この縛りが自由対流圏に無いから、と読む。

## 定式(段 L-3)

```
cap_f(T) = freeLayerRhCap · (1 − boundaryLayerSatFrac) · W_sat(T_s)     常に有効(c に依らない)
C_f      = conv_f · (W_f − cap_f)⁺,  conv_f = 30.44 / convectiveAdjustmentDays(c に依らない)
```

- `freeLayerRhCap`(新定数、0〜1.2、既定 0 = 従来どおり cap なし = ビット一致)。自由対流圏の相対湿度の上限。
  実物の自由対流圏の平均 RH は 0.3〜0.6(沈降域 0.2、対流域 0.8)。
- c > 0 のとき(cap が G 依存で作られる場合)は従来の cap と min を取る(強い方を採る)。
- W_sat(T_s) は既存の `saturatedColumnMm`(地表温から)。自由対流圏の温度で割り引く係数は
  (1 − satFrac) に含める(既に「境界層が持てる割合」として持っている)。

**上の「構造の事実」の帰結は外れていた**: 自由対流圏の水は高緯度に溜まっていない(60〜90° はむしろ薄い)。
欠けているのは **中緯度(30〜60°)、特に海上**(観測の 3 割)で、帯内の相関が負 = 分布が反転している。
熱帯の陸は過剰(0-30S 陸 1.27)。つまり自由対流圏の水は**赤道側へ**運ばれている。理由はコードの構造:
自由対流圏の風 = `monthlyColumnWind`(摩擦前の地表風 = 貿易風は赤道向き)。実物の自由対流圏(700〜300hPa)は
ハドレー循環の**戻り = 極向き**で、亜熱帯で上がった水は中緯度へ運ばれる。モデルは上がった水を赤道へ戻して
熱帯の陸を湿らせ、中緯度を乾かしている。
