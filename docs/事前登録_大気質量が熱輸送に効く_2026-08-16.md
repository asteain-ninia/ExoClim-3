# 事前登録: 大気質量を熱輸送に効かせる(段 40)

日付: 2026-08-16(実装前に書いた)
前段: [実験記録_惑星応答の初測定](実験記録_惑星応答の初測定_2026-08-16.md)

## 直す欠陥

気圧を 0.5 → 2.0 bar(4 倍)に振っても、この惑星では**何も起きない**:

```
赤道-極差   44.6 → 44.7 °C   （実質ゼロ）
乾燥帯緯度  28.8 → 28.8 °    （完全に不動)
全球気温   16.00 → 16.03 °C
陸降水       735 → 723 mm    （−1.6%）
```

コードを読むと原因は明確で、EBM の熱輸送係数が**大気質量を見ていない**:

```ts
const dBase = K.diffusionWm2PerK * radiusRatio² * heatTransportStrength;
//                                  ^^^^^^^^^^^^   ^^^^^^^^^^^^^^^^^^^^
//                                  半径は見る      利用者スライダーは見る
//                                                  **気圧は見ていない**
```

気圧が効いているのは熱容量(`+0.5×(p−1)` m 相当、`+2.4×p` m)と
蒸発の空気密度だけで、**熱の運ばれ方は大気が 4 倍あっても同じ**。

表面気圧は要件 §1-3 の利用者パラメータであり、UI のスライダーである。
**動かしても気候が変わらないのは、較正の問題ではなく機能の未完成**である。

## 物理

南北熱輸送は大気の質量流量に比例する成分を持つ。
渦拡散係数 D は「単位気圧あたりの輸送効率 × 大気質量」の形で書け、
質量は表面気圧に比例する(D ∝ p)。実際、系外惑星の EBM 文献では
熱拡散係数を大気質量(または表面気圧)に比例させるのが標準的な扱いである。

一方で拡散だけが強まると極が暖まりすぎるので、**指数は 1 に固定せず
定数で持つ**(既定 1.0、後述のとおり地球では恒等)。

## 実装

```ts
// 大気質量に対する熱輸送の依存(段 40)。地球 1 bar で厳密に 1 = 恒等
const massRatio = Math.max(0.05, atm.surfacePressureBar);
const pressureFactor = Math.pow(massRatio, K.heatTransportPressureExponent);
const dBase = K.diffusionWm2PerK * radiusRatio² * pressureFactor * heatTransportStrength;
```

- `heatTransportPressureExponent` の**既定は 1.0**(物理の素直な形)。
- **地球(1 bar)では `pressureFactor = 1` なので、地球の結果は 1 ビットも動かない。**
  較正 v24 が走行中でも安全であり、退行の心配が構造的に無い。
- 較正の探索空間には**入れない**。地球では恒等なので較正が決められない量であり、
  入れても探索が空回りする(2026-08-16 に「死んだ探索定数」で学んだ型)。

## 予測(結果を見る前に固定)

気圧 0.5 / 1.0 / 2.0 bar で応答表を測り直す。

1. **赤道-極差が単調に縮む。** 44.6(0.5bar) → 44.6(1bar) → **42 以下**(2bar)。
   0.5 bar 側は **46 以上**へ広がる。
2. **地球(1.0 bar)の行は現在と完全一致**(気温 16.01、年較差 18.8、
   乾燥帯緯度 28.8、陸降水 728)。1 ビットも動かない。
3. **年較差は 2 bar でさらに縮む**(18.1 → 17.5 以下)。熱容量の効果に
   輸送の効果が加わるため。
4. 乾燥帯の中心緯度は**大きくは動かない**(28.8 ± 1.5 以内)。
   ハドレー幅は自転が決めるので、気圧の主効果ではない。
5. 数値的健全性は全水準で保たれる(EBM の残差・ドリフト)。

**予測 2 が外れたら即座に実装を戻す。** 地球が動くなら規格化が壊れている。

**予測 1 が外れたら**(赤道-極差が縮まない): 熱輸送以外に赤道-極差を
固定している機構がある。拡散の上限(`zonalMetricCap`)か、
OLR の定式化を疑う診断へ進む。

## 判定と適用範囲

これは**地球の成績を動かさない修正**なので、採否の判断に較正は要らない。
判定は「予測 1・2・5 を満たすか」だけで、満たせば採用する。

満たさない場合も、**気圧が効かないという欠陥の所在は変わらない**ので、
実装を戻したうえで原因を掘り直す。
