# 事前登録: v29 較正 — 盆地を変えて比べる(機構ありの種からの多スタート)

日付: 2026-08-20(開始前に書いた)
前段: [実験記録_v28判定](実験記録_v28判定_2026-08-20.md) — 座標降下は
単独座標の跳びで両輪の谷を渡れない(9 試行全棄却、教訓 §9 の実例)。

## 設計

- SPACE・目的関数(v6)・打ち切り: **v28 と完全同一**。変えるのは種だけ。
- 種 = v28 最良 + { circulationLagMonths 1.0, conveyorStrength 15,
  monsoonTroughSubsRelief 0.3 }(45c の実測動作点)。
- 種は作業ツリーの constants.ts にのみ書いて起動し、起動後にツリーは
  コミット済み状態へ戻す(**種は採用ではない**)。run meta の gitDirty=true は
  この操作によるもので、採否判定は従来どおり値の全キー突合で行う。

## 予測と判定条件(結果を見る前に固定)

1. **盆地の比較**: v29 最終 fitness(v6) が v28 の **79.280 を超える**。
   (根拠: 酸性試験 +0.19・45c の超相加。降下が機構の周りの定数を
   磨けば単独付与の負けは返せるはず)
2. 終了時に 3 機構のうち **2 つ以上が非零のまま**(降下が 0 へ戻すなら
   「機構なし盆地が深い」という較正自身の答えとして受け取る)。
3. 中国東部 ≥ **340mm**(種の動作点は 395mm。降下がどこまで守るか)。
4. 数値的健全性 PASS。

## 判定

- 1 が当たったら: v29 を採用候補として利用者と相談(2・3 の中身も添える)。
- 1 が外れたら: 「v6 の下では機構なし盆地が深い」を受け入れる。重みは
  弄らない。残課題は機構の質の側(45d 理想化大陸・W の滞留構造・
  亜熱帯冬雨機構)へ振る。
