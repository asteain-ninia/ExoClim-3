## 変更(v7)= v6 + 中間場 2 項

観測は tests/fixtures/obs_intermediate(NOAA PSL、公有、1991-2020)。

1. **SST 偏差項**: モデルの `sstAnomalyC`(緯度円平均からの偏差)と、観測 SST 年平均の
   **同じ定義の偏差**(緯度帯の海平均からの差)の RMSE(海セル、|lat| ≤ 60°、面積重み)。
   観測側の偏差 SD で無次元化。重み `wSstAnom` = **wTempMean と同値**(対称性で決め、
   現状値を見た調整はしない)。
2. **陸上風速項**: モデル月別 |V| の年平均(陸セル)と観測 10m 風の年平均速度の
   RMSE(陸セル、面積重み)。観測 SD で無次元化。重み `wLandWind` = wTempMean と同値。

- 他の項・重みは v6 のまま。continuousV3 不変・v6 は fitnessV6 として併記。
- 観測は 2° なので、モデル場を 2° ブロック平均して比べる(既存の気温・降水と同じ作法)。

## 判定

- 50・51 が当たったら: v7 を有効化し v32 較正(種 = v30 最良、63 定数)。
- 50 が外れたら: 重みの対称性では足りない(係留が弱い)。**重みを上げる前に**
  項の定義(2° 平均・無次元化)を疑い、分解してから決める。
- 51 が外れたら: SST 偏差の定義が観測と噛み合っていない(緯度円平均の取り方・
  海氷域の扱い)。定義を直す。

## 追記 1: 基準値の実測(予測 49 の判定)と、風項の規模についての所見

v30 定数での実測(diag_v7_baseline):

```
SST 偏差   RMSE 1.828°C / 観測 SD 1.892 → 正規化 0.966
陸上風速   RMSE 7.629 m/s / 観測 SD 1.515 → 正規化 5.037
fitness    v6 79.233 → v7 55.220(風項 −20.1、SST 項 −3.9)
```

- 49 部分成立: 風は予測どおり 1.0 を大きく超える(5.0)。SST は 0.966 で
  僅かに 1.0 未満(帯・筋状でも振幅の桁は合っている、と読む)。
- **所見(結果を見る前に重みを変えない、の原則に従い記録のみ)**: 風項は
  単独で 20 点あり目的関数を支配する。これは「モデルの陸上風が観測の約 3 倍」
  という物理事実の反映で、物差しの欠陥ではない。ただし
  `landSurfaceFrictionFactor` の範囲 [0.6, 1] では観測水準(係数 ≈ 0.35)に
  **構造的に届かない**。範囲は較正結果でなく観測(陸上 2〜4 m/s 対 モデル
  7〜9 m/s)から決められるので、v32 前に **[0.3, 1] へ拡張**する
  (事実に基づく範囲設定であり、結果を見た緩和ではない)。

## 追記 3: 定義の修正(v7b)— 符号矛盾の項を足す(実装前に登録)

直接測定: ゲート 0 の SST 項 0.979 / ゲート 1 0.966。**項は偽寒流を見ている
が、縁海の面積が小さく全球 RMSE では罰が 0.05 点に希釈される**(旧物理の
大分類 +0.30 に負ける)。位相の教訓(二乗和は少数集団を薄める)と同型。

修正(定義のみ。重みは増やさない): SST 項に**符号矛盾 RMSE** を加える —
モデル偏差と観測偏差の符号が逆のセルだけの誤差を、全セルの面積重みで
正規化して RMS(偽の寒流・偽の暖流を名指しせず拾う量)。同じ重み 4 を掛ける。

予測(測る前に固定):
53. v7b ではゲート 1 がゲート 0 に**勝つ**(偽の海流は符号矛盾で露出する)。
54. 摩擦の結果は不変(風項に触れていない)。ソマリ 2.5 は ≥ 0 へ動く
    (ソマリ沖の偽暖流の符号矛盾が消える向き)。
