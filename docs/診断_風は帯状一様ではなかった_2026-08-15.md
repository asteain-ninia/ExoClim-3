# 診断: **風は帯状一様ではない。**検証待ち §2 の見立ては合成後の風では成り立たない

日付: 2026-08-15
道具: `scripts/diag_wind_zonality.ts`(新規)
出力: `out/diag_wind_zonality.txt`
前段: [診断_収束は二極分布](診断_収束は二極分布_2026-08-15.md)

## なぜ測ったか

引き継ぎ §13.5 で、次の一手の筆頭を**「風の場の経度依存」**とした。
根拠は [検証待ち](検証待ち_2026-08-12.md) §2:

> 残るのは偏西風が `westerlyWindMs` という 1 つの定数で**経度によらず一定**に
> 吹いていること。…**帯状一様では原理的に作れない構造。**

収束は `−(∂u/∂x + ∂v/∂y)` なので、**帯状一様なら ∂u/∂x = 0** になり、
収束の作れる範囲が原理的に狭くなる。**この読みを先に確かめた。**

## 結果 — **成り立たない**

```
【1】風の経度方向のばらつき(年平均)
帯                 |u|平均  u の経度σ  σ/|u|   |v|平均  v の経度σ  σ/|v|
熱帯 0〜15°          5.58     1.97    0.35    6.08     2.52    0.41
亜熱帯 15〜30°       7.67     2.44    0.32    5.69     2.27    0.40
**中緯度 30〜50°**   9.04     2.87    0.32    3.00     2.61    0.87
高緯度 50〜70°       5.97     2.81    0.47    1.47     2.69    1.82

【2】発散の内訳（1e-6 /s）
帯                 |∂u/∂x|  |∂v/∂y|   x の割合
中緯度 30〜50°       5.060    7.450     0.40
```

**風は経度方向にしっかりばらついている**(中緯度で σ/|u| = 0.32、σ/|v| = 0.87)。
**∂u/∂x は収束の 4 割を担っている。** 桁で小さくはない。

### なぜ検証待ちの見立てと違うのか

このモデルの風は**「帯状卓越風 + 気圧勾配風」の合成**である。
`westerlyWindMs` が効くのは**帯状卓越風の部分だけ**で、
気圧勾配風は `monthlyPressureAnomalyHpa`(経度で変わる)から作られる。

**検証待ち §2 は帯状卓越風の側だけを見ていた。**
合成後の風には既に経度依存がある。

> ## **訂正(同日、位相を測って分かった)**
>
> 下の「湿潤ゲートが 0.036 まで閉じている」は**誤り**である。
> **分位どうしを掛け算した。** 50% 分位の強度(0.129)と、
> そのセルのゲートは別物であり、割り算で後者を出すことはできない。
>
> 月ごとに測り直すと(`scripts/diag_convergence_phase.ts`)、
> **ゲートは十分開いている**:
>
> ```
> 中位の陸       年平均 強度 0.389 / ゲート 0.831 / 積 0.3708
> 強度と積の比 0.953（年平均ゲート 0.831 より**大きい**）
> ```
>
> 比がゲートの年平均より大きいので、**強い月ほどゲートも開いている**
> (正の相関)。1 月は強度 0.261・ゲート 0.569、7 月は 0.468・0.941 で、
> **位相はずれていない。**
>
> **低いのはゲートではなく強度そのもの(年平均 0.389)。**
> しかも月平均の収束指数は 6.3〜11.5 あり、それを強度に直せば 0.76〜0.85 に
> なるはずなのに、**セルごとに計算した強度の平均は 0.389** —
> つまり**中位の陸の中でも、収束が立つセルと立たないセルに割れている**。
> 二極分布は月ではなく**セル間**にある。

## では収束が二極分布なのはなぜか

`convergenceStrength01(x) = x/(1+x)`(norm = 2)で逆算すると:

```
分位     convIndex   strength   実際の持上げ倍率(boost 0.5)   ⇒ 湿潤ゲート
50%        0.297      0.129            1.0023                **0.036**
75%       15.439      0.885            1.4364                 0.97
```

**50% 分位では湿潤ゲートが 0.036 まで閉じている。**
収束の強度自体は 0.129 あるのに、`wetnessGate01(supply, 3)` が閉じて
掛け算で消えている。

つまり **収束が立つ月と、供給がある月が噛み合っていない**。
中位の陸の供給は年 80(月平均 6.7)あるので、
**年で見れば足りているが、収束が立つ月には乾いている**。

**これは空間の問題ではなく、季節(位相)の問題である。**

## 訂正

**引き継ぎ §13.5 の「次の一手の筆頭 = 風の場の経度依存」を取り下げる。**
風は既に経度依存を持っており、そこを直しても収束は広がらない。

**同時に、検証待ち §2 の記述も現状と合っていない。**
「帯状一様では原理的に作れない」は帯状卓越風だけを見た表現で、
気圧勾配風を含めた合成風には当てはまらない。
(§2 が指す東アジアの問題そのものが解決したわけではない。
 **原因の説明が違っていた**ということ。)

## 次に見るべきもの

**収束と供給の位相のずれ。**

- 中位の陸で、月ごとに `convIndex` と `supply` を並べる。
  両者のピークが何か月ずれているか。
- ずれているなら、**収束が立つ月に水が無い**ということ。
  処方は「収束を強める」でも「風を変える」でもなく、
  **その月に水を届かせる**ことになる。
- ずれていないなら、湿潤ゲートの基準 `convergenceWetnessNorm = 3` が
  高すぎる(供給の絶対値に対して)。こちらなら定数の問題。

**どちらかで処方がまったく変わるので、掃引の前に測る。**
