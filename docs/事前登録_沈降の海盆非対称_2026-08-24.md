# 事前登録: 沈降の海盆非対称(descW の源泉側設計、台帳 項目 15 続き)

日付: 2026-08-24 昼(実装前に書いた)
前段: docs/事前登録_東岸沈降緩和の減衰距離_2026-08-24.md 判定 2 —
「減衰距離は必要条件だが十分条件ではない。残りは帯(descW)そのものの
海盆非対称の問題」。v33 較正は東岸緩和(減衰 600 = 下限)を捨てコンベアを
選んだが、east_asia 年降水比 0.23・ラプラタ 0.25 のまま(新ゲート
argentina_humid は share 0.079)。

## 機構(実物の物理)

亜熱帯高気圧は帯ではなく**海盆の東側に錨を下ろした細胞**である
(アゾレス・バミューダ・太平洋高気圧)。沈降は海盆東部(大陸西岸沖)で
強く、海盆西部(大陸東岸沖 — 黒潮・メキシコ湾流・ブラジル海流域)では
対流と極向き湿潤流が高気圧を侵食して沈降が無い。現行 descW は緯度だけの
関数で、この経度構造を持たない — east_asia(25〜40°N)が 7 月のリッジ帯に
丸ごと入り凝結率が半減する真因。

## 設計(地理中立 — 海陸配置と自転方向だけから導く)

一度だけ(月非依存)、行内スキャンで幾何場 g[i] ∈ [0,1] を作る:

- **海セル**: dW = 自転の西向きに海上を辿って最初の陸までの距離(km)。
  海盆幅 widthDeg = 西陸〜東陸の連続水域の経度幅。
  `g = exp(−dW / subsidenceBasinAsymDecayKm) × widthGate`、
  `widthGate = clamp((widthDeg − 35) / 20, 0, 1)`(55° で全開 —
  境界流の発達条件 55° と同じ尺。**縁海の教訓**: 幅ゲートの無い海の機構が
  偽寒流を生んだ。地中海 ~35°・アラビア海 ~22°・ベンガル湾・メキシコ湾は
  ここで自動的に 0 になり、帯規則をアラビアで誤発火させない)。
- **陸セル**: 既存 eastOceanKm(自転の東の海までの距離)を使い
  `g = exp(−eastOceanKm / decayKm) × widthGate(東の海)`。
  西岸(カリフォルニア型)は東に海が無い(≥4400km 走査上限)ので g = 0。

月ごとの適用(descW の直後、源泉側):

```
descW ×= 1 − subsidenceBasinAsymmetry × g × (陸なら supplyGate、海は 1)
supplyGate = min(1, supply / eastReliefSupplyNorm)   // 既存定数を再利用
```

supplyGate は「実際に湿潤が届いている」条件(東岸緩和と同じ守り)。

## 新定数(すべて命名・既定で不発 = ビット一致)

| 定数 | 既定 | 意味 |
| --- | --- | --- |
| `subsidenceBasinAsymmetry` | **0** | 海盆西縁での沈降削減率の最大値(0 = 機構off) |
| `subsidenceBasinAsymDecayKm` | 1500 | 西縁からの減衰距離 |

幅ゲートの 35°/55° は境界流の既存尺(55)に合わせた固定値で、掃引しない。

## 既存機構との関係

陸上では東岸緩和(eastRelief)と形が似るが、(a) **海上にも効く**(帯が
海盆西部で開く — 沈降の帯状性そのものの修正)、(b) ゲートが SST 偏差でなく
海盆幾何(幅・西縁距離)、(c) descW の源泉に掛かるので診断場 subsDescW に
写り、分解(P=λGW)で追跡できる。

## 予測(測る前に固定)

59. a = 0 で全出力ビット一致(生存性)。
60. 地球・a 0.6 / decay 1500: east_asia 年降水比 0.23 → **0.35 以上**、
    ラプラタ 0.25 → **0.35 以上**、argentina_humid share 0.079 → 0.15 以上。
61. 守りのゲートは崩れない: mediterranean_cs / sahara / arabia /
    australia_interior / india_tropical は PASS のまま(幅ゲートと
    supplyGate が誤発火を止める)。
62. us_southeast_humid は改善方向(悪化しない)。

## 判定条件

- 59 ✗ → 実装バグ。直すまで進まない。
- 60 ○ かつ 61 ○ → 2 定数を SPACE に入れる(a [0, 0.8]、decay [800, 3000])。
  v34 較正(ゲート集合 v2)で共調整。
- 60 ○ だが 61 ✗ → 幅ゲートの閾を上げる(35→45)方向で 1 回だけ再試験。

## 判定 2: P=λGW 分解(25〜35° 陸、a=0 対 0.6)と SPACE 入りの裁定

```
                 基準 a=0                     a=0.6
帯        年降水  W     G    descW      年降水  W     G    descW
西岸       169   4.44  0.32  0.97       195   4.39  0.36  0.92
内陸       184   4.12  0.37  0.97       229   4.04  0.45  0.88
東岸       428   4.98  0.73  0.97       498   4.84  0.87  0.74
```

- **機構は設計どおり**: 東岸の descW 0.97→0.74(帯が経度方向に開いた)。
  G 0.73→0.87、年降水 +16%。
- **残りの律速は W に移った**: W は 4.98→4.84 でほぼ不変(供給 9.20→9.41)。
  G を 19% 上げて降水が 16% 増える線形応答 — これ以上の東岸の欠けは
  沈降でなく**水の量**(台帳 項目 1 = W の滞留・コンベア・海気分離の領分)。
- 予測 60 の帰結の整理: 「比が動かない」(登録した ✗ 分岐の前提)ではなく
  「動くが単独では 0.35 に届かない」。argentina は 0.15 以上を達成。
  61(守り)完全成立。62(us)成立。

**裁定: 2 定数を SPACE に入れる**(a [0, 0.8]、decay [800, 3000]、
65 定数)。理由: (1) 機構の因果が分解で確認できた、(2) 単調改善で
守り無傷、(3) 目的関数も +0.33 と正、(4) v34 の共調整でコンベア・
東岸緩和との役割分担を較正に裁定させるのが v33 で確立した作法。
較正が 0 を選べばそれが答え(最悪でも無害)。予測 60 の未達幅は
「沈降単独では埋まらない」ことの定量であり、撤退理由ではなく
**次の機構(W の滞留・海気分離)の照準**として台帳に残す。
