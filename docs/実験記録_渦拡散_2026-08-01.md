## 2. 仮説

供給は平均風に沿った風上追跡 + 指数減衰で作られ、**下限が無い**。
実大気では移動性擾乱(渦)が向きを持たない拡散として水蒸気を届け、
乾燥域にも下限を与える。この項の欠落が乾側の破綻の説明になる。

## 3. 事前登録した予測(結果を見る前に固定)

1. p10 と p25 が上がる(2→20mm 台、30→80mm 台)。p75・p90 はほぼ動かない
2. 年降水 100mm 未満の割合が 33.4% → 25% 前後へ
3. 大分類の乾燥 B が減り温帯 C が増える
4. 陸平均は上がる(813 → 850mm 級)
5. 混合長 0 でベースラインに一致(実装の健全性)

却下条件: p75/p90 が 15% 以上動く / B が減っても大分類が下がる /
混合長 0 で戻らない。

## 4. 実装

有限体積の等方拡散(球面・経度周期・極の辺長 0)。保存的。

**一度失敗した**: 反復回数に上限(64)を置きつつ拡散総量 κT = L²/2 を
保つと、1 歩あたりの κΔt が安定限界を超えて発散した
(L=300km で κΔt/dx² = 1.76、限界 0.25 → 全セル NaN)。
高緯度ほど東西のセル幅が縮むため、格子全体で一つの Δt を選ぶと極が
律速になり歩数が爆発する。

対処: **面ごとの拡散係数を局所の安定限界で頭打ちにする**。面の係数は
両側セルの小さいほうを採るので共有面で一致し、保存性は保たれる。
帰結として 1° 格子・64 歩で表現できる実効混合長は約 600km が上限。

単体試験: 混合長 0 で恒等 ✓ / 非有限ゼロ ✓ / 質量比 1.000000 ✓。

## 6. なぜ外れたか(次への手がかり)

**渦拡散は乾側を底上げせず、全体を一様に湿らせただけ**だった。

- p10 は 2→4mm で頭打ち。混合長を 100→600km と 6 倍にしても動かない。
  最も乾いた場所は数千 km 規模の乾燥域の**中心**にあり、
  600km の拡散では湿潤域から届かない。格子の制限(600km 上限)を
  外しても解決しないことが、この平坦さから言える。
- 一方 p75 は +13% 動いた。拡散は「湿った場所の周り」で最もよく効く。
  これは狙いと逆で、コントラストをむしろ弱める向き。

したがって**乾側の破綻は「水蒸気が届かないこと」では説明できない**。
供給が届いていても降水にならない、あるいは掛け算の因子が潰している
可能性が高い。因子別の動的範囲(§1 の表)で下降域の抑制が p10 = 0.348、
風上遮蔽が 0.357 と、この二つで 0.12 倍まで落ちることが示唆的。

次に確かめるべきは、乾燥域のセルで
**供給がゼロなのか、供給はあるのに因子で潰されているのか**の切り分け。

## 7. 副産物(採用しない)

混合長 200〜400km で大分類が 74.49 → 74.96(+0.47pt)、
詳細が 42.74 → 43.18(200km)、降水 RMSE が 760 → 751mm と改善した。
地域ゲートは全域で 13 のまま変わらない。

小さな改善ではあるが、**予測が外れた仮説を事後の理屈で採用するのは
凍結基準の趣旨に反する**ため採らない。渦拡散を入れるなら、
何のためにどれだけ効くはずかを別途事前登録してからやり直すこと。
