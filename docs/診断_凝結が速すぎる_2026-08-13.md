# 診断: 大気の水の滞留時間が実物の 5 分の 1

日付: 2026-08-13
前段: [診断_降水の分布](診断_降水の分布_2026-08-13.md)

## 寒い場所の内訳を出した

`scripts/diag_front_firing.ts` を寒い/高い地域へ向けた(夏の 3 か月平均)。

```
地域          前線持上げ 収束持上げ 遮蔽  沈降残存  凝結率G  前線の発火%
antarctica      1.000    1.000   1.000   1.000   **1.010**    0%
tibet           1.002    1.000   1.000   0.348   0.486      13%
east_siberia    1.339    1.000   1.000   1.000   1.880      32%
congo           1.000    1.000   1.000   0.981   1.845       0%
```

**南極の凝結率 G は 1.010 で、まったく抑制されていない。**
それでも降水は観測の 1% しかない。
つまり南極が乾いているのは**乗数のせいではなく、水が届いていない**からである。

チベットは別物で、沈降残存 0.348・G 0.486 と**沈降抑制で半減**している
(30°N 付近なので亜熱帯沈降帯の中)。**2 つは違う病気**である。

## 水が届かない理由の見当: 凝結が速すぎる

保存型の凝結率は `λ = U_ref / L`(距離減衰を凝結寿命として写したもの)。
数字を入れると:

```
1 か月の移動距離 = 10.95 m/s × 1 か月 = 28,804 km
陸  λ = 28804 / 1837 = 15.7 /月  → 滞留 **1.9 日**
海  λ = 28804 / 1627 = 17.7 /月  → 滞留 **1.7 日**

実物の大気の水の滞留時間 ≈ **9 日**
（全球降水 1000mm/年 ÷ 可降水量 25mm = 年 40 回転）
```

**モデルの水は実物の 5 倍の速さで落ちている。**

滞留 2 日では、風速 10 m/s でも **1,700 km しか進めない**。
南極内陸・チベット・大陸内部のような「海から遠い場所」へは、
**構造的に水が届かない**。下位 25% の分位が観測 120mm に対し 7mm という
実在しない乾きは、これで説明がつく。

## なぜこうなったか

段 1(2026-08-09)で保存型へ移すとき、既存の `moistureDecay*Km`(風上追跡の
距離減衰)を**そのまま凝結寿命として読み替えた**。
非保存の到達可能性指数では「供給がどこまで届くか」の距離だったが、
保存型では**水が落ちるまでの時間**を意味する。
**同じ数字が違う物理量になった**のに、値を測り直していない。

計画にも「λ = U_ref / L。既存の `moistureDecay*Km` を『水が消える距離』では
なく**凝結寿命**として写す」と書いてあり、写した後の妥当性は確かめていない。

## 次

`condensationRefWindMs`(10.95)を下げるか `moistureDecay*Km` を伸ばして、
**滞留時間を実物の 9 日へ合わせる**。どちらも較正の探索空間に入っているので、
較正が「全球 RMSE にとって最適」な位置へ寄せた結果として今の値がある。
**滞留時間という物理の目標を先に決めて、そこへ合わせる**のが筋である。

事前登録を書いてから測る。判定には南極・チベットに加えて、
**サハラが乾くか**(水が内陸まで届くようになれば砂漠は湿るはず — 逆効果の番人)
を必ず入れる。
