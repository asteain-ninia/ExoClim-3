# 事前登録: 乾いた端を作れるか(段 22)— 保存型の雲底下再蒸発

日付: 2026-08-15
**結果を見る前に書いている。**
前段: [診断_乾いた端が作れない](診断_乾いた端が作れない_2026-08-15.md)

## 問い

南極を除き面積で重みをつけると、モデルの陸の年降水は**観測より狭い**。
狭さは片側にしかない:

```
分位     モデル   観測   比
  1%       64      9    7.1   ← 本当に乾いた場所を作れない
  5%       88     47    1.9
 25%      241    300    0.80  ← 中位はむしろ乾かしすぎ
 50%      468    593    0.79
 95%     2353   2385    0.99  ← 湿った端は合っている
```

**モデルは水を「乾いた端から中位へ」動かす必要がある。**
総量ではなく配り方の問題である(面積重み平均はモデル 701 / 観測 767)。

## なぜこの機構か: 保存型の雲底下再蒸発(virga)

`subCloudEvapCoef`(既定 0)。Gregory 1995(Mon. Wea. Rev. 123, 2716)の形で

```
失われる割合 = k(1 − RH) / √P     （上限 subCloudEvapMaxFrac）
```

**弱い雨ほど多く失われる。** これは「乾いた端だけを選択的に削る」演算子で、
まさに今欠けている形をしている。中東で RegCM3 に入れた実測では年降水が最大
20% 減り、湿潤バイアスが観測の 15% 以内へ収束した(Marcella & Eltahir 2008)。

**保存型では意味が変わる。** 非保存の実装は降水を組み上げた**後**に削る
形で、水が虚無へ消えていた。保存型では凝結率を `(1 − 失われる割合)` 倍する
ので、**削られた水は気柱に残って下流へ運ばれ、別の場所で降る**。
つまり「乾いた端から中位へ動かす」演算子そのものになっている。

[計画_保存則の段階的置換_2026-08-09](計画_保存則の段階的置換_2026-08-09.md) §1 に
**「保存型で測り直す価値がある」と書かれたまま、一度も実行されていない。**
非保存で測った 2026-08-04 の結果(砂漠 61 → 57mm、v3 −0.08〜−0.63)は
**別の演算子の結果**であって、この機構の棄却根拠にはならない。

## 変えるもの

`subCloudEvapCoef` を 0, 1, 3, 6, 12 で掃く。他の 62 定数は現行(v22)のまま。
上限 `subCloudEvapMaxFrac` は触らない(既定のまま記録する)。

## 予測(先に書く)

- 1% 分位は下がる。**64 → 30mm 前後**まで届くと見る。
  弱い雨ほど削られる形なので、下位分位に選択的に効くはずである。
- 5% 分位も下がるが 1% ほどではない。
- 中位(50%)は**上がるか、少なくとも下がらない**。
  削った水は消えずに下流で降るため。**ここが保存型と非保存の分かれ目**で、
  非保存なら中位も一律に下がる。**中位が下がったら、私の「水が下流へ回る」
  という読みが間違っている。**
- 費用は増える(virga の外側反復が実際に回り始める)。現在は
  `subCloudEvapCoef = 0` で早期 return しているので、**外側反復 6 回ぶん
  丸ごと増える**。1 水準 600 秒を超える可能性がある。
- サハラは乾く方向へ動く(観測比 4.74 → 下がる)。

**外れる筋**: 保存型でも中位が下がる(= 水が戻ってこない)。
その場合この機構は「乾燥地を削るだけ」で、非保存のときと同じ結論になる。

## 判定(先に固定する。結果を見てから緩めない)

1. **収束**: 5 系統(輸送 / virga 外側 / 結合 / 土壌 / EBM)すべて未収束 0。
   満たさない水準は**適用範囲外**として、以降の条件を読まない。
2. **主判定**: 乾いた端の 1% 分位が **64 → 35mm 以下**へ下がる水準がある
   (観測 9mm。比 7.1 倍 → 3.9 倍以下)。
3. **番人(下げすぎ)**: その水準で 5% 分位が観測の **47mm を下回らない**。
4. **番人(中位)**: その水準で 50% 分位が現行の **468mm を下回らない**
   (観測 593mm。中位は既に乾かしすぎなので、これ以上乾かす手は採らない)。
5. **番人(地域)**: サハラの年降水／観測が **4.74 を超えない**、
   コンゴが **1.31 ± 0.3**(1.01〜1.61)に留まる。
6. **費用**: 1 水準 **900 秒**以内(virga の外側反復ぶん増えるので、
   段 20 の 600 秒より緩く置く。これは費用の閾値であって成績ではない)。

2〜5 をすべて満たす水準があれば**採用候補**とし、再較正へ進む。
無ければ棄却する。

### v3 の扱い(先に決める)

**v3 は記録するが、主判定には使わない。** 理由を先に書く:
他の 62 定数は `subCloudEvapCoef = 0` に対して較正された v22 の値であり、
**降水を配り直す機構はその前提の下で必ず不利に出る**。
掃引の目的は分布の形を見ることで、成績の判定は再較正の後である
(この立場は `scripts/exp_pressure_lever.ts` 冒頭に前から書かれている)。

ただし**歯止めを置く**: v3 が現行 85.235 から **3.0 以上**落ちる水準は、
再較正でも戻らない見込みとして採用候補から外す。
