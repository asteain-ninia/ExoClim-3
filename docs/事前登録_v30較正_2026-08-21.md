# 事前登録: v30 較正 — 縁海修正後の物理で、両輪の種から回し直す

日付: 2026-08-21 未明(開始前に書いた)
土台: 縁海の偽寒流修正(ゲート 1)を含む物理。種 = v29 最良(採用は保留中 —
種に使うことは採用ではない。v29 と同じ扱い)。
探索空間: 60 定数(v28 の 59 + conveyorLatPolewardDeg [0,8] 復帰 —
種で conveyor=15 が生きており基準点死が解消)。生存性: 測定中(完了と
死に定数 0 件の確認を**起動の前提**とする)。
目的関数: v6(凍結)
開始時基準線(修正後物理・v29 定数、同日測定):
大分類 74.7 / 中国東部 251mm / india BWh 49% / ラプラタ 217mm / 健全 PASS

## 予測と判定条件(結果を見る前に固定)

1. fitness(v6) が v29 の **79.836 を超える**(縁海修正で偽の支えが剥がれた
   ぶん、同じ定数の出発点は下がる — それでも較正が取り返して超えると予測)。
2. 機構の生存: lag・conveyor は非零のまま。relief は v29 で 0.006 まで縮退
   したが、**縁海修正後は偽暖流の代替供給が消えたため復活する**と予測
   (>0.05)。外れたら「relief の仕事は既存沈降系で代替可能」を受け入れる。
3. 中国東部 ≥ **300mm**(修正後基準 251 から +49。v29 判定の 340 は
   修正前物理の基準だったため、修正後基準で再設定)。
4. coldCoastSuppression が探索下端 0.25 から**離れる**(診断 (d) の宿題 —
   偽寒流が消えたので実在寒流に正しい強さを使えるはず)。
5. 数値的健全性 PASS。

## 判定

- 1・3・5 成立(2・4 は情報)→ 採用候補として利用者と相談。
- 1 が外れ → 縁海修正の剥がし幅が較正で取り返せない = 偽の支えへの依存度が
  想定より深い。v29(修正前)との比較は不成立になるため、修正後物理での
  基準線を新しい出発点として扱う(修正は撤回しない)。
