## 得られた分解 — 一様な熱的低気圧は「1 地域を助けて 2 か所を壊す」

| 対象 | 0 → 1.3 | 向き |
| --- | --- | --- |
| 米南東(C→B 失点の 39% の側) | 0.37 → **0.41** | ○ 助かる |
| 東アジア(同 33%) | 0.20 → 0.20 | — 微動もしない(8/11 と同じ) |
| 欧州 | 0.92 → **0.82** | ✗ 壊れる |
| 湿った端(99% 分位) | 3015 → **2783** | ✗ 観測 3393 から遠ざかる |
| 中位(50% 分位) | 532 → 487 | ✗ 観測 596 から遠ざかる |

物理として読み解ける形をしている:

- 大陸上の低気圧は反時計回り(北半球)の流れを作る。**東縁では南風**(湿潤流入 =
  米南東が助かる)、**西縁では北風**(乾いた流出 = 欧州が壊れる)。
  つまり一様な熱的低気圧は、**東岸を助けるのと同じ力学で西岸を壊す**。
  片方だけ欲しくても、円い低気圧は両方を連れてくる。
- 東アジアが動かないのは 8/11 の診断(北への流出 −840mm/年が最大項)と整合。
  低気圧をどう深くしても、そこで水が収束する前に西風が極側へ運び去る。

## 設計への含意(次の仕事)

「熱的低気圧を強くするか」は二値の問いではなかった。**欲しいのは
低気圧そのものではなく、その東縁の南風だけ**である。設計候補:

1. **深さを「湿り」でなく「海からの湿潤流入があるか」で決める**(事前登録に書いた案)。
   赤道側〜自転方向東側の近海が暖かい場合のみ低気圧を深くする。地理中立
   (海陸配置と海面温度の規則だけで書ける)。欧州のような「西縁だけが海」の
   場所では深くならないので、西岸を壊す副作用が構造的に消える。
2. 気圧場を経由せず、**亜熱帯高気圧セルの西縁の回転成分**を直接強める
   (`subtropicalCellEastBoost` の対になる西縁版)。海上の高気圧は既に
   離散セル化されているので配管の増設は小さい。
3. どちらも東アジアには足りない可能性が高い(壊れ方が「流出過多」なので)。
   東アジアは**極向きに抜ける水を前線帯で堰き止めて降らせる**側の問題として
   別に扱う。

まず 1 と 2 を紙の上で比較し、配管が小さい方から事前登録 → 実装 → 掃引の順。

## 教訓の確認

- 「棄却済みの機構を蒸し返さない」と「物差しが変わったら測り直す」は両立する。
  **測り直して棄却が再確認されたことにも価値がある** — 旧判定への信頼が
  回復し、机上の「もしかして」が消えた。4 予測が全部当たったのは、
  この機構の理解が正しい証拠でもある。
