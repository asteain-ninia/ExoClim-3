## 予測と判定条件(結果を見る前に固定)

1. fitness(v7) > **60**(風項 20 点の大半を摩擦で回収できる — 摩擦 0.3〜0.5 で
   陸上風の RMSE は 7.6 → 3 m/s 級に落ちる見込み)。
2. **機構に火が入る**: landSurfaceFrictionFactor < 0.7 かつ、somaliUpwellingC・
   itczMoistLandPullDeg・boundaryCurrent 系のうち 1 つ以上が端から離れる。
3. **大分類 ≥ 74.5**(中間場を係留しても最終地図を 0.3 以上売らない — これが
   外れたら「途中の場と最終地図が両立しない」構造問題として分解)。
4. SST 偏差 正規化 < 0.9、陸上風速 正規化 < 3.0。
5. 数値的健全性 PASS。
6. 中国東部(validate 箱)は情報として記録(条件にしない — 風を弱めると
   内陸輸送が落ちる綱引きが予想され、方向を事前に断言できない)。

## 判定

- 1・3・5 成立 → 採用候補として利用者と相談(2・4・6 の中身を添える)。
- 3 が外れ → 係留項の重み問題ではなく「モデルが両立できない」問題として、
  どの地域で最終地図を売ったかを分解(classdiff)してから次を決める。
  重みは弄らない。
