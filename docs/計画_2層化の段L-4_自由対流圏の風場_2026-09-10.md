## 出発点(結果に依存しない事実)

1. 自由対流圏 W_f の風は `monthlyColumnWind`(step04 の摩擦前の地表風)。地表の帯状風なので
   貿易風帯(0〜30°)では**赤道向き**、偏西風帯では西風 + 極向き成分。実物の 700〜300hPa は
   ハドレーの戻り(0〜30° で極向き)と、中緯度の強い偏西風(渦による極向き水輸送)。
2. W_f は c=0 で降らない(cap も床も無い)。抜ける口は下向き交換 X_dn = k_dn·(−div V)⁺·W_f + ε·W_f だけ。
   だから W_f の分布は「風がどこへ集めるか」と「どこで発散するか」だけで決まる。
3. W の帯別診断(v54): 中緯度 30〜60° の海が観測の 3 割・帯内の相関が負。熱帯の陸が 1.27 倍。
4. 風モード 1(ハドレー帯で v を反転)の帯別: 中緯度海 0.31 → 0.59 に上がるが、熱帯 0.3 に落ち、
   南極 13 倍(60-90S 陸 10.6mm 対 観測 0.8)。**極向きに流すだけでは極まで運んで溜める。**
   実物で極に溜まらないのは (a) 中緯度で降る(前線・渦)、(b) 気温の縛り(飽和水蒸気圧)、
   (c) 上層の収束が 30° 付近(亜熱帯高圧帯)で下向きに抜ける、の 3 つがあるから。

## 設計の候補(測る順)

### L-4a: 上層の子午面風を「帯の型」で与える(最小)

```
v_f(φ) = A_H · sin(2φ)·exp(−(|φ|/φ_H)²)  … ハドレー戻り(0〜30° で極向き、30° でゼロ)
       + v_col(φ) · [|φ| > φ_H]            … 中緯度以北は従来の気柱風(渦は拡散に任せる)
u_f     = u_col(従来)
```

- 新定数 2 つ(A_H m/s、φ_H 度)。既定 A_H = 0 でビット一致。
- 期待: 亜熱帯で上がった水が 30° 付近で収束 → X_dn(発散ではなく収束なので k_dn では抜けない)。
  **ここが罠**: 現行の X_dn は「風の発散」で抜くので、上層収束域(30°)では下向きに抜けない。
  実物の亜熱帯は「上層収束・下層発散」= 沈降。だから **X_dn は境界層の風の発散で判定する**(現行は
  境界層風 uq/vq の発散を使っている = 正しい側)。よって 30° の下層発散域で W_f が抜ける。○
- 測るもの: 帯別 W(中緯度海 ≥ 0.5・熱帯 ≥ 0.7・南極 ≤ 3 倍)、W-RMSE ≤ 22、v7b −0.3 以内。

### L-4b: 自由対流圏の凝結を「気温の縛り」で(段 L-3a の再設計)

- L-3a(cap 0.6 で W_sat(T_s) 比例)は W を消した(7.7mm)。原因は cap が全球一律に効いたこと。
  再設計: cap を **中緯度の前線帯だけ**で効かせるのではなく(地理の決め打ちは禁止)、
  **境界層の凝結率 rate が大きい所で W_f も同じ率で降る**(rate の共有、freeLayerLinearRateFrac の
  再来だが、c=0 でも rate は G から作られているか確認が要る)。
- 前提の確認: c=0 のとき rate(境界層)がどう作られているか(step06 の閉包)。rate が G 由来なら
  W_f にもそのまま使え、freeLayerLinearRateFrac を SPACE に入れるだけで済む(段 L-1 で 0 に落ちた
  理由は「W_f が薄い時期の値」なので、v54 既定で再掃引する価値がある)。

### L-4c: 中緯度の渦による極向き水輸送を拡散でなく「風」で

- 現行の渦は等方拡散(moistureEddyDiffusivityM2PerS、上限張り付き)。上層の渦輸送は −K·∂W/∂y で
  極向き。拡散を上げても W-RMSE が動かなかった(v45〜v47)。子午面の異方性拡散(K_y > K_x)を
  自由対流圏だけに入れる。新定数 1(比)。既定 1 でビット一致。

読み:
1. **水の 78% は自由対流圏にあり、一滴も降らない**(C_f = 0)。降水はすべて W_b(全球 4mm)の凝結。
   W が 18mm になっても「降る水」は単層時代の 4.9mm と同じ厚さ = 2 層化の得点は「境界層の水を薄く保つ」
   ことで得たもので、自由対流圏はまだ貯水槽。
2. **中緯度の自由対流圏は空(3.6〜6mm、熱帯の 1/6)で、しかも正味で輸出側(T_f < 0)**。上がった水(X_up 11)は
   ほぼ同量が降りる(X_dn 10)= 滞留 0.5 か月の短い循環で、亜熱帯からの流入は無い(30° の移流は両半球とも
   赤道向き)。観測の中緯度 W 17〜20mm は亜熱帯から極向きに運ばれた水。**L-4 の標的はここ**。
3. 熱帯の陸(X_up ≫ X_dn、T_f −10〜−12)が上げた水を熱帯の海(T_f +)が受けている = 熱帯内の陸 → 海の再配分。
   陸の W_f 27〜33mm が観測比 1.27 の正体。極向きに逃がす道が無いから海に落ちる。
4. 極は移流では輸出(60S で +4514 = 赤道向き)なのに T_f が正 = **拡散**(moistureEddyDiffusivity、上限張り付き)
   が極へ押し込み、気柱風が押し返している。風モード 1 で南極が 13 倍になったのは、この押し返しが消えたから。

設計への帰結(L-4a の定式を絞る):
- v_f をハドレー戻りの型(0〜30° で極向き、φ_H で 0)にすると、30° の移流の符号が反転して中緯度へ流入する。
  流入量の目安は現行の赤道向き移流と同程度(30N −2012 → +2000 級)= 30-60 の W_f を 3.6 → 7〜10mm に押し上げる
  規模。**φ_H から先は気柱風のまま**(押し返しを残し、極への運びきりを防ぐ)。
- 30° 付近に集まった W_f は下層の発散(亜熱帯高圧)で X_dn として境界層へ降り、境界層の偏西風が極向きに運ぶ
  (観測の「亜熱帯の水が前線帯で降る」経路)。C_f = 0 のままでも中緯度の W_b が増えれば降水の暦・量が動く。
- 予測の型(事前登録で数値化): 30-60 海の W 比 0.31 → ≥ 0.5、熱帯陸 1.27 → ≤ 1.1、60-90S ≤ 2 倍、
  W-RMSE ≤ 22、v7b −0.3 以内(単独損は棄却理由にしない)、35-90 冬雨の暦が −60 日より浅く。
