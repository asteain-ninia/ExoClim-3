# 事前登録: 水蒸気の渦拡散が地域構造を平していないか(段 14)

日付: 2026-08-12
**結果を見る前に書いている。**
前段: [実験記録_地形性上昇に峰の高さ](実験記録_地形性上昇に峰の高さ_2026-08-12.md)(段 13、棄却)

## ここへ来た経緯

利用者の指摘から地形の解像度を追いかけて、3 つ潰した。

1. 峰の標高を使う(段 13)→ 効かない(パタゴニア 1.48 → 1.47)
2. 理由: 地形性上昇の基準勾配 800 が 1° 格子では届かない(比 0.05)
3. 基準勾配を 8 倍強くする → **それでも 1.48 → 1.37**(目標 1.15)

**持ち上げを 8 倍にしても雨陰が出ない。** 別の犯人がいる。

## 桁の見積もり

保存型の輸送は移流 + **渦拡散**で解いている。拡散係数は較正後 2.06e6 m²/s。
凝結率 λ に対して、水が凝結するまでに拡散で広がる距離は √(D/λ):

```
凝結率 0.05 /月 → 10409 km
凝結率 0.3  /月 →  4250 km
凝結率 1.0  /月 →  2328 km
1 か月の拡散長 √(2Dt) = 3292 km

参考: アンデスの幅 ≈ 200km、1° セル ≈ 80km
```

**水は凝結する前に大陸をまたぐ距離まで広がっている。**
これでは山脈の風下に乾いた場所は作れないし、前線のような鋭い境目も残らない。

段 12 で「保存型の W は滑らかで前線の勾配が立たない」と分かったのも、
これで説明がつく。**滑らかなのは輸送の性質ではなく、拡散が強すぎるから**
かもしれない。

## この値の来歴

定数のコメントには「大気の水蒸気の渦拡散は 1〜2e6 m²/s 程度」とある。
文献値としては妥当な範囲だが、**それは大気全体の総観規模の渦拡散**であって、
1° 格子の柱モデルで移流と別に足す量として妥当かは別の話である。

そして探索空間は [5e5, 3e6] で、**較正は上端近く(2.06e6)へ寄せている**。
全球 RMSE は平すほど良くなるので、較正が滑らかさを好むのは当然である。
**地域構造の鋭さは v3 にほとんど現れない。**

## 変えるもの

`moistureEddyDiffusivityM2PerS` を下げる。掃く値:
**2.06e6(現行)/ 1e6 / 5e5 / 2e5 / 5e4**。

## 予測(先に書く)

- **パタゴニアの過剰が減る**(1.48 → 1.2 台)。風下が乾けるようになるため。
- **東アジアも動く**(現在 0.17)。ただし向きは分からない — 拡散で運ばれて
  いたぶんが減るので**さらに乾く**かもしれない。
- 全球の降水 RMSE は**悪化する**可能性が高い(平すほど RMSE は良くなる)。
- **v3 は下がるかもしれない。** それでも地域構造が出るなら、
  「物差しが滑らかさを好む」ことの証拠になる。

**外れる筋**: 拡散を下げると輸送の解が振動して収束しなくなる。
拡散は数値の安定化にも効いているので、下げすぎると解けなくなる。
未収束が出たらそこが下限である。

## 判定(先に固定する)

較正 v20 の定数の上で測る。

1. **patagonia の年降水が観測比 1.48 から 1.25 以下へ下がる。**
2. **輸送と結合反復が収束する**(未収束 0)。1 件でも出たらその値は棄却。
3. **v3 が 84.38 から 1.0 以上落ちない。**
4. **大分類が落ちない。**

1・2 を満たし 3・4 を満たさない場合は**保留**とし、
「地域構造と全球 RMSE のどちらを取るか」を利用者へ諮る。
**勝手に目的関数を変えない**(2026-08-11 に一度、物差しを疑って
測ったら外れている)。

## やらないと決めていること

- 拡散を下げると同時に凝結率や持ち上げを動かすこと。**1 本ずつ。**
- v3 が下がったことだけを理由に即棄却すること。判定 1・2 を先に見る。
