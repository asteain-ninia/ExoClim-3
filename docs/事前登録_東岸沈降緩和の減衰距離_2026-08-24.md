# 事前登録: 東岸の沈降緩和の減衰距離 — 範囲不足の疑い(台帳 項目 15)

日付: 2026-08-24(測る前に書いた)
診断: [診断_亜熱帯東岸の沈降](診断_亜熱帯東岸の沈降_2026-08-24.md)。
東岸緩和 = relief × eastWarmth × exp(−東海岸距離 / eastCoastSubsidenceDecayKm)。
v32 の decay = 962km、SPACE 範囲 [600, 1300]。亜熱帯東岸帯(幅 ~1300km)の平均で
緩和は 0.18 しか効かず、沈降残存 0.40〜0.47 が残る。

## 物理スケール(結果に依らない根拠)

実物の亜熱帯高気圧の西縁(下降が弱く湿潤南風が入る側)は大陸内へ
2000〜3000km 及ぶ: 湾流〜アパラチア〜ミシシッピ(~2000km)、
東シナ海〜四川盆地(~1800km)、ラプラタ〜パンパ西縁(~1500km)。
**範囲の上限 1300km はこのスケールに届いていない**(摩擦の床 0.6 と同型の
範囲不足)。範囲を [600, 3000] へ広げる — 観測スケールからの設定。

## 測ること

`eastCoastSubsidenceDecayKm` 962 / 2000 / 3000 を地球(v32 定数)で掃引し、
理想化大陸でも 3000 で因子分解を測る。

## 予測(結果を見る前に固定)

76. 理想化大陸の東岸 25-35°: 沈降残存 0.40 → **0.55 以上**、年降水 291 → 400mm 以上、
    Cfa+Cwa 10.6% → **25% 以上**。
77. 地球の中国東部(validate 箱) 340 → **420mm 以上**。
78. 豪州内陸の B→C 誤り 0% が**維持**、アラビア(eastWarmth ゲート)が湿らない
    (india_tropical の BWh が上がらない)。
79. 大分類 −0.3 以内(3000 で)。超えるなら 2000 を上限とする。

## 判定

- 76・77・78 ○ → SPACE 範囲を [600, 3000] に広げて次版較正に委ねる。
- 76 ○ だが 78 ✗ → 減衰を伸ばすと守りが崩れる。eastWarmth ゲートの形を
  見直してから(関係ない場所を湿らせない条件を先に)。
- 76 ✗ → 減衰距離は主因でない。descW(帯そのもの)の海盆非対称へ進む。
