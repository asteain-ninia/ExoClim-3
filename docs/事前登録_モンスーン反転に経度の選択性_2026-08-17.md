# 事前登録: モンスーン反転に経度の選択性を付ける(段 42)

日付: 2026-08-17(実装前に書いた)
前段: [診断_拡散は命綱で移流が犯人](診断_拡散は命綱で移流が犯人_2026-08-17.md) /
      [実験記録_モンスーンの子午面成分](実験記録_モンスーンの子午面成分_2026-08-16.md)(段 41、不採用)

## 何を直すか

段 41(貿易風帯の子午面反転)は、**風の向きを直すことには成功した**が
(C→B の極向き風 −0.79 → 0.00)、**反転を全経度に一様に掛けた**ため
海上でも極向き流が立ち、水蒸気を帯状に均してしまった(分布の両端が潰れた)。

昨日の診断で、C→B セルの犯人は**移流が水を奪っていること**(夏 −25.8mm/年)、
そして段 41 が唯一それに直接触った手だと確定した。
足りないのは**経度の選択性**である。実物のモンスーンは大陸の経度で強く、
海洋の経度では貿易風が普通に赤道向きに吹く。

## どう直すか

段 41 の反転強度に、**経度列の熱帯陸割合によるゲート**を掛ける。

```ts
// step04 で列ごとに計算(step02 の troughLandFrac と同じ定義):
//   colLandFrac[col] = |lat| ≤ 30° の帯に占める陸セルの割合
const gate = Math.min(1, colLandFrac[col] / K.monsoonLandFracRef);
monsoonMerid = K.monsoonMeridionalReversal * disp * (1 - away) * gate;
```

- `monsoonLandFracRef` = 0.3(構造定数)。熱帯陸割合が 30% 以上の経度で
  ゲート全開、海だけの経度で 0。アジア(0.4〜0.6)は全開、
  太平洋中央(≈0)は不動になる。
- **陸割合という幾何だけで書く**ので地理中立。手続き地形・逆行でも成立。
- 既定 `monsoonMeridionalReversal = 0` は変えない。**このとき従来とビット一致**
  (ゲートの計算自体を係数 > 0 のときだけ行う)。

## 予測(結果を見る前に固定)

`sweep_lever.ts monsoonMeridionalReversal 0,0.3,0.6,1.0` をゲート実装後に再実行し、
最良水準で `diag_ctb_budget` を走らせる。

1. **C→B の夏の移流流入が正へ転じる**(係数 1.0 で −25.8 → **0 以上**)。
   これが本丸。診断が特定した犯人に直接効いたかの判定。
2. **分布の両端がほぼ動かない**: 1% 分位 64±3、99% 分位 3015±40。
   段 41 は 74 / 2924 まで潰した。海を巻き込まなくなった証拠がこれ。
3. 地域比: インド 0.49 以上・米南東 0.39 以上(段 41 と同等以上)。
   コンゴ 1.25〜1.29・欧州 0.90 以上(不動)。
4. **連続部分が 70.32(基準)を上回り、分布誤差が 0.409 以下**
   (段 41 は連続部分 70.20、分布誤差 0.439 まで悪化した)。
5. 数値的健全性は全水準で保たれる。

## 判定

- **1・2・4 がすべて当たったら**: 採用候補。利用者に裁定を仰ぐ
  (探索空間へ入れる = 較正のやり直し。57 定数 + この 1 つで v25 を回す提案)。
- **1 が外れたら**(移流が正に転じない): ゲートで振幅も削がれた。
  ゲート通過後の実効反転率を測り、`monsoonLandFracRef` の設計を見直す。
- **2 が外れたら**(まだ分布が潰れる): 海を巻き込んでいる。ref を上げるか、
  ゲートの形(clamp でなく冪)を検討。
- **4 だけ外れたら**: 陸で反転しても別の何かを壊している。何が落ちたかを分解し、
  **説明できない改善・悪化は採用しない**(段 39 の規定と同じ)。

**目的関数の重みは動かさない。定数の既定値も 0 のまま**(採否は裁定事項)。
