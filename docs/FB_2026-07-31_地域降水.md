# ExoClim-3 地域降水 FB — 雨量の総量ではなく、輸送・季節性・遮蔽を直す

作成日: 2026-07-31

実装担当へ: この文書は `docs/FB_2026-07-31.md` とは別件の、
地域降水分布に関する作業票である。前文書の P0/P1 と変更禁止事項を優先し、
採点基盤を整えた後に本書の挙動変更へ進むこと。

この作業の目的は、地球専用の座標補正を足すことではない。
アマゾン、中国東部、ラプラタ盆地、パタゴニアに同じ物理則を適用し、
乾湿分布を同時に改善することである。

## 1. 現状の測定結果

現在の `amazon_tropical` ゲートは「A 群が過半なら合格」であり、
Aw が大半でも通る。現状は PASS だが、熱帯雨林の再現としては未達である。

## 2. 中心診断

### 2.1 アマゾン: 雨季の量より、乾季の自己維持が弱い

地点例:

- マナウス: モデル 1,915 mm/年、観測 2,345 mm/年
- マナウス最乾月: モデル 22 mm、観測 82 mm
- リオ・ブランコ: モデル 1,082 mm/年、観測 1,793 mm/年
- リオ・ブランコ最乾月: モデル 0 mm、観測 26 mm

`step06_precipitation.ts` の陸面再循環は、同じ月の降水だけから
`landSource` を作る。前月までの土壌水分や植生からの蒸発散を持たないため、

1. 雨が減る
2. 陸面供給が減る
3. 次の計算でも雨がさらに減る

という乾季の正帰還が起きる。

また、現在の陸面供給は 40 mm/月で飽和する。同じ「湿潤」と判定された後は、
非常に湿った雨林と普通の湿潤地の供給力を区別できない。

### 2.2 中国東部・ラプラタ: 暖海からの湿潤流を内陸降水へ変換できていない

中国東部とアルゼンチン北東部は、いずれも暖かい海からの流入、
季節性の大陸低圧、前線・収束によって、亜熱帯でも湿潤になる地域である。

現行モデルは次の構造を持つ。

- 亜熱帯高圧帯の `ridge −16°` から `ridge +5°` を広く抑制する。
- 抑制は主に緯度帯で決まり、局所的な湿潤収束では十分解除されない。
- 東岸緩和は海岸距離に対して指数減衰し、内陸へ届きにくい。
- 高温湿潤対流の係数は現在 0。
- モンスーントラフ追加深化の係数も現在 0。
- 風上追跡は一つの月平均風向に依存する。

「亜熱帯の東岸だから湿潤」という新しい地理規則を足すのではなく、
局所の水蒸気フラックス収束によって、沈降抑制の実効量と降水持上げを
連続的に決める必要がある。

### 2.3 パタゴニア: アルゼンチン全体が乾燥不足なのではない

北東部・パンパは乾きすぎている一方、パタゴニア東部は観測の 4.5 倍も雨が多い。
南米を一括して湿潤化すると必ず悪化する。

パタゴニアの主問題はアンデス遮蔽である。現行 1°平均標高では狭い高山脈が
均され、`crestProminenceFactor` も 0 のため、偏西風由来の水蒸気が東側へ
抜けすぎる。

## 3. 禁止する近道

次を単独の解決策として採用しない。

- `precipScaleMmPerUnit` の全球一律引上げ
- `landRecyclingStrength` の一律引上げだけで済ませる
- 亜熱帯沈降係数の全球一律引下げ
- ITCZ 残留幅の一律拡大
- アマゾン、中国、アルゼンチンの座標・地域名を使う計算規則
- 地域ゲートの合格閾値を結果に合わせて緩める
- 全球適合度だけを見た採否

全球平均は既に近く、パタゴニアは大幅に過湿である。
総量つまみでは乾燥不足と過湿を同時に直せない。

## 4. R0 — 地域採点を先に追加する

挙動を変える前に、地域別の退行を検出できるようにする。

### 実装

- 地域採点は `scripts` または検証用共有モジュールだけに置く。
- `src/sim` へ地球の地域名・座標を持ち込まない。
- 次を年量、月別、気候区分で報告する。
  - アマゾン
  - 中国東部
  - 中国南部
  - ラプラタ・アルゼンチン北東部
  - パンパ
  - パタゴニア東部
- 各地域でモデル値、観測値、比、最乾月、最多雨月を出す。
- 気候区分は上位クラスだけでなく、観測との分布差を出す。

### ゲートの見直し

- `amazon_tropical` は互換のため残してよいが、これだけで雨林合格としない。
- `amazon_rainforest` を追加し、Af+Am の比率と最乾月を評価する。
- `east_asia_humid` は C 群比率と年降水比を併記する。
- `la_plata_humid` または同等の検証を追加する。
- `patagonia_rainshadow` は年降水比も併記する。

### 受入条件

- 本書「1. 現状の測定結果」を許容差 ±2% で再現する。
- 同じ地域定義を最適化と標準検証で共有する。
- 観測欠損、海陸不一致、面積重みの扱いを JSON に明記する。
- この段階ではモデル出力を変えない。

## 5. R1 — 降水の内部要因を診断可能にする

現在の最終降水だけでは、供給不足なのか、持上げ不足なのか、
沈降・雨陰による抑制過多なのか判別しにくい。

診断時のみ、少なくとも次を地域集計できるようにする。

- 海洋由来供給
- 陸面再循環由来供給
- ストームトラック由来供給
- ITCZ 持上げ倍率
- 前線持上げ倍率
- 地形性持上げ倍率
- 亜熱帯沈降の残存倍率
- 風上山脈の遮蔽倍率
- 最終降水

常時 `PipelineResult` を肥大化させず、診断モード、集計フック、
または検証専用関数で実装してよい。

### 受入条件

- 各因子から最終降水を許容誤差内で再構成できる。
- 上記 6 地域の月別平均を機械可読 JSON へ出せる。
- 診断を無効にした通常実行の配列と速度を退行させない。

## 6. R2 — 無効になっている供給月ブレンドを直す

`step06_precipitation.ts` のコメントは前月/当月/翌月を
0.25/0.5/0.25 で混ぜるとしているが、実装は 0/1/0 の恒等写像である。

### 修正方針

- まずコメントの意図と較正記録を確認する。
- 供給場に対する循環 3 点ブレンドを、単独実験として復活させる。
- 1 月と 12 月の循環境界を含むテストを追加する。
- ブレンド前後で年総量が変わる場合、非線形変換による差を報告する。
- 後段の `precipMonthBlend` と役割を区別する。

### 受入条件

- 月境界で供給が 0 へ落ちるセル数が減る。
- アマゾン、中国、ラプラタの最乾月を悪化させない。
- サバナ・地中海性気候の連続した乾季を消さない。
- 効果が中立または悪化なら、無理に採用せず結果を記録して撤回する。

この修正は遷移月の断絶対策であり、数か月続く乾燥の完全な解決策とは扱わない。

## 7. R3 — 土壌水分の季節記憶を導入する

アマゾン乾季対策の本命とする。

### 最小モデル

各陸セルに月別土壌水分状態を持たせる。

1. 前月貯水に当月降水を加える。
2. 温度・日射・貯水率から蒸発散可能量を求める。
3. 実蒸発散を陸面水蒸気供給へ渡す。
4. 超過分を流出、下限を 0 とする。
5. 12 月から 1 月へ状態を接続する。
6. 同じ年周期へ収束するまで複数年空回しする。

単なる降水比例ではなく、過去の雨を乾季へ持ち越す状態であること。
初期値によって最終結果が変わらないよう、決定的な周期定常解を得る。

### 設計制約

- 地域別の貯水量を持たない。
- 新しい自由定数は最小限とし、貯水容量・蒸発散時定数など
  独立した物理的意味を持つ量に限る。
- 降水を無限に再利用しないよう、蒸発散・流出・貯水の収支を診断する。
- 全海・全陸・極端乾燥惑星でも有限かつ決定的に収束する。

### 受入条件

- アマゾンの最乾月が基準 40 mm から増加する。
- 雨季降水を一律に増やすのではなく、乾季への季節再配分が確認できる。
- アマゾン Af+Am 比率が基準 37% から改善する。
- 豪州内陸・サハラ・アラビアの乾燥ゲートを失わない。
- 全球の蒸発散、降水、流出、貯水変化の収支を報告する。
- 空回し年数を増やしても結果が所定の許容差内で変わらない。

## 8. R4 — 水蒸気フラックス収束を降水へ結ぶ

中国東部とラプラタ盆地対策の本命とする。

### 修正方針

- 局所水蒸気量の代理場を、既存の水蒸気供給から構築する。
- 水蒸気量 × 地表風から水蒸気フラックスを作る。
- 球面格子のセル幅を使い、水平発散を計算する。
- 湿潤かつ収束する場所だけ、前線・対流性持上げを増やす。
- 亜熱帯沈降は緯度帯だけで全開にせず、
  湿潤収束によって実効抑制が連続的に弱まるようにする。
- 乾いた低圧や乾いた収束では降水を発生させない。

この機構により、地域名なしで次を同じ原理から表現する。

- 中国東部の夏季モンスーン・梅雨前線
- ラプラタ盆地へ入る暖湿流
- アマゾン内陸の湿潤収束
- 米国南東部の湿潤東岸

### 受入条件

- 中国東部・ラプラタの海洋由来供給または収束持上げが増えたことを
  R1 の診断で説明できる。
- アラビア、サハラ、豪州内陸は、湿潤収束がない限り乾燥を維持する。
- 対称な全海惑星で不自然な経度模様を作らない。
- 自転方向を反転すると、東西位相が物理規則どおり反転する。
- 解像度変更で発散の強さが大きく変わらない。
- 負の降水、NaN、無限値を作らない。

## 9. R5 — パタゴニアはアンデス遮蔽として別に直す

北東部の湿潤化とパタゴニアの乾燥化を、同じ総量係数で解こうとしない。

### 修正方針

- 生の高解像度標高から、各気候セル内の最大標高または高分位標高を作る。
- 平均標高は気温・地表状態、山脈標高は遮蔽・脱水に使い分ける。
- 狭い高山脈と広い高原縁を区別できる補助量を検討する。
- 南米専用の山脈判定を作らず、全惑星で同じ地形演算を使う。

### 受入条件

- パタゴニア東部の年降水比 4.53 を大幅に下げる。
- `patagonia_rainshadow` の B 群を過半へ戻す。
- アンデス西側の地形性降水が同時に弱くならない。
- コンゴ盆地縁など、高原段差を狭い山脈と誤判定して熱帯を壊さない。

## 10. R6 — 蒸発冷却は降水場改善後に再試験する

既存記録では、降水に比例する蒸発冷却を先に導入すると、
誤った降水場が気温誤差へ伝播し、全球指標が悪化した。

R2～R5 で降水場を改善した後に限り、次を再試験する。

- 土壌水分と実蒸発散に基づく潜熱冷却
- 温度 → 降水 → 土壌水分・蒸発散 → 温度の反復
- エネルギー収支と水収支の両方の診断

単なる「当月降水 × 係数」には戻さない。

中国・アルゼンチンの高温偏差はケッペン B 閾値も押し上げるため、
降水改善後の蒸発冷却には追加効果が期待できる。ただし、降水誤差を
再び気温へ増幅しないことを必須条件とする。

## 11. 実験順

目的関数と地域基準を凍結し、次を別々に測る。

1. 現行基準
2. R2 供給月ブレンドのみ
3. R3 土壌水分のみ
4. R4 水蒸気フラックス収束のみ
5. R3 + R4
6. R3 + R4 + R5 アンデス遮蔽
7. 上記採用構成 + R6 蒸発冷却

各実験で、全球適合度だけでなく本書の全地域を同じ表で報告する。
一地域だけ改善して他地域を壊す変更は、総合点が上がっても採用しない。
