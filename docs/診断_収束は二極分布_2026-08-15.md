# 診断: 収束指数は**二極分布**。飽和点は機構を殺していない — 足りないのは「立つ範囲」

日付: 2026-08-15
道具: `scripts/diag_convergence_index.ts`(新規)
出力: `out/diag_convergence_index.txt`
前段: [実験記録_収束持上げ](実験記録_収束持上げ_2026-08-15.md)(段 29)

## なぜ測ったか

段 29 で `convergenceLiftBoost` を生き返らせたら、**今日初めて
「中位を守りつつ乾いた端を改善する」**形が出た。だが強さが足りず、
中位の正味流入は必要量の 1 割しか増えなかった。

事前登録の「外れる筋 C」に、こう書いていた:

> その場合は `moistureConvergenceNorm` / `convergenceWetnessNorm` が
> 機構を殺している側で、次はそこを見る。

今日、**飽和点や基準値が機構を殺している例を 3 つ**見つけている
(`orographicRefSlope` 800 / `upwindBlockReliefM` 1e9 / `upwindBlockFloor` 1)。
同じ型を疑って、**掃引の前に分布を見た**。

## 結果 — **予想と逆。飽和していた**

```
正規化 moistureConvergenceNorm = 2（この値で 1 に飽和）
収束指数が正のもの: 53.7%

分位    収束指数  指数/norm  実際の持上げ倍率（boost 0.5）
50.0%    0.297    0.15      1.0023   ← ほぼ効かない
75.0%   15.439    7.72      1.4364   ← 既に飽和
90.0%   55.861   27.9       1.4824
95.0%   93.973   47.0       1.4895
99.0%  193.033   96.5       1.4949   ← 完全に飽和
99.9%  309.439  154.7       1.4968

中緯度(|lat| 20〜50°): 中央 0.173 / 90% 55.840 / 99% 202.027
```

**収束指数は norm = 2 に対して桁違いに大きい。** 75% 分位で 7.7 倍、
99% で 97 倍。**`convergenceStrength01` は 1 に張り付いている。**

一方 50% 分位では指数 0.297(norm の 0.15)で倍率 1.0023 = ほぼ効かない。

**分布が二極化している — 0 近傍か、飽和か。**

## したがって

- **外れる筋 C(norm が機構を殺している)は外れ。**
  norm は低すぎて、収束を**オンオフのスイッチ**にしている。
- **norm を下げても意味がない**(既に飽和している場所がさらに飽和するだけ)。
- **norm を上げても意味がない**(弱い場所が相対的にさらに弱くなる)。
- 段 29 で boost を上げても中位が上がらなかった理由が説明できる:
  **収束が立つ場所では既に最大まで効いており、boost を上げても
  同じ場所が強くなるだけ**。中位の陸の半分では指数が 0.17 で、そこには届かない。

**足りないのは強さでも飽和点でもなく、「収束が立つ場所の範囲」である。**

## 何を意味するか

中緯度(20〜50°)の収束指数は**中央値 0.17、90% 分位 55.8** —
**2 桁半の広がり**がある。収束は「一部の場所で猛烈に立ち、大部分では立たない」。

実物の温帯低気圧は移動性で、**月平均すれば中緯度に広く分布する**。
モデルの月平均の風の場は、**その広がりを作れていない**。

これは [検証待ち](検証待ち_2026-08-12.md) §2「帯状卓越風の経度依存」と
同じ場所を指している:

> 残るのは偏西風が `westerlyWindMs` という 1 つの定数で**経度によらず一定**に
> 吹いていること。実物の夏は太平洋高気圧の西縁で偏西風が北へ迂回し、
> その南に湿った南西流が入る。**帯状一様では原理的に作れない構造。**

**中位の陸が乾いているのは、月平均の帯状一様な風の場が
中緯度の収束を広く作れないからである。**

## 次に効きそうなこと

1. **`convergenceLiftBoost` は採用候補として保留する。**
   段 29 で棄却したが、**今日唯一「中位を守りつつ端を改善した」手**である。
   風の場を直したときに、この機構が受け皿になる。
   単独では主判定に届かないので、**風の側と組で評価すべき**。
2. **風の場の経度依存**([検証待ち](検証待ち_2026-08-12.md) §2)。
   地理中立に書けるか(海陸分布から決まる形にできるか)が設計の勘所で、
   そこは未解決のまま残っている。
3. `convergenceWetnessNorm`(3、湿潤ゲート)は未確認。
   収束指数が立っていても湿潤ゲートが閉じていれば効かない。
   **ゲートの側の分布も見る価値がある**(この診断では見ていない)。
