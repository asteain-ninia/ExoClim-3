# 事前登録: 夏の高気圧の西方張り出し(段 39)は C→B の南風を作れるか

日付: 2026-08-16(実装は済んだが、**まだ一度も走らせていない**段階で書いた)
設計: [設計_夏の高気圧の西方張り出し](設計_夏の高気圧の西方張り出し_2026-08-16.md)

## 測ること

```
npx tsx scripts/sweep_lever.ts subtropicalCellWestSummerBoost 0,0.3,0.6,1.0 --parallel 4
```

有望なら(下の判定 1 を満たしたら)追加で:
- `diag_monsoon_inflow` を boost=最良水準で — C→B セルの夏の v が正へ動くか
- `diag_c_to_b` — C→B の面積そのものが減るか
- `exp_idealized_continent` — 東岸湿潤(いま 3.1%)が動くか

## 予測(結果を見る前に固定)

1. **米南東の年降水比が上がる**。0.37 → boost 0.6 で **0.42 以上**。
   バミューダ高気圧の西縁がちょうどそこに当たるため。
2. **欧州は壊れない**(0.92 → 0.88 以上を維持)。陸の気圧場に触らないので、
   熱的低気圧が欧州を壊した力学(大陸西縁の北風)を持たないはず。
   **ここが案 1 との分かれ目**であり、この予測が外れたら設計の前提が誤り。
3. **東アジアはほぼ動かない**(0.20 → 0.22 以下)。あちらは流出過多の問題
   (6 回の棄却)。動いたら嬉しい誤算だが、期待しない。
4. インドは小幅改善(0.45 → 0.46〜0.50)。アラビア海の高気圧西縁が効きうる。
5. **連続部分**: boost 0.3〜0.6 のどこかで **70.35 以上**(現行 70.31 を上回る)。
   気温 RMSE の悪化は 0.05 以内(海上の気圧だけを触るので、偏西風のときの
   ような陸の気温への直撃は無いはず)。
6. 数値的健全性は全水準で保たれる。

## 判定

- **予測 1 かつ 2 が当たり、5 も当たったら**: 採用候補。diag 3 種で裏を取り、
  そろったら利用者に「探索空間へ入れて較正をやり直す」裁定を仰ぐ
  (探索空間の変更 = v24 の打ち切りを意味するため、私の判断では動かせない)。
- **予測 1 が外れたら**(米南東が動かない): 西縁の回転成分が沿岸まで届いていない。
  気圧勾配風の上限(P_MAX=8)か回転係数を疑う診断へ。機構は既定 0 のまま残す。
- **予測 2 が外れたら**(欧州が壊れる): 設計の前提(陸に触らなければ西岸は
  無事)が誤り。掃引を止めて壊れ方を診断する。
- 5 だけ外れたら: 向きは正しいが桁が足りない(段 16 と同じ型)。
  張り出しの強さではなく**気圧→風の変換**の側を疑う。

**どの結果でも目的関数の重みは動かさない。定数の既定値も 0 のまま**
(採否は較正のやり直しとセットで、利用者の裁定事項)。
