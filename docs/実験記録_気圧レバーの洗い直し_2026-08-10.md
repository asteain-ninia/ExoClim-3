# 実験記録: 気圧レバーの洗い直し(段 8)— トラフ増深が生き返った

日付: 2026-08-10
事前登録: [事前登録_保存則で無効化された過去の棄却](事前登録_保存則で無効化された過去の棄却_2026-08-10.md)
道具: `scripts/exp_pressure_lever.ts`

判定は事前登録どおり **v3 ではなく夏の正味流入(P − E)** を主にした。
いまの定数は非保存向けで較正も途中なので、成績で判定すると風の改善が
定数の古さに埋もれる。

各掃引は**段 3 の構造(トラフ 0)からレバーを 1 本だけ動かしたもの**である。

## 1. モンスーントラフ増深 — **採用(0 → 1.5)**

```
増深      0      0.5     1.0     1.5     2.0
v3     80.696  80.919  80.954  81.046  80.881
大分類  71.40   71.67   71.82   72.02   72.00
詳細    41.73   41.76   41.79   41.86   41.70
インド流入 427    458     491     522     548   （夏、mm/年）
コンゴ    -311   -254    -191    -146    -113
米南東     -75    -76     -75     -75     -75
東アジア   -30    -29     -28     -28     -27
```

### 当時の棄却は再現しなかった

2026-07-29 の撤回理由は「**豪州・アラビアが湿る割にインドは動かず**」だった。
保存型では逆で、**インドの流入が単調に増える**(427 → 548)。

当時の降水は非保存の到達可能性指数で、風向が変わると風上追跡の経路が海を
長く通るようになり、**実際に収束していなくても供給が増える**。
乾燥大陸が湿ってインドが動かないのは、その型の欠陥の症状そのものである。

### 1.5 を採る(2.0 ではなく)

流入は 2.0 でも増え続けるが、**v3 と詳細は 1.5 が頂点**で 2.0 では下がる。
水は入るが降り方が観測と合わなくなる。

物理上限は 2.0 と見積もった: `itczTroughHpa`(5hPa)× (1 + 2.0) = 15hPa で、
実物のアジア夏季モンスーン低気圧の偏差 −10〜−15hPa に相当する。
**1.5 は上限の手前**なので、上限に張り付いた採用ではない。

### 対照は壊れていない

コンゴの持ち出しが −311 → −146 と縮む(実物のコンゴ盆地は夏に収束する場所
なので改善方向)。ヨーロッパ・ロシアは −53 → −54 で不動。

## 2. 大陸の熱的低気圧の振幅 — **棄却(9 のまま)**

```
振幅      9      14      20
v3     80.696  80.210  79.583
大分類  71.40   71.20   70.82
詳細    41.73   41.55   41.25
インド流入 427    392     404
東アジア   -30    -42     -57
コンゴ    -311   -412    -475
```

**上げると全部悪化する。** 現在値 9 が既に良い。

理由の見当: この項は `interiorness`(海岸距離 /1500km)で重みづけされている。
振幅を上げると**内陸の低気圧だけが深くなり**、海岸から内陸への勾配が
強まりすぎて、水が沿岸に届く前に内陸へ吸い込まれる。
中緯度東岸(海岸沿い)にはむしろ不利になる。

**探索空間に入れる価値も無い**(単調に悪化する向きなので、座標降下は
現在値へ戻すだけ)。

## 3. 未達 2 地域には効かない

`us_southeast`(−75)と `east_asia`(−28)は、どちらのレバーでも**まったく
動かない**。ITCZ トラフの緯度帯(熱帯)の外なので当然である。

中緯度東岸には別の機構が要る。次の候補は**亜熱帯高気圧の西縁**
(実物のバミューダ高気圧・太平洋高気圧が東岸へ南風を送る形)。

```
振幅      6      8      10
v3     81.046  81.049  80.927
大分類  72.02   72.11   72.03
詳細    41.86   41.61   41.57
位相    72.4    72.7    73.0
インド流入   522    531     539

東アジア流入 -28    -22     -18
コンゴ      -146   -131    -122

```

この掃引だけは**トラフ 1.5 を採用した後の構造**で測られている(値 6 の行が
上の表のトラフ 1.5 の行と全桁一致する)。走らせた時点では「トラフ 0 で
測っている」と見込んでいたが、実際には定数の書き換えが読み込みに間に合って
いた。**採用後の構造で測れているぶん条件は良い**。ついでに、同じ構造を
別プロセスで走らせて全桁一致したので、決定性も確かめられた。

### 事前登録の判定

1. **不成立。** 未達 3 地域が揃って正へ動くこと、が条件だった。
   東アジアは −28 → −18 と改善、インドは 522 → 539 と微増だが、
   **米南東は −75 → −85 と逆向きに悪化**する。
2. 成立。対照は壊れていない(コンゴ −146 → −122、ヨーロッパ −54 → −45)。
3. 成立。v3 の落ちは 0.12 で許容 1.0 の内。

条件 1 が満たされないので**棄却**。加えて**詳細が 41.86 → 41.57 と単調に
低下**しており、振幅を上げて得るものが無い。

### 「西縁の南風」は立たなかった

期待した機構は、海上の高気圧の西縁で時計回りの循環が大陸東岸に南風を
作る、というものだった。式の上では確かに存在する — 東岸では東ほど高圧
(`dp/dx > 0`)なので、回転成分 `pv = +rot·dp/dx` は南風になり、横断成分
`pu = −cross·dp/dx` は陸向きになる。

効かなかったのは、**同じ振幅が帯の南北勾配も一緒に強めるから**だと見て
いる。夏の稜線は 31° + 6°×赤緯 ≈ 37°N まで北上するので、米南東
(25〜37°N)は**稜線の赤道側**に入る。そこでは `dp/dy > 0` なので横断成分
`pv = −cross·dp/dy` が**赤道向き**に効き、西縁の南風を打ち消す。
東アジア(より低緯度側)で改善が出て米南東で悪化したのは、この向きの
違いで説明がつく。

**振幅を上げる形では届かない。** 高気圧の中心を海盆へ寄せて西縁を
陸へ当てる形(セル化の側)なら別だが、それは振幅のレバーではない。

## 5. 気圧勾配の横断成分 — **棄却(1.6 のまま)**

事前登録の項目 3。等圧線を横切って低圧側へ向かう成分の結合係数。

```
係数     1.6     2.4     3.2
v3     81.046  80.379  80.057
大分類  72.02   71.76   71.64
詳細    41.86   41.57   41.57
位相    72.4    73.0    73.0
インド流入   522    660     714
米南東流入   -75    -72     -71
東アジア流入 -28    -20     -15
コンゴ      -146   -183    -200
ヨーロッパ   -54    -35     -29
```

### 判定

1. 未達 3 地域は**全部正の向きへ動く**。ただし米南東は −75 → −71 で、
   4 mm/年 は不足 403 mm/年 に対して**有意とは言えない**。
2. **不成立。**対照のコンゴが −146 → −200 と 37% 悪化する。
3. 成立(81.046 → 80.057、0.99 の低下で許容 1.0 の内)。

条件 2 が満たされないので**棄却**。大分類・詳細も単調に低下する。

### 読み: 水は入るが、降り方が悪くなる

インドの流入は +192(37%)と大きく増えるのに、**成績はすべて下がる**。
横断成分は全球に一様に効くレバーなので、モンスーンだけを強めることが
できず、中緯度の西風まで陸へ曲げてしまう。ヨーロッパの持ち出しが
−54 → −29 と縮むのはその表れで、**すでに運びすぎている場所へさらに運ぶ**。

段 8 で振った 4 本のうち、**選択性があったのはモンスーントラフだけ**である
(熱帯の陸の多い経度にしか掛からない)。残り 3 本はいずれも全球一様な
振幅で、地域を選べないまま副作用の側が勝った。

## 6. ここまでの読み

気圧側のレバーを 3 本振って、**熱帯のトラフだけが効いた**。
中緯度東岸(米南東・東アジア)はどのレバーでも動かない。

3 本に共通するのは、**気圧場が幾何と日射だけから作られている**ことである
(`step02_windbelt.ts`)。大陸の熱的低気圧すら、モデル自身の気温ではなく
**日射の月偏差 × 海岸からの距離**で書かれている。だから
「夏に陸が熱くなったから低気圧ができる」という帰還が無く、
振幅をいくら上げても**低気圧が立つ場所が変わらない**。

診断 2 件と外部レビュー 2 件が指していたのはここである。
残りは事前登録の項目 1(赤道越えモンスーン風)で、これだけは
**ITCZ の変位に応じて掛かる**ので選択性を持つ。それを測ってから、
温度 → 気圧の帰還そのもの(段 9)へ進む。
