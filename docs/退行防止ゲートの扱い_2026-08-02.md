# 退行防止ゲートをどう扱うか(2026-08-02)

**判断は利用者に委ねる**。ここでは事実と選択肢だけを並べる。

## 何が起きたか

2026-07-31 に凍結した退行防止ゲートは、**数値に 3 つの欠陥を抱えたモデル**を
基準にしていた。一晩で欠陥を直した結果、同じ基準では大きく落ちる。

| 指標 | 凍結基準 | 欠陥ありの実測 (2026-07-31) | 修正後・較正前 |
|---|---:|---:|---:|
| 大分類一致率 | ≥ 73.4 | 73.93 | **70.61** |
| 詳細一致率 | ≥ 42.2 | 42.74 | **35.70** |
| 地域ゲート | ≥ 14 | 14 | **14** ✅ |
| 気温年 RMSE | ≤ 3.8 | 3.65 | **6.80** |
| 降水年 RMSE | ≤ 800 | 773 | **918** |
| ITCZ 線 RMSE | ≤ 8.6 | 8.33 | **8.20** ✅ |
| 陸平均降水比 | 0.9〜1.1 | 1.04 | **1.33** |

## 直した 3 つの欠陥(いずれも較正が吸収していた)

1. **線形解を 8 回で打ち切っていた**(隠しパラメータ)。収束させると
   気温場が面積平均 2.1°C 動く。
2. **南北界面の伝導度が非対称**で、亜熱帯にエネルギーの湧き出しがあった。
   面伝導度を両側平均にして保存形に。
3. **全熱容量で回すのが末尾 2 年だけ**(τ ≈ 3.2 年に対し 0.6τ)。
   周期定常に達していなかった。24 年まで回すと収束する。

いずれも「数値誤差を打ち消す向きに物理係数が較正されていた」という同じ構図。
**成績の一部は物理ではなく数値誤差への当てはめだった。**

## 物理の指標は改善している

採点(ケッペン一致率)は落ちるが、観測と直接比べる季節の指標は良くなる:

| | 修正前 | 修正後 |
|---|---:|---:|
| 季節位相の遅れ | 25.3 日 | **22.7 日** |
| 内陸の季節振幅の過大 | +4.32°C | **+3.85°C** |
| 地域ゲート | 13 | **14** |

## ここで見えた目的関数の盲点

**目的関数は季節振幅を一切測っていない**(気温は年平均 RMSE のみ)。
一方ケッペンの第 3 文字(a/b/c/d)は最暖月で決まる。
そのため「季節振幅が実測に近づいたのにケッペン一致率が下がる」ことが起きうる。
実際に起きた。目的関数の設計を見直す価値がある。

## 選択肢

### A. 基準を凍結したまま(現状)
CI は落ち続ける。「基準は緩めない」の原則には忠実だが、
基準が**存在しないモデル**を指しているので、退行検知として機能しない。

### B. 再較正の結果で基準を貼り直す
数値を直したモデルで較正し直し、その実測から新しい基準を凍結する。
旧基準は「欠陥ありの版の記録」として残す。
**推奨**。ただし「成績が下がったから基準を下げた」と読まれないよう、
下がった理由(数値の修正)と、下がっていない指標(地域ゲート・ITCZ)を
併記すること。

### C. 数値の修正を撤回する
成績は戻るが、**数値誤差に当てはめた係数**を維持することになる。
教訓 §1「客観の物差し」に反する。取らない。
