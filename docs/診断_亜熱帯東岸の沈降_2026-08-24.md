# 診断: 亜熱帯東岸の湿潤不足の主犯 — 沈降の帯状性(台帳 項目 15)

日付: 2026-08-24
道具: scripts/diag_eastcoast_factors.ts(新規)。理想化大陸(45d の検証台)と地球で、
亜熱帯 25〜35° の陸を西岸/内陸/東岸に分け、P = λ·G·W の因子を並べる。

## 理想化大陸(v32 定数、2°)

```
帯          年降水  W(mm)  G     沈降残存  東岸緩和  liftItcz  liftFront  供給
西岸 0-20%    132   2.74  0.35   0.27     1.00      1.00      1.05     6.48
内陸 40-60%    54   1.39  0.31   0.27     1.00      1.01      1.00     1.03
東岸 80-100%  294   3.25  0.62   0.40     0.82      1.01      1.22     6.98
```

**東岸には水がある**(W・供給とも西岸並み以上、前線持上げ 1.22 も立つ)のに、
**沈降の残存率 0.40 が雨の 6 割を殺す**。西岸(0.27)とほぼ同じ扱いで、
東岸緩和(eastCoastSubsidenceRelief)は 0.82 までしか緩めていない。

実物: 亜熱帯高気圧の下降枝は**海盆の東側(= 大陸の西岸側)**に集中し、
海盆の西側(= 大陸の東岸)は下降が弱く、高気圧の西縁を回る湿潤な南風が入る。
モデルの沈降は**リッジ緯度の帯**として置かれ、海盆内の東西非対称を持たない。
東岸緩和はその帯に後付けの割引を掛けているだけで、緩め切れていない。

## 地球(v32 定数、1°)— 同型を確認

```
帯          年降水  W(mm)  G     沈降残存  東岸緩和  供給
西岸 0-20%    220   3.84  0.40   0.28     0.97      8.17
内陸 40-60%   216   3.49  0.43   0.32     0.93      4.55
東岸 80-100%  408   4.26  0.69   0.47     0.72      8.57
```

地球でも東岸に水は十分(W 4.26・供給 8.57)で、沈降残存 0.47 が主犯。
**普遍的な弱点と確定**(理想化大陸と地球で同じ数字の型)。

## 処方(次の事前登録で)

沈降の強さを海盆内の位置で非対称にする(step02 の亜熱帯高気圧セルが既に
「海盆の東縁ほど強い」離散化を持つ — その東西プロファイルを step06 の沈降が
**読む**形)。東岸緩和の後付けではなく、**沈降の源泉に非対称を入れる**。
地理中立(海盆の東西位置と自転方向だけ)。
