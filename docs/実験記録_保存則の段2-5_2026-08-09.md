# 実験記録: 段 2〜5 — 補償だった乗数を 1 つずつ外す

日付: 2026-08-09
計画: [計画_保存則の段階的置換](計画_保存則の段階的置換_2026-08-09.md)
道具: `scripts/exp_conservative_stages.ts`
前提: 段 1 を[正しい判定で測り直した](実験記録_保存則の段1_2026-08-09.md)後の測定

## 事前に固定した読み方

> **外したのに悪化しない乗数は「保存の欠落を補っていた」ことの証明になる。**
> 悪化するなら別の物理を代弁していたので戻す。

## 結果

```
                              閉包    収束  v3      大分類  詳細   位相   陸降水
段 1（乗数そのまま）           -0.0%   ○    80.418  71.49  41.20  72.4    608
段 2（+地形の枯渇を外す）      -0.0%   ○    80.451  71.54  41.13  72.4    610
段 3（+広域の遮蔽を外す）      -0.0%   ○    80.688  71.39  41.72  72.1    630
段 4（+東岸の沈降緩和を外す）  -0.0%   ○    79.712  70.76  41.07  72.6    657
段 5（+距離減衰を外す）        -0.0%   ○    75.559  70.85  38.37  78.2    925
                                                          （段 0 = 77.18）
```

各段は**累積**である(段 3 は段 2 の除去も含む)。

## 判定

| 段 | 乗数 | 判定 | 根拠 |
|---|---|---|---|
| 2 | `orographicDepletionM` | **外す** | 動かない(v3 +0.03、詳細 −0.07) |
| 3 | `upwindBlockReliefM` / `Floor` | **外す** | 詳細 +0.59、陸降水が観測へ +20mm |
| 4 | `eastCoastSubsidenceRelief` | **戻す** | 大分類 −0.63、詳細 −0.65、位相も +0.5 日悪化 |
| 5 | `moistureDecay*Km` | **保持** | 実験の設計が誤っていた(下記) |

### 段 2 — 地形の枯渇は保存則が代わりに出す

風上山脈による水蒸気の枯渇を完全に無効化しても、成績が動かない。
保存則があれば「風上で降ったぶんだけ気柱の水が減る」ので、枯渇は収支から
自然に出る。**乗数として別途書く必要が無かった。**

### 段 3 — 広域の遮蔽は、外したほうが良かった

詳細一致率が **+0.59** 改善し、陸平均降水も観測 794 へ近づいた(610 → 630)。

広域の遮蔽は「風上に山があれば下流を一律に乾かす」乗数だが、保存則では
風上で降ったぶんの水が実際に減っている。**二重に乾かしていた。**

補償だったどころか、保存則の下では**積極的に害**になっていた乗数である。

### 段 4 — 東岸の沈降緩和は、別の物理を代弁していた

外すと大分類 −0.63、詳細 −0.65。**戻す。**

物理としても筋が通る。亜熱帯の沈降が大陸東岸で弱まるのは、暖かい海面水温と
モンスーン循環のためで、**2 次元の柱収支からは出てこない**情報である。
保存則を入れても代わりにならない。

### 段 5 — 実験の設計が誤っていた(棄却ではなく無効)

段 5 は「`moistureDecay*Km` の距離減衰を凝結寿命 λ へ移す」つもりだった。
だが**段 1 の時点で既に移してある** — 保存型では λ = U_ref / L として、
この定数そのものが凝結寿命である。

したがって段 5 がやったのは「移す」ではなく **λ を消す**ことだった。
L を 10 万 km にすれば λ ≈ 0 になり、水は凝結せずに漂い続ける。
陸平均降水 925(観測 794 を超過)、位相 78.2 日(段 0 より悪い)は当然で、
**物理の知見ではなく実験の誤り**である。

計画を書いた時点で「距離減衰」と「凝結寿命」を別物として数えていたのが原因。
**段 1 で意味が変わった定数を、段 5 の表が古い意味のまま持っていた。**

## 採る構造 = 段 3

```
conservativeMoisture      1（保存型を既定に）
orographicDepletionM      無効
upwindBlockReliefM        無効
upwindBlockFloor          1（遮蔽なし）
eastCoastSubsidenceRelief 残す
moistureDecay*Km          残す（凝結寿命 λ として）
precipScaleMmPerUnit      消滅（保存則の中に置き場所が無い）
```

この構造での段 0 との比較:

```
                段 0（非保存）   段 3（保存型）
閉包            +63.9%  ×       −0.0%  ○
v3              86.180          80.688
詳細             45.00           41.72
季節位相         77.18 日        72.10 日    −5.08 日
陸平均降水        742             630（観測 794）
```

**v3 は 5.49 落ちるが、水が閉じ、季節位相が 5 日改善する。**
ここから段 6(再較正)へ進む。v15 の 62 個の定数は非保存のモデルに
合わせて決まっているので、同じ値が同じ意味を持たない。
