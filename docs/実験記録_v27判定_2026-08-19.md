較正は「乾いた端」(1% 分位 61)と分布形を買うために、**C→B 作戦の
本丸である東アジア・ラプラタをさらに乾かした**。目的関数が「均す」を
報酬にする既知の癖([exoclim3-objective-favors-smoothing])の再演で、
地域構造を守る項(地域ゲートは 13 のまま動かず崖の外)が効いていない。

## 新機構が棄却された理由(定量)

- 暦の遅れ: 位相 RMSE は冬雨型が支配するため、熱帯を完治させても
  −1.2 日 ≈ +0.08 点にしかならず、大分類の −0.13 に負ける。
  **位相項の重み・形の問題として v28 の目的関数論点に登録。**
- コンベア: 単体では大分類 −0.2 前後の巻き添え(ゴビ等)が利得を上回る。
  段 44(沈降置換)との組で「水が来た場所でだけ沈降が緩む」を作るのが
  設計時からの本線(45c)。

## 推奨(利用者への相談)

**見送り(v26 のまま)を推奨する。**理由:
1. 全球 +0.21(大分類)の対価が東アジア C 群 1/4 化・ラプラタ 4 割減で、
   いま戦っている C→B 作戦の戦線をそのまま後退させる。
2. 45c と目的関数の位相・地域項の見直しがどのみち控えており、
   v28 の再較正で上書きされる公算が高い(v27 の state は種として残る)。
3. ただし itczMonsoonPullDeg=5.38(範囲拡張の的中)と気温 RMSE 3.49 は
   本物の前進なので、v28 の初期値には v27 の best を使う。

採用する場合の根拠も残す: 客観の物差し(目的関数)では明確に勝っており、
「結果を見て物差しを疑う」は作法違反すれすれである。ただし本件は
物差し自体の欠陥(地域構造の無報酬)が既知・記録済みであり、
「式の誤りを直すのは可」の側に該当すると判断した。

## 訂正(同日、利用者の指摘を受けた再検分)

**上の「代償」節は比較対象を取り違えていた。**401mm / 14.5% / 444mm /
1942mm / ゲート 14 は**古い凍結基準**(2026-08-02 前後)の値であり、
v26 の実力ではない。v26 を同条件で回し直した正しい対照は:

```
              v26     v27     差
中国東部 年降水  315  →  286   −29mm(基準 401 は旧凍結値)
中国東部 C 群    6.5% →  3.9%  −2.6pt(同 14.5 は旧凍結値)
ラプラタ 年降水  309  →  270   −39mm
パタゴニア東部   719  →  726   同等(1942 は旧凍結値 — v26 で解決済み)
地域ゲート       13   →  13    **不変**
```

退行は実在するが、当初報告(−115mm・ゲート喪失)より大幅に小さい。
これは光度事件(2026-08-17)と同型の「**比較対象の数字を自分で計算しない**」
の再犯である。validate の「基準から退行」表示は凍結基準比であって
直前版比ではない — 今後、版の比較には必ず両版を同条件で回す。
