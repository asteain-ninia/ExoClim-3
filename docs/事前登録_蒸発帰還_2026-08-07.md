# 事前登録: 蒸発冷却の陰的化(∂LE/∂T を EBM の対角へ)

日付: 2026-08-07
対象: R1(`docs/実験記録_冷帯の夏_2026-08-06.md` §4 の機構)
**この文書は結果を見る前に書いて確定させる。** 後から条件を緩めない。

## 何を変えるか

現在の蒸発冷却は、前パスの蒸発散から冷却量を作って EBM の**右辺へ定数として
足している**(`buildEvapCoolingAnomaly`)。気温が上がっても冷却は増えない。

実際は気温が上がれば飽和水蒸気圧が上がり、蒸発散が増えて潜熱の持ち出しが強まる。
これは**負帰還**であり、行列の**対角**へ入る量である。

前パスの気温 `T_ref` のまわりで線形化する(ニュートン法と同じ形):

```
LE(T) ≈ LE(T_ref) + k·(T − T_ref)
k = frac · λ · α(T_ref) · (E − Ē)          [W/m²/K]
λ = 28.4 W/m²/(mm/日)   … ρ_w·L_v/86400。物理定数、較正しない
α(T) = L_v/(R_v·T²)     … クラウジウス・クラペイロン。288K で 0.064/K
E − Ē                    … 陸面平均からの蒸発散の偏差(既存の陽的項と同じ基準)
```

実装は 2 行:
- `diag += k`
- `rhs += k · T_ref`

**偏差(E − Ē)を使う**のは既存の陽的項と揃えるため。平均的な潜熱損失は
OLR 切片 A / 傾き B に既に吸収されているので、絶対値を足すと二重計上になる。
偏差にすれば陸面平均は動かず、湿った陸だけ減衰が強まり、乾いた陸は弱まる。

`evapFeedbackFrac = 0` が既定で、**0 のときは従来と 1 ビットも変わらない**。

## 予測(事前に書く)

観測 D 帯 1609 セル(2° 集約)の最暖月ずれは現在:

```
40〜50°N  +4.77°C     50〜60°N  +5.38°C     60〜70°N  +1.08°C
D の第 3 文字の一致 31.3%
```

`evapFeedbackFrac = 1`(理論値そのまま)で:

1. **50〜60°N が最も大きく下がる**。蒸発散が最大の帯なので k も最大。
2. **60〜70°N はほとんど動かない**。蒸発散が小さいので k が小さい。
3. **砂漠は逆にわずかに暑くなる**(偏差が負 → k が負 → 減衰が弱まる)。
   これは既存の陽的項と同じ符号で、狙い通りの挙動である。

## 判定条件

### 主判定(これを満たさなければ機構が効いていない)

- 観測 D 帯の最暖月ずれが **40〜50°N と 50〜60°N の両方で +3.0°C 以下**
  (現在 +4.77 / +5.38)

### 副判定

- **D の第 3 文字の一致が 45% 以上**(現在 31.3%)
- **乾燥ゲート 3 件(`sahara_arid` / `arabia_arid` / `australia_interior_arid`)が
  PASS を維持**。1 件でも落ちたら砂漠を壊している
- **数値的健全性**: EBM 残差 < 1e-3 °C、年次ドリフト < 0.05 °C。
  これは必須条件で、満たさない結果は採点しない

### 棄却条件

- 主判定を満たさない → 機構が効いていない。`frac` を 1 から動かして
  再測定するのは可(理論値ちょうどである必然性は無い)。ただし
  **frac を 3 段階(0.5 / 1 / 2)試して主判定に届かなければ棄却**する。
- 乾燥ゲートが落ちる → 副作用が大きすぎる。棄却。

### v3(目的関数)の扱い

**較正前の単発では v3 が下がってもよい**(2026-08-02 の退行方針: 局所最適からの
脱出による一時的な低下は退行ではない)。ただし **v3 が 3 ポイント以上落ちたら
機構そのものを疑う** — 冷帯の夏を直す代わりに他を壊しているということなので、
その場合は原因を特定してから較正へ進む。

較正後の最終採否は従来どおり **数値的健全性 / 新旧両目的関数 / 季節指標 /
地域ゲート / 未見評価**の 5 点で総合判断する。
