## 予測(診断文書の (a)〜(d) を判定条件化。ゲート 0↔1 の比較で測る)

45. アラビア海・メキシコ湾+カリブ・南シナ海の SST 偏差平均が全て **+0.3°C
    以上**上がる(偽寒流の消滅)。カリフォルニア沖(実在)は **±0.1°C 以内**。
46. インド箱(india)の年降水比が**上がる**(向きのみ登録 — 量は蒸発・輸送
    経由で予測不能)。米南東(us)・華南も下がらない。
47. 大分類は v29 判定時の基準から **−0.3 以内**(較正なしの生の差し替えでの
    許容。座標は v30 較正が取り直す)。
48. 数値的健全性は維持。

## 判定

- 45 が外れたら実装のバグ(ゲートの向き・半球鏡像)を疑う。機構は疑わない。
- 45〜48 成立 → ゲート 1 を既定として v30 の基準線に含める(v30 の事前登録に
  基準線を post-fix で書き直す)。coldCoastSuppression の張り付き(0.25)が
  v30 で緩むか(診断の予測 (d))は v30 の判定で見る。

## 判定(同日未明、v29 定数上のゲート 0↔1 同条件比較)

```
                     ゲート0(旧)          ゲート1(修正後)
アラビア海      平均 −0.18 / 超え 25%   → +0.19 / **0%**
メキシコ湾+カリブ +0.39 / 14%           → +0.12 / **2%**
南シナ海        +0.38 / 20%            → +0.62 / **2%**
カリフォルニア(実在) −0.07 / 21%        → +0.07 / 10%
```

- 45 **部分成立**: 主害経路(寒流抑制の誤発火セル)は 3 海域とも壊滅(◎)。
  平均の +0.3 到達はアラビアのみ — 湾は**対の偽暖流の消滅**(診断に記載済みの
  西縁側)が差し引かれるため。実在カリフォルニアは +0.14・超え 21→10% と
  予測の ±0.1 を超えて弱化(列直進の走査が湾曲した岸沿いセルを塞ぐ粗さ)。
  → **v31 候補: 岸滑り(塞がれたら海側へ 1〜2 セル逃がして続行)**。
- 46 部分: india BWh 52→49%(改善方向 ○)。中国東部 285→251mm・ラプラタ
  243→217mm(**悪化** — 縁海の偽暖流が東シナ海等の蒸発源を偽って支えていた
  ぶんが剥がれた)。
- 47: 大分類 74.7(修正後・較正なし)。48: 健全性 PASS ○。

## 結論

**ゲート 1 を既定として維持**(撤回しない)。根拠は結果でなく事実(偽の海流)。
剥がれた偽の支えぶんは v30 較正が修正後物理で取り直す。中国東部の後退は
「偽の熱で湿らせていた」ことの露呈であり、コンベア(実在の水の輸送)への
需要がさらに明確になった。
