# 事前登録: 熱移流の保存化(段 C-0、台帳 26 — 0.68°C の偽熱源を閉じる)

日付: 2026-08-28 夜(実装前に書いた)
出所: 外部監査「2温度場の前に」+実測(結合 60↔30 で全球平均 0.675°C
シフト = 移流項が正味の熱源)。3 兄弟追跡の結論「すべての道が構造へ」の
初手として、海気分離 段 C の土台から着工する。

## 何が非保存か(精読の結果)

現行: セル i の式に `advC_i × (T_up − T_i)` を加える。advC_i は
**セル i 固有の係数**(季節・逆転・landGrip・海峡・v 帯域で変調)なので、
i が受け取る熱と、風上セルが(自分の式で)失う熱が一致しない —
面で相殺せず、変調の強い場所が正味の熱源/吸込みになる。

## 設計(面フラックス形式 — 水蒸気ソルバと同じ構造)

面ごとに一意の係数 c_f(両側セルの変調の**風上側**)を決め、
- 風下セル: `off += c_f × T_up`、`diag += (自セルが風上になる面の c_f の和)`
- 一様 T で厳密に相殺(Σ 面フラックス = 0)。行列は M 行列性を保つ。

切替: `advectionConservativeBlend`(既定 **0 = 旧式とビット一致**、1 = 面形式)。
保存型水蒸気(conservativeMoisture)と同じ段階切替の作法。
CPU を先に実装・検証し、GPU 2 カーネルは CPU と突合してから。

## 予測(測る前に固定)

140. 生存性: blend=0 ビット一致・1 で変化。
141. **酸性試験(この修正の存在理由)**: blend=1 で結合 60↔30 の全球平均
     シフトが **0.675°C → 0.15°C 未満**へ(偽熱源の消滅)。
142. 高緯度の年平均温暖バイアス(シベリア +9°C 等)が**縮む方向**
     (偽熱源は変調の強い高緯度陸に集中しているはず)。
143. 大分類は単独で ±1.0 以内(基準線が動く物理修正 — v39 の再較正前提)。

## 判定

- 141 ○ → 修正を確定(事実基準)。GPU 2 実装を CPU と突合して blend=1 を
  v39 の物理に含める(zonalAdvectionCoupling は再較正で再配分される)。
- 141 ✗(シフトが残る)→ 熱源は移流以外(海氷・雲・Q フラックス)。
  分解し直す。
