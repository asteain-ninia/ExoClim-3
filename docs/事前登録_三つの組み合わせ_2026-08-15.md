# 事前登録: 偏西風 × 渦拡散 × 収束持上げ(段 34)

日付: 2026-08-15
**結果を見る前に書いている。**
前段: [実験記録_偏西風と拡散の組み合わせ](実験記録_偏西風と拡散の組み合わせ_2026-08-15.md)(段 33)

## 問い

段 33 で「中位も乾いた端も改善する点」が初めて見つかったが、
主判定(中位 500 以上 かつ 1% 64 以下)には届かなかった。
**傾きから、この 2 つでは届かないと分かっている**(1% を 64 まで下げると
中位は 498.4)。

**中位をあと 8mm 押し上げる第 3 の手**が要る。

段 29 の `convergenceLiftBoost` は、今日測った 12 の手のうち**唯一**
「中位を下げずに端だけ改善する」性質を持っていた:

```
段 29（収束持上げ 0.5、単独）  中位 468 → 470（守る）  1% 64 → 57（改善）
```

これを足せば **1% を下げる負担を拡散から収束へ移せる**ので、
拡散を下げる量が減り、中位が保てるはずである。

## 「1 度に 1 つ」との整合

**3 つとも単独で測り終えており、効きを分離して把握している**:

```
段 29 収束持上げ 0.5     中位 +2    1% −7
段 31 拡散 2.98e6→2.0e6  中位 −12   1% −16
段 32 風 6.5→9.0         中位 +33   1% +5
```

段 33 で 2 つの重ね合わせが**ほぼ線形(+7 の非線形項)**と確かめてある。
したがってこれは「原因が分けられなくなる」状況ではなく、
**分離済みの 3 つを重ねたときに線形性が保たれるか**を問う実験である。

## 変えるもの

- `westerlyWindMs` = **9.0 固定**(範囲内の上端)
- `convergenceLiftBoost` = **0.5 固定**(段 29 で測った値)
- `moistureEddyDiffusivityM2PerS` を **2.98e6 / 2.5e6 / 2.0e6 / 1.5e6** で掃く

## 予測(先に書く)

- 線形なら、拡散 2.98e6 で **中位 503・1% 62** となり、**主判定を満たす**
  (段 33 の 501/69 に、収束の +2/−7 を足す)。
- **これが当たれば今日初めて主判定を満たす。**
- 拡散を下げるほど 1% は下がるが中位も下がるので、
  **満たす水準は 2.98e6 側に寄る**と見る。
- v3 は 84.5 前後(段 32 の 84.542 から収束のぶん −0.2 程度)。

**外れる筋 A**: 収束持上げの効きが、風を強めた状態では変わる。
段 29 は風 6.5 で測っており、**風 9.0 では収束の立ち方が違う**可能性がある
(収束は風の発散から作るので、風を変えれば収束も変わる)。
**これは十分ありうる。** その場合、線形の見積もりは外れる。
**外れる筋 B**: 3 つ重ねると輸送または結合反復が未収束になる。

## 判定(先に固定する。結果を見てから緩めない)

1. **収束**: 5 系統すべて未収束 0。満たさない水準は**適用範囲外**。
2. **主判定**: **中位 500 以上 かつ 1% が 64 以下**。
3. **番人(湿潤側)**: コンゴ **1.01〜1.61**、アマゾン **0.82〜1.12**。
4. **番人(成績)**: 大分類が **74.49 から 2.0 以上落ちない**
   (段 31〜33 と同じ理由・同じ値)。
5. **費用**: 1 水準 **900 秒**以内(単独換算)。

2〜5 をすべて満たす水準があれば**採用候補**とし、**再較正へ進む**。

## やらないと決めていること

- 未収束の水準の分位・成績を読むこと(**値も形も**)。
- `westerlyWindMs` を 9.0 より上げること(範囲外は採用しないと段 32 で決めた)。
