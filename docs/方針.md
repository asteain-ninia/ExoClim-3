## 2. 物理モデル(ExoClim-2 からの最大の変更)

### 2.1 原則

- **段階構成は Pasta の 7 ステップを踏襲**(ITCZ → 風帯 → 海流 → 気流 →
  気温 → 降水 → 気候区分)。可視化・教育的追跡性がこのツールの存在意義。
- **数値の中核は定量物理**。Pasta が定量を示さない箇所は標準的な気候物理で
  埋める(教訓 §2)。経験係数の後付けチューニングと地理決め打ちの
  強制ルールは禁止(教訓 §1)。
- **地理中立**: 計算層は惑星パラメータと地形グリッドのみから導出する。
  「地球ではここがこうなる」を計算層に書かない。

### 2.2 各ステップの中核手法

| Step | 手法 | -2 との差 |
| --- | --- | --- |
| 0 軌道・日射 | ケプラー方程式(離心近点角)+ 赤緯から日平均日射 S(緯度, 月) を厳密計算 | -2 は簡易式。離心率・近日点引数の効果を厳密化 |
| 1 ITCZ | 熱赤道追跡(日射重心 + 大陸モンスーン引き寄せ + 平滑化) | ほぼ継承 |
| 2 風帯 | ハドレー/フェレル/極セル境界の季節移動 + 卓越風 + 気圧場 | ほぼ継承 |
| 3 海流 | 海洋盆検出 + 環流の暖流/寒流セル分類 + 海面温度への熱輸送補正 + 流線(表示用) | 分類は継承。**気候への効き方を SST 補正として定量化** |
| 4 気流 | 卓越風 + 気圧勾配風の合成 + 山岳偏向 | ほぼ継承 |
| 5 気温 | **2 次元エネルギー収支モデル(EBM)**: セル別熱容量(陸/海/氷)、放射冷却(A + B·T)、水平拡散熱輸送、雪氷アルベドフィードバック内蔵。年周期を時間積分し周期定常解の月別気温を得る | **全面刷新**。-2 の経験 2 段階スケール + 帯状補正群を置換 |
| 6 降水 | **水収支モデル(mm/月)**: 海面蒸発(Clausius-Clapeyron スケール)→ 風による水蒸気輸送(到達距離減衰)→ 収束(ITCZ)・前線・地形性上昇で降水化、沈降域(亜熱帯高圧帯・風下)で抑制 | **全面刷新**。4 段階ラベルを廃止 |
| 7 気候区分 | 標準ケッペン=ガイガー判定(Peel et al. 2007 の閾値)を月別気温(°C)・降水(mm)に適用 | 判定自体は継承。**強制後処理ゼロ** |

### 2.3 気温 EBM の要点

セル毎のエネルギー収支を時間積分する:

```
C_i dT_i/dt = S_i(t)·(1 − α_i(T_i)) − (A + B·T_i) + D·∇²T_i
```

- `C_i`: 熱容量。海(混合層深さに比例、既定 ~50m 相当)≫ 陸(~2m 相当)。
  大陸性気候(内陸の大振幅)・海洋性気候(沿岸の小振幅・位相遅れ)が
  パラメータではなく**構造から出る**。
- `α_i(T_i)`: アルベド。地表種別の基礎値 + 氷雪条件(T < 閾値)で上昇。
  雪氷フィードバックが自然に入る(-2 §6.1.3 の多重冷却バグは構造的に消滅)。
- `A + B·T`: 線形化した外向き長波放射。温室効果強度は A を下げる形で効く
  (地球較正: A ≈ 210 W/m², B ≈ 2 W/m²/°C 前後から出発)。
- `D·∇²T`: 球面ラプラシアンによる拡散熱輸送(緯度経度の計量 cos φ を考慮、
  極近傍は帯状平均化で安定化)。海上は海流熱輸送相当として増強。
- 解像度: EBM は粗格子(既定 2°)で解き、表示格子(既定 1°)へは
  標高減率(lapse rate)と海岸距離を使って降尺度する。
- 極昼の過剰加熱(-2 §6.1.2 の破綻)は熱容量と放射冷却が抑える。

### 2.4 検証(実装より先に物差し)

1. **実在地球**: 実在海岸線 + 粗い標高の地球プリセットを入力し、
   月別気温・降水の帯状分布と、ケッペン主要区分の陸面積比
   (Peel et al. 2007 概数: A ≈ 19% / B ≈ 30% / C ≈ 13% / D ≈ 25% / E ≈ 13%)
   および代表地点(西岸海洋性・地中海性・大陸内陸・モンスーン域など)の
   区分一致を自動採点する。
2. **理想化大陸**: 単一矩形大陸・南北分断大陸で、西岸海洋性の楔・内陸乾燥帯・
   東西非対称などの定性特徴を自動判定。
3. **退化条件**: 全海・全陸・傾斜 0°・高離心率・逆行で破綻しない
   (NaN なし、物理的に説明可能な出力)。

ヘッドレスハーネス(Node 直接実行)が各ステップの PNG と採点 JSON を出力する。
開発中はこの画像と採点を見ながら反復する(教訓 §7)。

## 3. パラメータの二層化(教訓 §7)

- **利用者パラメータ** = 惑星の物理量(主星光度・軌道・自転・傾斜・大気圧・
  温室効果・アルベド・海洋混合層深さ・地形)。全て UI に露出する。
- **モデル定数** = 較正で固定する係数(放射 A/B、拡散 D、蒸発係数など)。
  仕様書に根拠つきで明記し、UI では点検ビュー(読み取り専用)に表示。
  スライダーにしない。地球検証で固定し、以後は触らない。
