# 実験記録: 惑星応答の初測定 — 傾斜と自転は生きている。**気圧が死んでいる**

日付: 2026-08-16
道具: `scripts/exp_planet_response.ts`(2026-08-16 に「向きだけは物理で決まる 3 点」を追加)
出力: `out/exp_planet_response.txt`

## なぜ測ったか

外部監査(2026-08-15)の指摘 — 「較正がすべて地球で行われたので、
地球はモデルにとって**恒等変換**であり、**地球以外での破綻が成績に現れない**」。

観測が無いので正解も無いが、**向きだけなら物理で決まる**量が 3 つある。
判定は置かず、まず測った(保存型の行だけを読む。非保存は既に採用外)。

## 判定

| 期待される向き(物理) | 実際 | 判定 |
| --- | --- | --- |
| 傾斜 ↑ → 陸の年較差 ↑ | 1.8 → 18.8 → **30.7** | ○ **生きている**(桁も妥当) |
| 自転 ↓ → 乾燥帯の中心緯度 ↑(Held-Hou) | 30.5 → 28.8 → **37.9** | ○ **生きている** |
| 気圧 ↑ → 赤道と極の気温差 ↓ | 44.6 → 44.6 → **44.7** | ✗ **死んでいる** |

### ○ 傾斜: 合格

年較差 1.8 → 30.7°C。傾斜 0 で季節がほぼ消える(1.8°C は離心率由来)のも正しい。
気候帯の分布も物理的に妥当に動く — 傾斜 45° で D 冷帯が 37.6% まで増え、
A 熱帯が 2.3% まで消える(高傾斜では年平均で低緯度も冷え、季節振幅が支配する)。

### ○ 自転: 合格。しかも Held-Hou の桁が合う

自転 24h → 72h で乾燥帯の中心が **28.8° → 37.9°**(+9°)。
ハドレー循環の幅は Ω^(−1/2) 程度で広がるので、周期 3 倍なら √3 ≈ 1.7 倍。
28.8 × 1.7 ≈ 49° には届かないが、**向きと桁の order は合っている**。
12h(周期 1/2)で 30.5° と、逆に少し広がるのは非単調で気になるが、
高速自転側は帯が細かく割れるので中心緯度という 1 数字では読みにくい。

**風帯が緯度で決め打ちされていない**ことの実証になった。
`hadleyEdgeBaseDeg × (P/24)^0.35` の配管が実際に効いている。

### ✗ 気圧: **応答がまったく無い**

```
気圧 0.5 → 2.0 bar(4 倍)で
  赤道-極差   44.6 → 44.7   （0.1°C。実質ゼロ）
  乾燥帯緯度  28.8 → 28.8   （完全に不動）
  陸降水       735 → 723    （−1.6%）
  全球気温   16.00 → 16.03  （+0.03°C）
```

**気圧を 4 倍にしても、この惑星では何も起きない。**

物理的にはありえない。実物なら:
- 大気の質量が 4 倍 → **熱輸送が効率化して赤道-極差が縮む**
- 気柱の熱容量が 4 倍 → **年較差が縮む**(実際は 19.2 → 18.1 と 6% しか縮まない)
- 飽和比湿 q_s は圧力に反比例 → 降水の全球分布が変わる

非保存型では気圧に強く応答していた(陸降水 936 → 1916 と 2 倍、
閉包 57.8% → 211.1%)。これは `P ∝ √(気圧)` の項が降水式に直接入っていたため。
**保存型への移行(段 6)で、気圧が降水へ効く経路が源泉の q_s だけになり、
そこも実質的に効いていない。**

## 何が原因か(未確認の見立て)

`docs/計画_保存則の段階的置換_2026-08-09.md` が予期していた事態そのもの:

> 非保存では P ∝ √(気圧) という降水効率の項が直接効いていたが、
> 保存型ではその項が凝結率へ入らず、気圧は**源泉の飽和比湿 q_s(T,p) を
> 通じてのみ**効く。どちらが正しいかは地球の成績では決められない。

測った結果、**「q_s を通じてのみ」の経路が実質ゼロだった**。
候補は 2 つで、まだ切り分けていない:

1. **EBM が気圧を見ていない。** 熱輸送係数 `diffusionWm2PerK` が定数で、
   大気質量に依存していない。だから赤道-極差が動かない。
   → これは配管の欠落であり、較正では絶対に直らない。
2. **源泉の q_s(T,p) の圧力依存が弱い、または打ち消されている。**
   蒸発が増えても輸送と凝結で吸収されている可能性。

**1 が本命**と見る。赤道-極差・乾燥帯緯度・年較差が揃って不動なのは、
「降水の作り方」ではなく「熱の運び方」が気圧に無関心だからと読むのが自然である。

## 位置づけ — 目的への距離

本ツールの目的は「**地球ではない星の地図を入れると尤もらしい気候区分が出る**」。

- **地図(地形)を変える**: 理想化大陸で内陸乾燥が物理から出た(2026-08-16)。○
- **惑星の回り方を変える**(傾斜・自転): **今回○**。骨格は信用してよい。
- **大気を変える**(気圧): **✗**。UI に露出しているスライダーなのに、
  動かしても気候が変わらない。**利用者から見て「壊れている」機能である。**

要件 §1-3 は表面気圧を利用者パラメータとして明記している。
**これは較正の話ではなく、機能として未完成という話**である。

## 次

1. **EBM の熱輸送が気圧を見ているかをコードで確認する**(測る前に読む)。
   見ていなければ、大気質量への依存を入れる設計 → 事前登録 → 実装。
   地球(1 bar)では恒等になるよう規格化すれば、**地球の成績は 1 ビットも動かない**。
2. 同時に源泉 q_s の圧力依存も確認する(1 と独立に測れる)。
3. 光度・半径の軸も測る(今回は 3 軸だけ)。半径は重力を通じて効くはずで、
   気圧と同じ型の欠落がある可能性が高い。

## 何が直ったか

気圧は**利用者スライダーとして機能するようになった**。0.5 bar の惑星は
極と赤道の差が 64°C に開いて寒冷化(全球 14.5°C)し、2 bar では 27°C まで縮んで
温暖化(17.6°C)する。年較差も 25.4 → 12.2 と 2 倍の開きが出る。
**薄い大気の惑星は極端な気候、厚い大気の惑星は均質な気候**という、
系外惑星の気候として最も基本的な性質がようやく出た。

気候帯の分布も物理的に妥当に動く:

```
気圧     A熱帯  B乾燥  C温帯  D冷帯  E寒帯
0.5bar   25.3   27.7    6.9   22.2   17.9   ← 極端。温帯が 7% しかない
1.0bar   22.9   28.9   10.7   21.9   15.6
2.0bar   20.4   30.0   22.5   15.3   11.7   ← 温帯が倍増、寒帯が減る
```

厚い大気ほど**温帯 C が広がり寒帯 E が減る**。熱が極まで運ばれるためで、
向きとして正しい。

## この修正の性質(重要)

**地球の成績は 1 ビットも動いていない**(予測 2)。地球 1 bar で係数が厳密に 1 に
なるよう規格化したためで、較正 v24 が走行中でも安全だった。

つまりこれは「較正で追い込む」類の改善ではなく、**無かった配管を作った**修正である。
地球だけを見ていては永遠に発見できず、成績にも一切表れない。
**外部監査の「地球はモデルにとって恒等変換」という指摘が、
そのまま実害として存在していた**ことの実例になった。

## 残る宿題

- **光度・半径の軸は未測定。** 半径は重力を通じて効くはずで、気圧と同じ型の
  欠落がある可能性が高い(`radiusRatio²` は熱輸送に入っているが、
  重力が気柱の質量や降水効率に効く経路は未確認)。
- 指数 1 が最適かは地球では決められない。**較正の探索空間には入れない**
  (地球で恒等な量を探索させると空回りする)。将来、系外惑星の観測が
  比較対象になったときに初めて調整できる量である。

## 半径: ○ 生きている。しかも物理として正しい向き

小さい惑星(×0.6)は赤道-極差が **21.7°C** まで縮み、大きい惑星(×1.6)は
**71.3°C** に開く。熱輸送係数に `radiusRatio²` が入っているためで、
**小さい惑星ほど熱が全球に行き渡る**という正しい振る舞いである。
年較差も 10.8 → 27.3 と連動する(小さい惑星は均質、大きい惑星は極端)。

気候帯も筋が通っている — ×0.6 では温帯 C が 30.2% まで広がり冷帯 D が 10.6% に
減る(全球が均質で温和)。×1.6 では逆に C が 6.2% まで潰れる。

**気圧と半径が独立に効く**ようになったので(段 40 の前は気圧だけが死んでいた)、
「小さくて厚い大気の惑星」「大きくて薄い大気の惑星」を作り分けられる。

## 光度: ○ 応答するが、**感度が高すぎる疑い**

```
日射 ±8% で 全球気温 4.45 → 16.01 → 26.21 °C
→ 感度 約 1.36 °C / 日射 1%
```

**これは実物の地球より 2〜3 倍高い。** 現実の気候感度は日射 1% あたり
0.5〜0.7°C 程度(2 倍 CO2 相当の放射強制 ~3.7W/m² で 2〜4°C、
日射 1% ≈ 2.4W/m² 吸収ベース)とされる。

光度 0.92(日射 −8%)で全球 **4.45°C**、A 熱帯が **0.0%** まで消え、
E 寒帯が 30.4% になる。実物の地球は日射 −8% でも熱帯が全滅する状態には
ならない(古気候の全球凍結でさえ、そこまでの日射低下は要らないが
別の機構が絡む)。

### 原因の見立て(未確認)

線形化 OLR `A + B·T` の **B が小さすぎる**可能性が高い。
B は放射による負のフィードバック(暖まると冷却が増える)の強さで、
小さいほど気候感度が上がる。現行 `olrBWm2PerC` は較正で決まっており、
**地球の気候値だけを合わせた結果、感度が過大になった**と読める。

これは気圧の欠落とは型が違う — **配管はあるが係数が地球に過適合**している。
地球の気温分布は「A と B の組」で決まり、**感度は A と B の比に依存する**ので、
地球の平均場だけからは B を一意に決められない。

### なぜ今は直さないか

- **地球の成績を必ず動かす。** B を変えると気温場が変わり、較正のやり直しが要る。
  段 40(地球で恒等)とは性質が違い、利用者の裁定なしには動かせない。
- **正解の物差しが手元に無い。** 気候感度は観測ではなく理論・古気候から来る量で、
  この検証ハーネス(地球の平年値)には入っていない。
- **優先度の判断が要る。** 「地球の再現」と「架空惑星の応答」のどちらを
  取るかという、目的に関わる裁定である。

**したがってここでは「測って記録する」に留める。**
利用者に報告し、裁定を仰ぐべき項目として引き継ぎに残す。
