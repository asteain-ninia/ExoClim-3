# 実験記録: 惑星応答の初測定 — 傾斜と自転は生きている。**気圧が死んでいる**

日付: 2026-08-16
道具: `scripts/exp_planet_response.ts`(2026-08-16 に「向きだけは物理で決まる 3 点」を追加)
出力: `out/exp_planet_response.txt`

## なぜ測ったか

外部監査(2026-08-15)の指摘 — 「較正がすべて地球で行われたので、
地球はモデルにとって**恒等変換**であり、**地球以外での破綻が成績に現れない**」。

観測が無いので正解も無いが、**向きだけなら物理で決まる**量が 3 つある。
判定は置かず、まず測った(保存型の行だけを読む。非保存は既に採用外)。

## 結果(保存型)

```
傾斜    年較差   乾燥帯緯度  赤道-極差
 0°      1.8      26.0      55.3
```

## 判定

| 期待される向き(物理) | 実際 | 判定 |
| --- | --- | --- |
| 傾斜 ↑ → 陸の年較差 ↑ | 1.8 → 18.8 → **30.7** | ○ **生きている**(桁も妥当) |
| 自転 ↓ → 乾燥帯の中心緯度 ↑(Held-Hou) | 30.5 → 28.8 → **37.9** | ○ **生きている** |
| 気圧 ↑ → 赤道と極の気温差 ↓ | 44.6 → 44.6 → **44.7** | ✗ **死んでいる** |

### ○ 傾斜: 合格

年較差 1.8 → 30.7°C。傾斜 0 で季節がほぼ消える(1.8°C は離心率由来)のも正しい。
気候帯の分布も物理的に妥当に動く — 傾斜 45° で D 冷帯が 37.6% まで増え、
A 熱帯が 2.3% まで消える(高傾斜では年平均で低緯度も冷え、季節振幅が支配する)。

### ○ 自転: 合格。しかも Held-Hou の桁が合う

自転 24h → 72h で乾燥帯の中心が **28.8° → 37.9°**(+9°)。
ハドレー循環の幅は Ω^(−1/2) 程度で広がるので、周期 3 倍なら √3 ≈ 1.7 倍。
28.8 × 1.7 ≈ 49° には届かないが、**向きと桁の order は合っている**。
12h(周期 1/2)で 30.5° と、逆に少し広がるのは非単調で気になるが、
高速自転側は帯が細かく割れるので中心緯度という 1 数字では読みにくい。

**風帯が緯度で決め打ちされていない**ことの実証になった。
`hadleyEdgeBaseDeg × (P/24)^0.35` の配管が実際に効いている。

### ✗ 気圧: **応答がまったく無い**

```
気圧 0.5 → 2.0 bar(4 倍)で
  赤道-極差   44.6 → 44.7   （0.1°C。実質ゼロ）
  乾燥帯緯度  28.8 → 28.8   （完全に不動）
  陸降水       735 → 723    （−1.6%）
  全球気温   16.00 → 16.03  （+0.03°C）
```

**気圧を 4 倍にしても、この惑星では何も起きない。**

物理的にはありえない。実物なら:
- 大気の質量が 4 倍 → **熱輸送が効率化して赤道-極差が縮む**
- 気柱の熱容量が 4 倍 → **年較差が縮む**(実際は 19.2 → 18.1 と 6% しか縮まない)
- 飽和比湿 q_s は圧力に反比例 → 降水の全球分布が変わる

非保存型では気圧に強く応答していた(陸降水 936 → 1916 と 2 倍、
閉包 57.8% → 211.1%)。これは `P ∝ √(気圧)` の項が降水式に直接入っていたため。
**保存型への移行(段 6)で、気圧が降水へ効く経路が源泉の q_s だけになり、
そこも実質的に効いていない。**

## 何が原因か(未確認の見立て)

`docs/計画_保存則の段階的置換_2026-08-09.md` が予期していた事態そのもの:

> 非保存では P ∝ √(気圧) という降水効率の項が直接効いていたが、
> 保存型ではその項が凝結率へ入らず、気圧は**源泉の飽和比湿 q_s(T,p) を
> 通じてのみ**効く。どちらが正しいかは地球の成績では決められない。

測った結果、**「q_s を通じてのみ」の経路が実質ゼロだった**。
候補は 2 つで、まだ切り分けていない:

1. **EBM が気圧を見ていない。** 熱輸送係数 `diffusionWm2PerK` が定数で、
   大気質量に依存していない。だから赤道-極差が動かない。
   → これは配管の欠落であり、較正では絶対に直らない。
2. **源泉の q_s(T,p) の圧力依存が弱い、または打ち消されている。**
   蒸発が増えても輸送と凝結で吸収されている可能性。

**1 が本命**と見る。赤道-極差・乾燥帯緯度・年較差が揃って不動なのは、
「降水の作り方」ではなく「熱の運び方」が気圧に無関心だからと読むのが自然である。

## 位置づけ — 目的への距離

本ツールの目的は「**地球ではない星の地図を入れると尤もらしい気候区分が出る**」。

- **地図(地形)を変える**: 理想化大陸で内陸乾燥が物理から出た(2026-08-16)。○
- **惑星の回り方を変える**(傾斜・自転): **今回○**。骨格は信用してよい。
- **大気を変える**(気圧): **✗**。UI に露出しているスライダーなのに、
  動かしても気候が変わらない。**利用者から見て「壊れている」機能である。**

要件 §1-3 は表面気圧を利用者パラメータとして明記している。
**これは較正の話ではなく、機能として未完成という話**である。

## 次

1. **EBM の熱輸送が気圧を見ているかをコードで確認する**(測る前に読む)。
   見ていなければ、大気質量への依存を入れる設計 → 事前登録 → 実装。
   地球(1 bar)では恒等になるよう規格化すれば、**地球の成績は 1 ビットも動かない**。
2. 同時に源泉 q_s の圧力依存も確認する(1 と独立に測れる)。
3. 光度・半径の軸も測る(今回は 3 軸だけ)。半径は重力を通じて効くはずで、
   気圧と同じ型の欠落がある可能性が高い。
