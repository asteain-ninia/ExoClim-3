# 設計: ストーム供給を保存型へ繋ぐ — **源泉に足すのは誤り。拡散を場所依存にする**

日付: 2026-08-15
前段: [診断_ストーム供給は保存型で死んでいる](診断_ストーム供給は保存型で死んでいる_2026-08-15.md)

**実装の前に設計を確定させる。**
[引き継ぎ](引き継ぎ_2026-08-15.md) §14 に「源泉 `src` に足すのが筋」と書いたが、
**設計を詰めたら誤りだった。** ここで訂正する。

## なぜ「源泉に足す」が誤りか

ストームトラックの機構はこう書かれている:

```ts
stormSupply = K.stormMoistureSupply × supplyW × qRel
            × exp(−coastKm / decayKm) × (1 + 0.55 × winterDepth01)
```

意味は「**移動性低気圧が近傍の海から水蒸気を混合する**」(実装のコメント)。
**海の水を陸へ運ぶ**機構であって、水を新しく作る機構ではない。

保存型で `src` に足すと、**陸で水が湧き出す**。海から引かないので
全球の水収支が閉じない。保存型に移した意味が失われる。

> 計画にも明記されている —
> 「evap 系は探索空間に入れない。**源泉を目的関数で動かすと
> 保存則が誤りを隠す装置になる**」
> ([計画_保存則の段階的置換](計画_保存則の段階的置換_2026-08-09.md))。
> **源泉に手を入れるのは、まさにその装置を作ることである。**

## 正しい形: **拡散を場所依存にする**

移動性低気圧が海と陸を混合するのは、月平均で見れば**実効的な拡散**である。
拡散は保存的な演算子なので、**水は湧かないし消えない**。

```
D(i) = D₀ × (1 + stormDiffusionBoost × supplyW × exp(−coastKm / decayKm))
```

- `supplyW` はストーム帯の緯度重み(既にある)
- `exp(−coastKm/decayKm)` は海岸からの減衰(既にある)
- **既存の `stormSupply` の形をそのまま使える** — 意味だけが
  「供給の追加」から「混合の増強」へ変わる

**利点:**

- **保存則が自動的に守られる**(拡散は保存的)。
- 段 31 で「拡散を下げると乾いた端が改善・中位が悪化」と測ってある。
  **場所を選んで拡散を上げれば、中位だけを狙える**可能性がある。
  段 31 は全球一律で下げたので、中位も乾いた端も一緒に動いた。
- 単位の問題が消える(拡散係数は m²/s で、無次元→mm/月 の変換が要らない)。

## 実装に要る変更

`solveMoistureTransport` の拡散係数は**スカラー**である:

```ts
diffusivityM2PerS?: number;                          // 33 行
const diffusivity = (options.diffusivityM2PerS ?? 0) * SECONDS_PER_MONTH;  // 140 行
```

これを**場(セルごと)**にする必要がある。行列の組み立てでは

```ts
const diffX = diffusivity ? (lenMeridionalM * diffusivity) / dxC : 0;
const diffY = diffusivity ? diffusivity / dyCenterM : 0;
```

のように使われているので、**面の値は両側セルの平均**にする
(共有面で一意 = 保存的、という既存の作法に合わせる)。

**これは輸送ソルバの中核への変更**なので:

1. **スカラーを渡したときに現行とビット一致すること**をテストで守る。
2. 場を渡したときも**全球の水収支が閉じること**(`globalBalanceResidual`)を
   テストで守る。**保存が壊れたら即座に棄却。**

## 判定の設計(事前登録は実装前に別途書く)

主判定は今日と同じ **「中位 500 以上 かつ 1% が 64 以下」**。
番人も同じ(コンゴ / アマゾン / 大分類 / 収束 / 費用)。

**加えて、この段だけの必須条件:**

- **全球の水収支の閉包残差が現行と同じ桁(1e-9 級)であること。**
  これを満たさなければ、他の条件を読まずに棄却する。

## なぜ今日は実装しないか

輸送ソルバの中核を触る変更で、**保存則の検査を含めて設計しないと
「保存型に移した意味」を壊す**。今日は 14 回の実験で
**判断の質が落ちている兆候**が既に 3 件出ている
(分位どうしを掛けた / 数字の一致を因果と読んだ / 因子分解の群平均を
因果と読んだ)。

**中核を触る変更は、判断が確かなときに着手する。**
設計はここに残したので、次のセッションは事前登録から始められる。
