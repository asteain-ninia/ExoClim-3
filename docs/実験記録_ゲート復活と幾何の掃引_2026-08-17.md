## 掃引 1: itczLiftSupplyNorm(ITCZ の傘のゲート)— **採用(範囲引き直し)**

```
norm     1%分位  50%   分布誤差  連続部分   詳細    インド
0.6(現行)  64    532   0.404    70.322   43.66   0.45
3          59    532   0.389    70.244   43.63   0.44
7          58    527   0.383    70.334   43.81   0.41
12         57    519   0.382    70.413   43.92   0.40
```

判定: 予測 2(中位 ≥515)○ / 3(コンゴ安定)○ / 4(連続部分 ≥70.40・誤差 ≤0.395)○。
予測 1(1% ≤55)は **58 で 3mm 届かず部分的中**。未予測のコスト: インド −0.05。

**匙加減(乾いた端 vs インド)はまさに較正の仕事**なので、SPACE の範囲を
[0.6, 1.8] → **[0.5, 18]** に引き直す(現行値 0.6 を含み、生きた範囲まで届く)。

> 注意(棚卸しの警告): この norm の `marineW` は持上げと沈降防護の**両方**に
> 入っており、掃引の効果は 2 経路の合算である。分離は較正後の診断で行う。

## 掃引 2: eastReliefSupplyNorm(東岸緩和のゲート)— **SPACE から除去**

```
norm     1%   50%   連続部分   詳細    インド  米南東  東アジア
0.51     64   532   70.274    43.61   0.45   0.37   0.20
12       63   520   70.303    43.98   0.42   0.34   0.18
```

判定: 予測 5(1% ≤60)✗ / 予測 6(米南東・東アジアが傷まない)✗ —
**ゲートを生かすと本丸の C→B 地域が乾く**(緩和を絞る先が主に東岸だから当然だった)。
詳細 +0.37 は別の場所の改善で、説明と挙動が一致しない。

処置: **SPACE から外し、現行値 0.51(= 実質ゲート無効)で固定**。
死んだ範囲に置く意味がなく、生かすと逆効果。ゲートの役割(アラビア防護)は
形骸化したまま — 防護の再設計はコンベア(段 45)側の課題として引き継ぐ。

## 掃引 3: subsidenceBandEquatorwardDeg(沈降帯の幾何)— **SPACE に足さない**

```
値      1%   50%   99%    連続部分   詳細    インド  東アジア
16      64   532   3015   70.322    43.66   0.45   0.20
9       62   557   2843   68.736    40.18   0.48   0.20
6       62   568   2786   67.858    38.61   0.52   0.20
```

判定: **予測 1(東アジア ≥0.24)が完全に外れた。** 帯を 6° まで狭めて
東アジア(25〜33°N)が帯からほぼ抜けても **0.20 のまま微動もしない**。
詳細は −5.05 と大崩れ(99% 分位が 3015→2786 へ崩落 — 亜熱帯全域の
沈降が外れて湿潤の型が総崩れ)。

**重要な含意**: C→B の G 分解で「沈降残存が主因(0.48 対 0.71)」と出たが、
**東アジアに限っては沈降を消しても降水が戻らない**。これは 2026-08-11 の
「東アジアは流出過多(北へ 840mm/年 抜ける)」と整合する — 沈降残存の低さは
東アジアでは**症状であって原因ではない**(インド・西アジア側では原因の一部:
インドは 0.45→0.52 と応答した)。C→B は一枚岩ではなく、
**インド型(沈降が犯人)と東アジア型(輸送が犯人)の混成**である。

## v26 バッチ(この記録で確定)

1. `itczLiftSupplyNorm` の範囲を [0.5, 18] へ(掃引 1)
2. `eastReliefSupplyNorm` を SPACE から除去(掃引 2)
3. 幾何は入れない(掃引 3)
4. 生存性を測り直し(CI が強制)、v26 を起動

## 教訓

- **同じ「主因」でも地域で原因が違う。** C→B の帯平均の G 分解が「沈降」を
  指しても、東アジアではそれが症状にすぎなかった。処方の前に、
  **主因の分解を地域(型)ごとに再確認**すること。
