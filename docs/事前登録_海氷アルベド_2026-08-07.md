# 事前登録: 海氷アルベドの連続化と融解中の凍結点固定(R2)

日付: 2026-08-07
対象: 0 層海氷模型の第 2 版
**結果を見る前に書いて確定させる。** 後から条件を緩めない。

## 前回(2026-08-04)何が起きたか

0 層模型の第 1 版は、事前登録した判定「両極が同時に改善」に対し**不成立**だった。

```
                        9-10月(北極の秋)   1-2月(南大洋の夏)
変化                        −3.84°C            −2.10°C
判定                        成立               不成立(逆方向)
```

北極の冬は劇的に改善した(1 月 −7.7 → −31.2°C、実物 −25°C 前後)が、
**北極の夏が +16.8°C まで走り**、南大洋はさらに冷えた(冬 −27.7 → −35.5°C)。

熱容量側の正帰還は潜熱で壊せたが、**アルベド側の正帰還が手つかず**だった、
というのが当時の読みである。

## 今回直す 3 点

### (1) 陸の季節雪が消える不具合 ← 実装の誤り

第 1 版は `iceW` を氷厚の有無だけで決めていた:

```ts
const iceW = slabIce ? (iceMm[i] > 0 ? 1 : 0) : 温度ランプ;
```

氷厚は**海セルにしか育たない**(更新ループが `oceanFrac <= 0` を飛ばす)ので、
0 層模型を有効にすると**陸の季節雪アルベドが丸ごと消える**。
北ユーラシア・北米の冬と融雪期がまるごと壊れる。第 1 版の結果は
この不具合を含んでいたので、そもそも機構の評価になっていなかった。

陸の雪と海の氷を分けて持ち、陸率で混ぜる:

```
snowW = 温度ランプ(陸の季節雪)
seaW  = min(1, 氷量 / 飽和量)(海氷の被覆率)
iceW  = 陸率·snowW + 海率·seaW      … アルベド用
断熱   = seaW · 海率               … 海の側だけの現象
```

### (2) アルベドを氷量に連続で結ぶ

被覆率を氷量の代理にする(`seaIceCoverScaleMm = 300`、水等価 0.3 m で飽和)。
実在の海氷域は薄くなるほど開水面(リード)が増える。二値だと融けた瞬間に
0.39 → 0.07 へ跳び、白夜の日射を吸い込む。

### (3) 融解中の表面を凍結点に留める

実在の融解期の海氷面が 0°C に張り付くのは、余分な熱が**全部潜熱に食われる**
から。伝導 k/h だけでは引き戻しが足りない。反復の後に、氷が残っている限り
超過熱を融解へ回して温度を凍結点へ戻す(混合セルでは海率ぶんだけ)。

### (4) GPU への移植 ← 必須

第 1 版は CPU 経路にしか無く、GPU があると**黙って 0 層模型なしで走っていた**。
WGSL へ同じ式・同じ順序で移植した(`updateIce` カーネル)。
較正は GPU で回すので、これが無いと実験そのものが成立しない。

## 判定条件

前回と**同じ主判定**を使う(条件を緩めないため)。

### 主判定 — 両極が同時に改善すること

温度ランプ(現行、`seaIceModel = 0`)を基準に:

1. 北極海 70〜90°N の 9〜10 月の海面温度が **下がる**
2. 南大洋 60〜70°S の 1〜2 月(夏)の海面温度が **上がる**
3. **両方**でなければ不成立(片方だけなら断熱の強さを動かしただけ)

### 副判定

- **北極の夏が暴走しない**: 北極海 70〜90°N の 7 月が **+5°C 以下**
  (第 1 版は +16.8°C、実物はほぼ 0°C)
- **帯状平均気温の最大乖離が下がる**(現在 26.4°C、7 月の 60°S)。
  最終受入の未達項目そのもの。**20°C 以下**を今回の目安とする
- **数値的健全性**: EBM 残差 < 1e-3°C、年次ドリフト < 0.05°C
- **CPU と GPU が一致する**: 同じ設定で両経路を回し、
  年平均気温の差が **0.5°C 以下**(f32 と f64 の丸めの差の範囲)

### 棄却条件

- 主判定を満たさない → 棄却。`seaIceCoverScaleMm` を 3 段階
  (150 / 300 / 600)試して届かなければ機構ごと棄却する
- CPU と GPU が一致しない → 実装の誤り。判定以前の問題として直す

## 予測(事前に書く)

- (1) の不具合を直すこと自体で、**北ユーラシア・北米の冬が改善**するはず。
  第 1 版の結果より全球成績はよくなる。
- (2)(3) で北極の夏の暴走は止まる。ただし**止まりすぎる**恐れもある —
  凍結点固定が強すぎると夏が 0°C に張り付いて融氷期が短くなる。
- 南大洋は (2) で断熱が弱まるので暖まる方向。ただし前回 −2.10°C だったので、
  **これが +へ転じるかが今回の山**である。
