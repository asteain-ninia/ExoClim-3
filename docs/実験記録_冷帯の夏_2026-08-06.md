# 実験記録: 冷帯の詳細一致 19.7% の正体 — 夏の気温という一変数

日付: 2026-08-06
道具: `scripts/diag_score_masks.ts`、`scripts/diag_boreal_letters.ts`、`scripts/diag_boreal_summer.ts`

## 0. きっかけ — 南極を除いた一致率

一致マップを描いたら南極大陸が全面緑だった。観測もモデルも一様に EF(氷雪)を
返すので当たるが、**当てて嬉しい一致ではない**。除いて測り直した
(面積重み cos 緯度は掛けたまま)。

| マスク | 残る面積 | 大分類 | 詳細 |
|---|---:|---:|---:|
| 全球(現行の採点) | 100.0% | 75.22 | 44.07 |
| 南極大陸を除く(60°S 以南) | 91.6% | 72.95 | **38.96** |
| 南極 + グリーンランドを除く | 89.8% | 72.66 | 38.15 |
| 観測が EF のセルを除く | 90.5% | 72.66 | 38.26 |
| 観測が E(寒帯)のセルを除く | 85.9% | 73.79 | 37.87 |

**詳細一致は 5 ポイント落ちる。** 大分類の 2.3 ポイントより打撃が大きい。
南極は詳細まで当たるので、詳細一致の水増し効果が強い。

この数字は**目的関数を置き換えない**(較正の物差しを動かすと過去の実験と
比べられなくなる)。解釈のための併記値として使う。

## 1. どの分類が成績を支えているか

| 観測の大分類 | 面積シェア | 大分類一致 | 詳細一致 |
|---|---:|---:|---:|
| A 熱帯 | 20.3% | 79.2% | 44.1% |
| B 乾燥 | 29.5% | 77.2% | 51.0% |
| **C 温帯** | 11.7% | **46.8%** | 32.0% |
| **D 冷帯** | 24.5% | 78.0% | **19.7%** |
| E 寒帯 | 14.1% | 83.9% | **81.9%** |

- **E 寒帯が全体を持ち上げている**(詳細 81.9%)。これが南極の効果の正体。
- **C 温帯だけ大分類が 5 割を切る**。乾燥に食われている(混同行列 C→B 5.4%)。
- **D 冷帯は大分類 78.0% に対し詳細 19.7%** と乖離が異常。しかも面積シェア最大。
  **ここが全体の詳細一致を押し下げている最大の要因**。

## 2. D の第 3 文字は何で外れているか

ケッペンの D の第 3 文字は**気温だけ**で決まる:

```
a = 最暖月 ≥ 22°C
b = 最暖月 < 22 かつ 10°C 以上が 4 か月以上
c = 10°C 以上が 1〜3 か月
d = 最寒月 ≤ −38°C
```

Beck(1°)と気候値(2°)の格子違いを避けるため、**すべて 2° の気候値の上で**
観測の文字を起こして比べた(観測 D 帯 1609 セル)。

```
観測\モデル      a      b      c      d      外    一致率
  D_a         175      9      0      0     55     73.2%
  D_b         251    169      0      0     62     35.1%
  D_c         198    226    160     84    200     18.4%
  D_d           0      6     10      0      4      0.0%
```

**すべての誤りが左上(暑い側)へ寄っている。** D_c を a や b と答え、D_b を a と答える。
逆向き(観測 a をモデル c)は 1 件も無い。

| 観測の文字 | 個数 | 最暖月のずれ | 最寒月のずれ | 10°C 以上の月数 |
|---|---:|---:|---:|---:|
| D_a | 239 | **+3.64°C** | −1.41°C | +1.02 |
| D_b | 482 | **+4.41°C** | −0.84°C | +0.98 |
| D_c | 868 | **+3.36°C** | +1.10°C | +0.83 |

**最寒月はほぼ合っている(±1.5°C)。ずれているのは夏だけ。**

### 仮想実験 — どの量を直せば当たるか

モデルの値を 1 つずつ観測に差し替えて、文字が当たるようになるかを数えた。

```
現状                              31.3%
最暖月と 10°C 以上の月数を観測に      84.8%   ← これだけで解決する
最寒月だけ観測に                    38.3%
全部観測に(上限の検算)             100.0%
```

**冷帯の詳細一致の失敗は、ほぼ全部「夏が暑い」の一変数で説明できる。**

### 緯度帯ごと

```
緯度帯     個数   最暖月ずれ   最寒月ずれ
  30〜40°    124   +3.24°C     -4.42°C
```

帯状平均の独立な測り方(`out/validate/report.json` の zonalAnnual)でも
**50°N の 7 月が観測 19.1°C に対しモデル 23.1°C(+4.0°C)**で、同じ数字が出ている。

## 3. 原因の切り分け — 水輸送ではない

仮説は 2 つあり、打ち手が正反対になる。

- **H1** 大陸内部へ水が届いていない → 土壌が乾く → 蒸発散が小さい →
  潜熱で冷えず夏が暑い。中国東部が砂漠になる件と同じ根。打ち手は**水輸送**。
- **H2** 水は届いているが、地表エネルギー収支・放射の側が足りない。
  打ち手は**地表収支**。

観測 D 帯の夏(6〜8 月、南半球は 12〜2 月)の降水を測った。

```
緯度帯     個数  最暖月ずれ   夏の降水(観測→モデル)     夏の蒸発散  夏の湿り  蒸発散/降水
  30〜40°    124   +3.24°C      199 →   77 mm (-61%)     124 mm   0.377   1.61
  40〜50°    416   +4.77°C      193 →  277 mm (+44%)     238 mm   0.727   0.86
  50〜60°    497   +5.38°C      235 →  336 mm (+43%)     258 mm   0.928   0.77
  60〜70°    541   +1.08°C      181 →  163 mm (-10%)     166 mm   0.908   1.02
```

**最悪の帯(50〜60°N、+5.38°C)がいちばん湿っている。** 夏の降水は観測より
43% 多く、土壌の湿りは 0.928(ほぼ飽和)、蒸発散も 258mm/3 か月 = 2.8 mm/日 出ている。
水は十分すぎるほど届いていて、それでも夏が 5°C 暑い。

念のため、降水の当たり具合でセルを 3 つに分けた。

```
降水が乾きすぎ(−25% 超)    600 個   最暖月 +3.48°C
降水がほぼ合っている(±25%)   420 個   最暖月 +3.16°C
降水が湿りすぎ(+25% 超)    589 個   最暖月 +4.19°C
```

**降水が合っているセルでも +3.16°C 暑い。** どの群でも大差ない。

→ **H1(水輸送)は棄却。原因は地表エネルギー収支・放射の側(H2)。**

## 4. 有力な機構 — 蒸発冷却が気温に対して陽的になっている

2.8 mm/日の蒸発散が出ているのに冷えないのは、**蒸発冷却が負帰還として
働いていない**からだと見ている。

現在の実装(`step05_temperature.ts` の `buildEvapCoolingAnomaly`)は、
先に計算した蒸発散から冷却量を作り、EBM の**右辺へ定数として足している**。
つまり気温が上がっても冷却は増えない。

実際の地表では気温が上がれば飽和水蒸気圧が上がり(クラウジウス・クラペイロン、
15°C で約 6.5%/K)、蒸発散が増えて潜熱の持ち出しが強まる。これは**負帰還**で、
EBM の対角へ入れるべき量である:

```
∂LE/∂T ≈ L·E·(1/q*)(dq*/dT) ≈ E[mm/日] × 28.4[W/m²/(mm/日)] × 0.065[/K]
```

E = 2.8 mm/日 なら **5.2 W/m²/K**。現在の減衰は `olrBWm2PerC = 2.1 W/m²/K` だけなので、
**湿った夏の陸では減衰が 3 倍以上になる**計算になる。

この機構が良い候補である理由:

- **選択的に効く**。E ≈ 0 の砂漠には何も足さないので、既に通っている
  乾燥のゲート 3 件(サハラ・アラビア・オーストラリア)を壊しにくい。
- **観測された分布と符号が合う**。湿った 50〜60°N が最悪、乾いた 30〜40°N は
  中程度、蒸発散の小さい 60〜70°N は +1.08°C とほぼ合っている。
- **地理中立**。局所の蒸発散と気温の関数であって、緯度や大陸を見ない。
  他の惑星でもそのまま意味を持つ。
- `evapCoolingWm2PerMmDay = 4` が物理的に期待される 28.4 の 1/7 に
  較正されたことも、**陽的な項に大きすぎる係数を入れると不安定になる**ことの
  裏返しとして辻褄が合う(2026-07-30 に降水で代用して係数 12 で破綻した経緯もある)。

## 教訓

- **成績の内訳を分類別に割ると、次に直す場所が一意に決まる**ことがある。
  「詳細 44.07%」では何も分からないが、「D 冷帯 24.5% の詳細が 19.7%」まで
  割れば、そこから先は文字を決める量まで一直線だった。
- **仮想実験(モデルの値を観測に差し替える)は原因の特定に効く。**
  最暖月を差し替えるだけで 31.3% → 84.8% と跳ねたので、他の量を調べる必要が消えた。
- **もっともらしい仮説ほど測ってから捨てる。** 「大陸内部へ水が届いていない」は
  中国東部の症状とも整合し、いかにも正しそうだったが、
  最悪の帯がいちばん湿っているという一枚の表で否定された。
- **陽的な強制と陰的な帰還は別物**。同じ物理量でも、右辺に足すか対角に足すかで
  意味が変わる。較正が係数を物理値の 1/7 まで下げていたら、
  項の置き場所を疑うこと。
