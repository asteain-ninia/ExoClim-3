# 事前登録: subsidenceBasinAsymmetry の上限 0.8 → 0.95(v35 で適用)

日付: 2026-08-25 午前(v34b 走行中・収束前に書いた)

## 事実(結果に依存しない根拠)

- 実物の亜熱帯高気圧の西翼(海盆西部、黒潮・湾流・ブラジル海流域)には
  沈降が実在しない — 再解析の ω(鉛直流)では同緯度帯でも海盆西部は
  上昇域で、モンスーン対流が高気圧を完全に侵食する(Rodwell–Hoskins 型)。
  つまり「西縁で沈降ゼロ(a→1)」までが物理的に許される範囲。
- 0.8 という現行上限は実装時(2026-08-24)の保守的な仮置きで、
  物理量や観測から導いた値ではない。
- 1.0 ちょうどは descW=0 の完全消去で、数値上も問題ないが、供給ゲート・
  幅ゲートの誤差に対する余裕として 0.95 で止める(0 除算等は無い)。

## 観測された徴候(動機。これ自体は根拠にしない)

v34b の降下は a を上限 0.8 に張り付けた(2026-08-25 早朝、走行中の暫定)。

## 予測と判定条件

79. v35(または v34b 採用後の次版)で上限を 0.95 にすると、a は 0.8 を
    超えて着地する(0.8 で止まるなら上限でなく最適点だった、が答え)。
80. east_asia / argentina の share は a の増分に対し単調に上がる。
81. 守り(sahara / arabia / australia / mediterranean)は崩れない。

- 81 ✗ なら a でなく幅ゲート・供給ゲートの形の問題として扱い、上限を戻す。
