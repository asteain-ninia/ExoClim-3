## 使い捨てスクリプトの置き場(out/)

診断・検収の一回きりのスクリプトは `out/` に置く(`out/eval_v42.ts`・`out/check_bound_sticking_state.ts`・
`out/eval_v8_v43.ts`・`out/diag_*.log` など)。`src/` には入れない — 計算層は純粋関数で、
使い捨ての測定コードを混ぜると spec との対応が崩れる。較正のログは `out/optimize/log_*.jsonl`、
検証の出力は `npm run validate` が `out/validate/`(PNG + 採点 JSON)へ書く。
判定手順そのものは [引き継ぎ_2026-09-06.md](引き継ぎ_2026-09-06.md) の「判定手順(較正版)」が正本。
