# 事前登録: サブグリッド山岳の風上凝結(監査 #4、台帳 23 — カナダ B の治療)

日付: 2026-08-27 昼(実装前に書いた)
出所: 外部監査 #4。canada_west_b_present は v37 で降水 96% まで来たが
B は 0%(山影が立たない)。1° 平均勾配では実勾配の 5% しか作れない
(2026-08-12 実測)。p95 稜線場(crestElev)は読み込まれているのに
orographicCrestBlend=0 で未使用。

## 機構(実在の物理)

気流が稜線を越えるとき、風上斜面の強制上昇で水が凝結して落ちる。
落ちた分は保存則により風下に届かない = 雨陰は「引き算」でなく
**風上で降った結果**として生じる。セル平均標高でなく、気流に直交する
稜線の実効高さ(p95)と物理幅で決まる。

## 設計(保存型に整合 — 水は G 経由で降らせ、直接は消さない)

凝結率係数 G に山岳項を掛ける:

```
w_oro = max(0, V·∇h_p95)                     # 風上向き上昇(既存の勾配式を p95 場で)
G_oro = 1 + crestUpliftEfficiency × min(2.5, w_oro / (基準勾配 × subgridOrographicWidthKm / 格子幅))
```

実装は既存の地形性上昇(orographicBoost)の**勾配場を p95 に置換する既存
定数 orographicCrestBlend の活性化**が最小(コードは実装済み・0 で不発)。
掃引で 0 / 0.5 / 1 を測り、雨陰側(rainShadowFloor)への同時効果を見る。
新規コードは書かない — **死んでいた機構の再測**(監査「配線切れ」3 の実行)。

## 予測(測る前に固定)

119. orographicCrestBlend 0.5〜1 で canada_west の降水が 96% から下がり、
     **B share が 0 から正へ**動く(ロッキー風下)。

     (同じ機構の南米版)。patagonia_rainshadow の share と東部年降水を併記。
121. 平坦地・海は不変(勾配ゼロ)。大分類 ±0.4 以内。
122. ○(119 かつ 121)なら SPACE へ([0, 1])。パタゴニアの行き過ぎは
     rainShadowFloor(SPACE 内)との共調整に委ねる。

## 判定 1 と追加登録(2026-08-27 午後)

- **119 ✗**: orographicCrestBlend 0/0.5/1 は全指標が雑音水準で不動
  (70.825/70.850/70.796)。勾配場を p95 にしても動かない。
- 原因の仮説(注記の再発見): **orographicRefSlope=800 が SPACE 外の固定
  定数**で、実勾配(峰でも 7.6〜29 m/km 級)との比が 0.01〜0.04 に潰れ、
  地形性上昇・雨陰の両方が実質不発。「探索空間の外の定数が機構を殺す」
  (G の 8 因子死亡)と同型。
- 追加登録(測る前に固定): SWEEP_OVERRIDE crestBlend=1 で
  orographicRefSlope 800 / 240 / 80 を掃引。
  123. 240 以下で canada_west の降水比が下がり **B share > 0** へ。
  124. パタゴニア東部はさらに乾く(rainShadowFloor との共調整前提)。
  125. 大分類 −0.5 以内なら refSlope を SPACE へ([80, 800]、crestBlend も
       [0, 1] で同時入り)。−0.5 超なら雨陰の副作用地域を classdiff で
       分解してから判断。

## 判定 2(refSlope 掃引と全ゲート実測)

- **123 △**: canada_west は降水 96→87% と乾く方向だが B share 0 のまま
  (1° の稜線では箱の湿りを剥がし切れない)。代わりに
  **patagonia_rainshadow が PASS へ**(share 0.431→0.565、BSk+BWk 58%)—
