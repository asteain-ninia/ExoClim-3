# 考察: 凝結率 λ と G は何を表しているのか

日付: 2026-08-13
発端: 利用者の指摘「滞留 N 日は学習で得た値では。実測に合わせるのは
惑星の観測値に合わせることにならないか」

**実験の前に、式が何を意味しているかを詰める。**

## 1. まず指摘への答え: τ は独立した観測ではない

保存型の降水は `P = λ·G·W` なので、局所の滞留時間は

```
τ = W / P = 1 / (λ·G)
```

**τ そのものがパラメータである。**「実物の 9 日に合わせる」は
「λ をその値にする」と同じことで、独立した観測を持ち込んではいない。
段 19 で「物理の目標値が独立に決まっている」と書いたのは**誤りだった**。

地理中立には触れない(地球の気候で定数を較正するのはこのプロジェクトの前提で、
禁じているのは**計算層に地球の地理を決め打ちすること**)。
だが「独立した目標がある」という私の主張は成り立たない。

## 2. λ を物理で見積もると、**現行値はむしろ妥当**

凝結率の物理的な中身は「上昇した空気が水を落とす速さ」である。

```
大規模上昇 w ≈ 1 cm/s、水蒸気スケールハイト H ≈ 2 km
上昇域の滞留 = H/w = 2.3 日  →  λ = 13.0 /月

モデルの λ（陸）= 15.7 /月 → 滞留 1.9 日
```

**桁も値もほぼ一致する。** λ は「上昇域での凝結の速さ」としては正しい。

つまり段 19 で私が下げようとしたのは、**下げるべきでない量**だった。
B′(λ を物理から導き直す)も、導いた先が同じ 13/月 になるので**意味が無い**。

## 3. ではなぜ全球の滞留が 9 日ではなく 2 日なのか

**実物の 9 日は「上昇域の 2.3 日」÷「実際に上昇している割合」である。**

```
9 日 / 2.3 日 = 3.9
→ 面積・時間で均した「雨が降っている割合」は 1/3.9 ≈ 0.26
```

この割合を担う量は、モデルでは **G** である。
G は「持ち上げ × 遮蔽 × 抑制」の積で、**平均 1 前後**になっている:

```
congo 1.845 / india 1.732 / west 1.809 / antarctica 1.010
us 0.923 / east 0.574 / tibet 0.486
```

**G の平均が 1 ということは「全球どこでも常に上昇域と同じ速さで雨が降る」
と言っているのに等しい。** 本来は 0.26 前後であるべきである。

### なぜこうなったか

非保存の時代、G は**相対的な倍率**だった。絶対量は
`precipScaleMmPerUnit` が担っていた。保存型へ移したときこの定数は消え、
**絶対の較正は λ が引き受けた**。だが **G は相対倍率のまま**で、
「実際に雨が降っている割合」という絶対の意味を持たされていない。

段 1 の計画書には「G は既存の持上げ・抑制の積を**そのまま**使う
(この段では 1 つも外さない)」と書いてある。**意味の変更を保留したまま
今日まで来た。**

## 4. もっと重い問題: G の幅が 2 桁足りない

```
モデルの G      最大 1.845 / 最小 0.486  =  3.8 倍
実物の降水比    コンゴ 1718mm / サハラ 30mm  =  57 倍
```

**G は 3.8 倍しか動かないのに、実物の降水は 57 倍動く。**
残りは輸送(W の分布)が担うことになるが、W は移流+拡散の解なので滑らかで、
2 桁の幅は作れない(段 12 で実測済み)。

**サハラが観測の 4.74 倍なのは、これで説明がつく。**
乾燥域で G が 0.4 までしか下がらないので、届いた水が降ってしまう。

## 5. その機構は既にあって、**0 で無効化されている**

```
crhSuppressionSharpness: 0     ← 柱相対湿度による指数抑制
```

定数のコメントにこう書いてある:

> 観測(Bretherton et al. 2004)では熱帯海上の降水が P ∝ exp(15.6·CRH) と
> 指数的に応答し、CRH ≈ 0.75 で点火して 0.5 では **2 桁落ちる**。

**まさに「2 桁の幅」を作るために用意された機構が、0 のまま眠っている。**
非保存の時代に測って採らなかったものだが、
**保存型では意味が変わる** — あのときは「降水を削る乗数」だったが、
いまは「凝結率 = 雨が降っている割合」であり、指数で効くのが物理的に正しい。

## 6. したがって次の一手

**λ には触れない。G の絶対的な意味と幅を作り直す。**

1. `crhSuppressionSharpness` を 0 から上げて掃く(文献値 15.6 が上限の目安)。
   **保存型で測るのは初めて**である。
2. G の平均が 0.26 前後へ下がり、幅が 2 桁近く開くかを見る。
3. そのとき λ は据え置き(物理的に妥当なので)。
   全球の滞留時間が自然に 9 日前後へ近づけば、**独立した検証になる**
   (合わせに行くのではなく、出てくるかを見る)。

**これが利用者の指摘に対する正しい答えである。**
地球の 9 日に合わせるのではなく、**物理の構造を直した結果として
9 日が出てくるか**を見る。出なければ構造がまだ違う。
