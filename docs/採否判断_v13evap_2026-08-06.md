# 採否判断: 蒸発冷却の実 ET 繋ぎ替え(v13evap)

日付: 2026-08-06
対象: `evapCoolingWm2PerMmDay` を 0 → 4 とし、繋ぐ物理量を降水量から実蒸発散へ変更
判断: **採用**(constants.ts へ 62 定数を反映済み)

利用者の方針(2026-08-02)に従い、**数値的健全性 / 新旧両目的関数 / 季節指標 /
地域ゲート / 未見評価**を総合して判断する。

## 1. 数値的健全性 — PASS(必須条件)

```
EBM 残差 5.91e-5°C / 年次ドリフト 9.15e-3°C / 全熱容量 24 年 / 反復 512
```

許容差(残差 1e-3、周期定常 0.05)をどちらも 1〜2 桁下回る。**未収束の解を
採用していない**ことが確認できた。

## 2. 目的関数 — 新旧どちらも改善

| 指標 | 数値修正直後 | v12desc | **v13evap** |
|---|---:|---:|---:|
| **v3(新)** | 76.10 | 84.92 | **85.77** |
| **v2(旧)** | 85.90 | 94.28 | **94.85** |

目的関数を改訂した以上「新しい物差しで良くなったのは当然」という自己欺瞞を
避ける必要がある。**旧定義でも改善している**ので、物差しの取り替えによる
見かけの改善ではない。

## 3. 分類の一致と季節指標

| 指標 | 数値修正直後 | v12desc | **v13evap** |
|---|---:|---:|---:|
| 大分類一致 | 70.61% | 74.91% | **75.22%** |
| 詳細一致 | 35.70% | 43.28% | **44.07%** |
| 気温 年平均RMSE | 6.80°C | 4.27°C | **4.16°C** |
| **年較差RMSE** | 8.98°C | 9.77°C | **8.97°C** |
| 季節位相RMS | 35.1日 | 34.43日 | **33.97日** |
| 降水 年RMSE | 918mm | 699mm | **695mm** |
| 降水 最少月RMSE | 45.9mm | 35.8mm | **35.6mm** |

**年較差 RMSE が動いたことが最大の成果**。3 回の較正で一度も動かず、
数値の欠陥を直した際に 8.98 → 9.77 と悪化していた指標が、9.77 → 8.97 と
修正前の水準へ戻った。診断(半乾燥の夏が +5.00°C 暑すぎる = 蒸発冷却の欠落)
が当たっていたことの裏付けになる。

## 4. 地域ゲート — 14/17 で不変

下がっていない。最終受入(全 17 件)には未達だが、これは今回の変更とは別の
残課題(帯状平均気温の最大乖離 26.4°C など)。

## 5. 未見評価(空間ホールドアウト 5 区画)— 過剰適合なし

30°×30° ブロックを決定的ハッシュで 5 分割し、区画ごとに
「その区画を目的関数から外して較正 → その区画だけで採点」した。

| 区画 | 訓練側 大分類 | 未見側 大分類 | 差 |
|---:|---:|---:|---:|
| 0 | 72.96 | 81.68 | +8.72 |
| 1 | 75.72 | 73.28 | −2.44 |
| 2 | 73.97 | 83.81 | +9.83 |
| 3 | 75.60 | 73.93 | −1.67 |
| 4 | 77.94 | 64.24 | −13.70 |
| **平均** | **75.24** | **75.39** | **+0.15** |

**未見側が訓練側をわずかに上回る。過剰適合は検出されない。**

区画ごとのばらつき(−13.7 〜 +9.8)は過剰適合ではなく**区画の難しさの違い**
である。区画 4 は外すと訓練側が 77.94 まで上がり、未見側は 64.24 に落ちる —
つまり残差の大きい土地が集中している。ゲートも 14 → 12 に落ちるので、
重要地域を 2 件含む。**この非対称自体が次の診断の手がかり**になる。

## 6. 未見での直接比較 — 蒸発冷却は未見でも効く

同じ未見区画で、**全球較正した v12desc(蒸発冷却なし)**も採点した。
v12desc はその区画を訓練に含んでいるので、**v13 側に不利な比較**である。

| 指標 | v13(未見較正) | v12desc(全球較正) | 差 |
|---|---:|---:|---:|
| 大分類 | **75.39** | 75.14 | **+0.25** |
| 詳細 | 43.49 | 43.70 | −0.22 |
| 気温 RMSE | **4.16** | 4.18 | **−0.02** |

区画ごとの大分類の勝敗は **4 勝 1 敗**(負けたのは区画 1)。
不利な条件でも勝っているので、**実 ET への繋ぎ替えは地球の特定の場所へ
合わせ込んだのではなく、手続きとして働いている**と読める。

詳細が −0.22 とわずかに負けているのは弱点だが、大分類・気温で勝ち、
全球では詳細も 43.28 → 44.07 と改善しているので、採用を妨げるものではない。

## 7. 参照値との比較(単独では落とさない)

```
⚠ 気温年 RMSE 4.16°C > 基準 3.8°C
```

2026-07-31 に凍結した参照値を上回っている。ただしこの基準は**数値の欠陥を
含んだ状態**で得られたもので(反復回数・界面の非対称・緩和年数の 3 件)、
収束解に移った時点で 6.80°C まで落ちた経緯がある。そこから 4.16°C まで
戻してきた途中であり、**退行ではない**(docs/退行防止ゲートの扱い_2026-08-02.md)。

## 結論

**採用する。** 5 つの観点すべてで条件を満たすか、満たさない項目については
理由が説明できている。

- 数値的健全性 … PASS(必須)
- 新旧両目的関数 … どちらも改善
- 季節指標 … 年較差が初めて改善、位相も微改善
- 地域ゲート … 不変(下げていない)
- 未見評価 … 過剰適合なし、未見での直接比較でも勝ち

## 追記: 区画 4 の正体(2026-08-06、scripts/diag_fold_regions.ts)

```
ゲート: arabia_arid, east_asia_humid, patagonia_rainshadow, antarctica_ice
主なブロック: 45N/105W(北米中西部) 75S/75E・75S/15E(東南極) 15N/45E(アラビア)
大分類: E寒帯 38.8% / B乾燥 24.9% / C温帯 14.4%
```

**モデルの既知の弱点がここに集中している**:
- 南極 … 冬 −10.6°C / 夏 −5.0°C 寒すぎる(海氷の双安定。南大洋が一年中凍結)
- アラビア … 亜熱帯砂漠の過大降水(供給が保存されていない)
- 東アジア … 中国東部の年降水が 340mm(基準 401、目標 750)と退行中
- 北米中西部 … 中緯度半乾燥の夏が暑すぎた層(蒸発冷却で一部改善したはず)

つまり未見成績の落ち込みは過剰適合ではなく、**難所が一つの区画に固まっていた**
だけである。逆に言えば、**この 4 つを直せば全体が大きく動く**。
海氷(南極)と亜熱帯の供給(アラビア)は既に診断済みで、設計もある。
