## 交換率の尺(結果に依存しない根拠 — 9/6 の診断 out/diag_layer_conv.ts)

純粋な風の発散指標 conv = −div(V)·τ(τ = 2e5 s、無次元、2°・v48 既定・12 か月):

| 集合 | 10% | 50% | 90% | 99% | 正の割合 |
| --- | --- | --- | --- | --- | --- |
| 陸 | −1.64 | 0.005 | 1.95 | 9.0 | 0.50 |
| 海 | −2.68 | 0.05 | 1.64 | 9.3 | 0.51 |
| 帯 15-35 | −3.10 | −0.22 | 1.03 | 4.5 | 0.41(亜熱帯は発散が優勢 = 下向き交換の主戦場) |
| 帯 60-90 | −2.68 | −0.22 | 1.89 | 15.8 | 0.38(極の裾は格子の歪み。σ が大きくても線形陰的で安定) |

σ_up = k_up·conv⁺ + ε [1/月]。conv ≈ 1 のとき k = 1 で境界層の水が月 1 回入れ替わる。実物の境界層の
換気時間は収束域で 1〜3 日(σ ≈ 10〜30/月)なので、k ∈ {0.3, 1, 3} が「弱・実物級・強」の 3 水準。
ε(cap 越しの背景混合)は自由対流圏との緩やかな結合で、k より 1 桁小さい {0, 0.1, 0.3}。

## 水準(1 度に 1 つ。他は既定。moistureLayerSplit = 1・boundaryLayerSatFrac 0.6 固定)

1. k_up = k_dn = k で k ∈ {0.3, 1, 3}(ε = 0.1 固定)— 交換の強さ。
2. ε ∈ {0, 0.1, 0.3}(k = 1 固定)— 背景混合の寄与。
3. boundaryLayerSatFrac ∈ {0.5, 0.6, 0.7}(k = 1・ε = 0.1)— 層の飽和割合の感度。

道具: `SWEEP_OVERRIDE='moistureLayerSplit=1,...' npx tsx scripts/sweep_lever.ts <定数> <水準> --parallel 3`
(環境変数 SWEEP_GRID_DEG は付けない — 教訓 §17)。k_up と k_dn を同時に振るには sweep_lever の 1 定数制約が
あるので、k_dn を SWEEP_OVERRIDE で水準ごとに合わせて 3 回打つ(記録に起動行を残す)。

## 予測(測る前に固定)

174. 全水準で健全性 PASS、層の往復(layerNonConverged)0、輸送の未収束 0。往復回数は 2〜6。
175. **全球 W は k とともに増える**(自由対流圏が「持っているが降らない」水を置く): k = 1 で
     ≥ 7mm(基準 4.9 の +40%)、k = 3 で ≥ 10mm。実物 25mm には届かない(λG は単層のまま)。
176. **乾いた収束**: gobi の降水比 3.92 → k = 1 で ≤ 3.0、k = 3 で ≤ 2.0。central_asia 3.04 → ≤ 2.4 / ≤ 1.6。
     sahara・arabia は PASS のまま(share ≥ 0.8)。境界層で収束した水が上に抜けて、気柱輸送風で運ばれる。
177. 1% 分位 15 → k ≥ 1 で ≤ 12(乾いた端がさらに乾く)。
178. 連続部分は単独では下がってよい(順序原則: 単独損は棄却理由にしない)。ただし大分類 −1.0 以内
     (k ≤ 1)。−1.0 を超えて落ちるなら、どの帯・どの大分類が動いたかを classdiff で分解して記録。
179. 熱帯ゲート(amazon・congo)は share ≥ 0.9 を保つ(収束域で境界層の水が抜けても、G が大きい所は
     自由対流圏の対流項で降る)。
180. ε は k より効きが小さい(ε 0 → 0.3 の W の変化は k 0.3 → 3 の 1/3 以下)。

## 判定

- 175・176 の針が予測の向きに動く(量は問わない)かつ 174・179 ○ → **段 L-2 へ**: k_up・k_dn・ε・
  boundaryLayerSatFrac を SPACE に入れる範囲を掃引の崖から決めて事前登録し、較正 v50。
- 175 は動くが 176 が動かない → 抜けた水が自由対流圏で同じ場所に降っている。自由対流圏の閉包
  (cap の割合・対流率)を疑う。freeLayerLinearRateFrac は 0 のまま、cap の残り (1−satFrac) を見直す。
- 176 は動くが 179 ✗(熱帯が崩れる)→ k_up を G で門する(持ち上げの強い所は境界層の水を残す)案を
  別登録。掃引の結果で門を決めない(結果依存の定式を避ける)。
- 174 ✗(往復が収束しない)→ 数値の工事が先(Gauss–Seidel の緩和か、層を同時に解く連立化)。
- 175 も 176 も動かない → 交換の定式(発散由来)が弱い。境界層の高さ(T_a − T_s の安定度)で
  σ を決める定式を検討。ここも結果を見てから閾値を作らない。
