# 事前登録: 亜熱帯沈降帯の赤道側の広がり(段 18)

日付: 2026-08-13
**結果を見る前に書いている。**
前段: [実験記録_リッジの経度依存](実験記録_リッジの経度依存_2026-08-13.md)(段 16)

## 段 16 が名指しした場所

リッジを経度で 9° 動かしても east_asia の降水は 0.17 → 0.19 しか動かなかった。
理由は**帯が広すぎる**ことだった:

```ts
const descLo = Math.abs(ridge) - 16;   // ← この 16
const descHi = Math.abs(ridge) + 5;
descW = 帯の中なら 1、外は exp(-d²/16)
```

**21° 幅**あるので、7 月のリッジ 37°N に対し帯は **21〜42°N**。
east_asia(25〜40°N)は**丸ごと帯の中**に入る。
沈降残存が 0.546(凝結率が半減)なのはこのため。

赤道側の広がり 16° は名前を持たない数で、下向きに測られた形跡が無い。

## 変えるもの

`subsidenceBandEquatorwardDeg`(既定 16)を掃く: **16 / 12 / 8 / 5**。
5 なら帯は 32〜42°N となり、east_asia の南半分が外れる。

`descHi` の +5 と裾の減衰 16 は**動かさない**(1 本ずつ)。

## 予測(先に書く)

- **east_asia と us_southeast の降水が上がる**。帯から外れて凝結率の
  半減が緩むため。狙いどおりならここが一番大きく動く。
- **砂漠が湿る**。サハラ・アラビア・豪州内陸は**この沈降帯で乾かしている**ので、
  狭めると湿るはず。**これが最大の危険**であり、判定 2 の番人になる。
- 地中海性気候(夏の乾き)も弱まる可能性がある。

**外れる筋**: 帯を狭めても east_asia が動かない。その場合は沈降抑制ではなく
別の要因(そもそも水が来ていない)が支配しており、**東岸の線は閉じる**。

## 判定(先に固定する)

較正 v22 の定数の上で測る。

1. **east_asia の年降水が観測比 0.17 → 0.30 以上。**
2. **砂漠が壊れない。** sahara と arabia の年降水比が現在から +0.3 を超えない。
3. **v3 が 85.235 から 1.0 以上落ちない。**
4. **大分類が落ちない。**

1〜4 をすべて満たせば採用。1 を満たさなければ、
**中緯度東岸は降水側の機構では直らないと結論して線を閉じる**(7 回目)。

## やらないと決めていること

- 帯の極側(+5)や裾の減衰(16)を同時に動かすこと。
- 砂漠が湿ったぶんを別の定数で補償すること。**1 本ずつ、補償なしで測る。**
