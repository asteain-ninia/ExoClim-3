## 判定: **採用候補にしない**(事前登録の規定どおり)

規定は「予測 1 かつ 2 かつ 5 が当たったら採用候補」だった。
**予測 1 が外れているので満たさない。** 既定 0 のまま残す。

> 連続部分は +0.098 改善しており、大分類・詳細も上がっている。
> **数字だけを見れば「小さいが改善」だが、これを理由に採用してはいけない。**
> 狙った機構(米南東への南風)がまったく効いていないのに全体が少し良くなるのは、
> **別の場所で偶然効いている**ということであり、機構の説明と挙動が一致していない。
> 説明できない +0.098 を採用するのは、まさに監査が指摘した
> 「崖を越えただけの解を採用する」のと同じ型の誤りである。
>
> なお +0.098 は較正の 1 反復ぶんより小さい(v24 は 194 評価で +0.57)。
> **採るなら探索空間へ入れて較正に判断させるべき量**で、掃引の 1 点で決めない。

## 追測(同日): 機構は**正しい向きに効いていた。桁が 2 桁足りない**

`diag_monsoon_inflow` を boost 0.6 で走らせ、C→B セルの夏の風を直接見た。

```
                        boost 0    boost 0.6    変化
極向き風 v (m/s)         −0.79      −0.73      +0.06
極向き水蒸気フラックス   −2.14      −1.98      +0.16
```

**向きは完全に正しい。** 赤道向きだった風が、狙いどおり極向きへ動いている。
副作用も無い(欧州・コンゴが不動)。設計の理屈は当たっていた。

**だが量が足りない。**

```
南風に転じるのに必要な変化   +0.79 m/s
boost 0.6 で得られた変化      +0.06 m/s   ← 必要量の 8%
線形外挿すると boost ≈ 7.9 が必要（現実的でない）
```

### そして本当の発見はこちら

```
対照(当たっている C)の極向き風 = −0.44 m/s ← **これも赤道向き**
```

**C→B のセルだけでなく、モデルの亜熱帯の夏はどこも南風が吹いていない。**
当たっている C ですら赤道向きである。つまりこれは
「亜熱帯モンスーン域という特定の場所の問題」ではなく、
**モデルの子午面循環そのものが、夏の亜熱帯で極向き成分を持たない**という
一段深い構造の問題である。

私は前段(diag_monsoon_inflow の初回)でこの数字を見ていたのに、
**C→B 群だけを見て「その場所の欠陥」と読んだ**。対照群も同じ符号だったのに、
比(1.63 倍)にばかり注目して**絶対値の符号を見落としていた**。

## なぜ効かなかったか(切り分け)

事前登録の規定:

> 予測 1 が外れたら(米南東が動かない): 西縁の回転成分が沿岸まで届いていない。
> 気圧勾配風の上限(P_MAX=8)か回転係数を疑う診断へ。

候補は 3 つある。**まだ切り分けていない。**

1. **気圧偏差そのものが小さい。** 海上重みは `0.8 + eastBoost×… + westBoost×…` で、
   `subtropicalHighHpa = 6` hPa に掛かる。boost 0.6 でも重みは最大 +0.6 で、
   気圧差にすると 3.6 hPa。**大陸東岸沖まで届く距離減衰**(2200km)を考えると、
   沿岸での増分はさらに小さい。
2. **気圧勾配風の上限で頭打ち。** `P_MAX = 8` m/s で合成を抑えている。
   既に上限に張り付いている場所では、気圧を強めても風が増えない。
3. **回転成分が低緯度で殺されている。** `rotRamp = (|lat|−10)/20` で
   |lat| < 30° では回転成分が弱められている(モンスーン流は非地衡という理由)。
   米南東(30〜37°N)は境界付近で、**回転成分がまだ十分立っていない**可能性。

**候補 3 は外れ**だった。`rotRamp = (|lat|−10)/20` は **30°N で既に 1.0** に
達しており、米南東(30〜37°N)で回転成分は殺されていない
(sin(lat) との積は 0.50〜0.60)。測る前にコードで確かめて棄却した。

残るのは 1(気圧偏差そのものが小さい)である。追測が示す
「向きは正しいが 8% しか動かない」はこれと整合する。

`subtropicalHighHpa = 6` hPa に海上重み(最大 +0.6)を掛けるので、
西縁の増分は最大 3.6 hPa。しかも距離減衰(2200km)がかかるため、
大陸東岸の沿岸ではさらに小さい。**気圧の振幅そのものが、
子午面風を 0.8 m/s 動かすには足りない。**

### 次にやるべきこと(この機構の枠を超える)

追測で「亜熱帯の夏はモデル全体で南風が無い」と分かったので、
**局所的な高気圧の強化では届かない**と考えるのが自然である。

- 段 39 の boost をさらに上げるのは筋が悪い(必要 7.9 は現実的でなく、
  そこまで上げれば亜熱帯高気圧そのものが非現実的な強さになる)。
- 疑うべきは**子午面循環の表現**である。実物の夏の亜熱帯は、
  ハドレー循環の下降域でありながら、大陸東岸ではモンスーン循環が
  下層に極向き流を作る。モデルの帯状卓越風は
  「貿易風(赤道向き成分)」と「偏西風」の 2 つで、
  **その中間の緯度に極向きの下層流を作る仕組みが無い**。
- 既存の `crossEquatorialMonsoon`(赤道越えモンスーン、既定 0 = 無効)が
  近い位置にある。**赤道越えではなく「亜熱帯での極向き」版**が要るのかもしれない。
  次はこれを設計として検討する。

## この実験で分かったこと(機構の理解として)

- **陸の気圧に触らない設計は、副作用を出さないことに成功した。**
  欧州が 0.92 で不動、コンゴも 1.27 で不動。熱的低気圧が欧州を 0.82 まで
  壊したのと対照的で、設計の狙い(西岸を壊す力学を構造的に持たない)は当たった。
- **だが「副作用が無い」は「効果がある」とは別。** 今回は前者だけ達成した。
- 東アジアが 0.20 → 0.21 とわずかに動いたのは、この機構が
  **6 回の棄却で一度も動かなかった東アジアを初めて動かした**ことになる。
  桁は足りないが、向きの手がかりとして記録しておく。
