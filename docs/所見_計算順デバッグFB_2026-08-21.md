# 所見: 計算順デバッグ v29 への利用者 FB と機構への対応付け(2026-08-21 朝)

利用者が[計算順デバッグ v29](報告/計算順デバッグ_v29_2026-08-21.html)を通読して
出した観察の記録と、各観察がどの機構・既知問題に対応するかの突き合わせ。
**v30/v31 への搭載候補はこの文書から拾うこと。**
記録: サブスレッド(コード・較正には触れていない)。

## Step 1 — ITCZ

| 利用者の観察 | 対応する機構・出典 |
| --- | --- |
| **全体的に振幅が大きい**(アフリカだけ正しく、他は全部広すぎ。太平洋・大西洋上も観測はもっと低振幅) | 海上の振幅は itczOceanFollowDamp が支配(v29 で 0.79 → 0.91 と大きく動いた定数)。**較正は点数のためにこの定数を動かしたが、目視は逆方向を支持** — 位相(帯別 RMSE)と振幅の綱引きを疑う。棚卸し 01 参照 |
| モデルは**インド東部に強く惹きつけられる**が観測はそうでもない | itczPlateauPullDeg 14° + itczMonsoonPullDeg 4°(チベット・モンスーンの吸引)。効かせる場所が広すぎるか強すぎる |
| 観測は**マダガスカル(北端)にすごく強く惹きつけられ、3 本全部が収束**する。モデルはアフリカの角を素通り | 島・半島スケールの吸引機構が無い(吸引は大陸プラトー基準)。地理中立に書くなら「湿った陸の対流源への吸引」の一般規則が要る |
| **メキシコへの張り出しが観測にはあるがモデルに無い** | 北米モンスーンの吸引が立っていない(同上 — 吸引規則が大陸スケールに限定されているため) |
| **チリ方面への冬 ITCZ の張り出しはモデルにしか無い** | 南東太平洋の吸引の誤発火。実物の同海域は寒流+層積雲で ITCZ が近寄らない — SST 帯(step 3)を ITCZ が読んでいないことの現れ |

## Step 2 — 風帯・気圧

- 「**帯すぎる。中立の白が少ない。陸上が激しすぎ、海上が穏やかすぎ**」
  → 既知(気圧は気温場を読まず、海陸+季節のパラメタ化)に加え、**振幅配分の誤り**という
  新しい言語化: 大陸パラメタ化の振幅が過大で、海上の低圧系(アリューシャン/
  アイスランド)が subpolarWinterLowHpa 7hPa の帯状近似しか無い。

## Step 3 — 海流 SST

| 利用者の観察 | 対応 |
| --- | --- |
| **全体的にモデルが弱すぎる。陸から真横に出る筋のよう。観測はずっと有機的** | 行走査(緯度行ごとの東西距離)で場を作るため帯・筋になる。振幅は縮退(棚卸し 03 疑い 4: EBM 結合だけが較正対象)で、他 4 経路の閾値には弱いまま |
| **地中海など小水域が観測では塗られている**のにモデルは黒(中立) | 縁海・閉鎖海の熱コントラスト機構が無い(縁海はゲート漏れの偽寒暖流以外は中立) |
| **アフリカの角・アラビア南岸に偽暖流**(定量: ソマリア沖 平均 +0.69°C/最高 +2.64°C、アラビア南岸 +0.76°C。実物は夏の湧昇で −3〜−5°C) | (a) 縁海バグの**西縁側の対**(アラビア海ミニ海盆の西岸暖流)+ (b) **ソマリ型湧昇は実装見送り**(step03_ocean.ts:138-140 の注記、2026-07-30)のまま未着手。[診断_縁海の偽寒流](診断_縁海の偽寒流_2026-08-21.md)に追記済み |
| **アルゼンチン東岸**: 観測は粒状の寒流+取り巻く暖流(ブラジル・マルビナス合流) | 中規模渦スケールの合流構造で、1° 帯規則の表現外。優先度低(形の問題であり符号は合っている) |

## Step 4 — 気流

- 「**モデルが圧倒的に強すぎる。帯状すぎ、有機性が足りない**」
  → 陸上の減衰が標高 1500m 超にしか無く、**地表摩擦(粗度)による陸の減速が無い**
  (観測の陸上月平均 10m 風は 2〜4 m/s、モデルは帯状卓越風 6.7〜9 がほぼ素通し)。
  海上は逆に月平均ベクトルの相殺が無いぶん…ではなく、モデルも月平均だが
  変動が無いので「常に定格で吹く」。蒸発は海上風なので源泉は無事だが、
  **陸上の水蒸気移流は強すぎる風で運ばれている**ことになる(内陸輸送の診断と交差)。
- 図の矢印が小さくて読みづらい → 図版の改善 TODO(次版で矢印を大きく・間引きを粗く)。

## v30/v31 への搭載候補(優先順の私案)

1. **縁海ゲートの修正(寒流・暖流の両側)**: 「海盆が極側(寒流)/赤道側(暖流)に
   開いているか」のトポロジー条件。ソマリ型湧昇の再検討もこの文脈で
   (見送り理由「ベンガル湾北岸と区別できない」は開き判定で解ける可能性)。
   **修正後は再較正必須 → v31 本命案と整合。**
2. **ITCZ の吸引規則の一般化**: プラトー・大陸決め打ちの吸引を「湿った陸の対流源への
   吸引」に置換し、海上振幅(itczOceanFollowDamp)を目視と両立する形で再較正。
3. **陸面摩擦による風の減衰**: 陸の粗度で地表風を減速(蒸発は海上なので源泉不変、
   陸の移流だけが変わる)。
4. **SST 縮退潰し**(棚卸し 03 疑い 4 の処方どおり物性側へ寄せる)。

いずれも実施は事前登録(予測固定 → 測定 → 答え合わせ)の作法で。
