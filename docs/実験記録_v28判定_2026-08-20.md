## 発見: 「谷を渡れない」の定量記録

新機構の試行 9 回の全履歴(対 当時最良):

```
relief:   −0.29 → −0.31 → −0.28   (78.93 / 78.94 / 79.00)
conveyor: −0.12 → −0.14 → −0.15   (79.10 / 79.11 / 79.14)
lag:      −0.001 → −0.11 → −0.09  (79.221 / 79.142 / 79.190)
```

- 酸性試験(v27 の点)では lag=1 が **+0.19 で勝った**のに、降下が他定数を
  磨くほど(79.14→79.28)lag の単独付与は負けが深くなる。
  = 最良点が「lag なし局所盆地」の底へ向かって整い、単独座標の跳びでは
  盆地の壁を越えられない。
- relief と conveyor は **45c で「対でだけ超相加」を実証済み**の組。
  座標降下は 1 座標ずつしか動かせないため、対の谷は構造的に見えない。
  教訓 §9「座標降下は谷を渡れない」の最も明瞭な実例。

## 処方(v29): 盆地を変えて比べる

目的関数は触らない(結果を見た重み弄りをしない)。**種を変える**:
v29 = 同一 SPACE・同一 v6 で、種 = v28 最良 + {lag 1.0, conveyor 15,
relief 0.3}(45c の動作点)。降下に「機構ありの盆地」の中を磨かせ、
最終値を v28(79.280)と同じ物差しで比べる。多スタートの正攻法であり、
どちらの盆地が深いかを較正自身に答えさせる。
