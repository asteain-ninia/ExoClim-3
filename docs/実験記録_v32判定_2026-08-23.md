## 分解(v30 → v32、面積重み)

```
改善 267.2 / 悪化 319.2(差 −52)
悪化の型: B→A サヘル南縁 57.7 / B→C 地中海南岸〜中東 54.3 / A→C コンゴ 51.0 /
          B→D 中央アジア 45.7 / D→C 五大湖〜東欧 42.8 / C→B 米南東 21.4
改善の型: B→C(温帯の回復)62.9 / C→D 40.7 / B→D 34.4 / B→A 34.2
```

**読み**: 改善も悪化も同じ型(B↔C・C↔D)の**境界の押し合い**で起きている。
風を弱めると内陸の乾燥境界が湿る方向へ全体に動き、**当たる場所と外れる場所が
ほぼ同数**出た(改善 267 対 悪化 319)。地域を名指しで壊したのではなく、
**気候帯の境界全体が一斉にずれた**。

## 意味(重要)

1. **v7b は「風を正しくする」課題を解いた**(正規化 5.04 → 1.60)。
   摩擦 0.39 は観測(陸上 2〜4 m/s)に整合する水準で、FB Step4 の指摘は解消。
2. **その代償として大分類が −0.4 落ちた**。しかしこれは「地図を捨てて風を取った」
   というより、**風が変わると気候帯の境界が動き、いまのモデルの他の機構では
   その新しい境界を正しい場所に置けない**という構造の露呈である。
3. つまり v32 の点は「**より正しい風・より正しくない地図**」であり、
   v30 は「**嘘の風・つじつまの合った地図**」。どちらを採るかは
   **地球の点数を取るか、他の惑星へ持っていける物理を取るか**の選択になる。

## 採否(利用者へ)

推奨: **採用**。理由は本プロジェクトの目的(地球は較正手段であって目的ではない)。
陸上風は観測に係留され、コンベア(実在の水輸送)は 33.0 まで強まり、
中国東部は 251→340mm と改善した。大分類 −0.4 は、境界を正しい場所へ置く機構
(冬雨・W の滞留・地中海型)が埋まれば取り返せる性質の失点である。

見送る場合の論拠も残す: 地球の一致率は現行 v30 が上(74.8 対 74.4)。
「まず地球で権威を得る」(裁定 2、2026-08-17)を厳格に取るなら v30 維持。
