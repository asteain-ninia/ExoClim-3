# 事前登録: ITCZ 傘の発散ゲート(角の治療、台帳 27 関連)

日付: 2026-08-28 午後(実装前に書いた)
出所: v38 分解 — 角の主犯は傘直撃(liftItcz ×2.70、降水 9.8 倍)。
供給ゲート(itczLiftSupplyNorm 0.5)は「海の湿り」で常時全開(C 類の
0 着地と同根)。実物のソマリアが ITCZ 通過期でも乾くのは、**低空ジェットが
水蒸気を沖へ持ち去る(柱の正味発散)**から。

## 設計(地理中立 — 既存の水蒸気収束指数を使う)

傘の持ち上げに発散ゲートを掛ける:

```
divF = clamp(−convIndex / itczDivergenceNorm, 0, 1)   # 正味流出の強さ 0〜1
liftItcz ×= 1 − itczDivergenceSuppress × divF
```

- convIndex は既存 moistureConvergenceIndex(保存的・全球)。
  ソマリア: ジェットで発散 → 傘が閉じる。ベンガル: 収束 → 全開のまま。
- 新定数: itczDivergenceSuppress ∈ [0, 1] 既定 **0**(ビット一致)、
  itczDivergenceNorm 既定 = wetConv 系と同じ既存正規化(新設 1 つに抑える)。

## 予測(測る前に固定)

     share > 0 へ。

     (収束側は divF=0 で不変)。

(モンスーン流入)、divF=0。実物のソマリジェットは岸と平行に吹いて水蒸気を
沖へ運ぶ。**角の欠落は G 側でなく風の場(step04 にジェット構造が無い)**。
撤退(既定 0 残置。実装は残す — 風が直った後に再測の枠)。

大気版)。海気分離 段 C・気圧場の熱駆動(台帳 9)と同じ「風の構造」群。
