# 較正計画: 収束させた EBM での再較正(事前登録、2026-08-01 23:17)

**結果を見る前に書く**。判定基準・棄却条件は実行前に固定し、あとから緩めない。

## 何が起きたか(前提)

EBM 内側の Gauss-Seidel 反復を 8 回で打ち切っていたが、これは
constants.ts にも spec にも無いベタ書き定数(`GS_SWEEPS = 8`)であり、
**答えを面積平均 2.1°C 動かす隠しパラメータ**だった。

収束させると採点はこうなる(実測、変更は反復回数だけ):

| | 反復 8(従来) | 反復 512(収束) | 差 |
|---|---:|---:|---:|
| 大分類一致率 | 74.32 | 71.92 | **−2.40pt** |
| 詳細一致率 | 42.40 | 39.38 | **−3.02pt** |
| 気温 RMSE | 3.670 | 4.738 | **+1.068°C** |
| 退行防止ゲート | 13 | 13 | 0 |
| 陸平均降水 | 813mm | 782mm | −31mm |

反復自体は健全に収束している(残差 6.4e-1 → 4.4e-1 → 2.7e-1 → 1.3e-1 →
3.6e-2 → 2.6e-3 → **1.7e-5** → 0)。問題は収束解のほうが成績が悪いこと。

## 仮説

**未収束の Gauss-Seidel は陰的作用素を途中までしか適用しないので、
拡散・移流による熱輸送が「弱く」効く。較正はそれを前提に輸送係数を
過大に決めていた。** 収束させると輸送が効きすぎて温度場が平坦化し、
大陸内部の夏の暑さ・冬の寒さ(大陸度)が失われて成績が落ちる。

この仮説が正しければ、**輸送係数を下げれば成績は戻る**。

## 事前登録する予測

1. `diffusionWm2PerK`・`zonalAdvectionCouplingWm2PerK`・`hadleyDiffusionBoost`
   を下げる向きで、収束 EBM の大分類一致率は単調に改善する。
2. 再較正後の大分類一致率は **73.5pt 以上**に戻る
   (失った 2.40pt のうち 1.6pt 以上を回復する)。
3. 退行防止ゲートは **13 以上**を維持する。
4. 気温 RMSE は **4.0°C 以下**へ戻る(失った 1.07°C のうち 0.7°C 以上を回復)。

## 棄却条件(これに触れたら「輸送係数では戻らない」と結論する)

再較正が収束したあと、次のいずれかなら仮説を棄却し、
**成績の低下を受け入れたうえで別の原因を探す**(しきい値は緩めない)。

- 大分類一致率が 73.5pt に届かない
- 退行防止ゲートが 13 を下回る

棄却された場合の解釈: 従来の 74.32pt は打ち切り誤差への当てはめであり、
モデルの真の実力は 72pt 前後だった、ということになる。
その場合でも**収束させた版を採用する**。数値誤差に当てはめた成績を
維持するのは教訓 §1「客観の物差し」に反する。

## やり方

- 目的関数は v2 のまま(2026-07-31 凍結)。**変更しない**。
- 探索空間は `scripts/optimize_lib.ts` の SPACE のまま。ただし下見の走査で
  最良点が境界に張り付いた定数があれば、**その事実を記録したうえで**
  範囲を広げる(記録なしの拡張はしない)。
- EBM は収束設定(赤黒 512 反復、残差 1e-3 を満たすことを実測済み)。
- 較正中は**コミットしない**(2026-08-01 の教訓: 走行中のコミットで
  来歴が食い違い 9 時間ぶんが無効になった)。
- 完走後は `scripts/verify_applied.ts` で来歴と全キーを照合してから採否を決める。

## 追記(2026-08-02 00:45)— 較正の前に**さらに 2 つの欠陥**が見つかった

較正を 2 度止めて先に直した。間違った土台の上で較正しても無駄なため。

### (1) 南極の棚氷が陸になっていた(利用者の指摘)

ETOPO 2022 の surface は氷の**上面**標高なので「標高 > 0」で陸を作ると
浮氷が陸に入る。Natural Earth の棚氷ポリゴンで 578 セルを海へ戻した。

  fit 88.90 → **89.34** / 大分類 71.92 → 72.27 / 気温RMSE 4.738 → 4.68

### (2) 南北界面の伝導度が非対称だった(Codex レビュー)

「対称化した」と謳いながらハドレー増強を自セルの緯度で評価しており、
30° 付近の界面で 8.7% 食い違って**亜熱帯にエネルギーの湧き出し**があった。
面の値を両側平均にして保存形にした。

  fit 89.34 → **88.31** / 詳細 39.69 → 37.25 / 気温RMSE 4.68 → 6.24
  **退行防止ゲート 13 → 14**(凍結基準に復帰)/ 陸平均降水 781 → 989mm

較正がこの非保存性を吸収していたので成績は落ちる。GS_SWEEPS と同じ構造。

## 予測の修正(修正後の土台で再登録、結果を見る前に固定)

土台が変わったので、当初の「大分類 73.5pt 以上」は基準として使えない。
**新しい出発点**(全修正込み、較正前):

  fit 88.31 / 大分類 72.19 / 詳細 37.25 / ゲート 14 / 気温RMSE 6.24 / 陸平均降水 989mm

輸送定数の下見走査(棚氷・界面の修正**前**の土台)では、拡散を下げると
大分類 +0.52pt・気温RMSE −0.46°C だった。界面を保存形にすると実効的な
南北輸送が変わるので、この走査はやり直す価値がある。

**予測**: 再較正後、fit は 90 以上へ戻る。
とくに気温 RMSE 6.24 は拡散・移流の再調整で 4.5 以下へ戻るはず
(非保存性が消えた now、係数は「素の値」として効くため)。

**棄却条件**: 再較正後に
  - 退行防止ゲートが 14 を下回る、または
  - fit が 89.34(棚氷修正のみの版)を下回る
なら、界面の保存化は成績上は損である。その場合でも**保存形を採る**
(エネルギーを作らない/消さないことは較正成績より優先する)が、
その事実を明記して残す。
