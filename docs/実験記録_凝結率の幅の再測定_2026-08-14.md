他の 62 定数は較正 v22 のまま。積算器のリセット漏れを直したうえで測った

## 予測の答え合わせ

事前登録に「鋭さ 4 の真の W は 29.1mm より必ず大きい(見積もり 30〜45mm)。
29.1mm 以下が出たら私の汚染の読み自体が誤り」と書いた。

**実測 38.4mm。** 見積もりの範囲のど真ん中に落ちた。
段 20 の表示 29.1mm は鋭さ 0 の 3.4mm に引き下げられた累積平均であり、
「実物 25mm に着地した」という段 20 の主張は**成立しない**ことが実測で確定した。

## 判定(事前登録の 6 条件)

1. **収束** — 輸送と virga は全水準で未収束 0。**結合反復は別途測り直し中**
   (掃引が輸送しか印字しておらず、事前登録が要求する 2 つのうち片方が
   抜けていた。道具の穴。鋭さ 4 では `npm test` の
   「結合反復が上限に到達せず収束している」が落ちているので、
   ここは未収束の可能性が高い)。
2. **主判定: W が 20〜30mm に入る水準がある** → **満たさない。**
   17.2(鋭さ 3)から 38.4(鋭さ 4)へ**窓を飛び越える**。
3. 番人(サハラ ≤ 3.5) → 鋭さ 2・3・4 で満たす。
4. 番人(コンゴ 1.31 ± 0.3 = 1.01〜1.61) → 鋭さ 2 のみ外れる(1.72)。
5. **成績: v3 が 85.235 から 1.0 以上落ちない** → **全水準で満たさない。**
   −3.12 / −6.98 / −5.42 / −3.45。
6. 費用 ≤ 600 秒 → 鋭さ 3(677s)・4(1346s)で満たさない。

**事前登録の規定により、判定 2 を満たす水準が無いので棄却。**
これは事前登録に書いた「外れる筋」そのものである:

> W が鋭さに対して急峻すぎて 25mm 付近を通らずに飛ぶ。その場合、
> CRH の指数抑制は幅を作る道具として**粗すぎる**ことになり、
> 鋭さを連続の較正対象にするのではなく**別の変数を探す**。

なお非整数(例 3.5)なら W が 20〜30 に入る可能性はあるが、**判定 5 が
全水準で大きく外れている**ため、そこを埋めても結論は変わらない。
成績を見てから閾値を緩めない(事前登録の「やらないこと」)。

## 分かったこと(棄却でも残るもの)

- **W は鋭さに対してほぼ倍々で増える**(3.4 → 6.0 → 9.6 → 17.2 → 38.4)。
  指数抑制は W を動かす強力なレバーではあるが、**粗すぎて狙った値に
  止められない**。25mm 前後を狙うには鋭さ 0.1 刻みの世界になる。
- **v3 が単調でない**(鋭さ 2 で 78.25 と底を打ち、3 で 79.81、4 で 81.78 と戻る)。
  単一の物理的トレードオフではなく、複数の効果が打ち消し合っている。
  **この非単調性は、鋭さを較正の探索空間に入れてはいけない理由になる**
  (座標降下が谷に落ちる)。
- **東アジアは一貫して悪化する**(0.17 → 0.10 → 0.05 → 0.03 → 0.03)。
  段 20 で「東岸を直接殴る手は 7 件すべて尽きた」と結論した問題に対し、
  この機構は**逆方向に効く**。
- **西欧は肥大する**(0.74 → 1.40 が鋭さ 3 の最悪)。乾燥域を乾かす代償に
  湿潤域が広がるという、段 19 で見たのと同じ形が再び出た。
- 費用は反復数で説明がつく(21k → 32k → 175k → 405k → 895k 反復)。
  鋭さを上げるほど輸送の求解が重くなるのは実在の効果であり、
  未収束による空転だけではない。

## 残る本丸

**モデルの大気は実物の 7 分の 1 しか水を持っていない**(W = 3.4mm 対 25mm)
という診断そのものは**生きている**。これは `diag_water_vapor.ts` が
自前でリセットしてから測った単発値なので汚染されていない。

CRH の指数抑制はその処方として棄却されたので、**別の変数を探す**必要がある。
`P = λ·G·W` で λ と G の平均は縮退しているため、意味があるのは G の空間的な幅
だけ、という段 20 の考察は依然として正しい([考察_凝結率の意味](考察_凝結率の意味_2026-08-13.md))。
