## 【1】3 群はどこか(南極を除く、面積重み)

```
群                 面積%  年降水 モデル/観測  中央緯度  気温    海岸km
乾いた側 (下位25%)  25.0   147/ 372  0.40     33°   10.5°C   612
**中位 (25〜75%)**  50.0   510/ 673  0.76     30°   11.9°C   568
湿った側 (上位25%)  25.0  1897/1570  1.21      3°   23.4°C   660
```

**中位と乾いた側は、緯度も気温も海岸距離もほぼ同じ**(30〜33°、10〜12°C、
570〜610km)。違うのは降水量だけである。
湿った側だけが別物(緯度 3°、23°C = 熱帯)。

つまり**中位の陸 = 亜熱帯〜温帯の陸**で、
これは大分類が最悪の C 温帯(46.8%)と重なる。

## 【2】水収支 — **「通り過ぎる」のではなく「来ていない」**

```
量                    乾いた側    中位     湿った側
可降水量 W (mm)         1.58     2.36      5.22
陸面蒸発散 E (mm/年)     138      461      1279
降水 P (mm/年)           147      510      1897
**正味流入 P−E**         8.7    **48.6**   617.9
```

**中位の降水 510 のうち 461 は自分の蒸発散の再循環**で、
外から入るのは **49mm/年**しかない。湿った側(618)の **8%** である。

観測の 673mm/年に届かせるには、E が同程度なら正味流入が **212mm/年** 要る。
**いまの 4 倍**である。

**私が段 28 で書いた「中位の陸は水の通り道」という読みは誤りだった。**
通り道ですらない。**そもそも水が入ってこない場所**である。

だから「そこで凝結を強める」だけでは足りない。**運んでこないといけない。**

### 死因はすべて「探索空間の外にある定数」

```

              convergenceSubsidenceRelief = 0  同上

              upwindBlockReliefM = 1e9        起伏で割ると比が 0（**二重に**無効）
```

`stormMoistureSupply`・`frontalLiftBoost` などは探索空間にあり、較正が動かしている。

**2 回目の確認**である。

## 何が言えるか

1. **中位の陸(面積の 50%)には水が来ていない。** 正味流入が必要量の 1/4。
   これが「モデルは中位を乾かしすぎ(0.76)」の正体である。
2. **中位へ水を運ぶ機構が、まさに死んでいる。**
   `convergenceLiftBoost = 0`(水蒸気フラックス収束 = 中緯度の低気圧)は、
   温帯の降水を作る主要な機構であり、**中位の陸に直接効く**。
3. 今日 5 回の失敗は、いずれも**生きている 4 因子を動かす**手だった。
   死んでいる 4 つには触れていない。**触れる場所を間違えていた。**

## 次(段 29)

**`convergenceLiftBoost` を生き返らせる。**

  `convergenceWetnessNorm` = 3)も既にある。**係数が 0 なだけ。**
