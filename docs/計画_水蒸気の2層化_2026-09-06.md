# 計画: 水蒸気の 2 層化 — 境界層 W_b と自由対流圏 W_f(台帳 34)

日付: 2026-09-06 夕。利用者の勘「多層化は早めにやってみるのが良いかも」(9/6 夕)を受けて、
v49(単層で W を厚くする賭け)と**並行して**設計・配線に入る。実装は git worktree で行い、
main の較正(v49)が見る src には触れない(教訓 §15)。合流は v49 の判定後。

## なぜ(単層では原理的に届かないもの)

1. **乾いた収束**: 地表で収束するのに降らない場所(サハラ・アラビアの熱的低気圧、ゴビ・中央アジア
   = 観測の 3〜4 倍湿る)。柱 1 本の収支では「収束した水はどこかで降る」しかない。8/4 の鉛直輸出は
   抜いた水の返し先が単層に無く、水が保存せず棄却([実験記録_保存型水蒸気輸送](実験記録_保存型水蒸気輸送_2026-08-04.md)、
   [実験記録_閾値凝結の測り直し](実験記録_閾値凝結の測り直し_2026-08-09.md))。
2. **W が実寸の 1/5**(λG 縮退、[計画_W実寸化章](計画_W実寸化章_2026-09-02.md))。単層では厚い W は
   そのまま降る。自由対流圏の層は「持っているが降らない」水を置く場所になる。
3. **山越え**: 境界層の水は風上で落ち、自由対流圏の水だけが山を越える(台帳 23 と重なる)。

## 支配方程式(定常・月ごと。単層の §0 を層に分ける)

```
0 = S − C_b(W_b) − ∇·(W_b V_10m) − X_up + X_dn          境界層
0 =   − C_f(W_f) − ∇·(W_f V_free) + X_up − X_dn         自由対流圏
X_up = σ_up·W_b    σ_up = k_up·max(0, conv_i) + ε        収束域で境界層の水が上へ
X_dn = σ_dn·W_f    σ_dn = k_dn·max(0, −conv_i) + ε       発散域で乾いた空気が下へ
P    = C_b + C_f
```

- conv_i は既存の地表収束場(step06 `computeConvergence` 490 付近、−div·τ)。**新しい場は作らない。**
- V_10m と V_free は台帳 20 で分離済みの 2 組の風(`monthlyColumnWindU/V`)。単層では blend で
  混ぜていたが、2 層では層ごとに自然に割り当てられる(blend は不要になる)。
- 閉包 C_b は §3 の二成分閉包を W_b に適用(cap・床は境界層の飽和 W_sat,b = `boundaryLayerSatFrac`·W_sat)。
  C_f は対流項だけ(cap を超えた分。持ち上げ G が大きい所で発火)+ ごく小さい線形項(既定 0)。
- ε は cap(逆転層)越しの背景混合。既定は小さく、v49 の床・cap と同じ「飽和からの距離」で減衰させるかは
  L-1 の掃引で決める。

**単層との対応**: `moistureLayerSplit = 0`(既定)のとき W_f は作らず X = 0・C_f = 0 で**従来とビット一致**。

## 実装の最小形(新しいソルバは要らない)

`solveMoistureTransport` は線形シンク(`linearRatePerMonth`)と源(`sourceMmPerMonth`)の口を持つので、
層間交換は **境界層の解では σ_up を線形シンクに足し、X_dn を源に足す / 自由対流圏の解では逆** として
既存ソルバを 2 回呼ぶ。層の間は結合反復(既存の外側ループ)の中で Gauss–Seidel に回す。
費用は 1 反復あたり 2 倍(輸送ソルバは CPU のみ。GPU 移植は無い)。

新定数(すべて既定で無効。SPACE へ入れるのは L-2 で事前登録):

| 名前 | 意味 | 既定 |
| --- | --- | --- |
| `moistureLayerSplit` | 2 層化のフラグ(0 = 単層とビット一致) | 0 |
| `layerExchangeUpPerConv` | 収束 1 単位あたりの上向き交換率 k_up [1/月] | 0 |
| `layerExchangeDownPerDiv` | 発散 1 単位あたりの下向き交換率 k_dn [1/月] | 0 |
| `layerBackgroundMixPerMonth` | cap 越しの背景混合 ε [1/月] | 0 |
| `boundaryLayerSatFrac` | 境界層が持てる飽和水の割合(水蒸気のスケール高 2〜2.5km 対 境界層 1〜1.5km で 0.5〜0.7) | 0.6 |
| `freeLayerLinearRateFrac` | 自由対流圏の線形凝結(層状雲)の割合 | 0 |

診断: `waterMm` は W_b + W_f、`waterBoundaryMm` / `waterFreeMm` を別に出す。`CONSERVATIVE_STATS.meanWaterMm` は
合計(実物 25mm との比較はこれ)。

## 凍結する原則

- 既定でビット一致(L-0)を保ち、単層(v48/v49)へいつでも戻れる。
- 「単独で沈む」は棄却理由にしない(順序原則)。ただし物理の針(W・滞留・乾燥内陸の降水比)が
  動かないものは棄却。
- 較正用の定数を UI に出さない。層の割合や交換率は利用者スライダーにしない。
- 新しい場(逆転層の強さなど)を足すときは、既存の場(T_a − T_s、収束、G)から作れないかを先に見る。
