# 事前登録: 水蒸気の 2 層化・段 L-1c — 上向き交換を持ち上げ G で門する(選択性の定式)

日付: 2026-09-07 朝(9:05 の層の診断の後、実装と掃引の前に書いた)。
前段: [実験記録_2層化の段L-1](実験記録_2層化の段L-1_2026-09-07.md)。k = 1 で上向き交換 X_up が
乾燥内陸(gobi 28 mm/年)より沿岸の収束域(california 171・horn 139・arabia 102・mediterranean 99)で
大きく、中緯度・亜熱帯の水が熱帯と極へ移って全球が一様に乾いた。

## 物理の根拠(結果に依存しない)

実物の「乾いた収束」(サハラ・アラビアの熱的低気圧、内陸の熱低)は、地表で収束した湿った空気が
**逆転層(cap)の下で浅く上昇し、cap を破れずに上層で発散・輸出される**現象である。深い対流が
立てる場所(cap が弱い・持ち上げが強い)では、収束した水は雲になって**その場で降る**。すなわち
同じ「地表収束」でも、
- 持ち上げが弱く沈降が強い(cap が強い)所 → 浅い循環 → 境界層から自由対流圏へ輸出、
- 持ち上げが強い所 → 深い対流 → 降水、
で行き先が分かれる。モデルでこの区別を担う既存の場は **G**(持ち上げの積 × 沈降残存、§4)であり、
G が小さい所は沈降域 = cap が強い所である。新しい場は作らない。

## 定式

```
σ_up = (k_up·conv⁺ + ε) · gate(G)
gate(G) = exp(−G / layerExchangeLiftGateG)      layerExchangeLiftGateG = 0 で gate ≡ 1(従来と一致)
```

G の尺: 帯平均で 3.1 / 1.0 / 3.2(熱帯/亜熱帯/中緯度、計画 W 実寸化章)、沈降域で 0.3〜0.5。
G_ref ∈ {0.5, 1, 2} を振る。G_ref = 1 なら沈降域(G 0.4)で gate 0.67、雨域(G 3)で 0.05。
下向き交換 σ_dn は変えない(発散域の乾いた沈降は G に依らない)。

## 水準

k = 1・ε 0.1・satFrac 0.6・3 往復で、layerExchangeLiftGateG ∈ {0.5, 1, 2}(基準は 0 = 水準 1 の k = 1)。

## 予測(測る前に固定)

181. 門を入れると X_up の分布が変わる: california・mediterranean・horn の X_up が半分以下になり、
     sahara・arabia・gobi・central_asia の X_up は 7 割以上残る(G_ref = 1 で)。診断で確かめる。
182. 全球の一様な乾きが戻る: 50% 分位 506(k=1、門なし)→ ≥ 520(基準 535 に近づく)、
     25% 分位 285 → ≥ 280。
183. 乾燥内陸の降水比は門なしと同等以下を保つ: gobi ≤ 3.3・central_asia ≤ 2.5(門なし 3.23 / 2.42 の
     ±0.1 以内。乾燥内陸の X_up は門で減らないので)。
184. 連続部分は門なし(74.348)より上がる(目安 +0.1〜+0.4)。大分類 ≥ 76.6。
185. 健全性 PASS・熱帯ゲート維持(被覆の和 ≥ 15.2)。
186. W は門なしと同程度(6.8 前後)。門は W を増やさない(W の天井は自由対流圏の cap の問題)。

## 判定

- 181・182・184 ○ → 門を採用して段 L-2(較正 v50)の定式とする。SPACE 候補: k_up・k_dn・ε・
  layerExchangeLiftGateG・boundaryLayerSatFrac(範囲は掃引の崖から)。
- 181 ○ だが 182・184 ✗ → 乾きの原因は交換の場所でなく自由対流圏の閉包(降らなさすぎ / 降りすぎ)。
  freeLayerLinearRateFrac と satFrac(水準 3)で追う。
- 181 ✗(門で乾燥内陸の X_up も落ちる)→ G の尺が違う。G の分布を印字して G_ref を選び直す
  (結果を見て門の形は変えない。尺だけ)。
- 183 ✗(乾燥内陸が湿り戻る)→ 乾燥内陸の X_up は実は「沿岸から運ばれた W_f が降らずに通過する」
  効果だった可能性。診断で X_up の内訳を見る。
