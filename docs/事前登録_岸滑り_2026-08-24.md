# 事前登録: 開きゲートの岸滑り — 実在寒流の岸沿いが塞がれる副作用の修正(台帳 項目 6)

日付: 2026-08-24(実装前に書いた)
発端: 縁海修正(2026-08-21)の判定で、実在のカリフォルニア寒流の閾値超えセルが
21% → 10% に弱化(列直進の走査が湾曲した岸で陸に当たり「開いていない」と誤判定)。

## 実装(既定 0 でビット一致)

`opennessAlongColumn` で陸に当たったとき、**海側へ 1〜S 列ずらして走査を続ける**
(S = `boundaryCurrentCoastSlipCells`、既定 0 = 従来)。海側 = 寒流(海盆東縁)
なら自転の逆向き、暖流(西縁)なら自転向き。ずらした列も陸なら塞がり。
実物の境界流は岸に沿って曲がるので、直進でなく岸滑りが正しい近似。
逆行では向きが反転して成立(地理中立)。

## 予測(結果を見る前に固定)

80. S=2 でカリフォルニア沖の閾値超えが 10% → **18% 以上**へ回復(修正前 21% に近づく)。
81. アラビア海・メキシコ湾・南シナ海の閾値超えは **3% 以内のまま**(縁海修正を壊さない
    — 縁海は岸滑りしても極側は陸で塞がる)。
82. 地球の大分類 ±0.2 以内。

## 判定

- 80・81 ○ → 既定を S=2 にする(バグ修正の完成として。SPACE 非投入)。
- 81 ✗ → 滑り幅が縁海を開けてしまう。S=1 か「滑りは 1 回まで」に制限して再測。

---

## 判定(同日): 80 ○ / 81 ○、82 は掃引中

```
S=2: カリフォルニア 10% → **21%**(修正前と同水準に完全回復)
     アラビア海 0% / メキシコ湾 2% / 南シナ海 3%(縁海修正は無傷)
```

縁海は岸滑りしても極側が陸で塞がるため開かず、湾曲した外洋の岸だけが
正しく「開いている」と判定されるようになった。82(大分類 ±0.2)の確認後、
既定を S=2 にする(バグ修正の完成)。
