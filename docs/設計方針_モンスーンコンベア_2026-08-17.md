## 何を「持つ」のか

**モンスーン気流が運ぶ水 — 海で蓄えられ、決まった経路で大陸に注がれ、
奥へ行くほど尽きる量。** 2 日間の測定でこれが唯一の欠落と確定した:

- C→B(失点の 32%)の主因は沈降残存(G)だが、沈降を緩めるだけでは
  豪州内陸型を巻き込む(段 44)。
- 巻き込みを防ぐ判別軸は、幾何(緯度・距離)には無い(全滅)。
  スカラー 1 つでは分けられない。**分けているのは気流の水そのもの。**
- その水は規定風では作れない(段 41〜43: 定常場が汲み直す)。

## 実物の対応物(設計の物差し)

C→B の本丸(華中 25〜33°N・米南東 30〜37°N)を湿らせているのは
ITCZ モンスーンの北進ではなく、**梅雨・Baiu 型の亜熱帯前線系**である:

1. 亜熱帯高気圧の西縁を回る下層湿潤流(LLJ)が、
   **西岸境界流(黒潮・湾流 = 暖流)の上**で水を蓄える
2. 大陸の東岸から内陸へ注がれ、前線帯で持ち上がって降る
3. 奥へ行くほど水が尽きる(浸透距離)

豪州内陸が乾く理由もこの枠で説明できる: 豪州には
「大陸の東の暖流の上を回って**大陸へ注ぐ**」配置の高気圧西縁流が
東岸(湿潤なクイーンズランド)にしか無く、内陸・西岸には無い。

## 実装の骨格(輸送方程式の側で、保存的に)

規定風(段 41〜43 で死んだ)ではなく、**輸送方程式の源泉・シンク対**として書く:

```
コンベアの取水(シンク): セクターの海セル(暖流域)で  −q_i
コンベアの給水(源泉):   セクターの陸セル(経路上)で  +q_j
制約: Σ q_i = Σ q_j     ← 保存。水は創らない(教訓 §9 の +64% 事件)
```

- **取水量は海の W に比例**(そこに在る水しか運べない。
  豪州西岸沖のように W が薄ければコンベアは細る — 判別が量で自然に出る)。
- **給水は東岸から内陸へ減衰**(浸透距離。実物の梅雨帯の奥行き ~1000km 級)。
- 経路の錨(アンカー)は既存の量だけで書ける:
  - 西岸境界流の暖偏差 `sstAnomalyC`(暖流の位置 = 蓄水域)
  - 亜熱帯高気圧セル(WL#29 の離散化 = 西縁の位置)
  - 夏半球(季節加熱)・R-H 位相(段 44 の配管を再利用 — アラビアを守る)
- **地理中立**: 海陸配置・海流・ITCZ 変位・自転方向だけから決まる。
  逆行では東西が全部反転して成立する。

### 部分判別の実測(設計に使う)

```
東海洋の SST 偏差   C→B: 中央 2.67°C(25% 分位 1.84)
                    豪州型 B→C: 中央 2.48(25% 分位 **0.00**)
```

暖流アンカーは豪州型の 1/4 以上を単独で切れる。残りは
**取水量 ∝ 海の W** と**浸透減衰**が担う設計(単一ゲートで切らず、
量の連鎖で自然に差が出る形にする — ここが段 44 までとの違い)。
