# 事前登録: 段 11 沿岸ジェット — ジェット列では ITCZ を通過流にし下流に沈降を置く(角の処方)

日付: 2026-09-04 朝(実装前に書いた)。
設計: [設計_沿岸ジェットとITCZの通過流](設計_沿岸ジェットとITCZの通過流_2026-09-03.md)
(判定 J 第 2 版は幾何のみで東アフリカ沿岸 39-45E が突出 0.84、インド西岸 0、
ベンガル湾 0、北西豪州 ≤0.22 を検証済み)。

## 機構(地理中立、既定 0 でビット一致)

1. **ジェット列の判定 J(col, month)**: 夏半球で ITCZ が赤道から変位している
   (disp ≥ 0.3)とき、赤道〜ITCZ の帯で「当列が海・西隣 3〜6° が陸」の割合 ×
   「西隣の陸が赤道の両側にある度合い(spanEq)」× (1 − 陸割合) × 高地係数。
   検証済みの式をそのまま実装(step06 の前計算、月別・列別)。
2. **下流拡張 J′**: J を ITCZ 変位の向き(極側)へ、halfWidth 相当の距離で減衰
   させて延ばし、さらに東隣へ 1 列ずつ 0.7 倍で漏らす(ジェットは海岸を離れて
   北東へ加速する)。J′ = max(J, 減衰後の値)。
3. **作用(3 定数、いずれも既定 0)**:
   - `jetItczLiftReduce` ∈ [0,1]: liftItczF ← 1 + (liftItczF − 1)·(1 − r·J′)
     (収束線を通過流に置換)。
   - `jetSubsidenceAdd` ∈ [0,1]: subs ← min(1, subs + a·J′)(ジェット下流の発散 →
     沈降。傘発散ゲートの死因「発散場が無い」の代替)。
   - `jetUpwellingBoost`(任意、後回し): somaliUpwellingC の効きを J′ で強める。
   風の転向(monsoonMeridionalReversal の J ゲート)は第 2 段。

## 掃引と測定(1°・v45 既定)

r ∈ {0.5, 1.0} × a ∈ {0, 0.5}(4 点)。測るもの: horn share・horn 年降水・
india/arabia/sahara/amazon の share・Af/Aw・fitness・大分類・詳細。

## 予測(実装前に固定)

137. horn 年降水 2418 → r=1,a=0.5 で **≤ 800mm**(観測 293)。horn share 0 → ≥ 0.3。
138. india ≥ 0.35 を維持(インド西岸は J=0 で無傷)・arabia PASS 維持。
139. amazon/congo PASS 維持・Af は ±0.5 以内(角は Af 面積の主要因ではない)。
140. fitness −0.3 まで受容(角ゲートの利得 +0.06 と大分類の得失)。健全性 PASS。
141. 巻き添え監視: 南米北岸(−47.5W、J 0.21)・インドシナ東岸(107-108E、J 0.2)の
     降水変化を記録(観測はいずれも乾季あり。悪化なら判定 J の閾値を上げる)。

## 判定

- 137・138・139 ○ → 3 定数を SPACE へ(r [0,1]・a [0,1])、生存性測り直し → v46。
- 137 ✗(角が乾かない)→ 下流拡張の距離・向きを実測の風で決め直す(ジェット無しの
  暫定幾何の限界)。138 ✗ → J の spanEq 閾値を上げる。

## 判定 1(同日): 137 ✗ — 角の雨は不動(2301→2298mm)。判定 J の季節・陸海の取り違え

```
r    a     fitness   角 年降水   南米北岸  インドシナ東岸  india  horn
0    0     74.012    2301        2567      2168           0.388  0.000
0.5  0     74.000    2300        2568      2136           0.388  0.000
1    0     73.988    2299        2570      2100           0.388  0.000
1    0.5   73.941    2298        2572      2060           0.388  0.000
```

- 137 ✗(角 −3mm)。138・139 ○(何も変わらないので当然)。141: インドシナ東岸
  だけ 2168→2060 と僅かに反応(ここは第 2 版でも点灯していた列)。
- **原因**: 第 2 版の J が東アフリカ沿岸 42-45E で高かった(0.84)のは、
  **南半球夏(1-2 月)の帯(0〜−10°、タンザニア沖の海)**での点灯だった。盛夏
  (JJA)の角の列は帯(0〜+10°)の中が**陸**(ソマリア本土)なので「当列が海」の
  条件で J≈0。診断は季節を max で潰していたため見落とした(教訓: 判定の検証は
  季節別に印字する)。
- 実物のジェットは角の**陸の上**(沿岸〜内陸 300km)を走る。判定は陸セルを含めて
  「西隣の陸が赤道の両側にある(spanEq)× 東〜南東 3° 以内に海がある(沿岸性)×
  夏半球の帯内」に直す(第 3 版)。エチオピア高地(内陸、JJAS 湿潤)は沿岸性 0 で
  外れ、インド西岸(西隣が海)・サヘル(東に海無し)・北東ブラジル(北隣が海)は
  spanEq 0 で外れる見込み。

## 判定 3(同日): J 場の印字 — 幾何は点灯していた。効かない理由は保存則

```
7 月の J(第 3 版・西窓 3-6 / 3-9): 3N43.5E 0.54/0.54・5N45.5E 0.35/0.52・7N47.5E 0.05/0.63・
9N49.5E 0/0.18・8N44.5E 0(内陸、沿岸性 0)。インド西岸・サヘル・エチオピア高地・
ベンガル湾・北東ブラジル = 0、北西豪州 ≤0.09。
```
- 幾何判定は**正しく角だけを点灯**させていた(西窓 3-9° なら 47.5E まで)。
- それでも r=1(点灯セルで ITCZ 持ち上げを 35〜60% 削減)で角の雨は −6mm。
  **保存型輸送では、収束域の降水量は水蒸気フラックスの収束で決まり、局所の
  凝結係数 G を下げても W が溜まって同じ量が降る**(段 41・42 の死因「場が
  汲み直す」の裏返し)。角に 2300mm 降るのは風場が角へ水を収束させているからで、
  乾かすには**風場を発散に変える**(海岸沿いジェットの形成)しかない。
- 帰結: 段 11 の作用 1・2(持ち上げ置換・沈降加算)は角には無力。作用 3(風の転向)
  が本体で、それは越赤道流の力学(モンスーン流一族の再設計)を要する = 別章。
  段 11 の部品(判定 J、既定 0)は風の転向の**適用域**として残す。SPACE 投入せず。
- 予測 137 ✗の登録分岐「下流拡張を実測の風で決め直す」は、風そのものが無い
  (v +2 m/s)ため成立せず。章の前提として「越赤道流の形成」を先に置く。
