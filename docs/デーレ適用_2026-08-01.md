# デーレ(出界)に ExoClim-3 を適用した結果 — 2026-08-01

利用者の依頼による単発実験。derle-climate の創作世界「出界(デーレ)」の地図に
ExoClim-3 の物理モデルをそのまま適用し、derle-climate v0.11 の結果と比較する。

- 地形: `derle-climate/data/processed/shukkai_geography_{1deg,05deg}.npz`
  → `scripts/build_derle_terrain.py` で変換(面積重み陸率 28.9%、最高 4,093m)
- 惑星諸元: `derle-climate/docs/PROJECT_CONTEXT.md`
  主星光度 1.2879 / 軌道長半径 1.225 AU / 半径 1.0489 地球 /
  自転 28.4698 h / 傾斜 19.505°
- 仮置き: 離心率・近日点位相は記載が無いため地球値(0.0167 / 283°)
- 出力: `out/derle/`(気候区分・気温・降水の PNG と summary.json)
- 実行: `npx tsx scripts/run_derle.ts`

## 1. 日射と温室効果 — 正典 8°C が要求する大気

デーレの日射は **1,168 W/m²(地球の 85.8%)**。主星は明るいが軌道が遠く、
差し引きで地球より暗い。ExoClim-3 は気温を物理から解くため、正典の
「全球平均 8°C」を満たす温室効果を逆算できる。

| 温室効果(地球 = 1.0) | 全球平均気温 |
| ---: | ---: |
| 1.0 | **−28.5°C(全球氷結)** |
| 1.375 | 3.68°C |
| **1.594** | **8.11°C(正典値)** |
| 1.813 | 11.12°C |
| 2.25 | 15.36°C |

**含意**: 地球と同じ大気ではデーレは雪玉惑星になる。正典の 8°C を成立させるには
**地球の約 1.6 倍の温室効果**が要る(金星ほどではなく、CO₂ 数倍〜十倍程度の
オーダー)。これは derle-climate 側が「全球平均 8°C を大域オフセットで固定」して
いた部分に、物理からの制約を与える。

**留保**: 温室 1.0 の全球氷結は氷アルベド暴走の解であり、本モデルの雪玉閾値は
検証済みではない(較正記録 2026-07-30 の「0 層海氷の双安定」参照)。
「1.0 と 1.375 の間に転移がある」ことまでが確かな主張。

## 2. 全球の比較(温室 1.594 = 正典 8°C 合わせ)

| 指標 | derle-climate v0.11 | **ExoClim-3** |
| --- | ---: | ---: |
| 全球平均気温 | 8.0(固定) | 8.11 |
| 陸平均気温 | 7.44 | 5.69 |
| 陸平均降水 | 690(固定) | **537** |
| 乾燥の割合 | 19.6%(乾燥指数) | 33.3%(ケッペン B) |

**最大の相違は全球の水量**。derle-climate は陸平均降水 690mm を大域スケールで
固定しているが、ExoClim-3 は物理から 537mm を予測する(28% 少ない)。

これは温度で説明できる。飽和水蒸気圧は陸平均 5.7°C で 14°C の 58% しかない。
地球の陸平均降水 794mm に対し 537mm = 68% は、この水蒸気量の差とほぼ整合する。
**「全球平均 8°C」と「陸平均降水 690mm」を同時に満たすのは物理的に苦しい** —
8°C の惑星は 500〜550mm 級になるのが自然、というのが本モデルの答え。

なお乾燥割合の定義が違う(derle = 乾燥指数 AI、ExoClim-3 = ケッペン B)ため、
33.3% と 19.6% を直接比べることはできない。水量の差がそのまま効いている。

## 3. 地域別 — 正典との整合(derle-climate の consistency_audit と同じ枠)

| 正典の期待 | derle v0.11 | **ExoClim-3** |
| --- | ---: | ---: |
| ウィル 乾燥 ≥ 50% | 42.3% ✗ | **78.2% ○** |
| デラドゥア沿岸 乾燥 ≥ 50% | 24.6% ✗ | 28.8% ✗ |
| デーレ中核 温帯 ≥ 50% | 84.0% ○ | 41.3% ✗ |
| デーレ中核 熱帯 < 10% | 6.5% ○ | 0% ○ |
| ルティア 熱帯 ≥ 50% | 68.9% ○ | 40.6% ✗ |
| シャンテリャ 乾燥 < 50% | 5.1% ○ | 90.7% ✗ |
| 全球 乾燥 < 23.9% | 19.6% ○ | 33.3% ✗ |

数値(気温 °C / 降水 mm / ケッペン大分類):

| 地域 | derle v0.11 | ExoClim-3 |
| --- | --- | --- |
| ウィル | 17.9°C / 658mm | 14.3°C / 344mm / B 78.2% |
| デラドゥア沿岸 | 6.2°C / 440mm | 6.5°C / 642mm / B 28.8% |
| デーレ中核 | 17.5°C / 1,165mm | 13.5°C / 521mm / B 55.6%・C+D 41.3% |
| ルティア | 23.2°C / 1,647mm | 18.0°C / 1,379mm / A 40.6% |
| シャンテリャ | 13.7°C / 883mm | 11.6°C / 243mm / B 90.7% |

### 読み解き

- **ウィルの謎が解けた可能性**: derle-climate が 3 つの海底地形シナリオすべてで
  再現できなかった「ウィルは乾燥が過半」を、ExoClim-3 は 78.2% で満たす。
  ウィルは 11〜34°N の亜熱帯にあり、**自転 28.5 時間(地球の 1.19 倍)が
  ハドレー循環を広げて亜熱帯高圧帯を極側へ張り出させる**のが効いている。
  ExoClim-3 は自転周期からハドレー端を計算するため、この効果が入る。
- **逆にシャンテリャとデーレ中核は乾かしすぎ**。全球の水量が 28% 少ないぶんが
  そのまま効いている。水量を 690mm に規格化すれば乾燥割合は大きく下がるため、
  「模様」ではなく「総量」の差と見るのが妥当。
- **ルティア(赤道直下)は熱帯 40.6%** で正典の 50% にわずかに届かない。
  残りは温帯 C で、熱帯の閾値(最寒月 18°C)をぎりぎり下回っている。
  全球が 6°C 低い惑星なので、赤道でも熱帯判定が厳しくなる。

## 4. 地図

`out/derle/` に 6 枚(physical / canonical8C × 気候区分・気温・降水)。
canonical8C の気候区分図は、**両半球の亜熱帯に幅の広い寒冷砂漠(BWk)帯**、
西岸に温帯(Cfb)、高緯度に広大なツンドラ・氷雪(E 31.1%)という構成。
地球より寒く、乾燥帯が広い惑星の姿になっている。

## 5. 本実験の限界

- 離心率・近日点位相が未定のため地球値を仮置き。公転周期も derle 側で保留中。
- デーレには高解像度標高が無く、稜線標高は 0.5° データの最大値集約(粗い)。
  R5 のアンデス型遮蔽は地球ほど効かない。
- ExoClim-3 の定数は**地球で較正**したもの。日射・自転が違う惑星への外挿で
  あり、較正の適用域内かどうかは別途検証が要る(適用範囲診断は ok を返した)。
- derle-climate は正典値で規格化、ExoClim-3 は物理から予測 — 目的が違うため
  優劣ではなく「独立した 2 系統の答え合わせ」として読むべき。
