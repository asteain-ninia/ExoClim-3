# デーレ(出界)に ExoClim-3 を適用した結果 — 2026-08-01

利用者の依頼による単発実験。derle-climate の創作世界「出界(デーレ)」の地図に
ExoClim-3 の物理モデルをそのまま適用し、derle-climate v0.11 の結果と比較する。

## 0. 何を正典とみなすか(利用者裁定 2026-08-01)

作業途中で前提が改められた。**以降はこちらが正**:

- **正典は「土地々々の気候」**。各地域が乾燥か温帯か熱帯か、という地域気候が
  動かせない設定であり、全球集計値は結果にすぎない。
- **陸平均降水 690mm は完全に無根拠**であり正典ではない。derle-climate が
  規格化に使っていた数値というだけ。
- **全球平均 8°C も正典ではない**。地域気候を成立させるための手段として
  過去に置かれた推定値。
- **天文値(光度・軌道・自転・傾斜)も変更可**。加えて表面気圧も自由変数。

したがって本実験の正しい問いは「8°C や 690mm を再現できるか」ではなく、
**「地域気候(7 項目)を最もよく満たす惑星諸元は何か」**である。
§1〜§5 は改訂前の枠組みで書かれているため、結論は §6 以降を読むこと。

- 地形: `derle-climate/data/processed/shukkai_geography_{1deg,05deg}.npz`
  → `scripts/build_derle_terrain.py` で変換(面積重み陸率 28.9%、最高 4,093m)
- 惑星諸元: `derle-climate/docs/PROJECT_CONTEXT.md`
  主星光度 1.2879 / 軌道長半径 1.225 AU / 半径 1.0489 地球 /
  自転 28.4698 h / 傾斜 19.505°
- 仮置き: 離心率・近日点位相は記載が無いため地球値(0.0167 / 283°)
- 出力: `out/derle/`(気候区分・気温・降水の PNG と summary.json)
- 実行: `npx tsx scripts/run_derle.ts`

## 1. 日射と温室効果 — 正典 8°C が要求する大気

デーレの日射は **1,168 W/m²(地球の 85.8%)**。主星は明るいが軌道が遠く、
差し引きで地球より暗い。ExoClim-3 は気温を物理から解くため、正典の
「全球平均 8°C」を満たす温室効果を逆算できる。

| 温室効果(地球 = 1.0) | 全球平均気温 |
| ---: | ---: |
| 1.0 | **−28.5°C(全球氷結)** |
| 1.375 | 3.68°C |
| **1.594** | **8.11°C(正典値)** |
| 1.813 | 11.12°C |
| 2.25 | 15.36°C |

**含意**: 地球と同じ大気ではデーレは雪玉惑星になる。正典の 8°C を成立させるには
**地球の約 1.6 倍の温室効果**が要る(金星ほどではなく、CO₂ 数倍〜十倍程度の
オーダー)。これは derle-climate 側が「全球平均 8°C を大域オフセットで固定」して
いた部分に、物理からの制約を与える。

**留保**: 温室 1.0 の全球氷結は氷アルベド暴走の解であり、本モデルの雪玉閾値は
検証済みではない(較正記録 2026-07-30 の「0 層海氷の双安定」参照)。
「1.0 と 1.375 の間に転移がある」ことまでが確かな主張。

## 2. 全球の比較(温室 1.594 = 正典 8°C 合わせ)

| 指標 | derle-climate v0.11 | **ExoClim-3** |
| --- | ---: | ---: |
| 全球平均気温 | 8.0(固定) | 8.11 |
| 陸平均気温 | 7.44 | 5.69 |
| 陸平均降水 | 690(固定) | **537** |
| 乾燥の割合 | 19.6%(乾燥指数) | 33.3%(ケッペン B) |

**最大の相違は全球の水量**。derle-climate は陸平均降水 690mm を大域スケールで
固定しているが、ExoClim-3 は物理から 537mm を予測する(28% 少ない)。

これは温度で説明できる。飽和水蒸気圧は陸平均 5.7°C で 14°C の 58% しかない。
地球の陸平均降水 794mm に対し 537mm = 68% は、この水蒸気量の差とほぼ整合する。
**「全球平均 8°C」と「陸平均降水 690mm」を同時に満たすのは物理的に苦しい** —
8°C の惑星は 500〜550mm 級になるのが自然、というのが本モデルの答え。

なお乾燥割合の定義が違う(derle = 乾燥指数 AI、ExoClim-3 = ケッペン B)ため、
33.3% と 19.6% を直接比べることはできない。水量の差がそのまま効いている。

## 3. 地域別 — 正典との整合(derle-climate の consistency_audit と同じ枠)

| 正典の期待 | derle v0.11 | **ExoClim-3** |
| --- | ---: | ---: |
| ウィル 乾燥 ≥ 50% | 42.3% ✗ | **78.2% ○** |
| デラドゥア沿岸 乾燥 ≥ 50% | 24.6% ✗ | 28.8% ✗ |
| デーレ中核 温帯 ≥ 50% | 84.0% ○ | 41.3% ✗ |
| デーレ中核 熱帯 < 10% | 6.5% ○ | 0% ○ |
| ルティア 熱帯 ≥ 50% | 68.9% ○ | 40.6% ✗ |
| シャンテリャ 乾燥 < 50% | 5.1% ○ | 90.7% ✗ |
| 全球 乾燥 < 23.9% | 19.6% ○ | 33.3% ✗ |

数値(気温 °C / 降水 mm / ケッペン大分類):

| 地域 | derle v0.11 | ExoClim-3 |
| --- | --- | --- |
| ウィル | 17.9°C / 658mm | 14.3°C / 344mm / B 78.2% |
| デラドゥア沿岸 | 6.2°C / 440mm | 6.5°C / 642mm / B 28.8% |
| デーレ中核 | 17.5°C / 1,165mm | 13.5°C / 521mm / B 55.6%・C+D 41.3% |
| ルティア | 23.2°C / 1,647mm | 18.0°C / 1,379mm / A 40.6% |
| シャンテリャ | 13.7°C / 883mm | 11.6°C / 243mm / B 90.7% |

### 読み解き

- **ウィルの謎が解けた可能性**: derle-climate が 3 つの海底地形シナリオすべてで
  再現できなかった「ウィルは乾燥が過半」を、ExoClim-3 は 78.2% で満たす。
  ウィルは 11〜34°N の亜熱帯にあり、**自転 28.5 時間(地球の 1.19 倍)が
  ハドレー循環を広げて亜熱帯高圧帯を極側へ張り出させる**のが効いている。
  ExoClim-3 は自転周期からハドレー端を計算するため、この効果が入る。
- **逆にシャンテリャとデーレ中核は乾かしすぎ**。全球の水量が 28% 少ないぶんが
  そのまま効いている。水量を 690mm に規格化すれば乾燥割合は大きく下がるため、
  「模様」ではなく「総量」の差と見るのが妥当。
- **ルティア(赤道直下)は熱帯 40.6%** で正典の 50% にわずかに届かない。
  残りは温帯 C で、熱帯の閾値(最寒月 18°C)をぎりぎり下回っている。
  全球が 6°C 低い惑星なので、赤道でも熱帯判定が厳しくなる。

## 4. 地図

`out/derle/` に 6 枚(physical / canonical8C × 気候区分・気温・降水)。
canonical8C の気候区分図は、**両半球の亜熱帯に幅の広い寒冷砂漠(BWk)帯**、
西岸に温帯(Cfb)、高緯度に広大なツンドラ・氷雪(E 31.1%)という構成。
地球より寒く、乾燥帯が広い惑星の姿になっている。

## 5. 本実験の限界

- 離心率・近日点位相が未定のため地球値を仮置き。公転周期も derle 側で保留中。
- デーレには高解像度標高が無く、稜線標高は 0.5° データの最大値集約(粗い)。
  R5 のアンデス型遮蔽は地球ほど効かない。
- ExoClim-3 の定数は**地球で較正**したもの。日射・自転が違う惑星への外挿で
  あり、較正の適用域内かどうかは別途検証が要る(適用範囲診断は ok を返した)。
- derle-climate は正典値で規格化、ExoClim-3 は物理から予測 — 目的が違うため
  優劣ではなく「独立した 2 系統の答え合わせ」として読むべき。

# 第 2 部 — 地域気候を正典とした探索(裁定後)

## 6. 探索の設計

正典 = 地域気候 7 項目(`LORE_CHECKS`)。これを目的関数の中核に据え、
天文値・大気を自由変数として探索する。加えて利用者の要望により
**居住可能性ベンチ**を追加した。

### 6.1 居住可能性ベンチ(全土アネクメーネの国が無いこと)

古典的な地理区分に従い、**アネクメーネ(人の常住が困難な土地)= 氷雪 EF ・
ツンドラ ET ・砂漠 BW** とする(ステップ BS は牧畜が成り立つのでエクメーネ)。
「国土の全域がアネクメーネの国」が存在する惑星設定は失敗とみなす。

国土は**国境の線ベクター**から復元した。地図(`イラレ出界図.svg`)の
`_国境界` レイヤーは線であってポリゴンではないため、derle-map-visualizer の
面復元処理(線 → 交点分割 → 平面グラフ → 面)を **Playwright ヘッドレスで
駆動**して面を得た(`scripts/extract_derle_polygons.mjs`)。SVG の実測 API
(`getPointAtLength` / `getCTM`)が要るためブラウザが必須。

- 国境線 44,800 / 海岸線 76,785 セグメント → 分割後 122,596 → 節点 121,933
- **面 619 個**。うち 0.5 度² 以上が 307 個
- 国名ラベルを内包する面に名前を与える → **名前つき 17 面 / 無名 290 面**
- 陸セル 3 個以上の面のみ評価 → 名前つき 17・スタブ 160

無名の面は「実在自体が怪しいスタブ的な国」との利用者裁定により、
全土アネクメーネのペナルティを **0.25 倍**に減衰させる。

居住可能性得点(0〜1、面の総数に依らないよう割合で測る):

```
得点 = 1 − (名前つきの全滅率 + 0.25 × スタブの全滅率) / 1.25
```

**落とし穴(実測)**: 抽出した点の座標は SVG の `viewBox` 単位(4249×2131)
ではなく **`width`/`height` 属性の単位(42492×21310)**。取り違えると 10 倍
ずれ、面積が全球の 34 倍(合計 221 万度²)という無意味な結果になる。
`pageSize` を書き出して割ることで固定した。

## 7. 気圧軸 — 気温を動かさずに湿らせる自由度

表面気圧は降水に `sqrt(P)` で効く(`step06_precipitation.ts:456,1325`)一方、
気温はほとんど動かさない。温室効果と直交する軸として機能する。

| 気圧 | 温室 1.65 での全球平均 | 陸平均降水 |
| ---: | ---: | ---: |
| 0.7 bar | 9.0°C | 469mm |
| 1.0 bar | 9.0°C | 570mm |
| 2.0 bar | 8.8°C | 816mm |
| **3.0 bar** | **8.7°C** | **999mm** |

気温 0.3°C の変化に対し降水は **+113%**。狙いどおりの直交軸である。

## 8. 結果 — 整合 3/7 → 4/7、しかし壁は「水準」ではなく「コントラスト」

気圧 3 bar / 温室 1.65 が最良で **整合 4/7**(従来 3/7)。内訳の変化:

| 検査 | 1 bar | 3 bar | 向き |
| --- | ---: | ---: | --- |
| 全球 乾燥 < 23.9% | 33.1% ✗ | **21.8% ○** | 改善 |
| デーレ中核 温帯 ≥ 50% | 38.9% ✗ | **53.7% ○** | 改善 |
| デーレ中核 熱帯 < 10% | 3.6% ○ | 0.3% ○ | 維持 |
| ルティア 熱帯 ≥ 50% | 67.9% ○ | 59.4% ○ | 維持 |
| シャンテリャ 乾燥 < 50% | 90.7% ✗ | 62.4% ✗ | 改善(未達) |
| **ウィル 乾燥 ≥ 50%** | **76.9% ○** | **33.6% ✗** | **悪化** |
| デラドゥア沿岸 乾燥 ≥ 50% | 28.6% ✗ | 16.7% ✗ | 悪化 |

**これが本実験の最大の発見**。乾きすぎの 3 件を治すために全体を湿らせると、
唯一成功していた「ウィルは乾燥」が壊れる。乾いた場所も湿った場所も一様に
スケールするため、**乾湿の空間的コントラストが足りない**。

同じ症状は地球検証にも出ている(温帯 C を乾燥 B と誤分類する偏り 4.6pt)。
デーレは**地球とは独立な大陸配置**でありながら同じ弱点を突いた。
較正で埋められる誤差ではなく、降水の定式化に由来する構造的欠陥であることの
独立した傍証になる。

### 8.1 居住可能性の結果(3 bar / 1.65)

名前つき 17 国のうち **2 国が全土アネクメーネ**:

| 国 | エクメーネ率 | 優占気候 | 陸セル |
| --- | ---: | --- | ---: |
| トゥインク連邦 | 0% | ET(ツンドラ) | 61 |
| 北ラヴィエン侯領国 | 0% | ET(ツンドラ) | 160 |
| ポ王国 | 15.9% | BWk(寒冷砂漠) | 232 |
| トルエ巫術都市国 | 38.2% | ET | 1,067 |
| アルラーク国 | 44.8% | ET | 1,215 |

いずれも**高緯度のツンドラ**か**寒冷砂漠**であり、惑星が寒すぎることを示す。
温室効果を上げると全滅国は減る(2.0 bar/1.70 では名前つき 1 国のみ)が、
今度は正典整合が落ちる。ここでも同じ綱引きが起きている。

## 9. 限界と次

- 天文値(傾斜 19.505° / 自転 28.4698h)は**探索の結果すでに最適**だった。
  正典の設定値が物理的にも良い選択だったことになる。
- 残る自由度(気圧・温室)では 4/7 が上限。**5/7 以上には降水のコントラスト
  改善が要る** — これは ExoClim-3 本体の課題であり、デーレ側の設定を
  いじって解くべきものではない。
- 離心率・近日点位相は未定のため地球値のまま(探索に含めていない)。
