# 事前登録: コンベアの経路場(段 45a)— 診断として作り、判別力を測る

日付: 2026-08-18(実装前に書いた)
設計: [設計方針_モンスーンコンベア](設計方針_モンスーンコンベア_2026-08-17.md)
裁定: 利用者「1 → 様子を見て 2」(2026-08-17)。v26 採用済み・位相調査は
段 46 系で総括済み(残課題の W 構造問題もコンベアに合流)。

## 何を作るか

**まだ物理には触れない。**診断スクリプト `diag_conveyor_path.ts` で、既存の量
だけから「コンベアの経路強度」をセルごとに合成し、その判別力を測る:

```
強度_j(月) = 取水(東の海の 暖流偏差 × W) × 浸透減衰 exp(−東海岸距離/L)
            × 夏ゲート(日射の季節偏差 > 0) × 緯度窓(ITCZ 極側〜リッジ+5°)
```

- 取水は陸セル j から自転方向(東)へ走査した先の海(フェッチ 2500km)で
  `max(0, sstAnomalyC) × waterMm` を平均。**在る水しか運べない**。
- 浸透 L = 1000 km(実物の梅雨帯の奥行き。感度は 500/1000/2000 で見る)。
- すべて既存の場(sstAnomalyC・waterMm・日射・ITCZ・リッジ)から合成。
  地理・緯度の名指しなし。逆行では走査方向が反転して成立する。

## 判定群(diag_penetration と同じ動的分類)

- **C→B 群(救う対象)**: 観測 C・モデル B の陸セル(華中型)
- **B→C 群(守る対象)**: 観測 B・モデル C の陸セル(豪州型)

名指しの箱(華中・米南東・豪州内陸・アラビア)は目視の参考のみに使い、
判定には使わない(地理中立)。

## 予測(結果を見る前に固定)

19. **夏平均の経路強度の中央値: C→B 群 ≥ 3 × B→C 群。**
    (設計の根拠: SST 偏差単独で 25% 分位が 1.84 対 0.00 と部分分離、
    そこに W の厚み・浸透減衰・緯度窓が乗算で重なるため)
20. B→C 群の 25% 分位は C→B 群の中央値の 10% 未満(下位が実質ゼロ)。
21. 浸透 L を 500〜2000 で振っても 19 の向きは変わらない(頑健)。

## 判定

- 19 が当たったら: この合成を段 45b(輸送方程式の源泉・シンク対)の
  経路重みとして採用し、45b を事前登録する。
- 19 が外れたら: どの因子が漏らすかを因子別の分位で切り分ける
  (診断には因子別列も出す)。**合成を結果に合わせて弄り回さない** —
  1 回の切り分けで直せる誤り(符号・規格化)以外は設計へ戻る。

## 追記 1: 判定と、守るべき本当の群(B 維持群)の追加測定

### 実測(予測 19〜21)

```
L=500   C→B 中央 0.18 / B→C 中央 0.00   中央比 87.6
L=1000  C→B 中央 0.55 / B→C 中央 0.05   中央比 11.9   ← 予測 19 ○(≥3)
L=2000  C→B 中央 0.92 / B→C 中央 0.21   中央比 4.4    ← 予測 21 ○(向き不変)
B→C の 25% 分位 0.00 < C→B 中央値の 10%(0.055)       ← 予測 20 ○
```

**3 つとも当たり。**ただし参考の箱に警告: 豪州内陸の箱平均 0.972 ≈ 華中 0.946。
B→C 群(現行モデルが既に湿らせ過ぎたセル)は少数で、45b の実害は
「**いま正しく B のセル(観測 B・モデル B)を新たに湿らせる**」ことで出る。
この群を測らずに 45b へ進むのは、段 44 の轍(豪州を壊してから気づく)を踏む。

### 追加測定(実行前に登録): B 維持群の経路強度

群を 3 つに拡張: C→B(救う)/ B→C(守る・既損)/ **B 維持(観測 B・
モデル B — 45b で壊してはならない)**。箱別の内訳(豪州内陸・アラビアの
B 維持セルの強度)も出す。予測:

22. B 維持群の中央値は C→B 群の中央値の **1/3 以下**。
    (根拠: B 維持群の多くは東に海が無い・W が薄い・緯度窓の外)
23. ただし**豪州内陸の B 維持セルは例外的に高く出る**(箱平均 0.97 の主因)。
    ここが 1/3 を超えるなら、合成には豪州型を切る因子がまだ足りず、
    45b の設計に「取水域の W の絶対閾値」か「浸透の上限」等の検討が要る
    (どれを足すかは因子別の分位を見て決め、45b の事前登録に書く)。

## 追記 2: 漏れ 2 件の実測と、設計に元からあった 2 因子の追加

### 実測(予測 22〜23)

```
B 維持群(2649 セル) L=1000: 中央 0.21、対 C→B 中央比 0.38(閾値 1/3 を僅かに超過)
豪州内陸の B 維持: 中央 0.34(比 0.62) / アラビアの B 維持: 中央 0.59(比 1.07)
```

- 予測 22 際どく外れ(0.38 対 1/3)。L=500 なら 0.13 で安全側、L=2000 は 0.70。
- 予測 23 当たり(豪州は高い)。**想定外はアラビアが最大の漏れ**(C→B 中央値超え)。

### 原因(設計文書に照らして)

どちらも合成への入れ忘れで、**設計方針に元から書いてある錨**:

- アラビア: **R-H 位相**(「段 44 の配管を再利用 — アラビアを守る」)。東に強い
  モンスーン加熱(インド)がある列は自分が沈降側 — 取水しても降らせられない。
- 豪州内陸: **東岸の峰の絞り**(大分水嶺)。経路上の最大峰標高で水を絞る。
  既存の crestElevationMeters(セル内 p95、段 30 系)を使う。

### 追加(実行前に登録)

強度に 2 因子を乗算:
- `rhFactor = 1 − clamp((eastH − hCol)/monsoonHeatContrastNorm)`(段 44 の鏡像)
- `crestFactor = exp(−経路上の最大峰標高 / 1000m)`

予測:

24. アラビア B 維持の中央値が **C→B 新中央値の 1/3 未満**へ落ちる。
    C→B 群の中央値の低下は 15% 以内(華中・米南東の東に強い加熱は無い)。
25. 豪州内陸 B 維持の中央値が **1/3 未満**へ落ちる。
26. 総合: B 維持群全体の中央比 ≤ 1/3、かつ C→B 対 B→C 中央比 ≥ 3 を保つ。

## 判定

- 24〜26 が揃ったら 45a 完了。この合成(取水 SST×W・浸透・夏・緯度窓・
  R-H・峰)を 45b の経路重みとして事前登録する。
- 外れたら因子別分位で切り分け、**それでも駄目なら設計へ戻る**
  (合成の弄り回しはしない)。

## 追記 3: 予測 24〜26 の判定 — 幾何の設計ミスが露呈、斜め走査へ

### 実測

```
                      v1(因子なし)   v2(R-H+峰)
C→B 中央(L=1000)      0.55           0.13(−76%。予測 24 の「15% 以内」大破)
B 維持 対 C→B 比       0.38           0.34(閾値 1/3 に届かず)
豪州内陸 B 維持        0.34           0.15(向きは正しいが 1/3 未満に届かず)
アラビア B 維持        0.59           0.25(同上)
米南東の箱             0.561          **0.040(壊滅)**
```

- 予測 24〜26 **外れ**。峰の絞り自体は豪州に正しく効いたが、
  **真東走査の幾何が誤り**: 米南東の経路が「アパラチアを越えて大西洋」に
  なり、救うべき側を絞ってしまう。実物のメキシコ湾 LLJ は**南東(赤道側)
  から回り込む**。高気圧の西縁を回る流れは斜めであり、設計方針の
  「西縁を回る下層湿潤流」を真東の走査で近似したのが誤りだった。

### 設計の修正(実行前に登録): 走査を「東+赤道側」の斜めへ

取水走査と峰の追跡を、東向き+赤道向きの斜め(2 セル東につき 1 セル赤道側、
ITCZ 緯度で打ち切り)に変える。これで
華中 ← 南シナ海・東シナ海 / 米南東 ← メキシコ湾(アパラチアを跨がない)/
豪州 ← 珊瑚海(大分水嶺は依然経路上 = 絞られる)/ アラビア ← アラビア海
(R-H が沈降側として切る)。逆行では全部が鏡像で成立(地理中立は保たれる)。

予測:

27. C→B 中央(L=1000)が **0.30 以上へ回復**し、米南東の箱が 0.30 以上へ戻る。
28. 豪州内陸・アラビアの B 維持中央は **C→B 新中央値の 1/3 以下**。
29. B 維持全体の比 ≤ 1/3、C→B 対 B→C 中央比 ≥ 3 を維持。

## 判定(再)

27〜29 が揃えば 45a 完了 → 45b の事前登録へ。外れたら**この合成での 45a を
一旦保留し、設計方針に立ち返って利用者へ中間報告**(3 回外したら独走で
弄り回さない、の自主規制)。

## 追記 4: 予測 27〜29 の判定 — 3 連続外れ。規定により合成の反復を停止

### 実測(斜め走査 v3)

```
C→B 中央(L=1000)     0.19(予測 0.30 に届かず。v2 の 0.13 からは回復)
米南東の箱            0.170(予測 0.30 に届かず。v2 の 0.040 から 4 倍回復)
B 維持全体の比        0.19 ○(≤1/3)/ C→B 対 B→C 中央比 91 ○
豪州内陸 B 維持       0.22(1/3 どころか C→B 中央値超え。斜め走査で北上し
                     大分水嶺の低い区間を抜けてしまう)
アラビア B 維持       0.16(比 0.84。R-H は 25% 分位を 0 にするが中央は残す)
```

登録した規定(3 回外したら独走で弄り回さない)に従い、**スカラー合成の
反復をここで停止**する。

### 3 回の反復が教えたこと(結果に依存しない読み)

1. **取水側の錨は働く**: SST 偏差 × W は B→C の下位 1/4 を確実に切り、
   C→B 対 B→C の中央比は常に ≥ 11(v1)〜91(v3)。
2. **浸透・峰のゲートが毎回破れる**: 経路の幾何(どこを通って水が来るか)を
   セルごとのスカラー走査で書くのは、真東でも斜めでも地形の網の目に負ける。
3. これは設計方針の原点に返る示唆: **45b の本体は輸送方程式の源泉・シンク対**
   であり、内陸への配分は保存型ソルバ(風・拡散・地形の絞りは既にある)に
   任せるのが筋。診断のスカラー合成が担うべきは**取水域の重みだけ**
   (そこは 3 回とも働いた)。浸透を短く(L=500 で B 維持比 0.05)して
   「海岸帯へ注ぎ、内陸へは輸送が運ぶ」形が、測れた範囲で最も安全。

→ 中間報告を利用者へ。45b の事前登録案(取水=検証済みの錨、給水=海岸帯、
配分=輸送方程式)を添えるが、**実装は報告後に着手**する。
