## 較正過程で確定した構造的知見(時系列)

1. **寒冷開始 → 雪玉解**。EBM は雪氷アルベドの双安定を持つ。温暖側から初期化し、
   序盤 2 年は熱容量 1/16 で加速スピンアップする。
2. **移流はセル熱容量に掛けない**。海面が風速で流される誤りになる。
   大気の上流結合(固定 W/m²/K)として表現する。
3. **等方拡散 + 球面計量は高緯度の大陸規模季節モードを潰す**(シベリア振幅 1/3 事件)。
   南北拡散(文献値 D)と東西(弱拡散 + 方向性移流)に分離する。
4. **一様雲は砂漠を ~9°C 冷やす**。雲は循環で変調する(沈降域=晴天、ITCZ=曇天、
   ストームトラック=海上曇天、寒流上=層積雲)。
5. **恒常氷床と季節雪は別物**。単一の温度ランプでは北半球の融雪と南極の恒常氷を
   両立できない。2 パス判定(年平均 + 最暖月)+ 隣接拡張で氷床を表す。
6. **周極海峡(陸に遮られない緯度行)は南北隔離 + 深い混合層**。南極周極流の
   効果をトポロジーから導出(地理決め打ちなし)。
7. **気圧勾配風は上限必須**。無制限だと ±40 m/s 級の月平均風が出て水蒸気追跡が壊れる。
8. **ハドレー域の拡散増強は諸刃**。効かせすぎると全球が寒冷側へ雪崩れる(1.1 で凍結)。
9. **亜熱帯高気圧は東西非対称**。「自転方向の東に海が近い陸ほど沈降が緩む」
   (バミューダ高気圧西翼の湿潤)で米南東部・東アジアの乾燥化を大きく緩和。
10. **月平均風の追跡だけでは中緯度の冬雨が出ない**(derle 教訓 §8.2 の再確認)。
    ストームトラック帯の渦供給(海岸距離減衰)を別途持つ。地中海 Cs はこれで出現。
11. **風上山脈の遮蔽**(スキャン 900km)でパタゴニア型雨陰を表現(部分的)。
12. **モンスーントラフは帯内陸標高で増強**(チベット効果)+ 平滑化幅を絞る。
    それでもインドの深いモンスーン(トラフ 25°N・南西季節風)は未達 → 残課題。

## 既知の残課題(結果を見て基準は緩めない。今後の物理強化で対応)

- **インドが BWh**(モンスーントラフが 14°N 止まり、南西季節風が立たない)。
  越赤道流 + トラフの気圧場表現の強化が必要。
- **米南東部・東アジアの湿潤不足**(BSk/BSh 優勢)。東岸暖流上の水蒸気を
  内陸へ運ぶ夏季流の弱さ。eastCoastSubsidenceRelief だけでは不足。
- **西欧が Dfc 優勢**(Cfb にならない。冬 +5°C 不足)。海洋熱輸送 → 陸への
  移流の強化が必要だが、上げすぎるとシベリアが暖まる交換条件がある。
- **東シベリアの乾燥過多**(BSk 優勢)。冬の弱前線降水と再循環の下限が必要。
- **パタゴニアが湿潤**(遮蔽が効き切らない + 大西洋側供給 + 再循環の雪崩)。
- **アラビアが Cwa 化**(東岸緩和則の副作用。インド洋が東にあるため)。
- 詳細分類での Dw 過多(冬降水の下限が低すぎ、f になるべき所が w 判定)。

## 環流流線の実装記録(2026-07-29 深夜、書き起こしベース)

Artifexian / WL#28 の演繹手順(字幕原文)どおりに `buildStreamlines` を実装。
反復で得た設計知見:

- **閉ループ主義**: 枝ごとに独立に描くと「縞」に見える。接合点(枝端の列)を
  厳密に共有し、海岸追跡が途中で止まったらその緯度で輪を閉じる。
- **陸横断ゼロは builder 側の不変条件**: 線分ごとに陸横断チェック。岬は
  L 字迂回(縦→横 / 横→縦)で回り込む。湾曲(bowZonal)も線分検査つき。
- **ラン選択は「重なり最大」でなく「縁の連続性」**: 重なり最大だと南シナ海の
  ような縁海に迷い込み環流が低緯度で閉じる(黒潮消失事件)。
- **帯状区間は環流内側へ弓なりに湾曲**(-2 P4-21 と同趣旨)。直線 + 直角では
  輪として読めない。
- **全周リング(陸なし行)には縁が無い**: 縁追跡から除外し、風帯ごとの帯状流
  (木星型バンド)として別途描く。全海惑星はバンド 6 本になる。
- **検証は scripts/preview_streamlines.ts**: 全プリセット + 逆行を一括描画し、
  陸横断サンプル数を自動集計(全構成で 0 を維持すること)。

**既知課題**: メキシコ湾型の縁海に入り込むとそこで輪が閉じる(実物は
フロリダ海峡を抜けて北上)。行単位の縁追跡の構造限界で、解決には海岸線の
輪郭追跡(-2 から持ち越しの agent-tracing)が必要。次期候補。

## WL#32 Fetch 則(内海の到達距離)の実装(2026-07-30)

Log の規則: 水域の湿潤が内陸へ届く距離はその水域の風上幅(Fetch)まで。
カスピ海級の内海は周囲しか湿らせない。

- **実装の変遷**: (1) 経路上の水域幅で判定 → 海峡をかすめた外洋まで
  「狭い」と誤判定し大分類 55.9〜60.3% に悪化。(2) **海の連結成分
  ラベリングで面積 < 1.2M km² の閉水域だけを対象**に変更(カスピ海・
  黒海・バルト海・五大湖級。地中海のように海峡で外洋に繋がるものは
  同成分になり免除)— 幾何でなく位相での判定なので地理中立。
- **ゲート**: f = clamp((min(Fetch, 2000km) + 250km − 進入前陸距離) / 500km,
  0.3, 1)。下限 0.3 = 完全遮断はしない(実在の黒海・バルト海は遠方にも
  幾らか湿潤を送る)。
- **同一コードでの A/B**(f=1 で無効化): 大分類 61.2% → 60.9%(−0.3pt)、
  詳細 26.0% → 26.2%(+0.2pt)、降水 RMSE 844 → 840mm、log 相関
  0.644 → 0.647、地域ゲート 10 = 10。B 乾燥の面積差 −0.7 → +1.1pt、
  D 冷帯 −6.0 → −6.8pt。
- **判断: 採用**。大分類は僅減だが場の指標(RMSE・相関・詳細)は改善で
  実質引き分け。Log 本編の明示手順であり、内海が超大陸を丸ごと湿らせる
  暴走を防ぐ本来目的(架空惑星)に直結するため、思いつき機構(撤回した
  モンスーン風)とは扱いを変える。B/D 境界の僅かな悪化は Fetch 由来の
  乾燥がケッペン閾値近傍のセルを B 側へ倒すためで、降水場自体は観測に
  近づいている。

## EBM 移流の 2D 化(2026-07-30)— 詳細 28.1% / 大分類 61.8% へ

熱帯沿岸の冬の冷えすぎ(ムンバイ沖 2月 17°C vs 実測 25°C、デリー 1月 −5°C)
の根因が「帯状(東西のみ)移流」だったため、Step 4 の 2D 風による風上結合に
置換した。試行錯誤の記録:

1. **素朴な 2D 化は大失敗**(詳細 26.1%、チェンナイ 1月 22→16°C):
   貿易風の v 成分がハドレー域内で恒常的に北風上流と結合し、
   シベリア→インドの「冷気コンベア」になる。ハドレー域の南北輸送は
   拡散増強で表現済みなので二重計上だった。
2. **v 結合をリッジより極側に限定** → 大分類 62.9% に跳ねたが南極海が
   +11°C 過熱・全球 +3.6°C・降水爆発。v 結合が周極海峡の隔離則を迂回した。
3. **v に海峡減衰(×0.45)と陸グリップ(0.25+0.75×陸率)を追加** → 確定:
   **詳細 27.0→28.1% / 大分類 61.1→61.8% / 気温 RMSE 年 8.45→7.89・
   1月 6.41→5.99・7月 12.61→12.1 / 全球平均 15.2°C**。降水は
   RMSE 828→849・相関 0.673→0.668 と僅かに悪化(許容)。
   西欧ゲートは ET 41→28%(Dfb 33% が最多)と大きく前進、チェンナイ沖
   1月 23°C・マイアミ 1月 17°C。ゲートは 10/17 のまま。

教訓: 帯状モデルに後から次元を足すときは、**既存機構がその輸送を
どこまで肩代わりしていたか**(ハドレー拡散・海峡則)を先に洗い出すこと。

## 次に較正するときに必ず見ること(2026-08-15 追記)

**探索空間の端に張り付いている定数を、較正の前後で必ず確かめる。**
道具: `npx tsx scripts/diag_space_bounds.ts`。

v22 の時点で **62 定数のうち 20 件が範囲の 5% 以内**にあり、うち 17 件は
ちょうど端の値だった。中身に方向があるのが問題である —
**水を均す方向の定数が 6 つ同時に天井へ当たっている**:

```
渦拡散 99.1% / 降水の月ブレンド 100% / ハドレー追加拡散 100% /
ストーム湿気の到達距離 96.4% / 冬季床の割合 95.1% / 同上限 88.0%
```

歴代の `best_*.json` を辿ると時系列でも出る:

```
                              v15     v20      v22
moistureEddyDiffusivityM2PerS 1.50e6  2.06e6   2.98e6  ← 天井へ登り続けた
warmHumidConvectiveBoost      0.032   0.0208   0       ← 能動的に切られた
itczHemisOffsetPerC           0.453   0.605    0       ← 能動的に切られた
```

**目的関数(ケッペン一致率)は「均す」を報酬にしている。**
均せば中位のセルが当たり、外れるのは分布の端で、端は面積が小さいからである。
実測でも、南極を除き面積重みで見るとモデルの降水は既に観測より**狭い**
(対数標準偏差 0.429 対 0.530)のに、較正はさらに均す方向へ押している。

詳細: [診断_較正が探索空間の端に張り付いている](診断_較正が探索空間の端に張り付いている_2026-08-15.md)。

### 含意

- **分布の端を直す機構を入れたら、再較正がそれを打ち消しうる。**
  均す定数にはまだ天井までの余地がある。再較正の結果は v3 だけでなく
  **乾いた端の分位(1%/5%、南極を除く・面積重み)が保たれているか**を並べて読む。
  掃引はこの分位を印字する(`scripts/sweep_lib.ts`)。
- **端に当たった定数は「範囲を広げる」前に、補償を疑う。**
  渦拡散 3e6 m²/s は中緯度の総観規模輸送としては既に大きい側であり、
  上限に当たっていること自体が「乾いた端を作る機構が無いので、せめて
  中位を当てる」という補償に見える。
