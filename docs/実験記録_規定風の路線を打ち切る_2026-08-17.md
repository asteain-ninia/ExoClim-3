## 判定: 不採用、かつ**規定風の路線ごと打ち切り**(事前登録の規定どおり)

4 m/s の加算 through-flow(海の fetch つき)でも、C→B の正味移流は動かなかった。
段 41(反転)・42(ゲート付き反転)・43(加算)と 3 通りの実装で同じ結果なので、

> **定常輸送モデルでは、規定風をどう細工しても特定セル群への正味輸入は作れない。**
> 場が汲み直して釣り合いを戻す。

という結論が確定した。

+0.21 の連続部分改善は魅力的だが、**狙った機構(C→B への輸入)が効いていない
のに全体が良くなる**のは説明と挙動の不一致であり、段 39 の規定どおり採用しない
(改善の出どころは中緯度帯の湿潤化で、C→B とは別の場所だった)。

## 打ち切りの測定から出た、より重要な事実

### C→B の欠損の分解(P = λ·G·W)

```
G(凝結率)   0.80 / 1.83 = 0.44   ← **2.3 倍の欠損。主因はこちら**
W(可降水量) 2.79 / 3.19 = 0.87   ←   1.15 倍
P(降水)     63 / 183   = 0.35   ≈ 0.44 × 0.87 ✓
```

**今日一日 W(輸送)側を攻めていたが、C→B の降水が 1/3 なのは主に
G(凝結率)が半分だからだった。** 0.87 の因子と戦って 0.44 を放置していた。

W 側の 4 連敗は必然だったことになる — W を 15% 直しても P は 15% しか動かず、
分類の閾値(2.9 倍の差)には最初から届かない。

### G の 2.3 倍は、どの因子か

```
【夏半年】              C→B     C→C      比
ITCZ 持上げ            1.170   1.253    0.93
前線 持上げ             1.206   1.369    0.88
収束 持上げ             1.195   1.357    0.88
**沈降残存**           0.480   0.712    **0.67**   ← 主因
その他                 0.987   1.095    0.90
—— 実効 G             0.797   1.826    0.44
```

**主因は沈降抑制。** C→B のセルは夏でも凝結効率の 52% を沈降帯に奪われている
(健康な C は 29%)。実物の夏のモンスーン域では、大陸上の下降枝は
モンスーントラフ(上昇域)に置き換わって存在しない。
**モデルは、実在しない沈降を亜熱帯モンスーン域の夏に敷いている。**

### そして沈降緩和の構造に、乾いた平衡と同じ罠がある

step06 の沈降には緩和の経路が 3 つあるが、**すべて「湿っていること」がゲート**:

```
ITCZ 防護     × marineW(供給ゲート)
東岸緩和      × supplyGate(供給ゲート)+ SST
収束緩和      × wetConv(湿潤収束)
```

**乾いているセルは緩和を獲得できない → 沈降が効き続ける → 乾いたまま。**
熱的低気圧の「湿りで深さが決まる」(段 9)と同型の自己固定である。
供給ゲート自体には理由がある(アラビアの再湿潤化を防いだ実績)ので、
外せばよいという話ではない — **アラビア/サハラと華中/米南東を、
降水以外の量で区別する設計**が要る。

## 教訓

- **比の分解を最初にやる。** P = λ·G·W なら、どの因子が欠損の主因かは
  割り算 2 回で分かった。それをせず「輸送が犯人」という 15 日の診断の
  雰囲気のまま一日を使った。**症状の分解 → 最大の因子 → その因子の分解**、
  の順を機械的に守ること。
- 規定風の 3 連敗は無駄ではない — 「定常輸送では規定風で正味輸入を作れない」
  は、この種のモデルの**一般的な性質**として今後の設計をすべて縛る。
