# 事前登録: ITCZ の赤道残存(equatorialItczResidual)と帯幅 — Af 過剰の直接の犯人か

日付: 2026-09-03 夕(測る前に書いた)。台帳 27。

## 根拠(実測、結果に依存しない)

- Af 過剰セル(模型 Af・観測非 Af、赤道 10° 以内が 7 割)の模型最乾月: P 99.7mm、
  **liftItcz 1.37**。ITCZ の移動量は観測並み(降水重心の年較差 8.1° 対 9.1°)。
- コード: `gIres = equatorialItczResidual·exp(−dMean²)`、`gI = max(gIm, gIres)` —
  年平均 ITCZ 位置に**年中残る持ち上げの床**。liftItcz = 1 + 3.2·0.3·marineW ≈ 1.37
  で過剰セルの実測と一致。SPACE 範囲 [0.3, 0.8] の**下限 0.3 に張り付き**
  (較正はもっと下げたい)。帯幅 itczHalfWidthDeg = 9 は SPACE 外。

## 掃引(1°・v42 既定)

(a) equatorialItczResidual ∈ {0.3(現行下限), 0.15, 0}
(b) itczHalfWidthDeg ∈ {9(現行), 7, 5}
測るもの: Af/Am/Aw・熱帯陸 最乾月<10mm・fitness・大分類・詳細・amazon/congo/india/
horn/east_asia・1% 分位。

## 予測(測る前に固定)

129. (a) 残存 0 で Af 11.4 → **≤ 8%**、Aw ≥ 9.5%、最乾月<10mm ≥ 30%。
130. (a) amazon/congo は PASS 維持(真の雨林は年間を通じて雨帯の通過か Am 型で、
     残存に頼っていない)。fitness は −0.3 まで受容 — 下限張り付きの解放なので
     むしろ改善を予想(+0.2)。
131. (b) 幅 5 で Af ≤ 9%。ただし雨季の総量が減り india/amazon が沈む可能性 —
     (a) より副作用が大きいと予想。
132. 健全性 PASS・気温 RMSE ≤ 4.4。

## 判定

- 129・130 ○ → 範囲を [0, 0.8] に拡張(根拠つき範囲拡張: 床は物理でなく便宜)
  し次の較正へ。8/24 の張り付き診断に「C: 機構の床 = 範囲の下限が答えを決めて
  いた」として記録。
- 129 ○ 130 ✗ → 残存はアマゾン/コンゴの保護に効いていた。地理を名指しせずに
  雨林を守る物理(陸面再循環・W)を先に補ってから。
- 129 ✗ → 過剰セルの持ち上げの残り(conv 1.15・G 1.41)の分解へ。

## 判定(同日): 129 ✗ / 131 ✗ — 赤道残存も帯幅も犯人ではない。床は λ そのもの


- 129 ✗: 残存を 0 にしても Af 11.4→10.9・最乾月<10mm 不変。130 ○(雨林無傷)。
- 131 ✗: 帯を狭めると Af は**増え**(12.1)、全指標が悪化。予測は真逆。
- **結論(算術)**: 過剰セルの最乾月は P 99.7 / G 1.41 = **70.7mm/G**。これは
  λ·W = (U_ref/L)·W ≈ 9.7/月 × 7.7mm ≈ 75mm と一致する。つまり**持ち上げが
  ゼロ(G=1)でも、W 7.7mm から λ が 75mm/月 を降らせる**。実物では持ち上げの
  無い柱は降らない。Af 過剰は ITCZ の移動でも幅でも残存でもなく、
  **λ·G 縮退(縮尺 W × 過大 λ)のもう一つの顔**である。
  沈降抑制 p や残存が最乾月を数 mm しか動かせなかったのも同じ理由。
- 帰結: 台帳 27 の診断は完了。処方は W 実寸化章(閾値型の排水 = 床・cap の
  レジーム)に合流する — 持ち上げの無い柱で降らない構造は、そこでしか作れない。
  v7b 上の単独レバーでは Af は動かない(本日 3 掃引で実証)。
