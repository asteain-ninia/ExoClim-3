# 事前登録: 渦拡散が降水分布の両端を潰しているか

日付: 2026-08-16(v24 較正の走行中に書いた。**結果を見る前に固定する**)
前段: [実験記録_目的関数v4](実験記録_目的関数v4_2026-08-16.md)、
      [外部レビュー_構造の歪み](外部レビュー_構造の歪み_2026-08-15.md)

## 疑い

独立な 3 つの観察が同じ向きを指している。

**(1) 降水分布の両端が潰れている**(2026-08-16 に初めて測った)

```
分位     モデル/観測
 1%        7.11   ← 乾いた端が過剰
 5%        2.04
50%        0.89
99%        0.89   ← 湿った端が不足
```

乾いた側が湿りすぎ、湿った側が乾きすぎ。**分布が中央へ寄っている。**

**(2) 較正が渦拡散を単調に上げ、上限に張り付いた**(外部監査の指摘)

`moistureEddyDiffusivityM2PerS` は探索空間の上限 3.0e6 m²/s にいる。
v24(目的関数 v4)でも、走り始めた時点で上限のままである。

**(3) 較正が構造を作る定数を 0 へ落とした**(同監査)

`convergenceLiftBoost` と `warmHumidConvectiveBoost` が能動的に 0 へ動いた。
どちらも**空間構造を作る**機構である。

拡散は勾配を均す演算子なので、強めれば分布は必ず中央へ寄る。
**「均して合わせる」ほうが目的関数の得点が高かった**のではないか、という疑い。

## 測ること

`moistureEddyDiffusivityM2PerS` を単独で掃引する(他の定数は動かさない)。

```
水準: 3.0e6(現在・上限) / 2.4e6 / 1.8e6 / 1.2e6 / 0.6e6
```

各水準で測る量:

| 量 | なぜ |
| --- | --- |
| 年降水の分位 8 点(面積重み・南極抜き) | **疑いの主対象**。両端が広がるか |
| `precipQuantileLogErr` | 分布形の誤差 |
| 大分類 / 詳細の一致率 | ケッペンが主目的である点は変えない |
| `continuousV3` | 目的関数の版をまたいで比べられる唯一の量 |
| `gateShare` | 地域の被覆 |
| 数値的健全性(5 系統の収束) | 拡散を弱めると輸送の収束が悪化しうる |

## 予測(**結果を見る前に固定する**)

1. **拡散を下げると 1% 分位は下がる**(乾いた端が作れるようになる)。
   3.0e6 → 0.6e6 で 66mm → 30mm 前後まで下がると読む。
2. **同時に中位(50% 分位)も下がる。** 2026-08-15 に 8 つの機構を測って
   8 回とも中位が下がった。拡散も例外ではないと読む。
   545 → 480 前後。**すでに観測 596 より低いので、これは悪化である。**
3. したがって **`precipQuantileLogErr` は下がるが、大分類は下がる**。
   目的関数 v4 では相殺し、**全体としては改善しない**と読む。
4. 数値的健全性は保たれる(拡散を弱めるのは輸送の対角優位性を弱めるが、
   1/5 程度なら収束するはず)。

**予測 3 が当たるなら、「拡散を下げる」は単独では手にならない。**
その場合の次の一手は「拡散を下げると同時に、失われた輸送を
**構造のある機構**(収束持上げ・経度依存の風)で置き換える」になる。
つまりこの実験は、**単独の手を探すのではなく、組で打つ必要があるかを決める**。

## 判定

- 予測 1 が外れて 1% 分位が下がらないなら、**両端の潰れは拡散のせいではない**。
  疑いを取り下げ、別の原因(源泉の作り方・凝結率の形)を探す。
- 予測 2 が外れて中位が下がらないなら、**これは 2026-08-15 以来はじめて
  「中位を守ったまま乾いた端を作る」手**である。単独で採用候補になる。
- 予測 3 が当たる(相殺する)なら、上に書いたとおり組で打つ設計へ進む。

**どの結果でも「条件を緩めて採用」はしない。** 較正 v24 は目的関数が
凍結されており、この掃引は**その外側で機構を理解するための測定**である。

## 実行

v24 較正の終了後(GPU の競合を避けるため)。
道具は `scripts/sweep_lib.ts` を使う。**`EBM_SOLVER.adaptive` を触らないこと**
(2026-08-15 に較正ワーカーから写して答えが 0.024〜0.057 ずれた)。
