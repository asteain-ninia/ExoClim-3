2. **変更ファイル**: `src/domain/terrain.ts` — 逐次乱数(mulberry32 消費)を廃止し、
   `hash(種子, オクターブ番号, 固定角度格子座標)` の座標ハッシュ方式へ。オクターブは
   角度定義(90/45/22.5/11.25/5.625° — 360 を割り切る値)で経度周期を厳密化。
   海水準の面積重み付き分位点方式は維持。
3. **追加テスト**: `tests/unit/domain/terrain.test.ts`(6 件): 決定性(配列一致)、
   種子差で別惑星、陸面積率 ±1pt(3 種子 × 3 解像度)、1° vs 0.5° の Jaccard ≥ 0.95、
   1° vs 2° の Jaccard ≥ 0.9、経度継ぎ目の連続性。
4. **修正前に失敗 → 修正後に通る証拠**: 修正前の実測 Jaccard = 0.198(1° vs 0.5°)/
   0.153(1° vs 2°)で 2 テスト FAIL(FB の実測 0.196/0.152 と一致 — 相互検証)。
   修正後 6/6 PASS。
5. **地球主要指標の前後**: リーン採点がビット一致
   (fit 93.09 / 大分類 73.93 / 詳細 42.74 / ゲート 14 / ITCZ 8.33)。
   地球・仮想大陸プリセットは手続きノイズを使わないため不変。

   0.977〜0.984(1° vs 2°)。陸面積率は全組合せで 30.0%(指定 30%)。
