# 診断: 大分類・詳細の伸び悩みは「カオスの限界」ではない。**失点は 1 か所に集中している**

日付: 2026-08-16
発端: 利用者の問い「数日較正を回してこれなので、なにか根本的なものがあるのか、
      それとも結局カオスはカオスで限界があるのか」
道具: `scripts/diag_c_to_b.ts`(新規)+ 外部文献の検索
出力: `out/diag_c_to_b.txt`

## 問いへの答え(先に結論)

**限界ではない。失点は特定の 1 か所に集中しており、その正体は
今日 3 つの掃引で確定した「欠落機構」と同じものである。**

- 誤りが空間的にランダムに散っているなら「カオスの限界」を疑う。
  実際は**誤りの 32% が C→B という 1 種類**に集中し、地理も
  亜熱帯モンスーン域(緯度 27°、内陸 515km)に集中している。
  ランダムではない = 系統誤差 = **構造の問題**である。
- 必要な改善量も測れた。**閾値まで中央 252mm/年**。
  観測との差(881mm)を全部埋める必要はなく、**29% 埋めれば分類は直る**。

## 【1】外部の相場観 — いまの成績はどの位置か

検索で確かめた(私はこれまで外部の相場を確認していなかった):

- 最新の**嵐解像(km 格子)全球モデル**(ICON / IFS-FESOM)でも、ケッペン分類の
  正解率は「**全格子点の約 2/3**」(約 67%、詳細寄りの分類)。
  モデル間で 10 ポイント差がある。
- CMIP6 の評価論文は「CMIP5 より少し良い」程度の記述で、
  単一の一致率をあまり出さない(それ自体、簡単な指標ではない証拠)。
- 観測データセット(CRU/ERA5/WorldClim 等 7 種)どうしでも分類は食い違い、
  「多数決マップ」を作る研究があるほどである。

**本モデルの大分類 74.2% / 詳細 43.7% は、月平均・単層の簡易モデルとしては
既に「実物の GCM の背中が見える」位置にいる。** 伸び悩むのは自然である —
ただしそれは「もう伸びない」を意味しない。以下のとおり、残りの失点は
拡散的な当てはめでは届かない場所に溜まっている。

## 【2】失点はどこか — 混同行列

```
大分類の混同(行 = 観測、列 = モデル、面積%)
        A      B      C      D      E     行の正解率
  A  17.90   1.30   1.00   0.00   0.00    88.6%
  B   4.00  20.10   2.60   2.40   0.40    68.1%
  C   0.60   5.60   5.30   0.10   0.10    45.3%  ← **最悪**
  D   0.00   1.50   1.80  18.50   2.70    75.5%
  E   0.00   0.70   0.00   1.00  12.30    87.9%
```

- **観測 C(温帯)の 48% を B(乾燥)と誤判定している。**
- 大分類の誤り 25.8 ポイントのうち、C↔B だけで **8.2 ポイント(32%)**。
- A・E は 9 割近く当たっている。**「全体がまんべんなく悪い」のではない。**

## 【3】C→B の正体 — あと何 mm 足りないのか

B/C 境界は乾燥閾値 `P_th = (2T+28|14|0)×10` という明示式なので、
「あと何 mm 降れば C になるか」がセルごとに計算できる。

```
【観測 C → モデル B】737 セル、C 関連面積の 42.1%
  年降水   モデル 306 / 観測 1227 mm   (1/4 しか降らせていない)
  気温     19.9°C   緯度中央 27°   海岸距離中央 515 km
  **閾値まで あと中央 252 mm/年**(25% 分位 137 / 75% 分位 367)
  経度帯   米州東 39% / 亜州東 33% / 亜州西 20%

【観測 B → モデル C】374 セル、19.6%
  年降水   モデル 752 / 観測 343 mm   (逆に 2.2 倍降らせている)
  経度帯   欧阿 38% / 米州西 30% / 米州東 25%
```

**双方向の誤りが同時にある。** 湿るべき場所(亜熱帯の大陸東側)が乾き、
乾くべき場所(中緯度の大陸西側〜内陸)が湿っている。
**水の総量ではなく、置き場所が間違っている。**

これは今日の掃引の結論とぴったり重なる:

- 渦拡散は**均す**ことで内陸を湿らせていた(置き場所を選べない)
- 理想化大陸でも**東岸湿潤だけが逆向き**に出た
- 観測 C→B の 72% が米州東・亜州東 = **亜熱帯の大陸東側、モンスーン域**

実物でここを湿らせるのは、亜熱帯高気圧の西縁を回る**南からの湿潤流**
(モンスーン循環・温帯低気圧の暖域流入)である。
モデルには月平均の帯状風 + 気圧勾配風しかなく、**この向きの輸送を持たない**。

## 【4】数日の較正で伸びない理由

較正は 61 定数の振幅を動かすが、**「南から湿った空気を大陸東側へ運ぶ」経路が
配管に無い**。無い経路の振幅は探索できない。
だから較正は拡散(均す)を上限に張り付かせ、崖(ゲート)を探して、
それでも届かない 8.2 ポイントが残る。

v24 較正が 82.26 → 82.54 と 0.3 しか動かないのは、この読みと整合する。
**残る失点は振幅の問題ではなく配管の問題**である。

## 何をすべきか(優先順)

1. **亜熱帯高気圧の西縁の湿潤流を機構として設計する。**
   位相規則(高気圧の東西の縁で流れの向きが違う)は既に
   `subtropicalCellEastBoost` などで部分的に存在する。
   **西縁版(南からの湿った流入)が無い**ことを確かめ、あれば強化、
   なければ設計する。地理中立(緯度・海陸配置の規則だけで書く)を守る。
2. その機構は**理想化大陸の東岸湿潤**(いま 3.1%)を自動的に改善するはず。
   地球と理想化大陸の両方で確かめれば、地理を覚えたのではない証拠になる。
3. 逆向きの誤り(B→C、モデルが湿らせすぎ)は、拡散を下げれば直る方向。
   1 の機構が入って初めて「拡散を下げても内陸が乾かない」状態になる。
   **順序が大事**: 運ぶ機構が先、拡散を下げるのが後。

## 教訓

- **「伸び悩み = 限界」と結論する前に、誤りの空間分布を見る。**
  ランダムなら限界、集中していれば構造。今回は 1 種類の誤りが 32% を占めていた。
- **外部の相場を確認せずに「悪い」「良い」を言わない。**
  嵐解像 GCM でも 2/3 なのだから、74%/44% は絶望する数字ではない。
- 診断の初版に 2 つのバグがあり、**まったく別のもの(D↔C)を測っていた**。
  `majorClassOf` の値域(0=A、1=B…)の取り違えと、観測ラスタの引き方の独自実装。
  **閾値と判定が矛盾する数字が出たら、まず対応付けを疑う**(採点と同じ引き方をする)。
